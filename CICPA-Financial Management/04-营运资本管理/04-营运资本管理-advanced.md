# 04-营运资本管理 —— 综合实战

## 一、综合题解题框架

### 营运资本管理综合题标准步骤

```
第一步：识别管理类型
  → 是现金管理？存货管理？应收账款管理？

第二步：分析当前状态
  → 计算关键指标（周转率、天数）
  → 评估当前政策

第三步：提出改进方案
  → 新政策对收益和成本的影响
  → 权衡风险与收益

第四步：综合决策
  → 选择最优策略
  → 考虑战略因素
```

## 三、陷阱与反套路

### 陷阱1：混淆"持有成本"与"交易成本"

**常见错误：** 在Baumol模型中混淆公式分子分母

**正确理解：**
```
C* = √(2×T×F/K)

分子：2×T×F（与需求量和交易成本成正比）
分母：K（与持有成本率成反比）

意义：
- 需求越大 → 最佳持有量越大（但不是线性关系）
- 交易成本越高 → 最佳持有量越大
- 持有成本越高 → 最佳持有量越小
```

### 陷阱2：Miller-Orr模型计算错误

**常见错误：** 忘记加L（下限）

**正确公式：**
```
R = ³√(3×δ²×F/4K) + L
```

注意：立方根内部是除以4K，不是除以K。

### 陷阱3：信用政策决策遗漏成本

**常见错误：** 只计算收益增加，不考虑成本

**完整决策框架：**
```
ΔNPV = Δ边际贡献 - Δ应收账款机会成本 - Δ坏账成本 - Δ管理成本

不要遗漏：
- 机会成本（最重要的隐性成本）
- 坏账成本
- 管理成本增加
```

### 陷阱4：存货计价影响EOQ

**常见错误：** 假设单位成本不变

**正确理解：**
```
EOQ假设：
- 单位采购/生产成本固定
- 需求率恒定
- 无数量折扣

若存在数量折扣：
→ 需要比较折扣节省 vs 持有成本增加
```

### 陷阱5：混淆"营运资本"与"净营运资本"

**常见错误：** 两个概念混淆使用

**正确区分：**
```
营运资本 = 流动资产（绝对数）
净营运资本 = 流动资产 - 流动负债（相对数）

投资/筹资策略中"流动资产/总资产"比率
→ 使用的是流动资产的绝对概念
```

## 四、真题变式推演

### 变式1：现金管理综合决策

**原题特征：** 单独计算Baumol或Miller-Orr模型

**变式升级：** 企业有多种短期投资选择时的最优现金持有

**训练题：** 某企业年现金需求1000万元，目前持有现金100万元。短期投资机会：
- 国债：收益率4%，每次交易成本500元
- 货币基金：收益率3%，每次交易成本200元

计算两种方案的最佳现金持有量。

**解题：**

```
方案1（国债）：
C* = √(2×1000万×500/0.04)
   = √(25000000000)
   = 158113元

方案2（货币基金）：
C* = √(2×1000万×200/0.03)
   = √(13333333333)
   = 115470元

比较：
国债：持有量大，交易次数少
货币基金：持有量小，交易灵活

选择考虑：
- 流动性需求高 → 选择货币基金（C*较小）
- 追求收益 → 选择国债（C*较大，但收益率高）
```

### 变式2：存货管理综合优化

**原题特征：** 单独EOQ计算

**变式升级：** 考虑数量折扣的存货决策

**训练题：** 某零件年需求3600件：
- 无折扣价格：10元/件
- 订货成本：200元/次
- 储存成本：单价的20%

若一次订购1200件以上，单价9.5元。

判断是否应接受折扣。

**解题：**

```
第一步：无折扣EOQ
H = 10×20% = 2元
EOQ = √(2×3600×200/2) = √720000 = 848件

第二步：无折扣总成本
TC = 采购成本 + 订货成本 + 储存成本
   = 3600×10 + (3600/848)×200 + (848/2)×2
   = 36000 + 849 + 848
   = 37697元

第三步：折扣总成本（Q=1200）
TC = 3600×9.5 + (3600/1200)×200 + (1200/2)×(9.5×20%)
   = 34200 + 600 + 1140
   = 35940元

第四步：决策
折扣节省 = 37697 - 35940 = 1757元

结论：应接受折扣（节省1757元）
```

### 变式3：营运资本策略与盈利能力分析

**原题特征：** 单独分析营运资本策略

**变式升级：** 营运资本策略对企业ROE的影响

**训练题：** 某公司经营资产800万，经营负债300万。三个策略方案：

| 方案 | 流动资产/总资产 | 流动负债/总资产 | 流动比率 |
|-----|----------------|----------------|---------|
| A | 50% | 30% | ? |
| B | 40% | 35% | ? |
| C | 60% | 25% | ? |

若净经营资产利润率15%，税后利息率8%，计算各方案ROE。

**解析：**

```
净经营资产 = 800万
净负债 = 流动负债（简化假设金融负债=流动负债）

方案A：
净负债 = 300万（或按比例计算：净负债/净经营资产 = 30%/50% = 60%）
→ 需要更详细数据，简化假设财务杠杆=0.3/0.5=0.6

方案A ROE：
净财务杠杆 = 净经营资产利润率 - 净负债成本率
           = 15% - 8% = 7%
ROE = 净经营资产利润率 - 净财务杠杆
    = 15% - 7% × (净负债/净经营资产)
    
若净负债/净经营资产 = 300/800 = 0.375
ROE = 15% - 7%×0.375 = 15% - 2.625% = 12.375%
```

### 变式4：供应链金融优化

**原题特征：** 传统营运资本管理

**变式升级：** 供应链融资（反向保理）决策

**训练题：** 某核心企业应付账款1000万，付款期60天。上游供应商希望提前收款，核心企业可选择：
- 方案A：60天后付款（无成本）
- 方案B：供应商向银行保理，核心企业承担贴现成本1.5%
- 方案C：核心企业开展供应链金融，45天付款，贴现成本1%

**解题：**

```
方案A：成本=0

方案B：
有效年利率 = 1.5% × (360/60) = 9%
供应商承担贴现成本

方案C：
有效年利率 = 1% × (360/45) = 8%
核心企业承担贴现成本

决策分析：
- 对核心企业：方案A最优（延迟付款）
- 对供应商：若能获得融资（利率<9%），方案B/C均可接受
- 供应链整体：最优方案取决于谁承担成本
```

## 五、实务衔接

### 实务场景1：电商企业营运资本管理

某电商企业运营数据：
- 年销售额：10亿
- 存货周转天数：30天
- 应收账款周转天数：15天
- 应付账款周转天数：45天

**现金周期分析：**
```
现金周期 = 存货周转天数 + 应收账款周转天数 - 应付账款周转天数
         = 30 + 15 - 45
         = 0天

现金周期为0，说明从采购到收款刚好覆盖对供应商的付款
→ 营运资本效率较高
```

**优化建议：**
```
1. 若延长应付账款至60天：
   现金周期 = 30 + 15 - 60 = -15天
   → 产生负现金周期，占用供应商资金

2. 若缩短存货至20天：
   现金周期 = 20 + 15 - 45 = -10天
   → 需要提高供应链效率

3. 风险考虑：
   负现金周期可能损害供应商关系
   需要平衡效率和关系
```

### 实务场景2：季节性企业现金管理

某服装企业季节性特征明显：
- 旺季（Q4）：销售占全年60%
- 淡季（Q2）：销售占全年15%

**现金管理模式：**
```
Q4后（12月）：大量现金回流
→ 偿还短期借款
→ 购买短期国债（流动性好，收益稳定）

Q1-Q2：淡季现金流不足
→ 出售国债补充运营资金
→ 考虑季节性信贷额度

Miller-Orr模型调整：
旺季：提高上限H
淡季：降低下限L
```

### 实务场景3：跨国企业营运资本优化

某跨国制造企业：
- 中国工厂：采购付款期30天
- 美国客户：收款期45天
- 欧元区域：收款期60天，付款期30天

**币种错配分析：**
```
欧元敞口：
- 应收账款60天 → 面临欧元贬值风险
- 应付账款30天 → 支付欧元稳定

套期保值决策：
- 若欧元波动大 → 买入远期欧元
- 若欧元趋势贬值 → 自然对冲（应收<应付）
```

## 六、速记总结

```
┌─────────────────────────────────────────┐
│        第4章营运资本管理速记            │
├─────────────────────────────────────────┤
│ 【Baumol模型】                          │
│   C* = √(2×T×F/K)                      │
├─────────────────────────────────────────┤
│ 【Miller-Orr模型】                      │
│   R = ³√(3δ²F/4K) + L                   │
│   H = 3R - 2L                           │
├─────────────────────────────────────────┤
│ 【EOQ模型】                             │
│   EOQ = √(2×D×S/H)                      │
├─────────────────────────────────────────┤
│ 【信用政策决策】                        │
│   ΔNPV = Δ贡献 - Δ机会成本 - Δ坏账     │
├─────────────────────────────────────────┤
│ 【放弃折扣成本】                        │
│   = 折扣/(1-折扣) × 360/(信用期-折扣期)│
├─────────────────────────────────────────┤
│ 【现金周期】                            │
│   = 存货天数 + 应收天数 - 应付天数     │
└─────────────────────────────────────────┘
```

**核心提示：**
- 现金管理模型是确定最佳持有量的工具
- EOQ是存货管理的核心公式
- 信用政策决策需要权衡边际收益与成本
- 放弃折扣成本反映隐含利率
- 现金周期反映营运资本效率
