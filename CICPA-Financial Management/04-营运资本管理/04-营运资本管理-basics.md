# 营运资本管理 —— 第一性原理教程

## 一、营运资本管理策略

### 1.1 投资策略

| 策略 | 特点 | 风险 | 收益 |
|------|------|------|------|
| 保守型 | 高流动资产/低流动负债 | 低 | 低 |
| 适中型 | 匹配到期 | 中 | 中 |
| 激进型 | 低流动资产/高流动负债 | 高 | 高 |

### 1.2 筹资策略
- **配合型**：短期来源满足短期需求，长期来源满足长期需求
- **激进型**：短期来源满足部分长期需求
- **保守型**：长期来源满足部分短期需求

## 二、现金管理

### 2.1 Baumol模型
```
最佳现金持有量 C* = √(2×T×F/K)

T=总需求，F=每次交易成本，K=持有成本率
```

### 2.2 Miller-Orr模型
```
回归点 R = 3√(3×δ²×F/4K) + L
上限 H = 3R - 2L
下限 L = 最低现金余额
```

---

## 三、应收账款管理

**信用政策决策：**
```
信用政策收益 = 销售增加额 × 边际贡献率
信用政策成本 = 应收账款机会成本 + 坏账成本 + 管理成本

应收账款机会成本 = 日赊销额 × 平均收账期 × 变动成本率 × 资本成本
```

---

## 四、存货管理

### 4.1 经济订货量(EOQ)
```
EOQ = √(2×D×S/H)

D=年需求，S=每次订货成本，H=单位储存成本
```

### 4.2 再订货点
```
再订货点 = 日均需求 × 交货时间 + 保险储备
```

---

## 五、短期债务管理

- 商业信用（应付账款）：放弃折扣的年成本率 = 折扣率/(1-折扣率) × 360/(信用期-折扣期)
- 短期借款：有效年利率考虑补偿性余额和承诺费
