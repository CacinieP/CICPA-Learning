## 二、财务报表分析和财务预测

### 2.1 关键财务比率

**短期偿债能力：** 流动比率=流动资产÷流动负债；速动比率=(流动资产-存货)÷流动负债

**长期偿债能力：** 资产负债率=总负债÷总资产；利息保障倍数=EBIT÷利息

**营运能力：** 存货周转率=营业成本÷平均存货；应收账款周转率=营业收入÷平均应收

**盈利能力：** ROE=净利润÷平均股东权益；ROA=净利润÷平均总资产

### 2.2 杜邦分析

```
ROE = 销售净利率 × 总资产周转率 × 权益乘数
权益乘数 = 1÷(1-资产负债率)
```

### 2.3 管理用财务报表

```
净经营资产 = 净负债 + 股东权益
净经营资产 = 经营资产 - 经营负债
净负债 = 金融负债 - 金融资产
```

### 2.4 增长率

**内含增长率（无外部融资）：**
```
= ROA × b ÷ (1 - ROA × b)    其中b=收益留存率
```

**可持续增长率（不增发新股）：**
```
= ROE × b ÷ (1 - ROE × b)
```

## 三、价值评估基础

### 3.1 利率

```
名义利率 = 无风险利率 + 通胀溢价 + 违约风险溢价 + 流动性溢价 + 期限溢价
```

### 3.2 货币时间价值

| 公式 | 计算 |
|------|------|
| 复利终值 | FV = PV × (1+r)^n |
| 复利现值 | PV = FV / (1+r)^n |
| 年金现值 | PVA = A × [1-(1+r)^(-n)] / r |
| 年金终值 | FVA = A × [(1+r)^n-1] / r |

### 3.3 风险与报酬

**CAPM模型：**
```
必要报酬率 = Rf + β × (Rm - Rf)
```

- β=1：与市场同步；β>1：比市场波动大；β<1：比市场稳定

### 3.4 债券股票估值

**债券价值：** V = Σ[C/(1+r)^t] + F/(1+r)^n

**股票价值（固定增长）：** V = D1 / (r - g)
