## 二、典型例题解析

### 2.1 杜邦分析综合题

**题目（计算分析题）：** 某公司2024年相关财务数据如下：
- 净利润：800万元
- 营业收入：5,000万元
- 平均资产总额：4,000万元
- 平均股东权益：2,000万元
- 资产负债率：50%

**要求：**
(1) 计算销售净利率、总资产周转率、权益乘数
(2) 用杜邦分析法计算ROE
(3) 若该公司计划提高ROE，指出最有效的改进方向

**解析：**

**(1) 三因子计算：**

第一步：销售净利率 = 净利润 ÷ 营业收入 = 800/5,000 = 16%

第二步：总资产周转率 = 营业收入 ÷ 平均资产总额 = 5,000/4,000 = 1.25次

第三步：权益乘数 = 1 ÷ (1 - 资产负债率) = 1 ÷ (1 - 50%) = 2

**(2) 杜邦分析：**
```
ROE = 销售净利率 × 总资产周转率 × 权益乘数
    = 16% × 1.25 × 2
    = 40%
```

**(3) 改进方向分析：**
- 销售净利率16%、总资产周转率1.25次、权益乘数2均有一定提升空间
- 最有效方向：提高销售净利率（可通过降价促销提升销量、优化成本结构实现）

**答案：**
(1) 销售净利率16%；总资产周转率1.25次；权益乘数2
(2) ROE = 40%
(3) 最有效改进方向为提高销售净利率

### 2.2 可持续增长率计算

**题目（单选题）：** 甲公司2024年相关数据：
- ROE = 20%
- 收益留存率b = 60%
- 不增发新股

在可持续增长率假设下，该公司2025年所有者权益增长率为多少？

**解析：**

可持续增长率公式（不增发新股）：
```
g = ROE × b ÷ (1 - ROE × b)
```

代入数据：
```
g = 20% × 60% ÷ (1 - 20% × 60%)
  = 12% ÷ (1 - 12%)
  = 12% ÷ 88%
  = 13.64%
```

**答案：** C（13.64%）

### 2.3 内含增长率计算

**题目（计算题）：** 乙公司2024年财务数据：
- 净利润：300万元
- 营业收入：2,000万元
- 资产总额：1,500万元
- 负债总额：800万元
- 假设公司不借款也不分配股利

求该公司的内含增长率。

**解析：**

第一步：计算ROA
```
ROA = 净利润 ÷ 平均资产 = 300/1,500 = 20%
```

第二步：确定留存率
不分配股利 → b = 100%

第三步：计算内含增长率
```
内含增长率 = ROA × b ÷ (1 - ROA × b)
            = 20% × 100% ÷ (1 - 20% × 100%)
            = 20% ÷ 80%
            = 25%
```

**答案：** 内含增长率为25%

### 2.4 货币时间价值综合题

**题目（计算分析题）：** 投资者拟购买一项资产，有两种付款方式：
- 方式A：现在一次性支付100万元
- 方式B：从第1年末开始，每年年末支付25万元，连续支付5年

假设折现率为8%，判断哪种付款方式对投资者更有利。

**解析：**

方式A现值 = 100万元

方式B现值 = 年金现值计算：
```
PVA = A × [1-(1+r)^(-n)] / r
    = 25 × [1-(1+8%)^(-5)] / 8%
    = 25 × [1-0.6806] / 8%
    = 25 × 0.3194 / 8%
    = 25 × 3.9927
    = 99.82万元
```

比较：方式B现值99.82万元 < 方式A现值100万元

**答案：** 方式B更有利，可节省约0.18万元

### 2.5 CAPM模型计算

**题目（单选题）：** 某公司股票的β系数为1.5，市场无风险利率为4%，市场组合预期收益率为12%。该公司股票的必要报酬率为多少？

**解析：**

CAPM模型：
```
必要报酬率 = Rf + β × (Rm - Rf)
           = 4% + 1.5 × (12% - 4%)
           = 4% + 1.5 × 8%
           = 4% + 12%
           = 16%
```

**答案：** D（16%）

### 2.6 管理用财务报表编制

**题目（计算分析题）：** 某公司2024年管理用资产负债表部分数据：
- 经营资产：3,000万元
- 金融资产：200万元
- 经营负债：1,000万元
- 金融负债：800万元
- 股东权益：1,400万元

**要求：** 验证净经营资产 = 净负债 + 股东权益

**解析：**

净经营资产 = 经营资产 - 经营负债 = 3,000 - 1,000 = 2,000万元

净负债 = 金融负债 - 金融资产 = 800 - 200 = 600万元

验证：净负债 + 股东权益 = 600 + 1,400 = 2,000万元 = 净经营资产 ✓

**答案：** 等式成立，净经营资产2,000万元

## 三、分录/计算模板

### 模板1：杜邦分析标准化计算

```
第一步：计算三因子
  销售净利率 = 净利润 / 营业收入
  总资产周转率 = 营业收入 / 平均资产总额
  权益乘数 = 1 / (1 - 资产负债率)

第二步：杜邦恒等式
  ROE = 销售净利率 × 总资产周转率 × 权益乘数
```

### 模板2：增长率计算

```
内含增长率（无外部融资）：
  g = ROA × b / (1 - ROA × b)

可持续增长率（不增发新股）：
  g = ROE × b / (1 - ROE × b)
  
其中：b = 收益留存率 = 1 - 股利支付率
```

### 模板3：CAPM模型

```
必要报酬率 = Rf + β × (Rm - Rf)

Rf：无风险利率（通常用国债收益率）
Rm-Rf：市场风险溢价
β：系统性风险系数
```

### 模板4：管理用财务报表关系

```
净经营资产 = 经营资产 - 经营负债
净负债 = 金融负债 - 金融资产
净经营资产 = 净负债 + 股东权益
```

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|-------|------|---------|
| 内含增长率 vs 可持续增长率 | 内含增长假设不借款；可持续增长假设不增发股票 | "内涵"不借钱，"可持续"不增股 |
| ROA vs ROE | ROA用总资产，ROE用股东权益 | "O"像资产圈大，"E"像权益窄 |
| 权益乘数 vs 资产负债率 | 权益乘数 = 1/(1-资产负债率) | 杠杆的倒数关系 |
| 净负债 vs 净金融负债 | 净负债 = 金融负债 - 金融资产 | 正数才是真正的负债 |

## 五、速记口诀

**杜邦分析三因子：**
> 净利周转与杠杆，三者相乘是ROE

**可持续增长公式：**
> 可持续，增 ROE，留存 b，不增股

**CAPM模型：**
> 无风险 加 贝塔 乘 溢价

**管理用报表：**
> 经营资产减经营负债，等于净负债加权益
