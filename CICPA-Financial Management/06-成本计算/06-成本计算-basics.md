# 成本计算 —— 第一性原理教程

## 一、产品成本计算

### 1.1 成本归集和分配

**直接成本**：直接计入产品（直接材料、直接人工）

**间接成本（制造费用）**：需分配计入
```
分配率 = 制造费用总额 ÷ 分配标准合计
某产品应分配 = 该产品分配标准 × 分配率
```

### 1.2 品种法
- **适用**：大量大批单步骤生产
- **特点**：以产品品种为成本计算对象
- **举例**：发电、供水

### 1.3 分批法
- **适用**：单件小批生产
- **特点**：以产品批别为成本计算对象
- **举例**：造船、专用设备

### 1.4 分步法
- **适用**：大量大批多步骤生产
- **特点**：以生产步骤为成本计算对象

**逐步结转分步法：**
- 上步骤半成品成本随实物转移至下步骤
- 可分为综合结转和分项结转
- 综合结转需要**成本还原**

**平行结转分步法：**
- 各步骤只计算本步骤应计入最终产成品的份额
- 半成品成本不随实物转移
- 不需要成本还原

## 二、标准成本法

### 2.1 标准成本的制定

| 成本项目 | 标准成本 = |
|----------|-----------|
| 直接材料 | 标准用量 × 标准单价 |
| 直接人工 | 标准工时 × 标准工资率 |
| 变动制造费用 | 标准工时 × 标准分配率 |

### 2.2 差异分析

**变动成本差异（2×2分析）：**

| 项目 | 价格差异 | 数量差异 |
|------|----------|----------|
| 直接材料 | (实际价格-标准价格)×实际数量 | (实际数量-标准数量)×标准价格 |
| 直接人工 | (实际工资率-标准工资率)×实际工时 | (实际工时-标准工时)×标准工资率 |
| 变动制造费用 | (实际分配率-标准分配率)×实际工时 | (实际工时-标准工时)×标准分配率 |

**固定制造费用差异（三差异法）：**
```
总差异 = 实际固定费用 - 标准工时×标准分配率

= 耗费差异 + 闲置能量差异 + 效率差异

耗费差异 = 实际费用 - 预算费用
闲置能量差异 = (预算工时-实际工时)×标准分配率
效率差异 = (实际工时-标准工时)×标准分配率
```

## 三、作业成本法和生命周期成本法

### 3.1 作业成本法(ABC)

**核心思想：** "作业消耗资源，产品消耗作业"

**步骤：**
1. 识别作业和资源
2. 将资源费用归集到各作业（资源动因）
3. 将作业成本分配到产品（作业动因）

**优点：** 更精确的成本分配，特别是间接费用占比较大的企业。

### 3.2 生命周期成本法

**考虑产品从研发到退出市场的全部成本：**
```
生命周期成本 = 研发成本 + 生产成本 + 营销成本 + 客户服务成本 + 废弃处置成本
```

**意义：** 避免只关注制造成本而忽视研发和售后成本。

## 考试要点

1. **三种成本计算方法**：品种法/分批法/分步法
2. **分步法**：逐步结转（需还原）vs 平行结转（不需还原）
3. **差异分析**：2×2变动成本差异 + 三差异法固定制造费用
4. **ABC**：作业消耗资源、产品消耗作业
5. **生命周期成本**：涵盖研发到废弃的全过程
