## 二、典型例题解析

### 2.1 NPV计算题

**题目：** 某公司拟投资一项目，相关资料如下：
- 初始投资：500万元
- 预计使用年限：4年
- 直线折旧，无残值
- 营业收入：第1年200万，第2年250万，第3年300万，第4年150万
- 营业成本（含折旧）：第1年120万，第2年150万，第3年180万，第4年100万
- 所得税税率25%
- 资本成本10%

**要求：** 计算该项目的NPV并判断是否可行。

**解析：**

**第一步：计算折旧**
```
年折旧 = 500/4 = 125万元
```

**第二步：计算各年营业现金流量**

| 年份 | 收入 | 成本（含折旧） | 折旧 | 税前利润 | 所得税 | 净利润 | 营业CF |
|-----|------|--------------|------|---------|--------|--------|--------|
| 1 | 200 | 120 | 125 | -45 | 0 | -45 | 80 |
| 2 | 250 | 150 | 125 | -25 | 0 | -25 | 100 |
| 3 | 300 | 180 | 125 | -5 | 0 | -5 | 120 |
| 4 | 150 | 100 | 125 | -75 | 0 | -75 | 50 |

说明：第1-4年税前利润均为负，无需交税，亏损可抵扣。

**第三步：计算NPV**

简化公式：营业CF = 收入 - 成本（不含折旧）- 所得税 + 折旧
= (收入 - 付现成本) × (1-T) + 折旧 × T = 净利润 + 折旧

第1年：营业CF = (200-120+125)无税... 用公式：CF = (收入-成本)(1-T) + 折旧×T
= (200-120-125)(1-25%) + 125×25% = (-45)×0.75 + 31.25 = -33.75 + 31.25 = -2.5... 

重新计算（更清晰的思路）：
```
净利润 = (收入 - 付现成本 - 折旧) × (1 - T)
营业CF = 净利润 + 折旧 = (收入 - 付现成本 - 折旧) × (1-T) + 折旧
       = (收入 - 付现成本) × (1-T) + 折旧 × T
```

第1年：
- 付现成本 = 120 - 125 = -5万元（实际是负的，说明毛利200-120=80，不含折旧的成本为负？）

**重新理解题目：**
营业收入 - 营业成本 = 200 - 120 = 80万元（这是不含折旧的收入）
折旧 = 125万元
EBIT = 80 - 125 = -45万元
税前利润 = -45万元，所得税 = 0
净利润 = -45万元
营业CF = -45 + 125 = 80万元

第1年营业CF = 80万
第2年：收入250万，成本150万，折旧125万 → EBIT = 250-150-125 = -25万 → CF = -25+125 = 100万
第3年：收入300万，成本180万，折旧125万 → EBIT = 300-180-125 = -5万 → CF = -5+125 = 120万
第4年：收入150万，成本100万，折旧125万 → EBIT = 150-100-125 = -75万 → CF = -75+125 = 50万

**第四步：计算NPV**

```
NPV = -500 + 80/(1.1)^1 + 100/(1.1)^2 + 120/(1.1)^3 + 50/(1.1)^4
    = -500 + 72.73 + 82.64 + 90.16 + 34.15
    = -500 + 279.68
    = -220.32万元
```

**答案：** NPV = -220.32万元 < 0，项目不可行。

### 2.2 IRR计算题

**题目：** 某投资项目现金流量如下：
- 第0年：-1000万元
- 第1-5年：每年300万元

**要求：** 计算该项目的IRR。

**解析：**

IRR是使NPV=0的折现率。

年金现值公式：
```
NPV = -1000 + 300 × (P/A, IRR, 5) = 0
(P/A, IRR, 5) = 1000/300 = 3.333
```

查年金系数表：
- (P/A, 10%, 5) = 3.791
- (P/A, 15%, 5) = 3.352
- (P/A, 16%, 5) = 3.274

插值法：
```
IRR = 15% + (3.352-3.333)/(3.352-3.274) × 1%
    = 15% + 0.019/0.078 × 1%
    = 15% + 0.24%
    = 15.24%
```

**答案：** IRR ≈ 15.24%

### 2.3 WACC计算题

**题目：** 某公司目标资本结构为：负债40%，股权60%。有关信息：
- 税前债务成本：8%
- 公司β系数：1.2
- 市场无风险利率：4%
- 市场组合预期收益率：12%
- 所得税税率：25%

**要求：** 计算WACC。

**解析：**

**第一步：计算权益成本（CAPM模型）**
```
Ke = Rf + β(Rm - Rf)
   = 4% + 1.2 × (12% - 4%)
   = 4% + 1.2 × 8%
   = 4% + 9.6%
   = 13.6%
```

**第二步：计算税后债务成本**
```
Kd(after-tax) = 8% × (1 - 25%) = 6%
```

**第三步：计算WACC**
```
WACC = 负债比重 × 税后债务成本 + 股权比重 × 权益成本
     = 40% × 6% + 60% × 13.6%
     = 2.4% + 8.16%
     = 10.56%
```

**答案：** WACC = 10.56%

### 2.4 营业现金流量计算题

**题目：** 某公司投资新设备，相关数据：
- 设备购置成本：800万元
- 预计寿命：5年
- 直线折旧，无残值
- 每年增加营业收入：500万元
- 每年增加付现成本：300万元（不含折旧）
- 所得税税率：25%
- 资本成本：10%

**要求：** 计算该项目的年营业现金流量。

**解析：**

**方法一：直接计算**
```
折旧 = 800/5 = 160万元

年营业CF = (收入 - 付现成本 - 折旧) × (1-T) + 折旧
         = (500 - 300 - 160) × (1-25%) + 160
         = 40 × 0.75 + 160
         = 30 + 160
         = 190万元
```

**方法二：简化公式**
```
营业CF = (收入 - 付现成本) × (1-T) + 折旧 × T
       = (500 - 300) × (1-25%) + 160 × 25%
       = 200 × 0.75 + 40
       = 150 + 40
       = 190万元
```

**方法三：净利润加折旧**
```
EBIT = 500 - 300 - 160 = 40万元
所得税 = 40 × 25% = 10万元
净利润 = 30万元
营业CF = 净利润 + 折旧 = 30 + 160 = 190万元
```

**答案：** 年营业现金流量 = 190万元

### 2.5 回收期法与折现回收期法

**题目：** 某项目初始投资200万，现金流：
- 第1年：80万
- 第2年：70万
- 第3年：60万
- 第4年：50万
- 第5年：40万

资本成本10%，求静态回收期和折现回收期。

**解析：**

**静态回收期：**
```
累计现金流入：
第1年：80万
第2年：80+70=150万
第3年：150+60=210万

回收期 = 2 + (200-150)/(210-150) = 2 + 50/60 = 2.83年
```

**折现回收期：**
```
第1年折现：80/1.1 = 72.73
第2年折现：70/1.1² = 57.85，累计130.58
第3年折现：60/1.1³ = 45.07，累计175.65
第4年折现：50/1.1⁴ = 34.15，累计209.80

折现回收期 = 3 + (200-175.65)/(209.80-175.65) = 3 + 24.35/34.15 = 3.71年
```

**答案：** 静态回收期2.83年；折现回收期3.71年

### 2.6 敏感分析

**题目：** 某项目NPV为50万元，敏感分析数据：
- 当销售量下降10%时，NPV变为20万元
- 当折现率上升1%时，NPV变为30万元

**要求：** 计算各因素的敏感系数。

**解析：**

```
销售量敏感系数 = NPV变动% / 销售量变动%
               = (20-50)/50 / (-10%)
               = -60% / -10%
               = 6

折现率敏感系数 = NPV变动% / 折现率变动%
               = (30-50)/50 / 1%
               = -40% / 1%
               = -40
```

**答案：** 销售量敏感系数6；折现率敏感系数-40（折现率更敏感）

### 2.7 实物期权 - 延迟期权

**题目：** 某矿业项目：
- 开发成本：5000万
- 项目价值（立即开发）：4000万
- 1年后的项目价值：若铜价上涨则6000万（60%概率），若铜价下跌则3000万（40%概率）
- 无风险利率：5%

**要求：** 判断是否应延迟一年开发。

**解析：**

**立即开发NPV：**
```
NPV(立即) = 4000 - 5000 = -1000万元（不可行）
```

**延迟开发的期权价值：**

第1年期望价值：
```
E(V) = 6000 × 60% + 3000 × 40% = 3600 + 1200 = 4800万元
```

折现到现值：
```
PV = 4800 / 1.05 = 4571.43万元
```

延迟开发净现值：
```
NPV(延迟) = 4571.43 - 5000 = -428.57万元
```

但延迟避免了立即亏损，且有上涨可能。

**答案：** 延迟开发更优，减少亏损571.43万元

## 三、计算模板

### 模板1：NPV标准计算步骤

```
第一步：计算年折旧额
  折旧 = 初始投资/使用年限

第二步：计算各年营业现金流量
  营业CF = (收入 - 付现成本 - 折旧) × (1-T) + 折旧
         = 净利润 + 折旧
         = (收入 - 付现成本) × (1-T) + 折旧 × T

第三步：计算NPV
  NPV = -初始投资 + Σ[营业CFt/(1+r)^t]
```

### 模板2：IRR计算步骤

```
第一步：计算年金系数 (P/A, r, n) = 初始投资/年营业CF

第二步：查表或插值
  若：(P/A, r1, n) > 目标值 > (P/A, r2, n)
  则：IRR = r1 + (目标值-(P/A, r1))/[ (P/A, r1)-(P/A, r2) ] × (r2-r1)
```

### 模板3：WACC计算

```
WACC = Wd × Kd(1-T) + We × Ke

其中：
- Wd = 债务市场价值/总价值
- We = 股权市场价值/总价值
- Ke = Rf + β(Rm-Rf)  (CAPM模型)

注意：使用目标市场价值权重
```

### 模板4：回收期计算

```
静态回收期 = 累计现金流入首次覆盖投资的时间点

折现回收期 = 累计折现现金流入首次覆盖投资的时间点
```

### 模板5：敏感分析

```
敏感系数 = 目标值变动% / 参数值变动%

绝对值越大，该因素越敏感
```

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|-------|------|---------|
| NPV > 0 vs IRR > WACC | NPV是绝对值，IRR是相对指标，资本成本决定IRR基准 | "有钱看NPV，有率看IRR" |
| 营业CF vs 现金流量 | 营业CF不含初始投资和终结现金流量 | "营业"只看经营成果 |
| 静态回收期 vs 折现回收期 | 静态不考虑时间价值，折现考虑 | "折现"更保守 |
| 敏感分析 vs 情景分析 | 敏感分析单因素变化；情景分析多因素组合 | "敏感"是单挑，"情景"是组合 |

## 五、速记口诀

**营业CF计算：**
> 收入减付现，减折算所得税，加回折旧是净现

**NPV判断：**
> NPV为正我可行，IRR高于WACC行

**WACC组成：**
> 债务权重乘税后，股权权重乘权益

**实物期权三种：**
> 扩张期权等扩张，延迟期权等消息，放弃期权保残值
