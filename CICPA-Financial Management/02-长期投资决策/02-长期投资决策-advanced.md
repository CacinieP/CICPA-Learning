# 02-长期投资决策 —— 综合实战

## 一、综合题解题框架

### 资本预算综合题标准步骤

```
第一步：识别项目类型
  → 是独立项目？互斥项目？还是有期权的复杂项目？

第二步：提取已知数据
  → 列出初始投资、营业现金流、终结现金流、资本成本

第三步：计算营业现金流量（核心！）
  → 折旧 = 初始投资/年限
  → 营业CF = (收入-付现成本)(1-T) + 折旧×T

第四步：计算评价指标
  → NPV、IRR、回收期、PI等

第五步：决策判断
  → NPV>0/IRR>WACC → 接受
  → 比较多个项目时：NPV最大优先（股东财富最大化）
```

## 三、陷阱与反套路

### 陷阱1：混淆"利润"与"现金流量"

**常见错误：** 直接用"收入-成本"计算营业现金流

**正确思路：**
```
营业CF = 净利润 + 折旧
       = (收入 - 付现成本 - 折旧) × (1-T) + 折旧
       = (收入 - 付现成本) × (1-T) + 折旧 × T
```

**反套路训练：**
```markdown
题目条件：收入100万，付现成本60万，折旧20万，税率25%
错误答案：CF = 100-60 = 40万
正确答案：CF = (100-60-20)×(1-25%)+20 = 35万
```

### 陷阱2：IRR多解问题

**常见错误：** 不考虑非常规项目的IRR多解

**正确识别：**
- 常规项目（只有初始为负，后续均为正）→ 唯一IRR
- 非常规项目（现金流多次变号）→ 可能多个IRR

**反套路训练：**
```markdown
项目A：-100, +150, -80
此项目有两个IRR（需解二次方程）

项目B：-100, +150, +50
此项目有一个IRR
```

### 陷阱3：使用账面权重而非市场价值权重

**常见错误：** 计算WACC时使用账面价值权重

**正确方法：**
```
目标资本结构权重 = 市场价值/总价值

债务市场价值 ≈ 账面价值（平价发行时）
股权市场价值 = 股价 × 流通股数
```

### 陷阱4：忽略残值回收的税务影响

**常见错误：** 终结现金流量直接加残值

**正确计算：**
```
终结CF = 残值 + 收回营运资本 - 所得税影响

若残值 > 账面价值：需交税
终结CF = 残值 - (残值-账面价值)×T

若残值 < 账面价值：形成税务亏损，可抵税
终结CF = 残值 + (账面价值-残值)×T
```

### 陷阱5：敏感分析与情景分析混淆

**常见错误：** 敏感分析中同时变动多个因素

**正确理解：**
- 敏感分析：其他因素不变，单一因素变动
- 情景分析：多个因素按特定情景组合变动

## 四、真题变式推演

### 变式1：互斥项目决策

**原题特征：** 单一项目NPV/IRR计算

**变式升级：** 两个互斥项目比较（寿命不同或投资额不同）

**训练题：** 
- 项目A：投资200万，寿命3年，每年CF 100万
- 项目B：投资300万，寿命6年，每年CF 80万
- 资本成本10%

**解题：**

```
项目A NPV：
= -200 + 100×(P/A,10%,3)
= -200 + 100×2.487
= 48.7万

项目B NPV：
= -300 + 80×(P/A,10%,6)
= -300 + 80×4.355
= 48.4万

按NPV决策：选A（NPV略高）

按等额年值决策：
项目A等额年值 = 48.7/2.487 = 19.58万
项目B等额年值 = 48.4/4.355 = 11.12万

按等额年值决策：选A
```

### 变式2：包含营运资本的投资项目

**原题特征：** 单纯固定资产投资

**变式升级：** 考虑营运资本变动

**训练题：** 某项目投资100万，每年CF 40万，寿命3年。同时需要追加营运资本20万（第0年投入，第3年收回），资本成本10%，计算NPV。

**解题：**

```
初始投资 = 100 + 20 = 120万

NPV = -120 + 40/(1.1) + 40/(1.1)² + (40+20)/(1.1)³
    = -120 + 36.36 + 33.06 + 45.07
    = -5.51万

结论：项目不可行
```

### 变式3：资本限量决策

**原题特征：** 不受资金限制的项目选择

**变式升级：** 资本限量下的最优组合

**训练题：** 资本限量500万，有以下项目：

| 项目 | 初始投资 | NPV | PI |
|-----|---------|-----|-----|
| A | 200万 | 60万 | 1.3 |
| B | 300万 | 90万 | 1.3 |
| C | 150万 | 30万 | 1.2 |
| D | 250万 | 40万 | 1.16 |

**解题：**

```
组合1：A+D = 450万，NPV=100万，PI=100/450=0.22
组合2：B+C = 450万，NPV=120万，PI=120/450=0.27 ← 最优
组合3：A = 200万，NPV=60万

最优选择：组合2（B+C），总NPV=120万
```

### 变式4：扩张期权评估

**原题特征：** 单一项目评价

**变式升级：** 考虑未来扩张选择权的项目价值

**训练题：** 某项目NPV=100万。同时，第2年末可以100万追加投资，预期产生额外NPV=80万（折现到第2年末）。无风险利率5%，计算包含扩张期权的项目价值。

**解题：**

```
扩张期权价值 = 80/(1.05)² = 72.56万

总项目价值 = 项目NPV + 扩张期权价值
           = 100 + 72.56
           = 172.56万
```

## 五、实务衔接

### 实务场景1：企业并购决策

某公司计划收购目标公司：
- 收购价格：5000万
- 目标公司年自由现金流：600万
- 永续增长率：3%
- WACC：10%

**估值分析：**
```
企业价值 = FCF/(WACC-g) = 600/(10%-3%) = 8571万

NPV = 企业价值 - 收购价格 = 8571 - 5000 = 3571万

结论：收购可行，创造3571万价值
```

### 实务场景2：研发投资决策

某企业研发项目：
- 研发投入：2000万（当年费用化）
- 成功后年收入增加：800万（持续5年）
- 成功率：60%
- 资本成本：12%

**决策分析：**
```
期望NPV = 0.6 × 成功时的NPV + 0.4 × 失败时的NPV

成功时NPV = -2000 + 800×(P/A,12%,5)
           = -2000 + 800×3.605
           = 884万

失败时NPV = -2000万（无额外收益）

期望NPV = 0.6×884 + 0.4×(-2000)
        = 530.4 - 800
        = -269.6万

结论：从纯财务角度，研发投资可能不经济
      但需考虑战略价值和溢出效应
```

### 实务场景3：项目敏感性管理

某制造企业进行项目敏感性分析：
- 基准NPV：500万
- 关键变量：原材料价格、产销量、价格

**敏感性分析结果：**

| 变量 | -10%变动 | +10%变动 |
|------|---------|---------|
| 原材料价格 | +200万 | -200万 |
| 产销量 | -150万 | +150万 |
| 产品价格 | -180万 | +180万 |

**管理建议：**
```
1. 原材料价格是最敏感因素
   → 建立战略供应商关系，锁定价格
   → 考虑期货套期保值

2. 产品价格敏感性次之
   → 差异化竞争策略
   → 减少对价格战的依赖

3. 产销量是关键
   → 加强市场营销
   → 建立客户粘性
```
