# 成本管理会计基础 —— 第一性原理教程

## 一、成本概念与分类

### 1.1 成本的基本分类

| 分类标准 | 类别 |
|----------|------|
| 按经济用途 | 生产成本（直接材料+直接人工+制造费用）、期间费用 |
| 按性态 | 变动成本、固定成本、混合成本 |
| 按可追溯性 | 直接成本、间接成本 |

### 1.2 变动成本与固定成本

| 类型 | 特点 | 举例 |
|------|------|------|
| 变动成本 | 总额随产量正比变动，单位额不变 | 直接材料 |
| 固定成本 | 总额不随产量变动，单位额反比变动 | 折旧、管理人员工资 |

### 1.3 混合成本分解

- **高低点法**：Y = a + bX，取最高点和最低点数据求解
- **回归直线法**：用最小二乘法拟合

## 二、管理决策与成本管理会计

### 2.1 相关成本与无关成本

| 相关成本 | 无关成本 |
|----------|----------|
| 机会成本 | 沉没成本 |
| 边际成本 | 共同成本 |
| 差量成本 | 不可递延成本 |
| 可避免成本 | 不可避免成本 |

**决策原则：** 只考虑相关成本（未来发生的、各方案不同的成本）。

### 2.2 成本管理会计的作用

- 为经营决策提供信息
- 为计划和控制提供信息
- 为业绩评价提供信息

## 三、环境变化对成本管理会计的影响

### 3.1 ESG因素

- 环境成本纳入管理决策（碳排放成本、环境治理成本）
- 社会责任成本考量

### 3.2 数字化转型

- 实时成本数据获取
- 自动化成本核算
- 大数据分析支持决策

### 3.3 全球竞争

- 全球供应链成本管理
- 跨国成本比较和优化

## 考试要点

1. **成本性态分类**：变动/固定/混合
2. **相关成本**：决策只看未来可变的成本
3. **高低点法**分解混合成本
4. **ESG与数字化**对成本管理的新要求
