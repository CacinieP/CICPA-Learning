## 一、综合题解题框架

### 成本决策综合题标准步骤

```
第一步：识别决策类型
  → 自制或外购？特殊订单？约束资源？继续或关闭？

第二步：识别相关成本
  → 未来成本 ✓
  → 方案间差异 ✓
  → 沉没成本 ✗
  → 不可避免成本 ✗

第三步：计算相关成本
  → 变动成本 + 机会成本 + 专属成本

第四步：比较分析
  → 收入 vs 相关成本
  → 或：A方案相关成本 vs B方案相关成本

第五步：决策与敏感性
  → 接受 vs 拒绝
  → 若关键参数变化，结论是否改变
```

## 三、陷阱与反套路

### 陷阱1：混淆"沉没成本"与"机会成本"

**常见错误：** 把沉没成本当作相关成本

**正确理解：**
```
沉没成本 = 已发生、无法改变的历史成本
机会成本 = 选择本方案而放弃的最大收益

举例：3年前花10万买的设备，现在价值2万

沉没成本：10万（已是过去）
当前机会成本：2万（若用于本项目，则失去出售可得2万）
```

**反套路训练：**
```markdown
题目：设备账面价值100万，已提折旧80万，可变现30万
分析：
- 沉没成本 = 100万（历史投入）
- 相关成本 = 30万（机会成本）
- 账面价值80万（已提折旧）→ 无关成本
```

### 陷阱2：忽视"不可避免成本"

**常见错误：** 把已发生的固定成本计入相关成本

**正确识别：**
```
不可避免成本 = 无论选哪个方案都要发生的成本

常见情况：
- 厂房租金（已签合同）
- 管理人员工资（必须支付）
- 折旧（直线法计提）

这些成本不因决策而改变，属于无关成本
```

### 陷阱3：混淆"专属成本"与"共同成本"

**常见错误：** 将共同成本计入单个方案

**正确区分：**
```
专属成本 = 专门为某方案发生的成本
共同成本 = 多个方案共同分摊的成本

例：购买专用设备 → 专属成本（只用于本项目）
     工厂租金 → 共同成本（无论做什么都要付）
```

### 陷阱4：约束资源决策中的单位边际贡献陷阱

**常见错误：** 直接按单位边际贡献排序

**正确方法：**
```
约束资源决策必须计算"单位约束资源边际贡献"

不是：按边际贡献排序
而是：按"边际贡献/单位约束资源"排序

例：
- A产品：边际贡献40元，占用2小时 → 20元/小时
- B产品：边际贡献30元，占用1小时 → 30元/小时

虽然A边际贡献更高，但B效率更高，应优先B
```

### 陷阱5：高低点法与回归直线法选择

**常见错误：** 不知道何时用哪种方法

**选择原则：**
```
高低点法：
- 优点：简单快速
- 缺点：只考虑两个极端点，可能失真
- 适用：初步分析、简单情况

回归直线法：
- 优点：利用所有数据，结果更准确
- 缺点：计算复杂
- 适用：精确分析、样本量较大时
```

## 四、真题变式推演

### 变式1：多方案综合决策

**原题特征：** 两个方案比较

**变式升级：** 多个自制方案比较

**训练题：** 某零件可以三种方式生产：
- 方式A：外购，单价15元
- 方式B：自制，变动成本10元，需增加设备（年折现成本8万）
- 方式C：自制，变动成本8元，需增加设备（年折现成本15万）

年需求5000件，企业资本成本10%，设备寿命5年。

**解题：**

```
方式A总成本：
TC_A = 5000 × 15 = 75,000元

方式B：
设备现值年金因子(P/A,10%,5) = 3.791
设备年成本 = 8万 / 3.791 = 21,097元
TC_B = 5000 × 10 + 21,097 = 71,097元

方式C：
(P/A,10%,5) = 3.791
设备年成本 = 15万 / 3.791 = 39,567元
TC_C = 5000 × 8 + 39,567 = 79,567元

最优：方式B（总成本最低）
```

### 变式2：继续或关闭决策

**原题特征：** 单一产品决策

**变式升级：** 多产品组合决策

**训练题：** 某分部A、B两种产品，关闭A后：
- B产品可增产增加边际贡献10万
- 节省A专属成本5万
- 仍需承担A分摊的共同成本3万

是否应关闭A？

**解析：**

```
关闭A相关成本：
- A专属成本5万（可避免）→ 相关成本
- A分摊共同成本3万（不可避免）→ 无关成本
- B增产边际贡献10万（机会成本）→ 相关成本

关闭A总相关成本 = 5 + 10 = 15万

若A当前亏损 < 15万 → 关闭
若A当前亏损 > 15万 → 不关闭
```

### 变式3：约束资源与产能扩张

**原题特征：** 固定约束资源下的生产决策

**变式升级：** 考虑扩张约束资源的投资决策

**训练题：** 承接前例，若购买额外机器工时，每小时需支付200元。
- 产品A：边际贡献40元，2小时
- 产品B：边际贡献30元，1小时

当前产能100小时，问是否应扩张？

**解析：**

```
当前最优：全产B，获利 = 100 × 30 = 3,000元

扩张10小时：
总工时110小时，全部产B
获利 = 110 × 30 = 3,300元
额外成本 = 10 × 200 = 2,000元
净增收益 = 3,300 - 3,000 - 2,000 = -1,700元

结论：不应扩张（成本>收益）
```

### 变式4：ESG成本融入决策

**原题特征：** 传统成本决策

**变式升级：** 考虑ESG因素的成本决策

**训练题：** 某企业面临两个供应商选择：

| 供应商 | 价格 | ESG评级 | 碳排放成本 |
|-------|-----|--------|-----------|
| A | 100元/件 | B级 | 需支付碳税10元/件 |
| B | 110元/件 | A级 | 碳排放为0，但获碳信用5元/件 |

年需求10000件，碳价20元/吨，供应商B碳排放比A少0.5吨/件。

**解题：**

```
供应商A总成本：
采购成本 = 100 × 10000 = 1,000,000元
碳税成本 = 10 × 10000 = 100,000元
总成本 = 1,100,000元

供应商B总成本：
采购成本 = 110 × 10000 = 1,100,000元
碳信用收益 = -5 × 10000 = -50,000元
总成本 = 1,050,000元

结论：选择B（节省50,000元）
```

## 五、实务衔接

### 实务场景1：产能扩张决策

某制造企业考虑产能扩张：
- 当前产能：10万件/年
- 当前销量：9万件/年（单价100元，单位变动成本60元）
- 扩张成本：500万（5年摊销，资本成本8%）
- 扩张后产能：15万件/年
- 扩张后预计销量：12万件/年

**决策分析：**
```
当前利润 = (100-60) × 9万 - 固定成本 = 40×9 = 360万

扩张后：
新增销量 = 3万件
新增边际贡献 = 3 × 40 = 120万
设备年摊销 = 500/5 = 100万
新增利润 = 120 - 100 = 20万

结论：扩张可增加利润20万/年，值得实施
```

### 实务场景2：产品线决策

某服装企业产品线分析：
- 产品A：T恤，售价100元，变动成本60元，销量5万件
- 产品B：裤子，售价200元，变动成本120元，销量3万件
- 共同固定成本：200万

**亏损产品分析：**
```
T恤利润：5×(100-60) - 100 = 5×40 - 100 = 100万
裤子利润：3×(200-120) - 100 = 3×80 - 100 = 140万

若关闭T恤：
裤子仍需承担200万固定成本 → 利润 = 140万

若关闭裤子：
T恤仍需承担200万固定成本 → 利润 = 100万

最优：保留两个产品线（合计利润240万）
```

### 实务场景3：成本管理数字化转型

某企业引入智能成本系统：
- 投资：200万
- 年维护成本：20万
- 效益：
  - 减少人工成本：50万/年
  - 减少材料浪费：30万/年
  - 提高决策质量（难以量化）

**投资决策：**
```
年净效益 = 50 + 30 - 20 = 60万
回收期 = 200/60 = 3.33年

考虑资本成本8%：
NPV = -200 + 60×(P/A,8%,5) = -200 + 60×3.993 = -200 + 239.6 = 39.6万

结论：值得投资（NPV=39.6万>0）
```
