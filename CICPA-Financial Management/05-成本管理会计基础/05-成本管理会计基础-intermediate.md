## 二、典型例题解析

### 2.1 成本性态分类

**题目：** 分析下列成本项目属于变动成本还是固定成本：

1. 生产工人计件工资
2. 机器设备折旧（直线法）
3. 管理人员工资
4. 按产量计提的工艺装备费
5. 财产保险费

**解析：**

| 成本项目 | 类别 | 说明 |
|---------|------|------|
| 生产工人计件工资 | 变动成本 | 总额与产量正比变动，单位额不变 |
| 机器设备折旧（直线法） | 固定成本 | 总额不随产量变动（产量为0也计提折旧） |
| 管理人员工资 | 固定成本 | 通常不随产量变动 |
| 按产量计提的工艺装备费 | 变动成本 | 产量增加则总额增加 |
| 财产保险费 | 固定成本 | 通常按年或月固定缴纳 |

**答案：** 1.变动 2.固定 3.固定 4.变动 5.固定

### 2.2 高低点法分解混合成本

**题目：** 某公司维修成本的历史数据如下：

| 月份 | 机器工时 | 维修成本 |
|-----|---------|---------|
| 3月 | 600 | 3000 |
| 4月 | 800 | 3600 |
| 5月 | 900 | 4200 |
| 6月 | 1000 | 4800 |
| 7月 | 500 | 2400 |

**要求：** 用高低点法分解混合成本。

**解析：**

**第一步：识别高低点**
```
高点：7月，工时1000小时，成本4800元
低点：5月（实际找最低点）→ 7月500小时，2400元才是低点

重新确认：
高点：7月，工时1000，成本4800
低点：7月前... 实际最低是？5月900小时是最低？还是...

再次检查：
- 最低工时应该是7月的500小时，但成本是2400
- 最高工时是7月？不对...

应该是：
高点：7月（工时1000，成本4800）
低点：5月...不对，让我重新看

实际上是：
最高点：7月，工时1000，成本4800
最低点：7月...抱歉，最低工时应该是500小时（7月前）
我重新看题目：
5月900小时，6月1000小时，7月500小时

所以：
高点：6月或7月，工时1000，成本4800
低点：7月前...应该是500工时对应2400成本的点

实际上题目给出的数据点：
- 3月：600/3000
- 4月：800/3600
- 5月：900/4200
- 6月：1000/4800
- 7月：500/2400

高低点：
高点：6月，1000/4800
低点：7月，500/2400
```

**第二步：计算单位变动成本**
```
b = Δ成本/Δ工时 = (4800-2400)/(1000-500) = 2400/500 = 4.8元/小时
```

**第三步：计算固定成本**
```
代入高点：4800 = a + 4.8×1000
a = 4800 - 4800 = 0

代入低点：2400 = a + 4.8×500
a = 2400 - 2400 = 0

混合成本公式：Y = 0 + 4.8X

结论：实际全是变动成本，没有固定成本
```

**验证其他点：**
```
3月：4.8×600 = 2880 ≈ 3000（误差120）
4月：4.8×800 = 3840 ≈ 3600（误差240）
5月：4.8×900 = 4320 ≈ 4200（误差120）

高低点法是最粗略的方法，仅用两个极端点
```

**答案：** 混合成本Y = 0 + 4.8X（元/小时）

### 2.3 回归直线法计算

**题目：** 承接上题，用回归直线法分解。

**解析：**

**建立回归方程：Y = a + bX**

需要计算：
```
n = 5

ΣX = 600+800+900+1000+500 = 3800
ΣY = 3000+3600+4200+4800+2400 = 18000
ΣXY = 600×3000+800×3600+900×4200+1000×4800+500×2400
    = 1800000+2880000+3780000+4800000+1200000 = 14460000
ΣX² = 600²+800²+900²+1000²+500² = 360000+640000+810000+1000000+250000 = 3060000
```

**计算b（斜率）：**
```
b = [nΣXY - ΣXΣY] / [nΣX² - (ΣX)²]
  = [5×14460000 - 3800×18000] / [5×3060000 - 3800²]
  = [72300000 - 68400000] / [15300000 - 14440000]
  = 3900000 / 860000
  = 4.535元/小时
```

**计算a（截距）：**
```
a = (ΣY - bΣX) / n
  = (18000 - 4.535×3800) / 5
  = (18000 - 17233) / 5
  = 767 / 5
  = 153.4元
```

**混合成本公式：**
```
Y = 153.4 + 4.535X
```

**答案：** Y = 153.4 + 4.535X（元）

### 2.4 相关成本决策 - 自制或外购

**题目：** 某公司需要A零件5000件，外购价格20元/件。若自制，单位成本构成为：
- 直接材料：8元
- 直接人工：5元
- 变动制造费用：3元
- 固定制造费用：4元（不可避免）

另外，自制需投入专用设备，若不用可出售得5000元。

**要求：** 决策是自制还是外购。

**解析：**

**相关成本分析：**

**外购方案：**
```
外购成本 = 5000 × 20 = 100,000元
```

**自制方案：**
```
变动成本 = (8+5+3) × 5000 = 16 × 5000 = 80,000元
机会成本 = 出售设备可得5,000元
相关成本 = 80,000 + 5,000 = 85,000元
```

**注意：** 固定制造费用4元×5000=20,000元是不可避免成本，属于无关成本，不考虑。

**比较：**
```
自制相关成本 = 85,000元
外购成本 = 100,000元
自制节省 = 15,000元
```

**答案：** 应选择自制（节省15,000元）

### 2.5 相关成本决策 - 特殊订单

**题目：** 某公司目前生产能力利用率70%，年产能10000件。目前正常价格50元/件，单位成本40元（其中变动成本30元，固定成本10元）。现有一客户提出订购2000件，价格35元/件。

**要求：** 判断是否接受该订单。

**解析：**

**相关成本分析：**
```
变动成本 = 30 × 2000 = 60,000元
边际贡献 = 35 × 2000 - 60,000 = 70,000 - 60,000 = 10,000元

结论：边际贡献>0，接受订单增加10,000元利润
```

**注意：**
- 固定成本10元是已发生的，属于无关成本
- 剩余生产能力的机会成本为0（无其他用途）
- 只要边际贡献>0，即可接受

**答案：** 应接受该特殊订单（增加利润10,000元）

### 2.6 相关成本决策 - 约束资源优化

**题目：** 某公司A、B两种产品共用同一关键设备，设备能力有限（每月100小时）。

| 产品 | 销售单价 | 变动成本 | 单位机器工时 |
|-----|---------|---------|-------------|
| A | 100元 | 60元 | 2小时 |
| B | 80元 | 50元 | 1小时 |

**要求：** 确定最优生产组合。

**解析：**

**计算单位约束资源边际贡献：**
```
产品A：
单位边际贡献 = 100 - 60 = 40元
单位机器工时边际贡献 = 40/2 = 20元/小时

产品B：
单位边际贡献 = 80 - 50 = 30元
单位机器工时边际贡献 = 30/1 = 30元/小时
```

**决策：** 产品B的单位约束资源边际贡献更高，应优先生产B。

**最优方案：**
```
全部生产B：
100小时 × 30元 = 3,000元边际贡献

若生产A和B混合：
方案1：50件A + 50件B = 50×40 + 50×30 = 2000 + 1500 = 3,500元
方案2：0件A + 100件B = 0 + 3000 = 3,000元

等等，重新计算：
方案1：50件A（100小时）+ 0件B = 50×40 = 2000元
方案2：0件A + 100件B = 100×30 = 3000元
方案3：33件A（66小时）+ 34件B（34小时）= 33×40 + 34×30 = 1320 + 1020 = 2340元

最优：全产B，获利3000元
```

**答案：** 优先生产B产品（30元/小时 > 20元/小时）

### 2.7 成本概念辨析

**题目：** 判断以下成本属于相关成本还是无关成本：

1. 机会成本
2. 沉没成本
3. 差量成本
4. 不可避免成本
5. 边际成本

**解析：**

| 成本 | 类别 | 说明 |
|------|------|------|
| 机会成本 | 相关成本（考虑） | 选择本方案而放弃其他方案的最大收益 |
| 沉没成本 | 无关成本 | 已发生、无法改变的历史成本 |
| 差量成本 | 相关成本 | 两个方案之间的成本差异 |
| 不可避免成本 | 无关成本 | 不管选哪个方案都要发生的成本 |
| 边际成本 | 相关成本（考虑） | 多生产一单位产品的增量成本 |

**决策原则：**
```
相关成本：未来发生的、两个方案之间不同的
无关成本：过去的（沉没）、不可避免的
```

**答案：** 1.相关 2.无关 3.相关 4.无关 5.相关

## 三、计算模板

### 模板1：高低点法分解混合成本

```
第一步：确定高低点
  高点：成本和业务量最高
  低点：成本和业务量最低

第二步：计算单位变动成本
  b = (最高点成本 - 最低点成本) / (最高点业务量 - 最低点业务量)

第三步：计算固定成本
  a = 最高点成本 - b × 最高点业务量
  或：a = 最低点成本 - b × 最低点业务量
```

### 模板2：回归直线法分解混合成本

```
b = [nΣXY - ΣXΣY] / [nΣX² - (ΣX)²]
a = (ΣY - bΣX) / n

回归方程：Y = a + bX
```

### 模板3：自制或外购决策

```
自制相关成本 = 变动成本 + 机会成本（含废弃损失）
外购成本 = 购买价格

若自制相关成本 < 外购成本 → 自制
```

### 模板4：特殊订单决策

```
特殊订单相关成本 = 变动成本 + 专属成本
特殊订单收入 > 相关成本 → 接受
```

### 模板5：约束资源决策

```
单位约束资源边际贡献 = 单位边际贡献 / 单位约束资源耗用量

排序：优先生产单位约束资源边际贡献最高的产品
```

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|-------|------|---------|
| 变动成本 vs 边际成本 | 变动成本是总额概念，边际成本是增量概念 | "变"是整体，"边"是增量 |
| 机会成本 vs 沉没成本 | 机会成本是相关成本，沉没成本是无关成本 | "机"会来，"沉"下去 |
| 可避免成本 vs 不可避免成本 | 可避免是相关，不可避免是无关 | "可"以逃，"必"须付 |
| 差量成本 vs 差异成本 | 差量是两个方案差异，差异是多个方案比较 | "差"一对一，"差"多对多 |

## 五、速记口诀

**成本性态记忆：**
> 变动成本随产量变，固定成本不随产量变

**高低点法口诀：**
> 高点减低点，得出变动率，代入求固定

**相关成本决策口诀：**
> 相关成本看未来，方案不同才要算

**沉没成本口诀：**
> 沉没成本是历史，过去已经无法改

**约束资源决策口诀：**
> 约束资源比边际贡献，单位资源贡献大优先
