## 二、典型例题解析

### 2.1 无税MM理论验证

**题目：** 假设无税，有两家公司：
- 公司U（无杠杆）：EBIT=1000万，股票市值=4000万
- 公司L（杠杆）：EBIT=1000万，债券面值=2000万（利率6%），股票市值=？

**要求：** 验证MM理论。

**解析：**

**公司U价值：**
```
VU = EBIT/权益成本率 = 1000/0.25 = 4000万
```

**公司L：**
- 债券价值 = 2000万
- 股票要求回报率：
  ```
  rS = r0 + (r0-rD)(D/S)
     = 25% + (25%-6%)(2000/S)
  ```
- 股票价值需满足：公司价值 = 债券价值 + 股票价值

根据MM理论：
```
VL = VU = 4000万
股票价值 = 4000 - 2000 = 2000万
```

验证：rS = 1000/(2000) = 50%
     验证MM：rS = 25% + (25%-6%)×(2000/2000) = 25%+19% = 44%... 

**修正计算：**
```
公司L股票价值 = EBIT - 利息 / 股票要求回报率
              = (1000 - 2000×6%) / rS
              = 880 / rS

同时：rS = r0 + (r0-rD)(D/S)
     = 25% + 19% × (2000/S)

联立求解得 S = 2000万，与MM理论一致
```

**答案：** 公司L价值=4000万，与公司U相等，验证MM理论

### 2.2 有税MM理论计算

**题目：** 某公司EBIT=500万，所得税税率25%，无杠杆时权益成本12%，债务利率8%，债务面值1000万。

**要求：** 计算有税条件下公司价值和股票价值。

**解析：**

**无杠杆公司价值：**
```
VU = EBIT(1-T)/r0 = 500×0.75/0.12 = 375/0.12 = 3125万
```

**有税MM理论：**
```
VL = VU + T×D
   = 3125 + 25%×1000
   = 3125 + 250
   = 3375万
```

**股票价值：**
```
股票价值 = VL - 债务面值 = 3375 - 1000 = 2375万
```

**权益成本：**
```
rS = r0 + (r0-rD)(1-T)D/S
   = 12% + (12%-8%)×0.75×1000/2375
   = 12% + 4%×0.75×0.421
   = 12% + 1.26%
   = 13.26%
```

**WACC计算：**
```
WACC = (S/VL)×rS + (D/VL)×rD(1-T)
     = (2375/3375)×13.26% + (1000/3375)×8%×0.75
     = 9.34% + 1.78%
     = 11.12%
```

验证：WACC确实低于无杠杆时的r0=12%

**答案：** 公司价值3375万；股票价值2375万；WACC=11.12%

### 2.3 杠杆系数计算

**题目：** 某公司目前销售量10000件，单价100元，变动成本率60%，固定成本200000元，利息费用50000元，所得税25%。

**要求：** 计算DOL、DFL、DTL。

**解析：**

**第一步：计算基期数据**
```
销售收入 = 10000 × 100 = 1,000,000元
变动成本 = 1,000,000 × 60% = 600,000元
边际贡献 = 1,000,000 - 600,000 = 400,000元
固定成本 = 200,000元
EBIT = 边际贡献 - 固定成本 = 400,000 - 200,000 = 200,000元
利息 = 50,000元
EBT = EBIT - 利息 = 200,000 - 50,000 = 150,000元
所得税 = 150,000 × 25% = 37,500元
净利润 = 150,000 - 37,500 = 112,500元
```

**第二步：计算DOL（经营杠杆系数）**
```
DOL = 边际贡献/EBIT = 400,000/200,000 = 2
```

**第三步：计算DFL（财务杠杆系数）**
```
DFL = EBIT/(EBIT-I) = 200,000/150,000 = 1.33
```

**第四步：计算DTL（总杠杆系数）**
```
DTL = DOL × DFL = 2 × 1.33 = 2.67
```

**含义解释：**
- DOL=2：销量变动1%，EBIT变动2%
- DFL=1.33：EBIT变动1%，EPS变动1.33%
- DTL=2.67：销量变动1%，EPS变动2.67%

**答案：** DOL=2；DFL=1.33；DTL=2.67

### 2.4 杠杆系数与利润预测

**题目：** 承接上题，预计下年销量增加20%，计算EBIT和EPS。

**解析：**

**EBIT预测：**
```
EBIT增长 = DOL × 销量增长 = 2 × 20% = 40%
EBIT(下年) = 200,000 × (1+40%) = 280,000元
```

**EPS预测：**
```
EPS增长 = DTL × 销量增长 = 2.67 × 20% = 53.4%
净利润(下年) = 112,500 × (1+53.4%) = 172,575元
EPS变化 = 172,575/112,500 - 1 = 53.4%
```

**验证计算下年净利润：**
```
EBT = 280,000 - 50,000 = 230,000元
所得税 = 230,000 × 25% = 57,500元
净利润 = 230,000 - 57,500 = 172,500元 ≈ 172,575（误差来自四舍五入）
```

**答案：** EBIT=280,000元；净利润=172,500元

### 2.5 可转债估值

**题目：** 某公司发行可转债：
- 面值1000元，票面利率4%，期限5年
- 转换比率：25股（即转换价格40元）
- 当前股价36元，预计年增长8%
- 市场利率（纯债利率）8%

**要求：** 计算可转债价值。

**解析：**

**第一步：计算纯债价值**
```
纯债价值 = 40×(P/A,8%,5) + 1000×(P/F,8%,5)
         = 40×3.993 + 1000×0.681
         = 159.72 + 681
         = 840.72元
```

**第二步：计算转换价值**
```
转换价值 = 25 × 36 = 900元

或者用第5年末的转换价值：
转换价值(第5年) = 25 × 36×(1.08)^5 = 25 × 52.96 = 1324元
```

**第三步：判断价值**
```
由于转换价值(900) > 纯债价值(840.72)
投资者会选择转换
可转债价值 = max(纯债价值, 转换价值) + 期权溢价
           ≈ 900 + 一定溢价
```

**保守估计（不考虑期权价值）：**
```
可转债价值 = max(840.72, 900) = 900元
```

**答案：** 可转债价值≈900元（保守估计）

### 2.6 优先股估值

**题目：** 某优先股面值100元，股息率6%，必要报酬率8%，求优先股价值。

**解析：**

```
优先股价值 = 年股息/必要报酬率
           = 100 × 6% / 8%
           = 6 / 0.08
           = 75元
```

**答案：** 优先股价值=75元

### 2.7 股利政策计算

**题目：** 某公司本年净利润1000万，预计明年投资需求800万。目标资本结构：负债60%，股权40%。

**要求：** 分别计算剩余股利政策和固定股利政策下的股利支付额。

**解析：**

**剩余股利政策：**
```
步骤1：确定投资所需股权融资
股权需求 = 800 × 40% = 320万

步骤2：从净利润中满足股权融资需求
股利 = 净利润 - 股权需求 = 1000 - 320 = 680万

股利支付率 = 680/1000 = 68%
```

**固定股利政策（假设去年股利700万）：**
```
股利 = 700万（固定不变）
股利支付率 = 700/1000 = 70%
```

**答案：** 剩余股利政策下股利680万；固定股利政策下股利700万

### 2.8 股票回购计算

**题目：** 某公司净利润1000万，流通股1000万股，EPS=1元。股价20元，市盈率20倍。公司计划用300万现金回购股票。

**要求：** 计算回购后EPS和每股收益变动。

**解析：**

```
回购股数 = 300/20 = 15万股

回购后净利润 = 1000万（不变）
回购后流通股 = 1000 - 15 = 985万股
回购后EPS = 1000/985 = 1.015元

每股收益增加 = (1.015-1)/1 = 1.5%
```

**答案：** 回购后EPS=1.015元，增长1.5%

## 三、计算模板

### 模板1：MM理论计算

```
无税MM：VL = VU
        rS = r0 + (r0-rD)(D/S)

有税MM：VL = VU + T×D
        rS = r0 + (r0-rD)(1-T)(D/S)
        WACC = r0(1-T×D/V)
```

### 模板2：杠杆系数计算

```
DOL = 边际贡献/EBIT = (Q(P-V))/[Q(P-V)-F]

DFL = EBIT/(EBIT-I) = EBIT/(EBT)

DTL = DOL × DFL = (Q(P-V))/[Q(P-V)-F-I]
```

### 模板3：可转债估值

```
可转债价值 = max(纯债价值, 转换价值) + 期权价值

纯债价值 = Σ[C/(1+r)^t] + M/(1+r)^n
转换价值 = 转换比率 × 股价
```

### 模板4：剩余股利政策

```
步骤1：确定投资所需股权融资 = 投资需求 × 股权比例
步骤2：股利 = 净利润 - 股权融资需求
步骤3：股利支付率 = 股利/净利润
```

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|-------|------|---------|
| 无税MM vs 有税MM | 有税时负债创造价值T×D | "有税"才能避税 |
| DOL vs DFL vs DTL | 销量→EBIT→EPS的传导链 | "经→利→股" |
| 可转债纯债 vs 转换价值 | 纯债是债的价值，转换价值是转为股票的价值 | "纯"是底价，"转"是潜力 |
| 剩余股利 vs 固定股利 | 剩余股利按投资需求分配，固定股利稳定发放 | "剩余"看投资，"固定"看承诺 |

## 五、速记口诀

**MM理论口诀：**
> 无税资本结构不影响价值，有税负债越多企业越值钱

**杠杆系数口诀：**
> 经营杠杆看边际贡献，财务杠杆看利息，总杠杆两个相乘

**可转债口诀：**
> 可转债价值取大值，债底和转股，期权价值要另加

**筹资顺序口诀：**
> 优序融资内源先，债务次之股权殿
