# 03-长期筹资决策 —— 综合实战

## 一、综合题解题框架

### 资本结构决策综合题标准步骤

```
第一步：识别题目类型
  → 是MM理论验证？杠杆系数计算？资本结构优化？

第二步：提取关键数据
  → EBIT、税率、资本结构比例、各项成本

第三步：构建财务杠杆与经营杠杆
  → 计算DOL、DFL、DTL
  → 分析风险水平

第四步：资本成本计算
  → WACC计算（使用目标权重）
  → 边际资本成本曲线

第五步：最优资本结构决策
  → 比较不同方案下的WACC
  → 考虑财务困境成本
  → 权衡税盾与风险
```

## 三、陷阱与反套路

### 陷阱1：混淆MM理论适用条件

**常见错误：** 不考虑税的存在与否

**正确识别：**
- 无税MM：资本结构与企业价值无关
- 有税MM：负债创造税盾价值T×D
- 权衡理论：税盾收益 - 财务困境成本 = 最优结构

**反套路训练：**
```markdown
题目条件："假设不考虑所得税"
→ 使用无税MM理论，VL = VU

题目条件："所得税率25%"
→ 使用有税MM理论，VL = VU + T×D
```

### 陷阱2：杠杆系数计算顺序错误

**常见错误：** 直接套公式，不先算中间变量

**正确顺序：**
```
第一步：计算边际贡献 = Q(P-V)
第二步：计算EBIT = 边际贡献 - 固定成本
第三步：计算DOL = 边际贡献/EBIT
第四步：计算DFL = EBIT/(EBIT-I)
第五步：计算DTL = DOL × DFL
```

### 陷阱3：混淆"税前"与"税后"成本

**常见错误：** 计算WACC时债务成本未乘(1-T)

**正确计算：**
```
WACC = Wd × Kd(1-T) + We × Ke

注意：
- 债务成本用税后（因为利息可抵税）
- 权益成本不用调整（股利不能抵税）
```

### 陷阱4：杜邦分析与资本结构脱节

**常见错误：** 单独分析杜邦，不结合资本结构

**正确思路：**
```
ROE = 净利率 × 周转率 × 权益乘数

权益乘数 = 1/(1-资产负债率)

结论：
提高负债率 → 提高权益乘数 → 提高ROE
但同时：提高负债率 → 提高财务风险 → 可能降低净利率
```

### 陷阱5：忽视财务困境成本

**常见错误：** 简单认为负债越多越好（有税MM）

**正确理解：**
```
最优资本结构 = 税盾收益 - 财务困境成本

财务困境成本包括：
- 直接成本：法律费用、清算成本
- 间接成本：客户流失、供应商收紧条款、员工流失
```

## 四、真题变式推演

### 变式1：最优资本结构决策

**原题特征：** 单一资本结构下的WACC计算

**变式升级：** 比较不同资本结构下的WACC，确定最优

**训练题：** 某公司无杠杆价值1000万，权益成本12%，债务成本6%，税率25%。

| 方案 | D/V | 权益成本 | 债务成本 |
|-----|-----|---------|---------|
| A | 0% | 12% | - |
| B | 30% | 13% | 6% |
| C | 60% | 16% | 7% |

**解题：**

```
方案A WACC = 100% × 12% = 12%

方案B WACC = 70% × 13% + 30% × 6% × 0.75
           = 9.1% + 1.35%
           = 10.45%

方案C WACC = 40% × 16% + 60% × 7% × 0.75
           = 6.4% + 3.15%
           = 9.55%

最优方案：C（最低WACC=9.55%）
```

### 变式2：杠杆系数与EBIT-EPS分析

**原题特征：** 单独计算杠杆系数

**变式升级：** EBIT-EPS无差异点分析

**训练题：** A公司目前无负债，EBIT=500万，税率25%，股份1000万股。
B公司结构与A相同，但有债务1000万（利率8%）。

求：EBIT-EPS无差异点。

**解题：**

```
A公司（无负债）：
EPS_A = [EBIT × (1-25%)] / 1000万

B公司（有负债）：
EPS_B = [(EBIT - 1000×8%) × (1-25%)] / 股份数

无差异点：EPS_A = EPS_B
[EBIT × 0.75] / 1000 = [(EBIT - 80) × 0.75] / 股份数

假设B公司股份数相同（简化）：
EBIT = EBIT - 80
80 = 0 → 无差异点不存在（因为B公司利息固定为80万）

修正：B公司因利息减少利润，股份数应变化
      但简化计算：EBIT > 80万时，B公司EPS较低
```

### 变式3：资本结构与WACC联动（第1章杜邦分析）

**原题特征：** 资本结构与WACC分开计算

**变式升级：** 资本结构调整后对ROE和WACC的综合影响

**训练题：** 某公司目前：
- 资产=2000万，负债=800万，权益=1200万
- EBIT=400万，利息=48万，税率25%
- 净利率=10%，周转率=1次

现计划增加负债500万（利率7%），用于回购股票。

**解题：**

**当前状态：**
```
资产负债率 = 800/2000 = 40%
权益乘数 = 2000/1200 = 1.67
ROE = 10% × 1 × 1.67 = 16.7%

净利润 = 400 - 48 = 352万
税后 = 352 × 0.75 = 264万
ROE验证 = 264/1200 = 22%（与杜邦不符，重新计算）

重新：
净利润 = (400-48)×0.75 = 264万
ROE = 264/1200 = 22%
```

**调整后：**
```
新负债 = 800 + 500 = 1300万
新权益 = 1200 - 500 = 700万（新股票价值下降）
新利息 = 48 + 500×7% = 83万

新资产负债率 = 1300/2000 = 65%
新权益乘数 = 2000/700 = 2.86

EBIT不变 = 400万
新EBT = 400 - 83 = 317万
新净利润 = 317 × 0.75 = 237.75万
新ROE = 237.75/700 = 33.96%

ROE大幅提升！但财务风险显著增加。
```

### 变式4：可转债与股权融资比较

**原题特征：** 单一融资方式评价

**变式升级：** 债券、可转债、普通股融资方案比较

**训练题：** 某公司需要融资1000万，三种方案：

| 方案 | 融资方式 | 条件 |
|-----|---------|------|
| A | 债券 | 利率8%，期限5年 |
| B | 可转债 | 票面1000元，利率4%，转股价25元 |
| C | 普通股 | 发行价20元/股 |

当前股价22元，预计年增长10%。

**解题：**

```
方案A（债券）：
年利息 = 1000×8% = 80万
5年后还本1000万
适合预计业绩稳定的企业

方案B（可转债）：
年利息 = 1000×4% = 40万（节省40万利息）
转换价值 = 1000/25 × 22 = 40×22 = 880元
纯债价值 ≈ 40×(P/A,8%,5) + 1000×(P/F,8%,5) ≈ 864元

若股价涨至30元，转换价值 = 40×30 = 1200元
投资者会选择转换，公司获得股权融资

方案C（普通股）：
融资额 = 1000/20 = 50万股
稀释现有股权

选择建议：
- 若股价被低估：可转债优于普通股（保护稀释）
- 若需要利息税盾：债券优于普通股
- 综合考虑：可转债是较好的折中选择
```

## 五、实务衔接

### 实务场景1：上市公司再融资决策

某A股上市公司情况：
- 市值：100亿
- 现有负债：30亿
- EBIT：15亿
- 税率：25%
- 无风险利率：3%
- 市场风险溢价：6%
- β系数：1.2

**融资方案分析：**
```
当前权益成本 = 3% + 1.2×6% = 10.2%
当前WACC = (70%×10.2%) + (30%×8%×0.75) = 7.14% + 1.8% = 8.94%

计划新增负债50亿，用于回购股票

新权益成本 = 10.2% + (10.2%-6%)×(50/50) = 14.2%（假设权益价值下降）
新WACC = (50/130×14.2%) + (80/130×6%×0.75) = 5.46% + 2.77% = 8.23%

WACC下降！但财务风险增加。
```

### 实务场景2：杠杆收购（LBO）分析

某PE拟杠杆收购目标公司：
- 收购价格：10亿
- 目标EBIT：1.5亿
- 利率：6%
- 税率：25%

**偿还能力分析：**
```
最大可承担利息 = EBIT × (1-税率) / 1.5
               = 1.5亿 × 0.75 / 1.5 = 7500万

对应最大负债 = 7500万 / 6% = 12.5亿

PE可承担的最大杠杆：负债12.5亿
股权出资 = 10亿 - 最大负债 = -2.5亿（需要额外股权）

实际方案：
- 负债：8亿（60%）
- 股权：2亿（40%）
- 年利息 = 8×6% = 4800万
- 税后利润 = (1.5亿-4800万)×0.75 = 7650万
- 利息保障倍数 = 1.5亿/4800万 = 3.1倍
```

### 实务场景3：股利政策与企业价值

某公司面临股利政策选择：
- 净利润：1亿
- 投资需求：6000万
- 股权成本：12%

**剩余股利政策：**
```
股利 = 1亿 - 6000万 = 4000万
股利支付率 = 40%

若剩余现金全部分配（固定股利1亿）：
→ 投资需借款2000万
→ 增加财务风险，可能影响价值
```

**股票回购：**
```
若采用股票回购替代部分现金股利：
→ 减少流通股数量
→ 提高EPS和ROE
→ 股东获得资本利得（税收优惠）
```

- MM理论是资本结构的理论基础

- WACC最小化是资本结构优化目标
- 可转债是混合融资工具
- 优序融资反映企业实际融资行为
