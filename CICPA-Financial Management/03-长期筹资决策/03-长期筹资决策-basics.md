# 长期筹资决策 —— 第一性原理教程

## 一、资本结构

### 1.1 理论

| 理论 | 观点 |
|------|------|
| 无税MM | 资本结构不影响价值 |
| 有税MM | VL = VU + T×D（负债增加价值） |
| 权衡理论 | 最优=税盾收益-财务困境成本最大 |
| 优序理论 | 内源>债务>股权 |

### 1.2 杠杆系数

```
DOL = 边际贡献/EBIT          销量变动→EBIT变动
DFL = EBIT/(EBIT-I)          EBIT变动→EPS变动
DTL = DOL × DFL              销量变动→EPS变动
```

## 二、长期筹资

### 2.1 债务筹资
- 债券：票面利率>市场利率→溢价；反之→折价

### 2.2 普通股筹资
- 优点：无固定负担、无到期日
- 缺点：成本高、分散控制权

### 2.3 混合筹资

| 类型 | 特征 |
|------|------|
| 优先股 | 固定股息、无表决权 |
| 可转债 | 债券+转股期权 |
| 附认股权证债券 | 债券+认股权证 |

**可转债价值 = max(纯债价值, 转换价值) + 期权价值**

---

## 三、股利分配、股票分割与回购

### 3.1 股利政策

| 政策 | 特点 |
|------|------|
| 剩余股利 | 满足投资后分配 |
| 固定股利 | 稳定但缺乏弹性 |
| 固定支付率 | 随盈余波动 |
| 低正常+额外 | 灵活 |

### 3.2 股票分割与回购
- **分割**：股数增加、面值降低、总价值不变
- **回购**：减少流通股、提高EPS

---

## 考试要点

1. **MM理论**：无税无关，有税负债增值
2. **三个杠杆**：DOL/DFL/DTL联动
3. **可转债**：纯债与转换价值取大+期权
4. **优序融资**：内源→债→股
