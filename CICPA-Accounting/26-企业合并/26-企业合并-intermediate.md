# 企业合并 —— 典型考题解析

## 一、核心考法分类

| 考法 | 题型 | 频率 |
|------|------|------|
| 同一控制下合并处理 | 计算/综合 | ★★★★★ |
| 非同一控制下合并处理 | 计算/综合 | ★★★★★ |
| 合并成本与商誉计算 | 计算 | ★★★★★ |
| 或有对价的处理 | 单选/计算 | ★★★★ |
| 反向购买 | 综合 | ★★★★ |
| 业务的判断 | 单选/多选 | ★★★ |

## 二、典型例题解析

### 2.1 同一控制下企业合并——合并日处理

**题目：** 甲公司以银行存款4000万元和一项账面价值2500万元（公允价值3000万元）的无形资产为对价，取得同一集团内乙公司100%股权。乙公司在最终控制方合并报表中的净资产账面价值为6000万元，此前集团从外部第三方购买乙公司时形成商誉200万元。求初始投资成本和合并日分录。

**解析：**
- 同一控制下初始投资成本 = 被合并方在最终控制方合并报表中的净资产账面价值 × 持股比例 + 最终控制方收购时形成的商誉
- 初始投资成本 = 6000 × 100% + 200 = 6200万元
- 合并对价账面价值 = 4000 + 2500 = 6500万元
- 差额 = 6200 - 6500 = -300万元，冲减资本公积

**答案：**
```
借：长期股权投资  6200
    资本公积——资本溢价  300
  贷：银行存款  4000
      无形资产  2500
```

### 2.2 非同一控制下企业合并——购买日处理

**题目：** 甲公司以5000万元现金购买乙公司80%股权（非同一控制）。购买日乙公司可辨认净资产公允价值为5500万元，账面价值5000万元。差异来自：存货（公允>账面200万元，已全部对外出售）；固定资产（公允>账面300万元，尚可使用10年）。求商誉和2026年末合并报表中的调整。

**解析：**
- 合并成本 = 5000万元
- 可辨认净资产公允价值份额 = 5500 × 80% = 4400万元
- 商誉 = 5000 - 4400 = 600万元
- 存货差异200万元：购买当年已售出，全额调减乙公司净利润
- 固定资产差异300万元：每年多提折旧30万元

**答案：**
购买日抵销：
```
借：存货  200
    固定资产  300
  贷：资本公积  500

借：净资产（乙公司公允价值）  5500
    商誉  600
  贷：长期股权投资  5000
      少数股东权益  1100（5500×20%）
```

### 2.3 或有对价

**题目：** 甲公司购买乙公司100%股权，合同约定：如果乙公司未来2年净利润超过1000万元，甲公司需额外支付500万元。购买日甲公司估计或有对价的公允价值为300万元。求合并成本。

**解析：**
- 非同一控制下，或有对价按公允价值计入合并成本
- 合并成本 = 基础对价 + 或有对价公允价值

**答案：**
- 合并成本 = 基础对价 + 300万元
- 或有对价后续变动：属于金融负债/金融资产，按公允价值计量，变动计入当期损益

### 2.4 反向购买

**题目：** A公司（上市公司，股本1000万股，每股公允价值20元）向B公司（非上市公司）原股东发行1200万股收购B公司100%股权。B公司股本500万股，每股公允价值30元。判断谁是法律上的收购方、谁是会计上的购买方。

**解析：**
- 法律上：A公司发行股份收购B公司，A是收购方
- 会计上：B公司原股东持有A公司1200/2200=54.5%股权，超过A原股东的45.5%
- B公司原股东实质上控制了A公司 → 会计上的购买方是B公司
- 这是反向购买：法律上的被购买方（B）是会计上的购买方

**答案：** 会计上以B公司为购买方，合并成本 = A公司公允价值 = 1000 × 20 = 20000万元。合并报表中以B公司的资产/负债为基础，加上A公司的可辨认净资产公允价值。

### 2.5 业务的判断

**题目：** 甲公司收购乙公司的一组资产，包括：厂房、设备、5名员工和客户合同。判断是否构成业务。

**解析：**
- 业务的判断标准：是否有投入+加工过程+产出
- 厂房设备=投入，员工=加工过程，客户合同=产出
- 三要素齐全 → 构成业务

**答案：** 构成业务，应按企业合并准则处理（而非单纯资产购买）。

## 三、分录模板

### 3.1 同一控制合并日

```
借：长期股权投资  [被合并方净资产账面价值 × 比例 + 原商誉]
    资本公积（差额或在贷方）
  贷：对价各项目（按账面价值）

合并日合并报表：
借：净资产（被合并方账面价值）
  贷：长期股权投资
      少数股东权益
```

### 3.2 非同一控制购买日

```
// 个别报表
借：长期股权投资  [合并成本 = 对价公允价值]
  贷：对价各项目（按公允价值）

// 合并报表：先调公允价值差异
借：资产（增值部分）
  贷：资本公积

// 抵销分录
借：净资产（被购买方公允价值）
    商誉
  贷：长期股权投资
      少数股东权益（公允价值 × 少数比例）
```

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|-------|------|----------|
| 同一控制 vs 非同一控制 | 同一控制用账面价值，不产生新商誉；非同一控制用公允价值，产生新商誉 | "同账非公，同不生商非生商" |
| 同一控制下原有商誉 | 如果集团从外部购买过该子公司，需加上原商誉 | "外购商誉要带上" |
| 或有对价（同一 vs 非同一） | 同一控制下或有对价不影响初始成本；非同一控制下计入合并成本 | "同控不算或非控算" |
| 法律主体 vs 会计主体（反向购买） | 法律上的收购方可能不是会计上的购买方 | "看股权比例定实质" |
| 资产购买 vs 业务合并 | 有投入+加工+产出=业务；否则为资产购买 | "三要素定业务" |

## 五、速记口诀

- **"同账非公"**：同一控制按账面价值，非同一控制按公允价值
- **"商誉只认非同控"**：非同一控制下产生商誉，同一控制下不产生新商誉（但需带上原商誉）
- **"反向看实质"**：法律形式不重要，看谁实质控制谁
- **"业务三要素"**：投入+加工+产出
