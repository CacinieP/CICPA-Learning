# 借款费用 —— 第一性原理教程

## 一、借款费用概念

### 1.1 借款费用的范围

**借款费用**是指企业因借款而发生的代价，包括：
- 借款利息（含折价/溢价的摊销）
- 辅助费用（手续费等）
- 外币借款汇兑差额

### 1.2 借款范围

- **专门借款**：为购建或生产符合资本化条件的资产而专门借入的款项
- **一般借款**：除专门借款外的其他借款

### 1.3 符合资本化条件的资产

需要经过**相当长时间**（≥1年）的购建或生产才能达到预定可使用或可销售状态的资产：
- 固定资产（在建工程）
- 投资性房地产（在建）
- 存货（如房地产开发产品、大型船舶）
- 无形资产（如研发支出）

---

## 二、借款费用的确认

### 2.1 开始资本化的时点（三个条件同时满足）

1. 资产支出已发生（支付现金/转移非现金资产/承担带息债务）
2. 借款费用已发生
3. 购建或生产活动已开始

### 2.2 暂停资本化的条件

**同时满足：**
1. 购建或生产活动发生**非正常中断**
2. 中断时间**连续超过3个月**

**非正常中断**的例子：劳资纠纷、安全事故、材料供应不及时
**正常中断**的例子：北方冬季施工暂停、雨季暂停（不停止资本化）

### 2.3 停止资本化的时点

资产达到**预定可使用或可销售状态**时。判断标志：
- 实体建造已完成
- 与设计要求基本相符
- 继续支出很少或几乎不再发生

---

## 三、借款费用的计量

### 3.1 专门借款利息资本化

```
资本化金额 = 专门借款当期实际利息 - 闲置资金投资收益

实际利息 = 期初摊余成本 × 实际利率
```

**关键点：** 专门借款利息资本化不需要与资产支出挂钩，只需要减去闲置部分的收益。

### 3.2 一般借款利息资本化

```
资本化金额 = 累计资产支出超过专门借款部分的资产支出加权平均数 × 资本化率

资本化率 = 一般借款当期实际利息之和 / 一般借款本金加权平均数
```

**关键点：** 一般借款利息资本化需要与资产支出**挂钩**，只有被占用的部分才能资本化。

### 3.3 辅助费用的处理

| 时间 | 处理 |
|------|------|
| 资本化期间内发生的 | 资本化（计入资产成本） |
| 非资本化期间发生的 | 费用化（计入当期损益） |

### 3.4 外币专门借款汇兑差额

**专门借款**的汇兑差额在资本化期间内**全部资本化**（无需与资产支出挂钩）。

---

## 考试要点总结

1. **三个时点**：开始/暂停/停止资本化的条件
2. **专门借款**：实际利息 - 闲置收益（不与支出挂钩）
3. **一般借款**：必须与资产支出挂钩，用加权平均数和资本化率
4. **非正常中断超过3个月**：暂停资本化
5. **外币汇兑差额**：仅专门借款可全部资本化
