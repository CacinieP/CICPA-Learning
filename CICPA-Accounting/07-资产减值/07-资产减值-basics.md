# 资产减值 —— 第一性原理教程

## 一、资产减值的基本概念

### 1.1 为什么需要减值

**第一性原理：** 资产的本质是预期带来未来经济利益。如果资产的账面价值超过了它能带来的经济利益，说明资产已经"不值那么多钱了"，必须将账面价值调减到合理水平。

**减值测试的核心问题：** 资产的账面价值是否高于其可收回金额？

### 1.2 减值的适用范围

| 资产类别 | 减值能否转回 | 适用准则 |
|----------|-------------|----------|
| 固定资产 | **不可转回** | CAS 8 资产减值 |
| 无形资产 | **不可转回** | CAS 8 |
| 长期股权投资（对联营/合营） | **不可转回** | CAS 8 |
| 投资性房地产（成本模式） | **不可转回** | CAS 8 |
| 商誉 | **不可转回** | CAS 8 |
| 存货 | **可以转回** | CAS 1 |
| 应收款项 | **可以转回** | CAS 22 金融工具 |
| 持有待售资产 | **可以转回**（在原确认范围内） | CAS 42 |

---

## 二、资产可收回金额的计量

### 2.1 基本原则

```
可收回金额 = max（公允价值减去处置费用后的净额，资产预计未来现金流量的现值）
```

**只要其中一项高于账面价值，就不需要减值。**

### 2.2 公允价值减去处置费用后的净额

**公允价值**的确定优先级：
1. 销售协议价格
2. 活跃市场的买方出价
3. 最佳信息的估计

**处置费用**包括：法律费用、搬运费、相关税费等，但不包括所得税和财务费用。

### 2.3 预计未来现金流量的现值

**计算步骤：**
1. 估计资产持续使用过程中产生的未来现金流量
2. 估计资产使用寿命结束时处置产生的现金流量
3. 选择适当的折现率折现

**折现率的选择：** 反映当前市场货币时间价值和资产特定风险的税前利率。

## 三、资产减值损失的确认与计量

### 3.1 确认原则

```
如果 账面价值 > 可收回金额 → 确认减值损失
减值损失 = 账面价值 - 可收回金额
```

**会计处理：**
```
借：资产减值损失
  贷：固定资产减值准备 / 无形资产减值准备 / 长期股权投资减值准备 等
```

### 3.2 减值后的调整

- 减值后的账面价值成为新的成本基础
- 未来期间计提折旧/摊销按新账面价值计算
- 已确认的减值损失**不得转回**（CAS 8 范围内）

---

## 四、资产组的认定及减值处理

### 4.1 为什么需要资产组

**问题：** 有些资产单独使用不能产生独立现金流（如生产线上的某台机器），无法单独确定可收回金额。

**解决：** 将能够独立产生现金流量的**最小资产组合**认定为资产组。

### 4.2 资产组的认定

**认定标准：**
- 该资产组合产生的现金流入基本上独立于其他资产或资产组
- 企业管理层对资产的日常管理方式

### 4.3 资产组减值测试

**步骤：**
1. 确定资产组的账面价值（含分摊的商誉和总部资产）
2. 确定资产组的可收回金额
3. 比较并确认减值

**减值分摊顺序：**
```
减值损失首先抵减商誉 → 然后按各项资产的账面价值比例分摊
```

**限制：** 分摊后的单项资产账面价值不得低于以下三者中的最高者：
- 公允价值减去处置费用
- 预计未来现金流量现值
- 零

---

## 五、商誉减值测试与处理

### 5.1 商誉的特殊性

**商誉不能独立存在**，必须结合相关资产组或资产组组合进行减值测试。

### 5.2 商誉减值测试步骤

**非同一控制下企业合并形成的商誉：**

1. 自购买日起将商誉分摊到相关的资产组或资产组组合
2. 调整资产组的账面价值（含分摊的商誉）
3. 比较资产组可收回金额与调整后账面价值
4. 减值损失首先冲减商誉

**部分持股子公司的商誉减值：**

```
商誉 = 全部商誉（含少数股东份额）= 合并成本 - 享有被购买方可辨认净资产公允价值份额
测试时：资产组账面价值应包含全部商誉（而非仅母公司享有的部分）
```

---

## 考试要点总结

1. **可收回金额 = max（净额，现值）**：两个维度取高者
2. **减值不可转回**（CAS 8 范围内资产）
3. **资产组**：不能单独产生现金流的资产组合
4. **减值分摊**：先冲减商誉，再按账面价值比例分摊
5. **商誉测试**：包含全部商誉（含少数股东份额）
