# 金融工具 —— 典型考题解析

## 一、核心考法分类

本章是CPA考试中难度最高的章节之一（能力等级3），主要考法包括：
1. **金融资产的分类判断**（SPPI测试+业务模式）
2. **金融负债和权益工具的区分**
3. **预期信用损失模型（三阶段）**
4. **以公允价值计量且变动计入当期损益(FVTPL)的会计处理**
5. **可转债等复合金融工具的拆分**
6. **金融资产转移的判断**

## 二、典型例题解析

### 2.1 金融资产分类判断（单选题）

**题目：** 甲公司将购入的债券分类为以公允价值计量且其变动计入其他综合收益的金融资产。下列各项中，不属于甲公司该债券业务模式特征的是（ ）。

A. 以收取合同现金流量为目标
B. 以出售债券为目标
C. 兼顾收取合同现金流量和出售目标
D. 以最大幅度出售债券获取利润为目标

**解析：** 金融资产的分类取决于业务模式和SPPI测试：

| 分类 | 业务模式 | 特征 |
|------|----------|------|
| AMC（摊余成本） | 收取合同现金流量 | 只收本息，不出售 |
| FVTOCI | 收取+出售 | 既收本息又可能出售 |
| FVTPL | 其他 | 主要目的不是收取本息 |

以公允价值计量且其变动计入其他综合收益（FVTOCI）的业务模式是"兼顾客户合同现金流量和出售"，而非"以最大幅度出售获取利润"。

**答案：** D

### 2.2 SPPI测试与分类（多选题）

**题目：** 下列各项金融资产中，应当分类为以公允价值计量且变动计入当期损益的有（ ）。

A. 在活跃市场中没有报价、公允价值不能可靠计量的权益工具投资
B. 债务工具投资，合同约定本息按固定日期支付，且与基础变量挂钩
C. 权益工具投资，被投资单位当年发生严重亏损
D. 衍生工具形成的资产

**解析：** SPPI测试（仅为本金和利息偿付的测试）：
- 通过SPPI测试 → FVTOCI或AMC
- 未通过SPPI测试 → FVTPL

| 选项 | 分析 | 分类 |
|------|------|------|
| A | 无活跃报价且公允价值不能可靠计量，应按成本计量，不属于FVTPL | 否 |
| B | 与基础变量挂钩（如股票指数），现金流不"纯粹"，未通过SPPI测试 | 是 |
| C | 投资本身不改变合同现金流特征，仍可能通过SPPI测试 | 否 |
| D | 衍生工具价值随基础变量变动，未通过SPPI测试 | 是 |

**答案：** BD

### 2.3 金融负债与权益工具区分（计算题）

**题目：** A公司2×21年1月1日按面值发行可转换公司债券100,000万元，期限5年，票面利率3%，每年年末付息，到期一次还本。发行时市场利率为6%。债券可转换为A公司普通股，转股价格为10元/股。假设当日全部被转换为普通股，计算A公司应确认的金融负债和权益工具金额。

**解析：**

**第一步：计算负债成分的公允价值（未来现金流按市场利率折现）**
```
第1-4年利息：100,000 × 3% = 3,000万元，复利现值系数(P/A,6%,4)=3.4651
第5年本息：100,000 + 3,000 = 103,000万元，现值系数(P/F,6%,5)=0.7473

利息现值 = 3,000 × 3.4651 = 10,395.3万元
本金现值 = 100,000 × 0.7473 = 74,730万元
负债成分 = 10,395.3 + 74,730 = 85,125.3万元
```

**第二步：计算权益成分**
```
权益成分 = 发行价格 - 负债成分公允价值
         = 100,000 - 85,125.3
         = 14,874.7万元
```

**第三步：转股时的会计分录**
```
借：应付债券——可转换公司债券（面值）     100,000
  贷：应付债券——可转换公司债券（利息调整） 14,874.7
      股本（100,000/10 = 10,000万股，每股面值1元） 10,000
      资本公积——股本溢价                  75,125.3
```

**答案：** 初始确认金融负债85,125.3万元，权益工具14,874.7万元。

### 2.4 预期信用损失模型（计算题）

**题目：** B银行2×21年发放了一笔贷款，账面余额10,000万元，年利率5%。2×21年末进行减值评估：
- 第一阶段：信用风险未显著增加，预计12个月违约损失率1%
- 第二阶段：信用风险显著增加，预计存续期违约损失率5%
- 第三阶段：已发生信用减值，预计存续期违约损失率10%，担保物价值3,000万元

要求：计算各阶段应计提的信用减值损失。

**解析：**

**第一阶段：**
```
账面余额 = 10,000万元
12个月预期信用损失 = 10,000 × 1% = 100万元
利息收入 = 10,000 × 5% = 500万元（按账面余额计算）
```

**第二阶段：**
```
账面余额 = 10,000万元（未减值）
存续期预期信用损失 = 10,000 × 5% = 500万元
利息收入 = 10,000 × 5% = 500万元
```

**第三阶段：**
```
账面余额 = 10,000 - 3,000（担保物）= 7,000万元（摊余成本）
存续期预期信用损失 = 7,000 × 10% = 700万元
利息收入 = 7,000 × 5% = 350万元（按摊余成本计算）
```

**答案：** 第一阶段100万元，第二阶段500万元，第三阶段700万元。

### 2.5 金融资产重分类（多选题）

**题目：** 甲公司2×21年1月1日将一项债权投资（分类为以摊余成本计量的金融资产）重分类为以公允价值计量且其变动计入当期损益的金融资产，重分类日该资产的账面价值为1,000万元，公允价值为1,050万元。下列关于甲公司会计处理的表述中，正确的有（ ）。

A. 应将公允价值与账面价值的差额50万元计入当期损益
B. 应将公允价值与账面价值的差额50万元计入其他综合收益
C. 重分类日应按账面价值作为新的公允价值
D. 该重分类应采用未来适用法处理

**解析：** AMC→FVTPL的重分类处理：
- 以**账面价值**作为新的公允价值
- 差额为零，不影响当期损益或OCI

| 重分类方向 | 会计处理 |
|-----------|----------|
| AMC → FVTPL | 账面价值 = 新公允价值，差额为零 |
| FVTPL → AMC | 公允价值 = 新摊余成本 |
| FVTOCI → FVTPL | 账面价值 = 新公允价值，之前OCI转当期损益 |

**答案：** AD

## 三、分录/计算模板

### 3.1 以摊余成本计量的金融资产（AMC）

```
初始确认：
借：债权投资——成本（面值）
    债权投资——利息调整（差额）
  贷：银行存款

后续计量（实际利率法）：
借：应收利息（票面利息）
  贷：投资收益（实际利息）
      债权投资——利息调整（差额）

减值：
借：信用减值损失
  贷：债权投资减值准备
```

### 3.2 FVTPL的处理

```
初始确认：
借：交易性金融资产——成本
  贷：银行存款

公允价值变动：
借：交易性金融资产——公允价值变动
  贷：公允价值变动损益

出售：
借：银行存款
  贷：交易性金融资产——成本
              ——公允价值变动（或者借方）
      投资收益（差额）
借：公允价值变动损益
  贷：投资收益
```

### 3.3 可转换公司债券

```
发行时：
借：银行存款
  贷：应付债券——可转换公司债券（面值）
              ——利息调整（负债成分公允价值低于面值的差额）
      其他权益工具（权益成分公允价值）

转换为权益时：
借：应付债券——可转换公司债券（面值）
          ——利息调整（剩余未摊销调整额）
    其他权益工具（初始确认的权益成分金额）
  贷：股本
      资本公积——股本溢价
```

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|-------|------|---------|
| SPPI测试 | 通过→AMC/FVTOCI；未通过→FVTPL | "本金利息纯通过，其他都要FVTPL" |
| FVTOCI的OCI | 债务工具→可转损益；权益工具→不转损益 | "债务转，权益不转" |
| 三阶段模型 | 第一阶段12个月ECL；第二三阶段整个存续期ECL | "一12，三整个" |
| 重分类 | AMC→FVTPL差额为零；FVTPL→AMC差额为新摊余成本 | "AMC出零，FVTPL入零" |
| 金融负债 vs 权益工具 | 固定换固定→权益；其他→负债 | "固定换固定是权益" |

## 五、速记口诀

**金融资产分类口诀：**
- 先看SPPI，本金利息纯不纯
- 通过再看业务模式，只收还是收着卖
- 兼顾客户合同+出售=OCI

**预期信用损失三阶段：**
- 第一阶段：风险未增加，12个月ECL
- 第二阶段：风险显著增，整个存续ECL
- 第三阶段：已发生减值，整个存续ECL，利息按净额算

**金融负债vs权益工具：**
- 能无条件避免交付现金→权益
- 必须交付现金/金融资产→负债
- 固定换固定→权益
