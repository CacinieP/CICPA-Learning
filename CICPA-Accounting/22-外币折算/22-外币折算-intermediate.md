# 外币折算 —— 典型考题解析

## 一、核心考法分类

本章在历年真题中的主要考法归纳如下：

1. **记账本位币的确定**（单选题）：影响销售价格、劳务成本、融资活动、收款货币
2. **外币货币性项目的汇兑差额计算**（计算分析题）：汇率变动导致的收益/损失
3. **外币报表折算**（综合题）：境外子公司报表折算，差额计入其他综合收益
4. **非货币性项目处理**（多选题）：历史成本 vs 公允价值的区别

## 二、典型例题解析

### 2.1 记账本位币的确定

**题目：**
单选题——下列各项中，不影响甲公司记账本位币认定的是（ ）

A. 甲公司30%的收入来自向美国客户销售产品，收取美元
B. 甲公司30%的成本用于向德国供应商采购原材料，支付欧元
C. 甲公司80%的融资活动通过美元债券进行
D. 甲公司50%的商品在中国境内销售，收取人民币

**解析：**
记账本位币的确定考虑四个因素：
1. 从收取现金角度看，主要影响**销售价格**的货币
2. 从支付现金角度看，主要影响**劳务和材料成本**的货币
3. **融资活动**获得的资金所使用的货币
4. 保留从经营活动中收取款项所使用的货币

选项D：境内销售收取人民币，这是最基本的情况，不影响判断。
选项A、B、C分别涉及境外销售、境外采购、境外融资，都是影响因素。

**答案：** D

### 2.2 外币货币性项目的汇兑差额计算

**题目：**
计算分析题——甲公司以人民币为记账本位币，采用当日即期汇率对外币业务进行折算。2024年12月有关业务如下：

（1）12月1日，赊销商品给境外客户，货款1,000,000美元，当日即期汇率1美元=7.1人民币元，12月31日即期汇率1美元=7.2人民币元。
（2）12月1日，从银行借入美元借款5,000,000美元，年利率6%，当日即期汇率1美元=7.1人民币元，12月31日即期汇率1美元=7.2人民币元。

要求：计算甲公司12月份应确认的汇兑差额，并编制相关分录。

**解析：**

**第一步：识别货币性项目**
- 应收账款（美元）：货币性资产
- 短期借款（美元）：货币性负债

**第二步：计算汇兑差额**

**应收账款（资产，汇率上升→收益）：**
- 12月1日折算金额：1,000,000 × 7.1 = 7,100,000元
- 12月31日账面金额：1,000,000 × 7.2 = 7,200,000元
- 汇兑差额 = 7,200,000 - 7,100,000 = +100,000元（收益）

**短期借款（负债，汇率上升→损失）：**
- 12月1日折算金额：5,000,000 × 7.1 = 35,500,000元
- 12月31日账面金额：5,000,000 × 7.2 = 36,000,000元
- 汇兑差额 = 36,000,000 - 35,500,000 = +500,000元（损失）

**第三步：编制分录**
```
借：应收账款——美元       100,000
  贷：财务费用——汇兑差额   100,000

借：财务费用——汇兑差额   500,000
  贷：短期借款——美元      500,000
```

**答案：** 12月份应确认汇兑净损失400,000元（500,000-100,000）

### 2.3 外币财务报表折算

**题目：**
单选题——下列关于外币财务报表折算的表述中，正确的是（ ）

A. 资产和负债项目按交易发生日的即期汇率折算
B. 所有者权益项目中，只有"未分配利润"按期末汇率折算
C. 折算差额在合并利润表中确认
D. 处置境外经营时，处置境外经营的当期期末已确认的折算差额应转入当期损益

**解析：**
- A错误：资产和负债按**资产负债表日**即期汇率折算
- B错误：实收资本按**发生时的**即期汇率；未分配利润是倒算出来的平衡数
- C错误：折算差额计入**其他综合收益**，不在利润表确认
- D正确：处置时转入当期损益

**答案：** D

### 2.4 非货币性项目的处理

**题目：**
多选题——下列各项中，期末不需要按照期末即期汇率折算的有（ ）

A. 以历史成本计量的固定资产
B. 以公允价值计量且其变动计入当期损益的外币货币性金融资产
C. 以公允价值计量且其变动计入其他综合收益的外币非货币性项目
D. 存货

**解析：**
非货币性项目是否需要期末调整，取决于计量属性：
- **历史成本计量**（如固定资产）：不调整，按历史汇率保留
- **公允价值计量**（如交易性金融资产）：按期末汇率调整，公允价值变动+汇兑差额一并计入当期损益

选项A：固定资产按历史成本，不调整
选项B：交易性金融资产按公允价值，调整
选项C：其他权益工具投资等非货币性项目，按公允价值但汇兑差额计入其他综合收益，不调整汇率
选项D：存货按成本计量，不调整

**答案：** A、C

### 2.5 记账本位币变更

**题目：**
单选题——甲公司的记账本位币为人民币，2024年12月31日变更为美元。下列关于记账本位币变更的会计处理中，正确的是（ ）

A. 采用变更当日的即期汇率将所有项目折算，折算差额计入当期损益
B. 采用变更当日的即期汇率将所有项目折算，折算差额计入其他综合收益
C. 采用变更当日的即期汇率将所有项目折算，折算差额计入期初留存收益
D. 不进行会计处理，仅在附注中披露变更情况

**解析：**
记账本位币变更属于**会计政策变更**：
- 应当采用**变更当日的即期汇率**将所有项目折算
- 折算差额调整**期初留存收益**（其他综合收益）

**答案：** C

## 三、分录/计算模板

### 模板1：外币交易初始确认

```
借：银行存款/应收账款（外币金额 × 即期汇率）
  贷：主营业务收入/银行存款/应付账款
```

### 模板2：期末货币性项目调整

**货币性资产（汇率上升→收益）：**
```
借：应收账款——外币
    银行存款——外币
  贷：财务费用——汇兑差额
```

**货币性负债（汇率上升→损失）：**
```
借：财务费用——汇兑差额
  贷：应付账款——外币
      短期借款——外币
```

### 模板3：外币报表折算

| 项目 | 折算汇率 | 差额处理 |
|------|----------|----------|
| 资产、负债 | 期末即期汇率 | - |
| 收入、费用 | 交易发生日汇率（或近似汇率） | - |
| 实收资本 | 发生日汇率 | 差额→其他综合收益 |
| 外币报表折算差额 | - | →其他综合收益 |

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|-------|------|---------|
| 货币性 vs 非货币性 | 货币性：钱（现金、应收应付）；非货币性：物（存货、固定资产） | "钱"是流动的，"物"是固定的 |
| 汇率上升时资产/负债 | 资产汇率上升→收益；负债汇率上升→损失 | "欠债还钱"→欠的变多了，自己赚到了 |
| 报表折算 vs 交易折算 | 报表折算用期末汇率；交易确认用交易当日汇率 | "一年结束看总账"→期末汇率 |

## 五、速记口诀

**外币折算三步走：**
- 交易发生日：即期汇率记账
- 期末调整：货币性项目按期末汇率
- 汇兑差额：财务费用（或资产/负债）

**折算汇率记忆：**
- 资产负债看期末
- 收支利润看交易
- 实收资本看发行
- 差额计入其他综合
