# 财务报告 —— 第一性原理教程

## 一、财务报表概述

### 1.1 财务报表的构成

**一套完整的财务报表包括：**
1. 资产负债表
2. 利润表
3. 现金流量表
4. 所有者权益变动表
5. 财务报表附注

### 1.2 列报的基本要求

- 持续经营假设
- 权责发生制（除现金流量表外）
- 重要性原则
- 列报的一致性
- 可比性（列报项目不得随意变更）

---

## 二、资产负债表

### 2.1 结构

**资产 = 负债 + 所有者权益**

**分类：**
- 资产：流动资产 + 非流动资产
- 负债：流动负债 + 非流动负债
- 所有者权益

### 2.2 填列方法

| 填列方法 | 举例 |
|----------|------|
| 根据总账科目余额直接填列 | 短期借款、实收资本 |
| 根据明细科目余额计算填列 | 应收账款=应收账款借方余额+预收账款借方余额-坏账准备 |
| 根据总账科目余额计算填列 | 货币资金=库存现金+银行存款+其他货币资金 |
| 根据有关科目余额减去备抵科目后的净额填列 | 固定资产=固定资产-累计折旧-减值准备 |
| 综合运用上述方法 | 存货=原材料+库存商品+委托加工物资+...-存货跌价准备 |

---

## 三、利润表

### 3.1 结构（多步式）

```
营业收入
减：营业成本
    税金及附加
    销售费用
    管理费用
    财务费用
    资产减值损失
    信用减值损失
加：公允价值变动收益
    投资收益
    资产处置收益
    其他收益
= 营业利润
加：营业外收入
减：营业外支出
= 利润总额
减：所得税费用
= 净利润
加：其他综合收益税后净额
= 综合收益总额
```

## 四、现金流量表

### 4.1 现金流量的分类

| 类别 | 内容 | 典型项目 |
|------|------|----------|
| **经营活动** | 日常生产经营活动 | 销售商品收到的现金、支付职工薪酬 |
| **投资活动** | 长期资产的购建和处置 | 购建固定资产支付的现金、出售投资收到的现金 |
| **筹资活动** | 吸收投资和分配利润 | 吸收投资收到的现金、偿还借款支付的现金 |

### 4.2 编制方法

**直接法：** 按现金收入和现金支出的类别直接列示（正表使用）。

**间接法：** 从净利润出发，调节非现金项目后得出经营活动现金流量（补充资料使用）。

### 4.3 间接法调节项目

```
经营活动现金流量 = 净利润
  + 资产减值准备
  + 固定资产折旧/无形资产摊销
  + 处置固定资产等损失（-收益）
  + 财务费用
  + 投资损失（-收益）
  + 存货减少（-增加）
  + 经营性应收项目减少（-增加）
  + 经营性应付项目增加（-减少）
```

---

## 五、所有者权益变动表

反映构成所有者权益各组成部分当期的增减变动情况。

**至少应单独列示：**
- 会计政策变更和差错更正的累积影响
- 净利润
- 其他综合收益
- 所有者投入和减少资本
- 利润分配
- 所有者权益内部结转

---

## 六、财务报表附注披露

### 6.1 分部报告

**报告分部的确定：**
- 收入占所有分部收入合计10%以上
- 或利润（亏损）占所有盈利分部或亏损分部合计10%以上
- 或资产占所有分部资产合计10%以上

### 6.2 关联方披露

**关联方的认定：**
- 母公司和子公司
- 受同一方控制的企业
- 合营企业、联营企业
- 主要投资者个人及其关系密切的家庭成员
- 关键管理人员及其关系密切的家庭成员

**披露要求：** 关联方关系的性质、交易类型、交易金额和比例。

---

## 七、中期财务报告

### 7.1 定义

**中期财务报告**是指以中期（短于一个完整会计年度的报告期间）为基础编制的财务报告。

### 7.2 编制要求

- 采用与年度财务报告一致的会计政策
- 重要性程度的判断应以中期的财务数据为基础
- 中期发生的会计政策变更按相关规定处理

---

## 考试要点总结

1. **资产负债表填列**：重点关注综合计算的项目
2. **现金流量分类**：经营/投资/筹资三大类
3. **间接法调节**：净利润→经营活动现金流量的调节项目
4. **关联方披露**：关联方的认定和披露要求
5. **分部报告**：10%重要性测试
