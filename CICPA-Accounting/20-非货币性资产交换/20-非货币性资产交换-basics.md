# 非货币性资产交换 —— 第一性原理教程

## 一、非货币性资产交换的概念

### 1.1 定义

**非货币性资产交换**是指企业主要以固定资产、无形资产、投资性房地产和长期股权投资等非货币性资产进行的交换。

### 1.2 货币性资产 vs 非货币性资产

| 类型 | 定义 | 举例 |
|------|------|------|
| 货币性资产 | 固定或可确定金额的资产 | 现金、银行存款、应收账款 |
| 非货币性资产 | 金额不固定的资产 | 存货、固定资产、无形资产、长期股权投资 |

### 1.3 判断标准

**25%测试：**
```
补价占整个资产交换金额的比例 ≤ 25% → 非货币性资产交换
补价占整个资产交换金额的比例 > 25% → 视为货币性交易
```

## 二、确认与计量

### 2.1 计量基础的选择

| 条件 | 计量基础 |
|------|----------|
| 同时满足两个条件 | **以公允价值为基础计量** |
| 不满足 | **以账面价值为基础计量** |

**公允价值计量的两个条件：**
1. 该项交换具有**商业实质**
2. 换入资产或换出资产的公允价值能够**可靠计量**

### 2.2 商业实质的判断

满足下列条件之一即具有商业实质：
1. 换入资产与换出资产的**未来现金流量**在风险、时间分布或金额方面**显著不同**
2. 换入资产与换出资产的预计未来现金流量现值**不同**，且其差额与公允价值相比是**重大**的

**关联方之间的交换**通常不具有商业实质。

## 三、会计处理

### 3.1 以公允价值计量

```
换入资产成本 = 换出资产的公允价值 + 支付的补价（-收到的补价）+ 相关税费

交换损益 = 换出资产的公允价值 - 换出资产的账面价值
```

**会计处理：**
```
借：换入资产（公允价值）
    资产减值准备/累计折旧等
  贷：换出资产（账面余额）
      银行存款（补价/税费）
      资产处置损益（差额，可能在借方）
```

### 3.2 以账面价值计量

```
换入资产成本 = 换出资产的账面价值 + 支付的补价（-收到的补价）+ 相关税费
```

**不确认交换损益。**

### 3.3 涉及多项资产的处理

**公允价值计量：**
1. 先确定换入资产的总成本（换出资产公允价值±补价+税费）
2. 按各项换入资产公允价值的比例分配总成本

**账面价值计量：**
1. 先确定换入资产的总成本（换出资产账面价值±补价+税费）
2. 按各项换入资产公允价值的比例分配（如公允价值能可靠计量），否则按账面价值比例分配

---

## 考试要点总结

1. **25%测试**：判断是否属于非货币性资产交换
2. **计量基础**：公允价值（有商业实质+公允可靠）vs 账面价值
3. **商业实质**：现金流显著不同或现值差额重大
4. **公允价值计量确认损益**，账面价值计量不确认损益
5. **多项资产**：先算总成本再按比例分配
