# 每股收益 —— 第一性原理教程

## 一、基本概念

**每股收益(EPS)**是反映企业普通股股东每持有一股所能享有的企业利润或承担的亏损。

---

## 二、基本每股收益

### 2.1 计算公式

```
基本每股收益 = 归属于普通股股东的净利润 ÷ 发行在外普通股的加权平均数
```

### 2.2 加权平均数的计算

```
加权平均数 = 期初发行在外股数
           + 当期新发行股数 × 已发行时间/报告期时间
           - 当期回购股数 × 已回购时间/报告期时间
```

---

## 三、稀释每股收益

### 3.1 核心原理

**假设所有潜在普通股都已转换为普通股**，重新计算每股收益。如果稀释后EPS下降，则具有稀释性。

### 3.2 各种潜在普通股的处理

**可转换公司债券：**
```
稀释EPS = (净利润 + 可转债税后利息费用) ÷ (加权平均股数 + 转股增加的股数)
```

**认股权证/股份期权：**
```
增加的股数 = 拟行权股数 - (行权价格 × 拟行权股数) ÷ 当期平均股价
```
（无对价股份，即"免费"增加的股数）

**限制性股票：**
- 未解锁的限制性股票视同已发行
- 根据解锁条件分别处理

### 3.3 反稀释性判断

如果某潜在普通股转换为普通股会增加每股收益或减少每股亏损 → **不具有稀释性**，不纳入稀释EPS计算。

---

## 四、每股收益的列报

### 4.1 重新计算

**以下情形需要重新计算各列报期间的EPS：**
1. 派发股票股利
2. 公积金转增资本
3. 拆股或并股

```
重新计算后的EPS = 原EPS × 调整系数
```

**配股：**
```
调整系数 = 行权前每股公允价值 ÷ 每股理论除权价格

每股理论除权价格 = (行权前公允价值 + 配股收到款项) ÷ 配股后总股数
```

---

## 考试要点总结

1. **基本EPS** = 净利润 ÷ 加权平均股数
2. **稀释EPS**：假设所有潜在普通股都已转换
3. **可转债**：分子加回税后利息，分母加转换股数
4. **认股权证**：用"无对价股数"增加分母
5. **反稀释性**：增加EPS的不纳入计算
6. **重新计算**：股票股利/拆股/并股/配股需追溯调整
