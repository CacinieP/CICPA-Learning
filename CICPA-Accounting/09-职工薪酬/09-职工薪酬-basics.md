# 职工薪酬 —— 第一性原理教程

## 一、职工和职工薪酬的范围及分类

### 1.1 职工的范围

**职工**包括：
- 与企业订立劳动合同的全职/兼职/临时职工
- 未订立劳动合同但由企业正式任命的人员（如董事、监事）
- 在企业计划和控制下向企业提供服务的劳务用工

### 1.2 职工薪酬的分类

| 类别 | 说明 |
|------|------|
| 短期薪酬 | 一年内支付的薪酬（工资、奖金、社保、福利等） |
| 离职后福利 | 退休或离职后提供的薪酬（养老金、医疗等） |
| 辞退福利 | 解除劳动关系时给予的补偿 |
| 其他长期职工福利 | 超过一年的其他福利（长期带薪缺勤、长期残疾福利等） |

---

## 二、短期薪酬

### 2.1 货币性短期薪酬

**基本原则：** 根据职工提供服务受益对象，计入当期损益或相关资产成本。

```
借：生产成本 / 管理费用 / 销售费用 / 在建工程 等
  贷：应付职工薪酬——工资 / 奖金 / 津贴 等
```

**社保和公积金：**
- 企业承担部分：按受益对象计入相关成本费用
- 个人承担部分：从工资中代扣

### 2.2 带薪缺勤

**分类：**
| 类型 | 特征 | 会计处理 |
|------|------|----------|
| 累积带薪缺勤 | 可结转以后期间使用 | 期末按预计将使用的累积未使用权利金额确认 |
| 非累积带薪缺勤 | 不可结转 | 实际发生时确认 |

### 2.3 短期利润分享计划

**确认条件：**
1. 企业因过去事项而承担支付义务
2. 该义务金额能够可靠估计

### 2.4 非货币性福利

**常见形式及处理：**

| 形式 | 会计处理 |
|------|----------|
| 以自产产品发放 | 按公允价值确认收入，结转成本（视同销售） |
| 以外购商品发放 | 按购买价款确认 |
| 提供自有资产免费使用 | 按折旧金额确认费用 |
| 租赁资产免费提供 | 按租金确认费用 |
| 低于成本价出售 | 差额确认为职工薪酬 |

## 三、离职后福利

### 3.1 分类

| 类型 | 特征 |
|------|------|
| 设定提存计划 | 企业按固定金额缴存，投资风险由职工承担（如社保养老） |
| 设定受益计划 | 企业承诺未来支付确定金额，投资风险由企业承担 |

### 3.2 设定提存计划

**会计处理简单：** 缴存时按受益对象计入当期损益或资产成本。

### 3.3 设定受益计划

**会计处理步骤（复杂）：**

1. **确定义务**：精算确定设定受益义务的现值
2. **确定服务成本**：当期服务成本 + 过去服务成本
3. **确定净利息**：净负债/净资产 × 折现率
4. **重新计量**：精算利得/损失、计划资产回报、资产上限变动 → 计入**其他综合收益**

```
借：当期服务成本 → 管理费用/生产成本 等
    利息费用     → 财务费用
  贷：应付职工薪酬

借/贷：其他综合收益（精算利得/损失）
  贷/借：应付职工薪酬
```

---

## 四、辞退福利

### 4.1 确认条件

同时满足：
1. 企业已制定正式的解除劳动关系计划或提出自愿裁减建议
2. 该计划或建议即将实施（年内）
3. 企业不能单方面撤回

### 4.2 会计处理

**一律计入管理费用**（不论职工原属哪个部门）：

```
借：管理费用
  贷：应付职工薪酬——辞退福利
```

### 4.3 计量

- 在可行权日之后12个月内支付的 → 短期薪酬计量
- 超过12个月支付的 → 折现后确认（选择同期限国债利率折现）

---

## 五、其他长期职工福利

包括长期带薪缺勤、长期残疾福利、长期利润分享计划等。

**会计处理：** 类似设定受益计划，但重新计量产生的变动计入**当期损益**（而非其他综合收益）。

---

## 考试要点总结

1. **职工范围**：不仅限于签订劳动合同的员工
2. **非货币性福利**：自产产品发放视同销售
3. **设定受益计划**：重新计量计入其他综合收益
4. **辞退福利**：一律计入管理费用
5. **其他长期职工福利 vs 设定受益计划**：重新计量的处理不同
