# 债务重组 —— 综合实战

## 一、综合题解题框架

### 债务重组综合题标准化步骤

```
步骤1：识别重组方式
       ↓
步骤2：确定债务账面价值与实际支付/转让/转换金额
       ↓
步骤3：计算差额，判断归属
       ↓
步骤4：编制正确分录
```

### 混合重组处理原则

当存在多种重组方式组合时，按**各组成部分的公允价值比例**分配债务账面价值，分别处理。

## 二、跨章联动图谱

本章与其他章节的关联考点：

> 🔗 跨科联动：
> - 与**所得税**联动：债务重组利得/损失的所得税影响，递延所得税资产/负债
> - 与**长期股权投资**联动：债权人以债转股方式取得子公司股权
> - 与**或有事项**联动：债务重组协议中的或有应付/应收金额处理

## 三、陷阱与反套路

### 陷阱1：混淆债务人"投资收益"与"资产处置损益"

**典型错误：** 债务人以存货抵债时，将债务账面价值与存货公允价值的差额全部计入投资收益

**正确理解：**
1. 债务账面价值与存货账面价值的差额 → 债务重组利得
2. 存货公允价值与账面价值的差额 → 资产处置损益（正常出售逻辑）

### 陷阱2：债权人受让多项资产时忘记分配

**典型错误：** 债权人按各项资产的账面价值比例分配放弃债权公允价值

**正确理解：** 应按**公允价值比例**分配，而非账面价值比例

### 陷阱3：忽略债务重组的"不改变交易对手方"前提

**典型错误：** 将"发行债券偿还债务"认定为债务重组

**正确理解：** 新债权人（新购买债券的人）与原债务人没有直接债务关系，不属于债务重组

## 四、真题变式推演

### 变式1：混合重组方式

**题目：**
甲公司应收乙公司账款1,200万元，乙公司以现金600万元和公允价值300万元的设备偿还，设备账面价值250万元。甲公司已计提坏账准备80万元。

要求：编制甲公司和乙公司的会计分录。

**解题步骤：**
1. 现金部分：600万元
2. 设备部分：公允价值300万元
3. 债务账面价值：1,200万元
4. 剩余债务：1,200 - 600 - 300 = 300万元（假设300万为将债务转为权益的部分）

**乙公司（债务人）：**
```
借：应付账款                    12,000,000
  贷：银行存款                  6,000,000
      固定资产清理              2,500,000
      股本等（300万部分）       3,000,000（示例）
      投资收益                    500,000
      资产处置损益（300-250）    500,000
```

**甲公司（债权人）：**
```
借：银行存款                  6,000,000
    固定资产等                3,000,000
    长期股权投资等            3,000,000（示例）
    投资收益                   200,000（差额）
  贷：应收账款                12,000,000
      坏账准备                   200,000
```

### 变式2：与差错更正结合

**题目：**
甲公司2024年1月发现2023年12月进行的一笔债务重组业务处理有误：原作为债务重组损失处理的200万元，实际应区分100万元为坏账损失、100万元为债务重组损失。该差错于2024年发现，甲公司按10%计提盈余公积。

要求：编制差错更正分录。

**解题步骤：**
1. 判断差错性质：属于前期重大差错
2. 采用追溯重述法

```
借：以前年度损益调整          1,000,000
  贷：坏账准备                1,000,000

借：盈余公积                    100,000
    利润分配——未分配利润      900,000
  贷：以前年度损益调整        1,000,000
```

### 变式3：与长期股权投资结合

**题目：**
甲公司应收乙公司（甲公司的子公司）账款800万元，因乙公司资金困难，双方达成债务重组协议：乙公司以100万股普通股抵债。甲公司按权益法核算对乙公司的投资，重组日甲公司"长期股权投资——乙公司"账面余额为2,000万元（持股80%），乙公司股本为1,000万元。

要求：分析合并报表层面的处理，并编制相关抵消分录。

**解题步骤：**
1. 个别报表：按放弃债权公允价值确认长期股权投资
2. 合并报表层面：母公司与子公司之间的债务重组，在合并工作底稿中进行抵消
3. 确认少数股东损益影响

## 五、实务衔接

### 债务重组在破产重整中的应用

在企业破产重整实务中，债务重组是常见的债务化解手段：

1. **削债**：债权人减免部分债务本金或利息
2. **展期**：延长债务偿还期限
3. **债转股**：将债权转为对债务人的股权投资

**会计处理要点：**
- 债务人应确认债务重组利得，计入当期损益
- 如涉及税务处理，注意债务重组所得的所得税递延问题
- 债转股需关注股权公允价值的确定方法

## 六、速记总结

| 情形 | 债务人处理 | 债权人处理 |
|------|-----------|-----------|
| 现金清偿 | 差额→投资收益 | 差额→投资收益 |
| 非现金清偿 | 资产视同出售，债务账面与资产账面差额→投资收益 | 放弃债权公允价值入账 |
| 债转股 | 贷记"股本+资本公积" | 放弃债权公允价值确认长投 |
| 修改条款 | 修改后债务公允价值<原账面→差额投资收益 | 按修改后公允价值确认新债权 |

**核心口诀：**
- 债务人：差额全进"投资收益"
- 债权人：公允入账，差额进损
- 多项资产：公允比例分配
