# 债务重组 —— 第一性原理教程

## 一、债务重组的定义和方式

### 1.1 定义

**债务重组**是指在不改变交易对手方的情况下，经债权人和债务人协定或法院裁定，就清偿债务的时间、金额或方式等重新达成协议的交易。

### 1.2 方式

1. 以资产清偿债务（现金/非现金资产）
2. 将债务转为权益工具
3. 修改其他条款（减少本金、降低利率、延长还款期等）
4. 以上三种方式的组合

---

## 二、债务重组的会计处理

### 2.1 以现金清偿债务

**债务人：**
```
借：应付账款（账面余额）
  贷：银行存款（实际支付金额）
      投资收益（差额=债务账面价值-支付金额）
```

**债权人：**
```
借：银行存款（收到金额）
    投资收益（差额=债权账面价值-收到金额）
  贷：应收账款（账面余额）
```

### 2.2 以非现金资产清偿债务

**债务人：**
- 终止确认债务
- 按所清偿债务账面价值与转让资产账面价值之间的差额确认损益
- 资产本身视同处置（公允价值与账面价值的差额确认资产处置损益）

**债权人：**
- 按放弃债权的**公允价值**作为受让资产的初始确认金额

### 2.3 将债务转为权益工具

**债务人：**
```
借：应付账款（账面余额）
  贷：股本（面值）
      资本公积——股本溢价（差额）
```

**债权人：**
```
借：长期股权投资等（放弃债权的公允价值）
  贷：应收账款（账面余额）
      投资收益（差额，可能在借方）
```

### 2.4 修改其他条款

**债务人：**
- 修改后债务的公允价值 < 原债务账面价值 → 差额确认**投资收益**
- 修改后条款中的实际利率需要重新计算

**债权人：**
- 按修改后债权的公允价值确认新债权
- 差额确认投资收益

### 2.5 组合方式

按各组成部分分别处理，总体差额计入当期损益。

---

## 三、债务重组的披露

**债务人应披露：**
- 债务重组方式
- 确认的债务重组利得总额
- 或有应付/应收金额

**债权人应披露：**
- 债务重组方式
- 确认的债务重组损失总额
- 或有应收金额

---

## 考试要点总结

1. **不改变交易对手方**是债务重组的前提
2. **四种方式**：现金、非现金、转股、修改条款
3. **债务人**：债务账面价值与支付/转让/转股金额的差额计入投资收益
4. **债权人**：按放弃债权的公允价值确认受让资产
