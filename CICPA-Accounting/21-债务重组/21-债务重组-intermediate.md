# 债务重组 —— 典型考题解析

## 一、核心考法分类

本章在历年真题中的主要考法归纳如下：

1. **债务重组方式识别**（选择题高频）：判断属于哪种重组方式
2. **债务人会计处理**（计算分析题）：确认债务重组利得/损失
3. **债权人会计处理**（计算分析题）：受让资产的入账价值确定
4. **混合重组方式**（综合题）：组合方式下各类资产的分别处理

## 二、典型例题解析

### 2.1 债务重组方式判断

**题目：**
单选题——下列各项中，不属于债务重组方式的是（ ）

A. 债务人以低于债务账面价值的现金清偿债务
B. 债务人以公允价值低于债务账面价值的存货清偿债务
C. 债务人将债务转为权益工具
D. 债务人发行可转换公司债券

**解析：**
债务重组的核心是"不改变交易对手方"，重组方式包括：
- 以资产清偿债务（现金/非现金资产）
- 将债务转为权益工具
- 修改其他条款
- 上述方式组合

选项D"发行可转换公司债券"属于正常融资行为，并非与原债权人重新达成协议，不属于债务重组。

**答案：** D

### 2.2 以现金清偿债务的会计处理

**题目：**
计算分析题——甲公司2024年1月1日应收乙公司账款余额为500万元，因乙公司财务困难无法偿还，双方达成债务重组协议：乙公司以银行存款400万元清偿该债务。不考虑相关税费。

要求：分别编制甲公司（债权人）和乙公司（债务人）的会计分录。

**解析：**

**债务人（乙公司）会计处理：**
- 债务账面价值：500万元
- 实际支付金额：400万元
- 差额100万元 → 计入"投资收益"（债务重组利得）

```
借：应付账款                    5,000,000
  贷：银行存款                  4,000,000
      投资收益——债务重组利得   1,000,000
```

**债权人（甲公司）会计处理：**
- 债权账面价值：500万元
- 收到金额：400万元
- 差额100万元 → 计入"投资收益"（债务重组损失）

```
借：银行存款                    4,000,000
    投资收益——债务重组损失     1,000,000
  贷：应收账款                  5,000,000
```

**答案：** 详见上述分录

### 2.3 以非现金资产清偿债务

**题目：**
多选题——关于债务人以非现金资产清偿债务的会计处理，下列说法正确的有（ ）

A. 债务人应按所清偿债务的账面价值与转让资产账面价值之间的差额确认为债务重组利得
B. 债务人转让的非现金资产公允价值与其账面价值之间的差额，应确认为资产处置损益
C. 债权人应按放弃债权的账面价值作为受让资产的初始确认金额
D. 债权人受让多项非现金资产的，应按各项资产的公允价值比例对放弃债权的公允价值进行分配

**解析：**
根据债务重组准则：
- A正确：差额确认债务重组利得
- B正确：非现金资产视同正常出售处理
- C错误：债权人按放弃债权的**公允价值**入账，而非账面价值
- D正确：多项资产按公允价值比例分配

**答案：** A、B、D

### 2.4 将债务转为权益工具

**题目：**
计算分析题——甲公司应收乙公司账款800万元，乙公司无力偿还，经协商将债务转为乙公司100万股普通股（面值1元/股）。债务重组日乙公司股票的公允价值为6元/股。假定不考虑相关税费。

要求：编制甲公司和乙公司的会计分录。

**解析：**

**债务人（乙公司）处理：**
- 债务账面价值：800万元
- 发行股份的面值：100万元
- 股本溢价：700万元

```
借：应付账款                    8,000,000
  贷：股本                      1,000,000
      资本公积——股本溢价       7,000,000
```

**债权人（甲公司）处理：**
- 放弃债权的公允价值：100万股 × 6元 = 600万元
- 差额200万元计入投资收益

```
借：长期股权投资                6,000,000
    投资收益                   2,000,000
  贷：应收账款                  8,000,000
```

### 2.5 修改债务条款的会计处理

**题目：**
单选题——2024年3月1日，甲公司应收乙公司货款1,000万元，因乙公司资金周转困难，双方达成修改债务条款协议：原债务延期1年，利率降低。重组日修改后的债务公允价值为900万元。甲公司已计提坏账准备50万元。甲公司应确认的投资收益为（ ）万元。

A. 50
B. 100
C. 150
D. 0

**解析：**
- 债权账面价值：1,000 - 50 = 950万元
- 修改后债务公允价值：900万元
- 差额：950 - 900 = 50万元
- 债权人应确认的投资收益 = 50万元

**答案：** A

## 三、分录/计算模板

### 模板1：以现金清偿债务

**债务人：**
```
借：应付账款（账面余额）
  贷：银行存款（实际支付）
      投资收益（差额，确认利得）
```

**债权人：**
```
借：银行存款（收到）
    坏账准备（如有）
    投资收益（差额，确认损失）
  贷：应收账款（账面余额）
```

### 模板2：以非现金资产清偿债务

**债务人：**
```
借：应付账款
  贷：银行存款/相关资产
      资产处置损益（资产公允价值与账面价值差额）
      投资收益（债务账面价值与资产账面价值差额）
```

**债权人：**
```
借：相关资产（放弃债权公允价值）
    坏账准备
    投资收益
  贷：应收账款
```

### 模板3：债务转权益

**债务人：**
```
借：应付账款
  贷：股本（面值）
      资本公积——股本溢价
```

**债权人：**
```
借：长期股权投资（放弃债权公允价值）
  贷：应收账款
      投资收益（借或贷）
```

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|-------|------|---------|
| 债务重组利得 vs 资产处置损益 | 债务重组利得是"债务"消失产生的；资产处置损益是"资产"转让产生的 | 债务的账本 vs 资产的账本 |
| 债权人放弃债权公允价值 vs 账面价值 | 公允价值是"买价"，账面价值是"原值" | "新官上任三把火"→公允价值是新入账基础 |
| 现金清偿 vs 修改条款 | 现金清偿是"真金白银"支付；修改条款是"记账"变化 | 有现金流出 vs 无现金流出 |

## 五、速记口诀

**债务重组四方式：**
- 现金一锤定音
- 非现金卖了算账
- 转股股本增加
- 改条延期减息

**债权人入账要诀：**
- 放弃债权看公允
- 多项资产按比分
- 差额进损益
