# 长期股权投资与合营安排 —— 典型考题解析

## 一、核心考法分类

| 考法 | 题型 | 频率 |
|------|------|------|
| 初始投资成本计算 | 单选/计算 | ★★★★★ |
| 权益法下投资收益确认 | 单选/计算/综合 | ★★★★★ |
| 成本法转权益法（因持股比例下降） | 综合 | ★★★★★ |
| 公允价值计量转权益法 | 计算/综合 | ★★★★ |

## 二、典型例题解析

### 2.1 同一控制下企业合并取得长期股权投资

**题目：** 甲公司为同一集团内子公司，2026年1月1日以银行存款5000万元和一项账面价值3000万元（公允价值3500万元）的固定资产为对价，取得集团内乙公司80%股权。乙公司在最终控制方合并报表中的净资产账面价值为8000万元。此前集团未曾从外部购买乙公司。求初始投资成本及差额处理。

**解析：**
- 同一控制下企业合并，初始投资成本 = 被合并方在最终控制方合并报表中的净资产账面价值 × 持股比例
- 初始投资成本 = 8000 × 80% = 6400万元
- 合并对价的账面价值 = 5000 + 3000 = 8000万元
- 差额 = 6400 - 8000 = -1600万元（贷差），调整资本公积（资本溢价/股本溢价）

**答案：**
```
借：长期股权投资  6400
    资本公积——资本溢价  1600
  贷：银行存款  5000
      固定资产清理  3000
```

### 2.2 非同一控制下企业合并——可辨认净资产公允价值调整

**题目：** 甲公司以6000万元现金购买乙公司70%股权（非同一控制）。购买日乙公司可辨认净资产公允价值为7000万元，账面价值为6500万元，差异来自一项尚可使用10年的固定资产（公允价值高于账面价值500万元）。求商誉金额及购买日抵销分录。

**解析：**
- 合并成本 = 6000万元
- 可辨认净资产公允价值份额 = 7000 × 70% = 4900万元
- 商誉 = 6000 - 4900 = 1100万元

**答案：**
购买日抵销分录：
```
借：固定资产  500
  贷：资本公积  500

借：净资产（乙公司，公允价值）  7000
    商誉  1100
  贷：长期股权投资  6000
      少数股东权益  2100
```

### 2.3 权益法——投资收益的确认

**题目：** 甲公司2026年1月1日以4000万元取得乙公司30%股权，能够施加重大影响。2026年乙公司实现净利润2000万元。投资日乙公司可辨认净资产公允价值为12000万元，账面价值为11000万元，差异来自一项尚可使用5年的管理用固定资产。求甲公司2026年应确认的投资收益。

**解析：**
- 固定资产公允价值与账面价值差异 = 12000 - 11000 = 1000万元
- 每年多提折旧 = 1000 / 5 = 200万元
- 调整后净利润 = 2000 - 200 = 1800万元
- 投资收益 = 1800 × 30% = 540万元

**答案：**
```
借：长期股权投资——损益调整  540
  贷：投资收益  540
```

### 2.4 逆流交易未实现内部交易损益

**题目：** 甲持有乙30%股权（权益法）。2026年乙公司向甲公司销售商品，售价600万元，成本400万元。甲公司当年未将该商品对外出售。乙公司2026年实现净利润1500万元。求甲公司2026年应确认的投资收益。

**解析：**
- 未实现内部交易损益 = 600 - 400 = 200万元
- 应抵减的投资收益 = 200 × 30% = 60万元
- 调整后投资收益 = (1500 - 200) × 30% = 390万元

**答案：**
```
借：长期股权投资——损益调整  390
  贷：投资收益  390
```
如果甲公司后续将该商品全部对外出售，则未实现损益已实现，应补确认60万元投资收益。

### 2.5 成本法转权益法（丧失控制权）

**题目：** 甲公司持有乙公司80%股权（成本法），账面价值8000万元。2026年甲公司出售乙公司50%股权（即总股权的50%），取得价款7000万元。剩余30%股权公允价值为4200万元。出售日乙公司可辨认净资产公允价值为13000万元。求确认的投资收益。

**解析：**
- 丧失控制权，剩余股权按公允价值重新计量
- 处置收益 = 处置价款 + 剩余股权公允价值 - 原持股比例对应的可辨认净资产份额
- 处置收益 = 7000 + 4200 - 8000（原投资账面价值）= 3200万元
- 但更准确的做法：
  - 处置50%的投资账面价值 = 8000 × 50/80 = 5000万元
  - 处置部分收益 = 7000 - 5000 = 2000万元
  - 剩余30%股权按公允价值重新计量：4200万元
  - 剩余股权原账面价值 = 8000 - 5000 = 3000万元
  - 重新计量收益 = 4200 - 3000 = 1200万元
  - 合计投资收益 = 2000 + 1200 = 3200万元

**答案：**
```
借：银行存款  7000
  贷：长期股权投资  5000
      投资收益  2000

借：长期股权投资  1200
  贷：投资收益  1200
```

## 三、分录模板

### 3.1 成本法核算

```
// 初始确认（同一控制）
借：长期股权投资  [被合并方净资产账面价值 × 持股比例]
    资本公积（差额，或在借方）
  贷：银行存款/股本/固定资产清理等  [对价账面价值]

// 宣告分配现金股利
借：应收股利
  贷：投资收益
```

### 3.2 权益法核算

```
// 初始投资成本调整（负商誉）
借：长期股权投资——投资成本
  贷：营业外收入  [被投资方可辨认净资产公允价值份额 - 初始投资成本]

// 确认投资收益
借：长期股权投资——损益调整
  贷：投资收益  [调整后净利润 × 持股比例]

// 确认其他综合收益
借：长期股权投资——其他综合收益
  贷：其他综合收益

// 宣告分配现金股利
借：应收股利
  贷：长期股权投资——损益调整
```

### 3.3 转换核心规则

| 转换类型 | 核心处理 |
|----------|----------|
| 公允价值→权益法 | 原公允价值+新增对价=初始投资成本，比较可辨认净资产公允价值份额 |
| 权益法→公允价值 | 公允价值与账面价值差额计入投资收益 |
| 成本法→权益法（降） | 追溯调整：视同自始采用权益法 |
| 公允价值/权益法→成本法 | 以原股权账面价值/公允价值+新增对价作为初始成本 |
| 成本法→公允价值（丧失控制） | 剩余股权按公允价值重新计量，差额计入投资收益 |

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|-------|------|----------|
| 同一控制 vs 非同一控制初始计量 | 同一控制用账面价值，非同一控制用公允价值 | "同账非公" |
| 成本法 vs 权益法确认投资收益时点 | 成本法在宣告分配时确认；权益法在实现利润时确认 | "成本等宣告，权益跟着赚" |
| 顺流交易 vs 逆流交易 | 顺流：投资方向被投资方卖；逆流：被投资方向投资方卖。权益法下均需抵减未实现损益 | "都是未实现，方向不重要，持股比例乘" |
| 因追加投资导致公允价值→权益法 vs 成本法 | 前者无需追溯调整；后者（多次交易分步实现同一控制合并）需追溯调整 | "公允转权不追溯，成本转权要追溯" |
| 丧失控制权 vs 未丧失控制权处置 | 丧失控制：剩余股权重新计量，确认投资收益；未丧失控制：差额调资本公积 | "丧失控权进损益，未丧失进资本公积" |

## 五、速记口诀

- **"同账非公"**：同一控制看账面价值，非同一控制看公允价值
- **"权益三步曲"**：调成本（比较份额）→ 调利润（公允价值调整+未实现损益）→ 调其他
- **"成本法一句"**：初始按成本，后续只认宣告股利
- **"转换口诀"**：升股降投——持股比例上升看成本/公允，下降看权益法追溯
