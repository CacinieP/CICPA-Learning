# 长期股权投资与合营安排 —— 综合实战

## 一、综合题解题框架

长期股权投资综合题通常组合以下考点：
1. **初始计量**（同一/非同一控制）
2. **后续计量**（权益法调整）
3. **转换**（因追加/减少投资）
4. **与合并报表结合**（内部交易抵销）

**解题步骤：**
```
Step 1: 判断控制/重大影响 → 确定核算方法
Step 2: 计算初始投资成本 → 比较份额确定是否调整
Step 3: 后续计量调整 → 公允价值差异摊销 + 未实现损益
Step 4: 转换处理 → 追溯/重新计量
Step 5: 合并层面 → 抵销分录（如涉及）
```

## 三、陷阱与反套路

### 陷阱1：混淆同一控制与非同一控制的初始计量

**陷阱表现：** 在非同一控制下使用被购买方可辨认净资产账面价值份额。
**正确做法：** 非同一控制下初始投资成本 = 支付对价的公允价值，不比较账面价值份额。

### 陷阱2：权益法初始投资成本调整遗漏

**陷阱表现：** 初始投资成本大于可辨认净资产公允价值份额时做营业外收入调整。
**正确做法：** 只有初始投资成本 **小于** 可辨认净资产公允价值份额时才调整（贷记营业外收入），大于时产生商誉隐含在投资成本中。

### 陷阱3：逆流交易未实现损益在合并报表的特殊处理

**陷阱表现：** 在个别报表中全额抵减投资收益。
**正确做法：** 个别报表中按持股比例抵减。但在编制合并报表时（投资方有子公司），还需在合并层面做额外调整：
```
借：长期股权投资（抵减额）
  贷：存货/固定资产等（未实现损益 × 持股比例）
```

### 陷阱4：多次交易分步实现同一控制合并的追溯

**陷阱表现：** 将原持股的公允价值直接加入新的对价。
**正确做法：** 在最终控制方合并报表中的净资产账面价值 × 总持股比例 = 合并日初始成本，原持股部分按合并日账面价值份额计算（而非原投资的账面价值或公允价值）。

### 陷阱5：丧失控制权但保留重大影响的追溯调整范围

**陷阱表现：** 只调整剩余股权而不追溯以前年度。
**正确做法：** 从成本法转为权益法，需要从最初取得投资日起追溯调整（假设一直采用权益法），调整期初留存收益和当期投资收益。

## 四、真题变式推演

### 变式1：多次交易分步实现非同一控制合并

**场景：** 甲公司先以2000万元取得乙公司20%股权（权益法，可辨认净资产公允价值9000万元）。一年后追加投资4500万元取得乙公司40%股权（此时乙可辨认净资产公允价值为10000万元，原20%股权公允价值为2500万元）。

**解题思路：**
- 合并成本 = 原股权公允价值 + 新增对价 = 2500 + 4500 = 7000万元
- 可辨认净资产公允价值份额 = 10000 × 60% = 6000万元
- 商誉 = 7000 - 6000 = 1000万元
- 原权益法下确认的其他综合收益/资本公积：在处置时或相关资产处置时转入损益

### 变式2：处置部分股权但通过其他方式维持控制

**场景：** 甲持有乙80%股权。甲与第三方签订一致行动协议，虽减持至45%但通过一致行动协议仍控制乙公司60%表决权。

**解题思路：**
- 控制权未丧失，仍按成本法核算
- 处置部分股权的差额计入资本公积
- 关键判断：是否仍控制 → 看表决权+协议安排

### 变式3：权益法下被投资方其他综合收益变动

**场景：** 甲持有乙30%股权（权益法）。乙公司将一栋投资性房地产从成本模式转为公允价值模式，产生其他综合收益500万元。

**解题思路：**
```
借：长期股权投资——其他综合收益  150（500×30%）
  贷：其他综合收益  150
```
处置投资时，该其他综合收益按比例转入当期投资收益（或留存收益，取决于性质）。

## 五、实务衔接

在实务中，长期股权投资的典型场景：
- **战略投资**：企业出于产业链整合目的进行的股权投资
- **估值挑战**：非上市公司的可辨认净资产公允价值确定需要估值专家介入
- **控制判断**：需综合考虑表决权、董事会席位、一致行动协议等，而非仅看持股比例
- **商誉减值**：非同一控制合并形成的商誉每年需进行减值测试

## 六、速记总结

```
长投核心框架：
├── 控制(>50%) → 成本法 → 个别报表只认股利
├── 共同控制/重大影响(20%-50%) → 权益法 → 三步调整
│   ├── 步骤1：初始成本比较
│   ├── 步骤2：净利润调整（公允差异+未实现损益）
│   └── 步骤3：其他权益变动
├── 转换六种路径
│   ├── 升：公允→权益 / 公允/权益→成本
│   └── 降：成本→权益 / 权益→公允 / 成本→公允
└── 合营安排
    ├── 合营企业（净资产法）→ 权益法
    └── 共同经营（直接确认资产/负债/收入/费用）
```
