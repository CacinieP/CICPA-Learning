# 长期股权投资与合营安排 —— 第一性原理教程

## 一、基本概念

### 1.1 股权投资的分类

企业持有的股权投资，根据投资方对被投资方的影响程度，分为四种类型：

| 类型 | 影响程度 | 典型持股比例 | 会计处理 |
|------|----------|-------------|----------|
| 控制 | 控制被投资方 | >50%（实质判断） | 成本法（纳入合并报表） |
| 共同控制 | 与其他方共同控制 | 合营企业 | 权益法 |
| 重大影响 | 参与财务经营决策 | 20%~50%（实质判断） | 权益法 |
| 三无投资 | 无控制/共同控制/重大影响 | <20% | 金融工具准则（FVTPL或FVTOCI） |

### 1.2 关键概念区分

- **联营企业**：投资方对其具有重大影响的企业
- **合营企业**：投资方与其他合营方一同对其实施**共同控制**的企业
- **子公司**：投资方能够对其**控制**的企业
- **合营安排**：两项或多项约定的、由参与方共同控制的安排

## 二、长期股权投资的初始计量

### 2.1 企业合并形成的长期股权投资

**同一控制下企业合并：**

**核心原则：** 按照被合并方在最终控制方合并财务报表中的**净资产账面价值**的份额作为初始投资成本。

```
初始投资成本 = 被合并方在最终控制方合并报表中的净资产账面价值 × 持股比例
              + 最终控制方收购时形成的商誉（如有）
```

**差额处理：** 初始投资成本与支付对价账面价值的差额 → 调整**资本公积（股本溢价）**，不足冲减的调整**留存收益**。

**非同一控制下企业合并：**

**核心原则：** 按照支付对价的**公允价值**作为初始投资成本。

```
初始投资成本 = 支付对价的公允价值 + 直接相关费用
```

**注意：** 合并方发生的审计、法律服务、评估咨询等中介费用 → **管理费用**（不论同控还是非同控）。

### 2.2 非企业合并形成的长期股权投资

**核心原则：** 以支付对价的公允价值 + 直接相关费用作为初始投资成本。

## 三、长期股权投资的后续计量

### 3.1 成本法

**适用范围：** 投资方能够对被投资方实施**控制**的长期股权投资（个别报表中）。

**会计处理：**
- 初始确认后，账面价值**不随**被投资方净资产变动而变动
- 被投资方宣告分派现金股利时：借记"应收股利"，贷记"投资收益"
- 减值测试：发生减值时计提减值准备（不可转回）

### 3.2 权益法

**适用范围：** 对联营企业、合营企业的长期股权投资。

**核心原则：** 长期股权投资的账面价值随被投资方净资产的变动而**同方向**调整。

**初始投资成本的调整：**

```
比较：初始投资成本 vs 投资时享有被投资方可辨认净资产公允价值份额

若 初始投资成本 > 份额 → 商誉包含在投资成本中，不调整
若 初始投资成本 < 份额 → 差额计入当期损益（营业外收入），调整增加投资成本
```

**权益法下的后续调整：**

| 被投资方事项 | 投资方处理 |
|-------------|-----------|
| 实现净利润 | 借：长期股权投资——损益调整，贷：投资收益 |
| 发生净亏损 | 借：投资收益，贷：长期股权投资——损益调整（以账面价值减至零为限） |
| 宣告分派现金股利 | 借：应收股利，贷：长期股权投资——损益调整 |
| 其他综合收益变动 | 借/贷：长期股权投资——其他综合收益，贷/借：其他综合收益 |
| 其他权益变动 | 借/贷：长期股权投资——其他权益变动，贷/借：资本公积 |

**净利润调整（重要考点）：**

投资时被投资方资产公允价值与账面价值不同的，需要对被投资方净利润进行调整：

```
调整后净利润 = 账面净利润
             ± 固定资产/无形资产公允价值与账面价值差额的摊销
             ± 存货公允价值与账面价值差额的已实现部分
             - 未实现内部交易损益（顺流/逆流）
```

## 四、长期股权投资核算方法的转换及处置

### 4.1 核算方法的转换（五种情形）

| 转换情形 | 个别报表处理 |
|----------|-------------|
| 公允价值 → 权益法（5%→20%） | 公允价值作为初始投资成本；原持有其他综合收益转入当期损益/留存收益 |
| 公允价值 → 成本法（5%→60%） | 公允价值作为初始投资成本（非同控）；或按最终控制方账面价值份额（同控） |
| 权益法 → 成本法（20%→60%） | 账面价值作为初始投资成本 |
| 权益法 → 公允价值（20%→5%） | 公允价值与账面价值差额计入当期损益；原其他综合收益转入当期损益/留存收益 |
| 成本法 → 公允价值（60%→5%） | 公允价值与账面价值差额计入当期损益 |

**关键记忆点：**
- 增资时（比例增加）：个别报表不确认处置损益
- 减资时（比例减少）：公允价值与账面价值的差额计入投资收益

### 4.2 长期股权投资的处置

**处置损益 = 取得价款 - 长期股权投资账面价值**

权益法下还需结转：
- 原计入其他综合收益的金额 → 按处置比例转入当期损益
- 原计入资本公积的金额 → 按处置比例转入当期损益

## 五、合营安排

### 5.1 合营安排的认定

**合营安排的特征（必须同时具备）：**
1. 各参与方均受到该安排的约束
2. 两个或两个以上的参与方对该安排实施**共同控制**

**共同控制的判断：**
- 必须经过所有参与方一致同意才能决策 → 共同控制
- 只需一方同意即可决策 → 不是共同控制

### 5.2 合营安排的分类

| 类型 | 特征 | 典型形式 |
|------|------|----------|
| **共同经营** | 合营方享有各自份额的资产、承担各自份额的负债、费用 | 合作开发房地产项目 |
| **合营企业** | 合营方享有该安排的净资产（权益） | 设立独立的法人公司 |

**区分关键：** 合营方是对该安排的**单独资产和负债**享有权利（共同经营），还是对该安排的**净资产**享有权利（合营企业）。

### 5.3 共同经营的会计处理

合营方确认：
- 其**直接享有**的资产份额
- 其**直接承担**的负债份额
- 其**直接发生**的费用份额
- 出售共同经营产出份额产生的收入

---

## 考试要点总结

1. **四种影响程度**决定会计处理方式（控制/共同控制/重大影响/三无）
2. **同控 vs 非同控**：初始投资成本确定方式完全不同
3. **权益法**：投资成本调整、净利润调整、其他综合收益和其他权益变动的处理
4. **转换**：五种情形的个别报表处理，重点关注增资和减资的不同逻辑
5. **合营安排**：区分共同经营和合营企业
