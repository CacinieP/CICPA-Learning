# 04-无形资产：第一性原理教程

## 一、无形资产的本质认知

**第一性原理思考**：无形资产与固定资产的本质区别是什么？

固定资产是有形的物理资产（机器、厂房），无形资产是没有实物形态的可辨认非货币性资产（专利、商标、软件）。两者都是长期使用的资产，核心逻辑相同：**一次性投入，分期摊销**。

**无形资产的特征**：
- 由企业拥有或控制并能带来未来经济利益
- 不具有实物形态
- 具有可辨认性
- 属于非货币性资产

> **不可辨认的无形资产 = 商誉**，商誉不作为无形资产核算。

---

## 二、确认和初始计量

### 2.1 确认条件

1. 与该无形资产有关的经济利益**很可能**流入企业
2. 该无形资产的成本能够**可靠地计量**

### 2.2 初始计量

#### （1）外购无形资产

> **成本** = 购买价款 + 相关税费 + 直接归属于使该项资产达到预定用途所发生的其他支出

**分期付款购买**（具有融资性质）：
- 成本 = 购买价款的**现值**
- 差额确认为**未确认融资费用**

#### （2）投资者投入

按投资合同或协议约定的价值确定（不公允的除外）。

#### （3）土地使用权的处理

| 情形 | 处理 |
|------|------|
| 自用 | 确认为无形资产，单独摊销 |
| 房地产开发企业用于建造对外出售的房屋 | 计入所建造房屋的成本 |
| 企业外购房屋及建筑物 | 合理分配；确实无法分配的，全部作为固定资产 |
| 用于出租或资本增值 | 转为投资性房地产 |

## 三、内部研究开发支出（核心考点）

### 3.1 研究阶段与开发阶段的划分

**第一性原理**：研究开发活动分为两个阶段——"探索未知"（研究）和"将已知转化为产品"（开发）。

| 阶段 | 特征 | 会计处理 |
|------|------|---------|
| **研究阶段** | 探索性、计划性、较大的不确定性 | **全部费用化** → 管理费用 |
| **开发阶段** | 针对性、形成成果的可能性较大 | 满足条件**资本化**，不满足**费用化** |

### 3.2 开发阶段资本化的五个条件

必须**同时满足**以下条件才能资本化：

1. 完成该无形资产以使其能够使用或出售在**技术上具有可行性**
2. 具有完成该无形资产并使用或出售的**意图**
3. 无形资产产生经济利益的方式，证明存在**市场**或对企业**有用**
4. 有足够的技术、财务资源和其他资源支持，以完成该无形资产的开发
5. 归属于该无形资产开发阶段的支出能够**可靠地计量**

### 3.3 会计处理

```
（1）研究阶段支出
借：研发支出——费用化支出
    贷：原材料 / 银行存款 / 应付职工薪酬等

期末：
借：管理费用
    贷：研发支出——费用化支出

（2）开发阶段支出（满足资本化条件）
借：研发支出——资本化支出
    贷：原材料 / 银行存款 / 应付职工薪酬等

达到预定用途时：
借：无形资产
    贷：研发支出——资本化支出
```

> **注意**：无法区分研究阶段和开发阶段的支出，应当在发生时全部**费用化**，计入管理费用。

## 四、后续计量

### 4.1 摊销

**第一性原理**：无形资产的价值在使用过程中逐渐消耗，需要系统分摊到各期——即摊销。

#### 摊销范围

- 使用寿命**有限**的无形资产 → 应当摊销
- 使用寿命**不确定**的无形资产 → **不摊销**，但每年末进行减值测试

#### 摊销方法

根据与无形资产有关的经济利益的预期消耗方式选择：
- 直线法
- 产量法
- 其他方法（如类似加速折旧的方法）

#### 摊销起止时间

- **当月增加**：当月开始摊销
- **当月减少**：当月不再摊销

> 注意：与固定资产折旧不同！固定资产是"当月增加下月折旧"，无形资产是"当月增加当月摊销"。

#### 残值

- 一般为零
- 除非有第三方承诺在无形资产使用寿命结束时购买该无形资产
- 或根据活跃市场可以得到残值信息

#### 会计处理

```
借：制造费用 / 管理费用 / 其他业务成本等
    贷：累计摊销
```

### 4.2 减值

- 使用寿命有限的无形资产：出现减值迹象时进行减值测试
- 使用寿命不确定的无形资产：**每年末**必须进行减值测试

> **重要**：无形资产减值准备一经计提，不得转回。

```
借：资产减值损失
    贷：无形资产减值准备
```

### 4.3 使用寿命的复核

- 每年年末对使用寿命进行复核
- 如果使用寿命的预期发生变化 → 作为**会计估计变更**处理
- 如果原使用寿命不确定变为有限 → 作为**会计估计变更**处理

## 五、处置

### 5.1 出售（转让所有权）

```
借：银行存款
    累计摊销
    无形资产减值准备
    贷：无形资产
        应交税费——应交增值税（销项税额）
        资产处置损益 [差额，可能在借方]
```

### 5.2 出租（转让使用权）

```
（1）确认租金收入
借：银行存款
    贷：其他业务收入
        应交税费——应交增值税（销项税额）

（2）摊销成本
借：其他业务成本
    贷：累计摊销
```

### 5.3 报废

无形资产预期不能为企业带来经济利益时：
```
借：累计摊销
    无形资产减值准备
    营业外支出 [差额]
    贷：无形资产
```

## 六、列示与披露

- 资产负债表中"无形资产"项目 = 无形资产账面余额 - 累计摊销 - 无形资产减值准备
- 开发支出项目 = "研发支出——资本化支出"余额
- 披露摊销方法、使用寿命、减值等信息

---

## 考试要点总结

1. **研究阶段与开发阶段的划分**及不同处理是主观题高频考点
2. **开发支出资本化的五个条件**需牢记
3. **土地使用权**的不同处理是重要考点
4. 无形资产摊销的时间与固定资产折旧不同（当月增加当月摊销 vs 下月折旧）
5. 使用寿命不确定的无形资产**不摊销**但每年减值测试
6. 无形资产减值准备**不得转回**
7. 无法区分研究阶段和开发阶段的支出全部费用化
