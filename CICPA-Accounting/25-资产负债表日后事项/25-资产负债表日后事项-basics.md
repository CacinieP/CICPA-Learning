# 资产负债表日后事项 —— 第一性原理教程

## 一、概述

### 1.1 定义

**资产负债表日后事项**是指资产负债表日至财务报告批准报出日之间发生的有利或不利事项。

### 1.2 时间范围

```
资产负债表日（12月31日）──────→ 财务报告批准报出日
         资产负债表日后期间
```

### 1.3 分类

| 类型 | 定义 | 会计处理 |
|------|------|----------|
| **调整事项** | 对资产负债表日已存在的情况提供新的或进一步证据的事项 | 调整资产负债表日的报表 |
| **非调整事项** | 资产负债表日后才发生的事项 | 不调整，但需披露 |

---

## 二、调整事项的会计处理

### 2.1 常见调整事项

1. 资产负债表日后诉讼案件结案（法院判决与预计不同）
2. 资产负债表日后取得证据表明资产减值需要调整
3. 资产负债表日后发现财务报表舞弊或差错
4. 资产负债表日后进一步确定了购建资产的成本或售出资产的收入

### 2.2 处理方法

**调整资产负债表日的报表：**

```
1. 涉及损益的：
   借/贷：以前年度损益调整
     贷/借：相关科目

2. 调整所得税：
   借/贷：应交税费——应交所得税
     贷/借：以前年度损益调整

3. 结转以前年度损益调整：
   借/贷：以前年度损益调整
     贷/借：盈余公积
            利润分配——未分配利润

4. 调整报表相关项目数字
```

---

## 三、非调整事项的会计处理

### 3.1 常见非调整事项

1. 资产负债表日后发生重大诉讼、仲裁、承诺
2. 资产负债表日后资产价格、税收政策、外汇汇率发生重大变化
3. 资产负债表日后因自然灾害导致资产发生重大损失
4. 资产负债表日后发行股票和债券
5. 资产负债表日后资本公积转增资本
6. 资产负债表日后发生巨额亏损
7. 资产负债表日后发生企业合并或处置子公司
8. 资产负债表日后利润分配方案（股利分配）

### 3.2 处理方法

**不调整报表数字，但应当在附注中披露：**
- 事项的性质
- 事项的内容
- 对财务状况和经营成果的影响（如无法估计应说明原因）

---

## 考试要点总结

1. **区分关键**：事项在资产负债表日是否已存在
2. **调整事项**→调整报表数字
3. **非调整事项**→不调整但需披露
4. **利润分配方案**：宣告分配现金股利→调整事项（确认为负债）；股票股利→非调整事项
5. **以前年度损益调整**：调整事项涉及损益的过渡科目
