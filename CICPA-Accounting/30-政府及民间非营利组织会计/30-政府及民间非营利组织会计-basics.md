# 政府及民间非营利组织会计 —— 第一性原理教程

## 一、政府会计概述

### 1.1 标准体系

政府会计由**预算会计**和**财务会计**构成（"双体系"）。

### 1.2 核算模式

**双功能、双基础、双报告：**

| 维度 | 预算会计 | 财务会计 |
|------|----------|----------|
| 功能 | 反映预算执行情况 | 反映财务状况 |
| 基础 | 收付实现制 | 权责发生制 |
| 报告 | 预算会计报告 | 财务报告 |

### 1.3 会计要素

**财务会计要素：** 资产、负债、净资产、收入、费用

**预算会计要素：** 预算收入、预算支出、预算结余

## 二、政府单位特定业务的会计核算

### 2.1 财政拨款收支业务

**财政直接支付：**
```
借：行政支出/事业支出
  贷：财政拨款收入

同时：
借：行政支出/事业支出
  贷：财政拨款预算收入
```

**财政授权支付：**
```
收到额度：借：零余额账户用款额度，贷：财政拨款收入
使用额度：借：行政支出/事业支出，贷：零余额账户用款额度
```

### 2.2 预算管理一体化相关

- 资金支付通过预算管理一体化系统
- 实行全流程电子化管理

### 2.3 非财政拨款收支业务

**事业收入：** 开展专业业务活动取得的收入。

**上级补助收入：** 从主管部门和上级单位取得的非财政拨款收入。

### 2.4 预算结转结余及分配业务

- **财政拨款结转**：当年未使用完毕、需结转下年继续使用的财政拨款
- **财政拨款结余**：项目已完成或终止的财政拨款剩余
- **非财政拨款结转**：非财政专项资金的结转
- **非财政拨款结余**：非财政非专项资金的剩余

### 2.5 净资产业务

**累计盈余** = 期初累计盈余 + 本期收入 - 本期费用

### 2.6 资产业务

**固定资产：**
- 按成本初始计量
- 按月计提折旧（文物和陈列品、动植物、图书档案除外）

**无形资产：**
- 按成本初始计量
- 按月摊销（使用寿命不确定的不摊销）

### 2.7 负债业务

- 应缴财政款
- 应付职工薪酬
- 长期应付款

### 2.8 部门合并财务报表

政府部门编制合并财务报表，合并范围包括部门及所属单位。

## 三、民间非营利组织会计

### 3.1 概述

**特征：**
- 不以营利为目的
- 资源提供者不享有所有权
- 资源提供者不要求经济回报

**会计核算基础：** 权责发生制

### 3.2 特定业务核算

**捐赠收入：**
- 区分限定性收入和非限定性收入
- 如果限制在以后期间满足 → 限定性收入
- 限制在本期满足 → 非限定性收入

**会费收入：** 按权责发生制确认。

**政府补助收入：** 按用途区分限定性和非限定性。

**业务活动成本：** 直接用于项目的成本。

**管理费用：** 行政管理活动发生的费用。

### 3.3 财务报告

**包括：**
- 资产负债表
- 业务活动表
- 现金流量表
- 会计报表附注

---

## 考试要点总结

1. **双体系**：预算会计（收付实现制）+ 财务会计（权责发生制）
2. **双分录**：一项业务同时做财务会计和预算会计分录
3. **财政拨款**：区分直接支付和授权支付
4. **民间非营利**：区分限定性和非限定性收入
5. **净资产**：政府会计的累计盈余概念
