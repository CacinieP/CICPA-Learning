# 会计政策、会计估计及其变更和差错更正 —— 典型考题解析

## 一、核心考法分类

本章在历年真题中的主要考法归纳如下：

1. **会计政策与会计估计的区分**（单选题）：判断属于政策还是估计
2. **会计政策变更的处理**（计算分析题）：追溯调整法的应用
3. **会计估计变更的处理**（单选题）：未来适用法的应用
4. **前期差错的会计处理**（综合题）：追溯重述法的应用
5. **累积影响数的计算**（计算分析题）：追溯调整法下的影响数计算

## 二、典型例题解析

### 2.1 会计政策与会计估计的区分

**题目：**
单选题——下列各项中，属于会计政策变更的是（ ）

A. 固定资产折旧方法由年限平均法改为双倍余额递减法
B. 存货发出计价方法由先进先出法改为月末一次加权平均法
C. 坏账准备计提比例由3%改为5%
D. 投资性房地产后续计量由成本模式改为公允价值模式

**解析：**
判断原则：
- **会计政策**：涉及会计确认、计量基础或列报项目的**选择**
- **会计估计**：对不确定事项的**判断或估计**

| 选项 | 事项 | 分类 | 理由 |
|------|------|------|------|
| A | 折旧方法变更 | **会计估计变更** | 折旧方法是对资产使用寿命的估计方式 |
| B | 存货计价方法变更 | **会计政策变更** | 计价方法是会计确认/计量的基础选择 |
| C | 坏账计提比例变更 | **会计估计变更** | 比例是对应收款项可收回性的估计 |
| D | 投资性房地产计量模式变更 | **会计政策变更** | 计量模式是会计确认/计量的基础选择 |

**答案：** B、D

### 2.2 会计政策变更的追溯调整法

**题目：**
计算分析题——甲公司2024年1月1日起，将发出存货的计价方法由先进先出法（FIFO）改为月末一次加权平均法。假设：
- 变更日存货余额：1,000万元（按FIFO）
- 按加权平均法计算的存货余额：920万元
- 所得税税率25%，按10%提取盈余公积

要求：编制甲公司的会计政策变更处理分录。

**解析：**

**步骤1：计算累积影响数**
- 累积影响数 = 新政策计算的金额 - 原政策计算的金额
- 累积影响数 = 920 - 1,000 = -80万元（减少利润80万元）

**步骤2：编制调整分录**

```
借：利润分配——未分配利润    80
    递延所得税资产            20
  贷：存货                    80
      盈余公积                 8
      利润分配——未分配利润（其他转入） 12
```

等等，这里需要理清逻辑：

**正确分录：**
```
借：存货                      80（增加）
    递延所得税资产            20（25%×80）
  贷：利润分配——未分配利润  100（80÷75%）
```

但这是假设存货增加了80万。如果题目说按加权平均法计算的存货余额为920万（原1000万），则存货减少了80万：

**如果存货减少（原值1000→920）：**
```
借：利润分配——未分配利润    80
    递延所得税资产            20
  贷：存货                    80

借：盈余公积                   8
    利润分配——未分配利润    72
  贷：利润分配——未分配利润（调整） 80
```

**答案：**
```
借：盈余公积                   8
    利润分配——未分配利润    72
  贷：存货                    80

借：利润分配——未分配利润    80
  贷：递延所得税资产          20
```

或者更清晰地：
```
借：盈余公积                   8
  贷：利润分配——未分配利润    8
```
（调整期初报表时）

### 2.3 会计估计变更的未来适用法

**题目：**
单选题——2024年1月1日，甲公司将一项管理用固定资产的折旧年限由10年改为8年。该固定资产原值500万元，预计净残值为0，原折旧年限10年，已使用3年。假设按年限平均法计提折旧，变更当日，甲公司应（ ）

A. 将剩余折旧年限调整为5年，当年多提折旧100万元
B. 将剩余折旧年限调整为5年，当年按新折旧额计提折旧
C. 将剩余折旧年限调整为7年，当年多提折旧50万元
D. 将剩余折旧年限调整为7年，当年按新折旧额计提折旧

**解析：**

**变更前：**
- 年折旧额 = 500/10 = 50万元
- 已提折旧 = 50×3 = 150万元
- 账面价值 = 500 - 150 = 350万元

**变更后：**
- 尚可使用年限 = 8 - 3 = 5年
- 年折旧额 = 350/5 = 70万元

**当年影响：**
- 原折旧额 = 50万元
- 新折旧额 = 70万元
- 多提折旧 = 20万元

**答案：** B（将剩余折旧年限调整为5年，当年按新折旧额计提折旧）

### 2.4 前期重大差错的追溯重述

**题目：**
计算分析题——甲公司在2024年发现2023年漏记了一项固定资产的折旧300万元（属于重要差错），适用所得税税率25%，公司按10%提取盈余公积。2023年该固定资产未对外出售。

要求：编制差错更正分录。

**解析：**

**步骤1：补提折旧，影响所得税**
- 补提折旧300万元 → 减少2023年利润300万元
- 少计所得税 = 300×25% = 75万元
- 净利润影响 = 300 - 75 = 225万元

**步骤2：编制更正分录**
```
借：以前年度损益调整         300
  贷：累计折旧               300

借：应交税费——应交所得税    75
  贷：以前年度损益调整        75

借：盈余公积                  22.5
    利润分配——未分配利润   202.5
  贷：以前年度损益调整       225
```

**答案：** 详见上述分录

### 2.5 不属于会计政策变更的情形

**题目：**
多选题——下列各项中，不属于会计政策变更的有（ ）

A. 因业务模式变化，将债权投资重分类为交易性金融资产
B. 初次发生的融资租赁业务，采用新租赁准则的会计处理
C. 固定资产预计使用寿命变更
D. 所得税会计处理方法由应付税款法改为资产负债表债务法

**解析：**

**不属于会计政策变更的情形：**
1. 本期发生的交易与以前相比有**本质差别**→ 不属于
2. **初次发生**的交易或事项→ 不属于
3. **不重要**的交易或事项→ 不属于

| 选项 | 判断 | 理由 |
|------|------|------|
| A | 不属于 | 业务模式变化是客观事实，本质不同 |
| B | 不属于 | 初次发生的业务，属于首次执行新准则，不属于政策变更 |
| C | 不属于 | 固定资产使用寿命是会计估计，不是会计政策 |
| D | 属于 | 所得税会计处理方法属于会计政策 |

**答案：** A、B、C

## 三、分录/计算模板

### 模板1：会计政策变更（追溯调整法）

```
1. 调整资产/负债：
借/贷：相关资产/负债
  贷/借：利润分配——未分配利润

2. 调整递延所得税：
借/贷：递延所得税资产/递延所得税负债
  贷/借：利润分配——未分配利润

3. 结转盈余公积：
借/贷：盈余公积
  贷/借：利润分配——未分配利润
```

### 模板2：会计估计变更（未来适用法）

```
不调整以前期间，直接从变更当期开始采用新估计：

借：管理费用等
  贷：累计折旧/坏账准备等
```

### 模板3：前期重大差错更正

```
1. 补提折旧/确认负债等：
借：以前年度损益调整
  贷：相关科目

2. 调整所得税：
借/贷：应交税费——应交所得税/递延所得税资产
  贷/借：以前年度损益调整

3. 结转以前年度损益调整：
借/贷：盈余公积
  贷/借：利润分配——未分配利润
```

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|-------|------|---------|
| 折旧方法变更 | 年限平均→双倍余额递减→**会计估计变更** | 方法变更是"估计寿命变了" |
| 存货计价方法变更 | 先进先出→加权平均→**会计政策变更** | 计价方法是"确认计量基础" |
| 折旧年限变更 | **会计估计变更** | 估计资产还能用多久 |
| 残值变更 | **会计估计变更** | 估计还能卖多少钱 |
| 本期新发生 vs 首次执行 | 本期新发生→不属于变更；首次执行准则→不追溯 | "第一次发生"不算变更 |

## 五、速记口诀

**会计政策变更 vs 会计估计变更：**
- 政策：方法、基础的选择（计价、计量模式）
- 估计：不确定性判断（年限、比例、残值）

**追溯调整法：**
- 累积影响数
- 调整期初留存收益
- 调整比较报表

**差错更正：**
- 重大差错：追溯重述
- 非重大差错：当期调整
- 以前年度损益调整
