# 负债 —— 第一性原理教程

## 一、流动负债

### 1.1 负债的本质

**负债**是指企业过去的交易或事项形成的、预期会导致经济利益流出企业的**现时义务**。

**流动负债**是指在一年或一个营业周期内（以较长者为准）需要清偿的负债。

### 1.2 常见流动负债

#### 短期借款
- 向银行等金融机构借入的期限在一年以内的借款
- 利息计入当期损益（财务费用）

#### 应付票据
- 商业承兑汇票和银行承兑汇票
- 到期无力支付的商业承兑汇票 → 转入"应付账款"
- 到期无力支付的银行承兑汇票 → 转入"短期借款"

#### 应付账款
- 因购买材料、商品或接受劳务而发生的债务
- 附有现金折扣的：按**总价法**入账，折扣实际获得时冲减财务费用

#### 预收账款/合同负债
- 预收客户款项
- 新收入准则下，不含税部分计入"合同负债"，增值税部分计入"待转销项税额"

#### 应交税费

**增值税（一般纳税人）：**
- 进项税额：购入时支付，可抵扣
- 销项税额：销售时收取，应交未交
- 应交增值税 = 销项税额 - 进项税额 + 进项税额转出

| 项目 | 借方科目 | 贷方科目 |
|------|---------|---------|
| 购入商品 | 应交税费——应交增值税（进项税额） | 银行存款 |
| 销售商品 | 银行存款 | 应交税费——应交增值税（销项税额） |
| 交纳增值税 | 应交税费——应交增值税（已交税金） | 银行存款 |

**消费税：**
- 价内税，计入税金及附加
- 委托加工收回后直接销售的，消费税计入委托加工物资成本

#### 应付职工薪酬
详见"职工薪酬"章节。

#### 其他应付款
- 应付租入固定资产租金
- 存入保证金
- 应付暂收款项

## 二、非流动负债

### 2.1 长期借款

**初始计量：** 实际收到的金额（扣除交易费用）。

**后续计量：** 按摊余成本计量，采用**实际利率法**确认利息费用。

```
每期利息费用 = 期初摊余成本 × 实际利率
每期应付利息 = 本金 × 合同利率
差额 = 利息调整的摊销
```

**利息费用资本化 vs 费用化：**
- 符合资本化条件的 → 计入相关资产成本
- 不符合资本化条件的 → 计入财务费用

### 2.2 应付债券

**发行价格：**
- 面值发行：票面利率 = 市场利率
- 溢价发行：票面利率 > 市场利率
- 折价发行：票面利率 < 市场利率

**会计处理：**

| 阶段 | 会计处理 |
|------|----------|
| 发行 | 借：银行存款（实际收到），贷：应付债券——面值，差额：利息调整 |
| 计息 | 借：在建工程/财务费用（摊余成本×实际利率），贷：应付利息（面值×票面利率），差额：利息调整 |
| 到期偿还 | 借：应付债券——面值，贷：银行存款 |

### 2.3 长期应付款

**常见类型：**
- 应付融资租赁款（详见"租赁"章节）
- 具有融资性质的延期付款购买资产

**未确认融资费用：**
- 实质是利息费用的递延确认
- 采用实际利率法摊销
- 摊销金额满足资本化条件的计入资产成本，否则计入财务费用

## 考试要点总结

1. **流动负债**：重点关注增值税的会计处理
2. **非流动负债**：核心是**实际利率法**，理解摊余成本的概念
3. **应付债券**：溢价/折价的产生原因和摊销处理
4. **借款费用资本化**：与借款费用章节结合考查
