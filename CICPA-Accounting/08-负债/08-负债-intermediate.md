# 负债 —— 典型考题解析
## 一、核心考法分类

1. **增值税会计处理**（计算题高频考点）
2. **实际利率法摊余成本计量**（计算题核心考点）
3. **应付债券溢折价摊销**（综合题）
4. **流动负债分类判断**（选择题）

5. **未确认融资费用摊销**（计算题）

## 二、典型例题解析

### 2.1 增值税处理
**题目:** 甲公司购入原材料价款100万元，增值税13万元；销售产品价款200万元，增值税34万元。进项税额转出2万元（非正常损失）。应交增值税?
**解析:** 应交增值税 = 销项34 - 进项17 + 进项转出2 = 19万元
### 2.2 摊余成本计算
**题目:** 甲公司2x23年1月1日发行5年期债券，面值1,000万元，票面利率55%，实际利率6%，发行价960万元。第1年利息费用?
**解析:** 第1年利息费用 = 960×6% = 57.6万元；应付利息 = 1,000×5% = 50万元；利息调整摊销 = 7.6万元;年末摊余成本 = 960+7.6 = 967.6万元
### 2.3 应付票据到期无力支付
**题目:** 甲公司商业承兑汇票50万元到期无力支付，应如何处理?
**解析:** 商业承兑汇票→1转入应付账款；银行承兑汇票→1转入短期借款
### 2.4 未确认融资费用摊销
**题目:** 甲公司分期付款购入设备，总价500万元分3年支付，实际利率5%。第1年摊销?
**解析:** 设备入账价值 = 500/(1+5%)^3现值；第1年摊销 = 期初摊余成本×5%

## 三、分录/计算/框架模板

```
应付债券（溢价发行）:
发行: 借银行存款1,060，贷应付债券——面值1,000、——利息调整60
计息: 借财务费用(摊余×实际利率)，贷应付利息(面值×票面利率)、利息调整(差额)
偿还: 借应付债券——面值1,000、利息调整(余额)，贷银行存款1,000
```

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|-------|------|---------|
| 商业汇票到期无力支付 | 商业→1应付账款；银行→1短期借款 | 商业归商,银行归银 |
| 摊余成本 | 期初摊余×实际利率 | "实际利率法" |
| 溢价vs折价 | 票面>市场→1溢价；票面<市场→1折价 | 高溢低折 |
| 进项转出 | 非正常损失转出；正常不转出 | "非正常才转出" |

## 五、速记口诀

> 摊余成本实际利率法，利息调整差额摊；
> 红利溢价折价发行，高溢低折记心间；
> 屇票到期无力付，商业归商银行归银。
