# 租赁 —— 第一性原理教程

## 一、租赁概述

### 1.1 租赁的识别

**租赁**是指在一定期间内，出租人将资产的使用权让与承租人以获取对价的合同。

**核心判断：** 合同是否让渡了在一段时间内控制一项已识别资产使用的权利。

**识别租赁的三要素：**
1. 存在**已识别资产**（明确指定或隐性指定）
2. 承租人有权获得在使用期间内因使用资产所产生的**几乎全部经济利益**
3. 承租人有权主导资产的**使用方式和使用目的**

### 1.2 租赁的分拆与合并

**分拆：** 合同中包含租赁和非租赁成分的，承租人和出租人可以选择不分拆（整体按租赁处理）。

**合并：** 同时满足以下条件的合同应当合并：
- 与同一交易方或关联方签订
- 总体构成一揽子交易
- 每份合同单独看对价不反映独立市场价格

### 1.3 租赁期

**租赁期** = 不可撤销期间 + 合理确定会行使的续租选择权期间 - 合理确定不会行使的终止选择权期间

**关键判断：** 是否"合理确定"行使续租/不行使终止选择权需考虑：
- 行使选择权的经济激励
- 过去交易习惯
- 特定经营需求

## 二、承租人的会计处理

### 2.1 基本原则（新租赁准则的重大变化）

**核心变化：** 取消了经营租赁/融资租赁的分类，承租人对几乎所有租赁确认**使用权资产**和**租赁负债**。

### 2.2 初始计量

**使用权资产：**
```
使用权资产 = 租赁负债初始计量金额
           + 预付租赁付款额
           + 初始直接费用
           + 预计拆卸拆卸费用现值
           - 租赁激励
```

**租赁负债：**
```
租赁负债 = 尚未支付的租赁付款额的现值
折现率：租赁内含利率（出租人角度）或增量借款利率
```

### 2.3 后续计量

**使用权资产（成本模式）：**
- 计提折旧（直线法或其他系统方法）
- 减值测试（适用资产减值准则）

**租赁负债：**
- 采用实际利率法确认利息费用
```
每期利息 = 期初租赁负债余额 × 折现率
本金偿还 = 实际支付 - 利息
```

**会计处理：**
```
借：使用权资产累计折旧（折旧）
    租赁负债——利息（利息）
  贷：使用权资产累计折旧
      银行存款（租金支付）
```

### 2.4 短期租赁和低价值资产租赁

**可以豁免确认使用权资产和租赁负债：**
- **短期租赁**：租赁期不超过12个月的租赁（不含购买选择权）
- **低价值资产租赁**：单项资产全新时价值较低的租赁（通常≤5,000美元）

**处理方式：** 按直线法计入当期损益。

## 三、出租人会计处理

### 3.1 出租人仍然区分融资租赁和经营租赁

**融资租赁的判断（满足任一即为融资租赁）：**
1. 租赁期满所有权转移给承租人
2. 承租人有购买选择权且合理确定行使
3. 租赁期占资产使用寿命的大部分（≥75%）
4. 租赁付款额现值几乎相当于资产公允价值（≥90%）
5. 资产性质特殊，只有承租人才能使用

### 3.2 融资租赁的会计处理

**出租人（制造商/经销商出租人）：**

```
借：应收融资租赁款——租赁收款额（未收租金总额）
  贷：融资租赁资产（资产账面价值）
      资产处置损益（公允价值-账面价值，厂商出租人）
      应收融资租赁款——未实现融资收益（差额）
```

后续按实际利率法确认租赁收入。

### 3.3 经营租赁的会计处理

出租人继续将租赁资产作为自有资产核算，租金收入按直线法确认。

## 四、特殊租赁业务

### 4.1 转租赁

**判断：** 中间出租人（原承租人）基于原租赁产生的使用权资产进行分类：
- 转租赁分类取决于"使用权资产"而非原资产本身

### 4.2 生产商/经销商出租人

- 融资租赁下确认收入（按公允价值或现值较低者）
- 确认销售成本（资产成本）
- 差额即为生产商利润

### 4.3 售后租回

**判断是否属于销售（IFRS 15）：**

| 情形 | 会计处理 |
|------|----------|
| 属于销售 | 买方/出租人确认资产购买；卖方/承租人按比例确认使用权资产 |
| 不属于销售（实质是融资） | 卖方/承租人不终止确认资产，确认金融负债 |

**售后租回中销售但保留使用权：**
- 仅确认转让给买方的权利部分的销售收入
- 保留部分的使用权确认为使用权资产

---

## 考试要点总结

1. **承租人不区分**经营/融资租赁（统一确认使用权资产+租赁负债）
2. **租赁负债** = 未来租金的现值
3. **短期租赁和低价值资产租赁**可以豁免
4. **出租人仍区分**融资租赁和经营租赁
5. **售后租回**：核心判断是否构成销售
