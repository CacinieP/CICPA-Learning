# 租赁 —— 综合实战

## 一、综合题解题框架

### 1.1 租赁综合题标准解题步骤

```
第一步：识别租赁
        ├─ 是否存在已识别资产
        ├─ 是否获得几乎全部经济利益
        └─ 是否主导资产使用方式

第二步：确定租赁期
        ├─ 不可撤销期间
        ├─ 续租选择权（合理确定→纳入）
        └─ 终止选择权（合理确定→不纳入）

第三步：承租人会计处理
        ├─ 初始确认：使用权资产+租赁负债
        ├─ 后续计量：折旧+利息+租金支付
        └─ 短期/低价值租赁豁免

第四步：出租人会计处理
        ├─ 判断租赁类型（融资/经营）
        └─ 相应会计处理

第五步：特殊业务处理
        └─ 售后租回、转租赁等
```

### 1.2 典型综合题模板

**题目框架：**
```
背景：企业签订租赁合同，涉及多种租赁资产
要求：（1）判断是否属于租赁及租赁类型
      （2）计算租赁负债和使用权资产
      （3）编制租赁相关会计分录
      （4）说明折现率的确定方法
```

## 三、陷阱与反套路

### 3.1 常见陷阱

| 陷阱类型 | 出题方式 | 应对方法 |
|----------|----------|----------|
| 租赁期计算错误 | 忘记考虑续租/终止选择权 | 严格按照"不可撤销+续租-终止"计算 |
| 折现率确定 | 混淆租赁内含利率和增量借款利率 | 优先用租赁内含利率，不能确定时用增量借款利率 |
| 豁免条件混淆 | 将短期租赁和低价值租赁混淆 | 短期租赁是"期限"概念，低价值租赁是"资产价值"概念 |
| 出租人分类错误 | 忘记出租人仍需区分融资租赁和经营租赁 | 承租人不分，出租人要分 |
| 售后租回判断 | 将所有售后租回当作销售处理 | 必须先判断是否构成销售 |

### 3.2 反套路要点

1. **租赁期确定四步法：**
   - 确定不可撤销期间
   - 判断续租选择权（合理确定→纳入）
   - 判断终止选择权（合理确定→不纳入）
   - 计算租赁期

2. **使用权资产计算公式：**
   ```
   使用权资产 = 租赁负债 + 预付租金 + 初始直接费用 + 拆卸费用现值 - 租赁激励
   ```

3. **租赁负债计算：**
   - 租赁付款额现值
   - 使用实际利率法摊销

## 四、真题变式推演

### 变式一：租赁+借款费用资本化

**原题特征：** 单一租赁的会计处理

**变式扩展：**
```
背景：甲公司2×21年1月1日开始自建一栋办公楼，建造期2年。
公司于2×21年1月1日与乙公司签订租赁合同，租入一台大型设备用于工程建设：

租赁条款：
- 租赁期：5年（不可撤销期间3年 + 续租选择权2年，管理层合理确定会行使）
- 租金：每年年末支付200万元
- 租赁内含利率：5%
- 初始直接费用：20万元
- 该设备使用寿命8年

要求：
（1）计算该租赁的租赁期
（2）计算租赁负债和使用权资产的初始确认金额
（3）计算2×21年度应资本化的借款费用金额（假设该设备专门用于该工程）
（4）编制2×21年度相关会计分录
（5）判断如果租赁期缩短为2年，该租赁是否可以豁免确认
```

**解题要点：**
1. 租赁期 = 3 + 2 = 5年（续租选择权纳入）
2. 计算租赁付款额现值，编制会计分录
3. 租赁负债的利息可以资本化（计入资产成本）
4. 租赁期2年不能豁免（>12个月）

### 变式二：售后租回综合题

```
背景：丙公司拥有一栋自用办公楼，原价5,000万元，已计提折旧1,000万元，
账面价值4,000万元，公允价值4,500万元。2×21年1月1日，丙公司与丁公司
签订售后租回协议：

条款：
- 售价：4,500万元
- 回租期：10年，每年年末支付租金600万元
- 租赁内含利率：6%
- 该办公楼预计剩余使用寿命20年

要求：
（1）判断该售后租回是否构成销售
（2）如构成销售，计算转让给买方的权利部分的销售收入
（3）编制丙公司相关的会计分录
（4）说明丁公司（出租人）的会计处理
```

**解题要点：**
1. 判断是否构成销售（根据IFRS 15控制权转移判断）
2. 如构成销售，确认使用权资产
3. 出租人按融资租赁或经营租赁处理

### 变式三：转租赁综合题

```
背景：甲公司（中间出租人）原从A公司租入一台设备，原始租赁：
- 租赁期：5年
- 每年年末支付租金100万元
- 无法取得租赁内含利率，增量借款利率5%
- 设备公允价值2,200万元

甲公司于2×21年1月1日将其转租给B公司，转租赁条款：
- 转租赁期：3年
- 每年年末收取租金800万元
- 该设备使用寿命5年，预计无残值

要求：
（1）判断原租赁的类型
（2）计算甲公司作为承租人的租赁负债
（3）判断转租赁的类型
（4）编制甲公司的相关会计分录
（5）说明如果B公司违约，甲公司面临的风险
```

## 五、实务衔接

### 5.1 租赁在实务中的应用

**经营租赁（承租人视角）：**
- 办公楼、店铺的租赁
- 办公设备的租赁
- 车辆租赁

**融资租赁（出租人视角）：**
- 飞机的融资租赁
- 大型设备的融资租赁
- 船舶的融资租赁

### 5.2 租赁对报表的影响

| 项目 | 承租人 | 出租人 |
|------|--------|--------|
| 资产负债表 | 使用权资产↑，租赁负债↑ | 应收融资租赁款↑ |
| 利润表 | 折旧费用+利息费用 | 租赁收入（融资租赁按实际利率法） |
| 现金流量表 | 偿还本金→筹资活动，利息→筹资或经营活动 | 收到的租金→经营活动 |

> ⚠️ **实务警示：** 企业应在附注中披露租赁资产的详细信息，包括使用权资产期末余额、本期折旧、租赁负债利息费用等。

## 六、速记总结

**承租人会计处理：**
```
不区分经营/融资租赁，统一确认：
使用权资产 = 租赁负债 + 相关调整
租赁负债 = 租赁付款额现值
折旧：直线法计入成本费用
利息：实际利率法确认财务费用
```

**出租人会计处理：**
```
仍然区分融资租赁和经营租赁：
融资租赁：确认应收融资租赁款，实际利率法确认收入
经营租赁：按直线法确认租金收入
```

**租赁期确定口诀：**
```
不可撤销期间
+ 合理确定续租
- 合理确定终止
= 租赁期
```

**短期租赁和低价值租赁：**
```
豁免确认，但仍需在附注中披露
```

**售后租回：**
```
判断是否构成销售
构成销售：按比例确认转让部分
不构成销售：视为融资，保留资产账面价值
