# 物权法律制度 —— 第一性原理教程

> 从"什么是物"出发，理解物权的本质、变动规则以及各类物权的具体制度，覆盖注会考试全部考点。

---

## 一、物权概述

### 1.1 物权的概念与特征

**什么是物权？**

物权是权利人依法对特定的物享有直接支配和排他的权利，包括所有权、用益物权和担保物权。

**物权的特征（与债权对比）：**

| 特征 | 物权 | 债权 |
|------|------|------|
| 权利性质 | 支配权 | 请求权 |
| 效力 | 排他性、优先性 | 相容性、平等性 |
| 义务主体 | 不特定的人（对世权/绝对权） | 特定的人（对人权/相对权） |
| 客体 | 特定的物 | 给付行为 |
| 追及效力 | 有（不论物流转到何处都能追及） | 无 |
| 设立原则 | 物权法定、公示原则 | 契约自由 |

### 1.2 物权法定原则

**基本内容：**
- 物权的**种类**和**内容**由法律规定，当事人不得自由创设
- 违反物权法定原则的约定不发生物权效力（但不影响合同效力）

### 1.3 物权的种类

```
物权
├── 所有权（自物权）—— 对自己所有物的全面支配权
│   ├── 国家所有权
│   ├── 集体所有权
│   └── 私人所有权
├── 用益物权（他物权）—— 对他人所有物的使用收益权
│   ├── 建设用地使用权
│   ├── 土地承包经营权
│   ├── 宅基地使用权
│   ├── 地役权
│   └── 居住权
└── 担保物权（他物权）—— 以物的交换价值担保债权实现
    ├── 抵押权
    ├── 质权
    └── 留置权
```

## 二、物权变动

### 2.1 物权变动的含义与形态

**物权变动**是指物权的产生（取得）、变更和消灭。

**物权取得的分类：**
- **原始取得**：不依赖于他人原有权利而取得（如生产、添附、善意取得、没收）
- **继受取得**：基于他人原有权利而取得（如买卖、赠与、继承）

### 2.2 物权变动的原因

物权变动的原因包括**法律行为**（如买卖合同、抵押合同）和**非法律行为**（如继承、法院判决、建造）。

#### （一）基于法律行为的物权变动（核心规则）

**不动产：登记生效主义**

不动产物权的设立、变更、转让和消灭，经依法**登记**，发生效力；未经登记，不发生效力（法律另有规定的除外）。

> 例：甲将房屋卖给乙，双方签订买卖合同并交付房屋，但未办理过户登记。乙此时对房屋不享有所有权，只有合同上的债权。

**动产：交付生效主义**

动产物权的设立和转让，自**交付**时发生效力（法律另有规定的除外）。

> 例：甲将汽车卖给乙，自甲将汽车交付给乙时，乙取得汽车所有权。

#### （二）非基于法律行为的物权变动

不以登记或交付为要件，物权自事实行为完成或法律文书生效时发生效力：

1. **法院/仲裁机构的法律文书** —— 自文书生效时发生效力
2. **继承** —— 自继承开始时（被继承人死亡时）发生效力
3. **合法建造/拆除房屋** —— 自事实行为成就时发生效力

> 但处分上述物权时，依照法律规定需要办理登记的，未经登记不发生物权效力。

### 2.3 物权行为理论

**物权行为独立性（分离原则）：**
- 买卖合同（债权行为）与物权变动（物权行为）是两个不同的法律行为
- 买卖合同有效仅产生债权债务关系，不直接导致物权变动

**物权行为无因性：**
- 物权行为的效力独立于其原因行为（债权行为）
- 即使买卖合同被宣告无效或撤销，只要物权行为本身有效且已完成公示，物权变动仍然有效
- 我国立法未完全采纳无因性理论，而是通过不当得利制度调整

### 2.4 公示方式

**公示原则：** 物权的变动必须以一定方式向社会公众公示，使第三人能够知悉。

#### （一）登记（不动产的公示方式）

**登记的类型：**

| 类型 | 说明 |
|------|------|
| **设立登记** | 首次登记物权（如首次登记房屋所有权） |
| **变更登记** | 物权内容发生变化（如房屋面积变化） |
| **转移登记** | 物权主体发生变化（如买卖过户） |
| **注销登记** | 物权消灭（如房屋拆除） |
| **更正登记** | 权利人/利害关系人认为登记错误，申请更正 |
| **异议登记** | 对登记有异议的临时保护措施（登记后15日内不起诉则失效） |
| **预告登记** | 为保障将来实现物权而作的登记（如预售商品房预告登记） |

**预告登记的效力：**
- 预告登记后，未经预告登记的权利人同意，处分该不动产的，不发生物权效力
- 债权消灭或者能够进行不动产登记之日起 **90日** 内未申请登记的，预告登记失效

#### （二）交付（动产的公示方式）

| 交付方式 | 说明 | 适用情形 |
|---------|------|---------|
| **现实交付** | 直接将物交由对方占有 | 最基本的交付方式 |
| **简易交付** | 受让人已占有该动产，物权自法律行为生效时转移 | 借用的东西直接购买 |
| **指示交付** | 转让人将返还原物请求权让与受让人 | 将出租中的设备出卖 |
| **占有改定** | 出让人继续占有动产，但双方约定由受让人取得间接占有 | 卖出后约定继续使用 |

## 三、所有权

### 3.1 所有权的概念

所有权是所有人依法对自己的不动产或动产享有的占有、使用、收益和处分的权利。

**所有权四项权能：**
- **占有**：对物的实际控制
- **使用**：按物的性能加以利用
- **收益**：收取物的孳息
- **处分**：决定物的法律命运（核心权能）

### 3.2 所有权的类型

**国家所有权：**
- 国家专有的财产：矿藏、水流、海域、无居民海岛、城市土地、无线电频谱资源、国防资产
- 法律规定属于国家所有的野生动植物资源、文物等

**集体所有权：**
- 法律规定属于集体所有的土地和森林、山岭、草原、荒地、滩涂
- 集体所有的建筑物、生产设施、农田水利设施等

**私人所有权：**
- 私人对其合法的收入、房屋、生活用品、生产工具、原材料等享有所有权

**业主的建筑物区分所有权：**
- 专有权（自己的房屋）
- 共有权（公共部分如电梯、楼道、绿地）
- 共同管理权（业主委员会等）

### 3.3 善意取得

**概念：** 无处分权人将不动产或动产转让给受让人时，如果受让人受让该财产时出于善意，并以合理价格有偿受让，且已完成法定公示（登记或交付），则受让人取得该财产的所有权。

**善意取得的构成要件（缺一不可）：**

1. **出让人无处分权** —— 如果有处分权则是一般转让
2. **受让人善意** —— 受让时不知道且不应当知道出让人无处分权
3. **合理价格** —— 以合理的价格有偿取得（赠与不适用）
4. **已完成公示** —— 不动产已登记，动产已交付
5. **转让合同有效** —— 合同本身须无无效事由

**善意取得的法律效果：**
- 受让人取得所有权（原始取得）
- 原所有权人丧失所有权，可向无处分权人请求损害赔偿

**不适用善意取得的情形：**
- 遗失物、盗赃物原则上不适用善意取得（权利人可在2年内请求返还）
- 货币和无记名有价证券适用"占有即所有"，不适用善意取得

### 3.4 动产所有权的特殊取得方式

| 方式 | 说明 |
|------|------|
| **先占** | 以所有的意思占有无主物（如捡拾废弃物） |
| **拾得遗失物** | 应返还权利人，不知权利人的应送交公安等部门。公告1年内无人认领的归国家所有 |
| **发现埋藏物** | 参照拾得遗失物规则处理 |
| **添附** | 包括附合、混合、加工。由新物所有人取得所有权，另一方可获得补偿 |
| **生产** | 通过劳动创造新物 |
| **孳息** | 天然孳息由所有权人取得；法定孳息按约定取得，无约定按交易习惯 |

> **天然孳息 vs 法定孳息：**
> - 天然孳息：果树所结的果实、母畜所生的幼畜
> - 法定孳息：利息、租金、股利

## 四、用益物权

### 4.1 用益物权概述

用益物权是对他人所有的不动产或动产，依法享有占有、使用和收益的权利。

### 4.2 建设用地使用权（重点）

**概念：** 建设用地使用权人依法对国家所有的土地享有占有、使用和收益的权利，有权利用该土地建造建筑物、构筑物及其附属设施。

**取得方式：**
1. **出让** —— 国家将土地使用权在一定年限内让与土地使用者，土地使用者支付出让金
   - 工业、教育、科技、文化、卫生、体育等用地：50年
   - 商业、旅游、娱乐用地：40年
   - 住宅用地：70年
2. **划拨** —— 县级以上人民政府依法批准，在土地使用者缴纳补偿、安置等费用后将土地交付其使用，或者将土地使用权无偿交付给土地使用者使用

**建设用地使用权的转让：**
- 以出让方式取得的，转让时应符合：已支付全部出让金并取得证书；属于房屋建设工程的，应完成投资总额的25%以上
- 以划拨方式取得的，转让须经有批准权的人民政府审批

**住宅建设用地使用权续期：**
- 住宅建设用地使用权期限届满的，**自动续期**
- 续期费用的缴纳或者减免，依照法律、行政法规的规定办理

## 五、担保物权

### 5.1 担保物权概述

**概念：** 担保物权是以直接支配特定财产的交换价值为内容，以确保债权实现为目的的他物权。

**特征：**
1. **从属性** —— 担保物权从属于主债权，主债权无效则担保物权无效
2. **不可分性** —— 担保物权人在全部债权受清偿前，可就担保物的全部行使权利
3. **物上代位性** —— 担保物毁损、灭失后，担保物权人可就获得的保险金、赔偿金等优先受偿

### 5.2 抵押权

**概念：** 债务人或第三人不转移财产的占有，将该财产作为债权的担保，债务人不履行债务时，债权人有权就该财产优先受偿。

#### （一）抵押物范围

**可以抵押的财产：**
1. 建筑物和其他土地附着物
2. 建设用地使用权
3. 海域使用权
4. 生产设备、原材料、半成品、产品
5. 正在建造的建筑物、船舶、航空器
6. 交通运输工具
7. 法律法规未禁止抵押的其他财产

**不得抵押的财产：**
1. 土地所有权
2. 宅基地、自留地、自留山等集体土地使用权（法律规定可以抵押的除外）
3. 学校、幼儿园、医疗机构等为公益目的成立的非营利法人的教育设施、医疗卫生设施和其他公益设施
4. 所有权、使用权不明或有争议的财产
5. 依法被查封、扣押、监管的财产

#### （二）抵押权的设立

| 抵押物类型 | 抵押权设立要件 |
|-----------|--------------|
| **不动产** | 抵押合同生效 + **登记**（登记时设立） |
| **动产** | 抵押合同生效时设立（登记为对抗要件） |

**动产抵押未经登记的，不得对抗善意第三人。**

#### （三）抵押权的效力

1. **抵押权与租赁的关系：**
   - 先租后抵：原租赁关系不受抵押权影响（买卖不破租赁）
   - 先抵后租：抵押权实现时，租赁合同对受让人不具有约束力

2. **抵押物的转让：**
   - 抵押期间抵押人可以转让抵押财产，当事人另有约定的从其约定
   - 抵押人转让抵押财产的，应及时通知抵押权人
   - 抵押权不受影响（即抵押权具有追及效力）

3. **抵押权的顺位：**
   - 同一财产向两个以上债权人抵押的，拍卖、变卖所得价款按以下顺序清偿：
     - 不动产抵押：按**登记先后**顺序
     - 动产抵押：已登记的先于未登记的；均登记的按**登记先后**；均未登记的按**债权比例**

#### （四）最高额抵押

**概念：** 为担保债务的履行，债务人或第三人对一定期间内将要连续发生的债权提供担保财产的，债务人不履行到期债务或发生当事人约定的实现抵押权的情形，抵押权人有权在最高债权额限度内就该担保财产优先受偿。

**特征：** 抵押权设立时债权尚未确定，在决算期到来时才确定实际担保的债权额。

#### （五）浮动抵押

**概念：** 企业、个体工商户、农业生产经营者可以将现有的以及将有的生产设备、原材料、半成品、产品抵押，债务人不履行到期债务时，债权人有权就实现抵押权时的动产优先受偿。

**特征：** 抵押财产在抵押期间可以流转，浮动抵押在抵押财产**确定**之前具有浮动性。

### 5.3 质权

**概念：** 债务人或第三人将其动产或权利凭证移交债权人占有，作为债权的担保，债务人不履行债务时，债权人有权就该动产或权利优先受偿。

#### （一）动产质权

**设立要件：** 质押合同生效 + **交付**动产（交付时设立）

#### （二）权利质权

| 权利类型 | 设立要件 |
|---------|---------|
| 票据、存款单、仓单、提单 | 交付权利凭证（或有权机关登记） |
| 基金份额、股权 | **登记**（证券登记结算机构/工商部门） |
| 知识产权中的财产权 | **登记** |
| 应收账款 | **登记**（征信机构） |

### 5.4 留置权

**概念：** 债权人合法占有债务人的动产，在债务人不履行到期债务时，有权留置该动产并优先受偿的权利。

**特征：**
1. 留置权是**法定担保物权**，不需当事人约定（区别于抵押权、质权）
2. 留置的动产应当与债权属于**同一法律关系**（企业之间留置的除外）
3. 留置权人负有妥善保管留置财产的义务

**留置权的实现：**
- 留置后应给债务人 **60日以上** 的履行期限
- 债务人逾期仍不履行的，可就留置财产折价、拍卖或变卖优先受偿

**担保物权的实现顺序：**
同一动产上已设立抵押权或质权，该动产又被留置的，**留置权人优先受偿**。

### 5.5 让与担保

**概念：** 债务人或第三人为担保债务的履行，将标的物转移给债权人，债务履行后标的物应返还给债务人或第三人，债务不履行时债权人可以就标的物优先受偿。

**效力：**
- 当事人约定到期不能清偿债务时标的物归债权人所有的（流质/流押条款），该约定无效，但不影响担保合同的效力
- 债权人可以依法就标的物折价或拍卖、变卖所得价款优先受偿

## 考试要点总结

| 考点 | 核心记忆 |
|------|---------|
| 不动产物权变动 | 登记生效 |
| 动产物权变动 | 交付生效 |
| 交付方式 | 现实交付、简易交付、指示交付、占有改定 |
| 善意取得 | 无权处分+善意+合理价格+已公示 |
| 建设用地使用权 | 住宅70年自动续期 |
| 抵押权（不动产） | 登记设立 |
| 抵押权（动产） | 合同生效设立，登记对抗 |
| 质权（动产） | 交付设立 |
| 留置权 | 法定担保物权，优先于抵押权和质权 |
| 让与担保 | 流质条款无效，但可优先受偿 |
