# 国际税收税务管理实务 —— 综合实战

## 一、综合题解题框架

```
【国际税收综合题解题步骤】

Step 1：判断纳税人身份
├─ 居民企业 → 全球所得，境外所得可抵免
└─ 非居民企业 → 来源于境内所得
         ↓
Step 2：判断是否涉及常设机构
├─ 有常设机构 → 与常设机构有实际联系的所得按25%征税
└─ 无常设机构 → 预提所得税10%（协定从优）
         ↓
Step 3：境外所得抵免
├─ 直接抵免（分公司）→ 限额抵免
└─ 间接抵免（子公司）→ 股息还原→限额→比较
         ↓
Step 4：反避税规则
├─ 转让定价调整
├─ 受控外国公司（CFC）
└─ 资本弱化限制
```

## 二、跨章联动图谱

> 🔗 **跨科联动：**
>
> **国际税收 ↔ 企业所得税（第4章）**：
> - 境外所得抵免规则直接影响企业所得税计算
> - 居民企业/非居民企业的判定在两章中有交叉
>
> **国际税收 ↔ 个人所得税（第5章）**：
> - 个人境外所得同样适用抵免规则
> - 居民个人/非居民个人的判定标准（183天）
>
> **国际税收 ↔ 会计（合并报表）**：
> - 境外子公司在合并报表中的税务处理
> - 递延所得税资产的确认（境外已纳税款）

## 三、陷阱与反套路

| 陷阱类型 | 典型表现 | 识别要点 |
|----------|----------|----------|
| **常设机构时间标准** | 不同类型活动适用不同时间标准 | 建筑工程6个月，咨询服务按协定 |
| **间接抵免持股比例** | 不检查每层持股比例是否≥5% | 三层各≥5% |
| **预提税协定优惠** | 不考虑税收协定优惠税率 | 有协定从协定 |
| **抵免限额计算基数** | 境外所得未还原税前利润 | 间接抵免需还原 |

## 四、真题变式推演

### 变式一：综合抵免计算

**题目：**
中国A公司（居民企业）2024年度：
- 境内所得：8,000,000元
- 甲国分公司所得：3,000,000元，已在甲国缴纳所得税750,000元
- 从乙国子公司取得股息2,000,000元（乙国子公司税前利润10,000,000元，已缴所得税2,500,000元）
- A公司持有乙国子公司20%股权

**要求：** 计算A公司2024年度应向中国缴纳的企业所得税。

**解析：**

**（1）甲国分公司（直接抵免）**

$$抵免限额 = (8,000,000 + 3,000,000 + 2,666,667) × 25\% × \frac{3,000,000}{13,666,667}$$

先计算乙国股息还原：2,000,000 ÷ (1-25%) = 2,666,667元

境内外总所得 = 8,000,000 + 3,000,000 + 2,666,667 = 13,666,667元

甲国抵免限额 = 13,666,667 × 25% × 3,000,000/13,666,667 = 750,000元

甲国已缴750,000 = 限额750,000 → 可全额抵免

**（2）乙国子公司（间接抵免）**

间接抵免税额 = 2,500,000 × 2,000,000/7,500,000 = 666,667元

乙国抵免限额 = 13,666,667 × 25% × 2,666,667/13,666,667 = 666,667元

间接抵免 = 666,667 = 限额 → 可全额抵免

**（3）应纳税额**

$$应纳税额 = 13,666,667 × 25\% - 750,000 - 666,667 = 2,000,000元$$

**答案：** 2,000,000元

---

### 变式二：转让定价+反避税

**题目：**
中国A公司（25%税率）向其B国母公司（10%税率）销售产品，单价80元/件，年销量100,000件。独立第三方销售同类产品价格为100元/件。

**要求：** 说明税务机关如何进行转让定价调整。

**解析：**

**方法：可比非受控价格法**

调整后价格：100元/件

A公司调增收入：(100-80) × 100,000 = 2,000,000元

A公司调增应纳税所得额：2,000,000元

调增企业所得税：2,000,000 × 25% = 500,000元

**答案：** 调增应纳税所得额2,000,000元，补税500,000元

## 五、实务衔接

| 场景 | 要点 |
|------|------|
| **走出去企业** | 境外所得需在中国申报并抵免 |
| **外资企业** | 常设机构判定、预提所得税管理 |
| **转让定价合规** | 同期资料准备（主体文档/本地文档/国别报告） |
| **CRS信息交换** | 金融账户信息自动交换 |
