# 国际税收税务管理实务 —— 第一性原理教程

## 一、国际税收协定

### 1.1 税收协定概述

**税收协定**是两个或两个以上主权国家/地区为协调相互间税收管辖关系而签订的条约。

**中国采用的协定范本**：以联合国范本（UN范本）为基础，同时参考经合组织范本（OECD范本）。

### 1.2 协定的主要内容

| 内容 | 说明 |
|------|------|
| **征税权划分** | 居住国与来源国之间征税权的分配 |
| **常设机构** | 确定非居民企业在来源国的纳税义务 |
| **股息/利息/特许权使用费** | 限制来源国预提所得税税率 |
| **联属企业** | 转让定价调整对应调整 |
| **消除双重征税** | 抵免法/免税法 |
| **非歧视待遇** | 国民待遇/常设机构待遇 |
| **情报交换** | 缔约国间税务信息交换 |

### 1.3 常设机构（PE）

**固定常设机构：**
- 管理场所、分支机构、办事处、工厂、矿场等
- 时间要求：通常为12个月内累计超过6个月（建筑工地/建筑/安装工程）

**例外**：专用于储存/陈列/交付货物、采购货物、广告等不构成常设机构。

## 二、非居民企业税收管理

### 2.1 非居民企业所得类型

| 所得类型 | 征税方式 |
|----------|----------|
| 与机构场所有实际联系的所得 | 25%企业所得税 |
| 与机构场所无实际联系的所得（来源于境内） | 10%预提所得税 |

### 2.2 源泉扣缴

- 支付人代扣代缴
- 扣缴义务发生时间：实际支付/到期应支付之日
- 税率：10%（有税收协定的从协定）

### 2.3 股息/利息/特许权使用费

- 股息：按协定税率（通常5%-10%）
- 利息：按协定税率（通常7%-10%）
- 特许权使用费：按协定税率（通常10%）

## 三、境外所得税收管理

### 3.1 境外所得的确认

**来源于境外的所得：**
- 销售货物→按交易活动发生地确定
- 提供劳务→按劳务发生地确定
- 不动产→按不动产所在地确定
- 动产→按转让动产的企业所在地确定
- 股息/红利→按分配所得的企业所在地确定
- 利息/租金/特许权使用费→按负担/支付所得的企业所在地确定

### 3.2 抵免方法

**直接抵免：** 适用于同一经济实体（总公司与分公司）。

$$抵免限额 = 境内外所得按中国税法计算的应纳税总额 \times \frac{来源于某国所得}{境内外所得总额}$$

**间接抵免：** 适用于母子公司之间的股息所得。

- 三层持股比例要求：各层持股比例均≥5%
- **间接抵免的计算**：先将股息还原为税前利润，再计算抵免限额

### 3.3 抵免限额的确定

- 境外已纳税款<抵免限额→补缴差额
- 境外已纳税款>抵免限额→超过部分可在以后5年内抵免

## 四、国际反避税

### 4.1 BEPS行动计划

**税基侵蚀和利润转移（BEPS）** 是指跨国企业利用各国税制差异和漏洞，将利润转移至低税率地区的行为。

**BEPS 15项行动计划核心：**
- 第1项：数字经济征税
- 第5项：打击有害税收实践
- 第6项：防止协定滥用
- 第8-10项：转让定价（无形资产、风险和资本、其他交易）
- 第13项：国别报告
- 第15项：多边公约

### 4.2 双支柱方案

| 支柱 | 内容 |
|------|------|
| **支柱一**：金额A | 向市场管辖区重新分配征税权（适用于全球营业额>200亿欧元、利润率>10%的跨国企业） |
| **支柱二**：全球最低税 | 确保大型跨国企业有效税率不低于15%（GloBE规则） |

### 4.3 特别纳税调整

**转让定价调整：** 关联方之间的交易不符合独立交易原则的，税务机关有权调整。

**其他特别纳税调整：**
- 成本分摊协议
- 受控外国公司（CFC）规则
- 资本弱化（债务/股权比例限制）
- 一般反避税条款

---

## 五、转让定价税务管理

### 5.1 独立交易原则

关联方之间的交易应按**独立交易原则**进行。

### 5.2 转让定价方法

| 方法 | 说明 |
|------|------|
| **可比非受控价格法** | 以非关联方之间的可比交易价格为参照 |
| **再销售价格法** | 从再销售价格中扣除合理毛利 |
| **成本加成法** | 成本加上合理利润 |
| **交易净利润法** | 比较交易的净利润率 |
| **利润分割法** | 按各方贡献分割利润 |

### 5.3 同期资料

| 类型 | 适用 |
|------|------|
| 主体文档 | 跨国企业集团最终控股企业 |
| 本地文档 | 发生关联交易的居民企业 |
| 国别报告 | 最终控股企业合并收入>55亿元 |

## 六、国际税收征管合作

### 6.1 税收情报交换

- **专项情报交换**：针对特定涉税事项
- **自动情报交换**：定期自动交换（如CRS——金融账户涉税信息自动交换）
- **自发情报交换**：主动提供
- **同期税务检查**：缔约国双方同时检查

### 6.2 CRS（Common Reporting Standard）

- 金融机构收集非居民金融账户信息
- 自动交换至账户持有人所在国税务机关
- 覆盖存款账户、托管账户、投资实体权益、保险产品等

### 6.3 税收协定相互协商程序

- 纳税人认为缔约国一方/双方的措施导致或将导致不符合协定的征税
- 可向居民国主管税务机关申请启动相互协商程序
