# 税务行政法制 —— 典型考题解析

## 一、核心考法分类

| 考法类型 | 出现频率 | 典型特征 |
|----------|----------|----------|
| **税务行政处罚** | ★★★★★ | 罚款/没收/停止出口退税权/吊销许可证 |
| **一事不再罚原则** | ★★★★ | 同一违法行为不得两次罚款 |
| **处罚程序** | ★★★★ | 简易/一般/听证的适用条件 |
| **复议前置** | ★★★★★ | 征税行为必须先缴税再复议再诉讼 |
| **诉讼举证责任** | ★★★★ | 被告（税务机关）承担举证责任 |
| **起诉期限** | ★★★★ | 直接6个月/复议后15日 |

## 二、典型例题解析

### 2.1 税务行政处罚种类

**题目：** 下列属于税务行政处罚种类的有（ ）。

A. 罚款  
B. 没收违法所得  
C. 停止出口退税权  
D. 暂扣营业执照  
E. 吊销税务行政许可证件

**解析：**

税务行政处罚种类包括：
1. **罚款**（最常用）
2. **没收违法所得/非法财物**
3. **停止出口退税权**
4. **吊销税务行政许可证件**

注意：暂扣营业执照属于工商管理部门的处罚，不属于税务行政处罚。

**答案：** A、B、C、E

---

### 2.2 一事不再罚原则

**题目：** 某企业因偷逃税款，被税务机关处以罚款200,000元。后经进一步调查，发现同一偷税行为还涉及另一税种。税务机关能否再次对该企业处以罚款？

**解析：**

**一事不再罚原则：** 对同一违法行为不得给予两次以上**罚款**的行政处罚。

**关键判断：**
- 是否为"同一违法行为"：同一偷税行为
- 是否为"罚款"：是罚款

**结论：** 不能再次处以罚款，但可以追缴税款、加收滞纳金

**答案：** 不能再次处以罚款

---

### 2.3 处罚程序适用

**题目：** 税务机关拟对某企业处以罚款50,000元。该案件应适用什么处罚程序？

**解析：**

**三种处罚程序适用条件：**

| 程序 | 适用条件 |
|------|----------|
| **简易程序** | 对公民≤200元/对法人≤3,000元罚款或警告 |
| **一般程序** | 不符合简易程序的案件 |
| **听证程序** | 对公民>2,000元/对法人>10,000元罚款或没收较大数额违法所得 |

本题：对企业罚款50,000元
- > 3,000元 → 不适用简易程序
- > 10,000元 → **应当适用听证程序**（企业有权申请听证）
- 同时适用一般程序

**答案：** 适用一般程序，且应告知当事人有申请听证的权利

---

### 2.4 复议前置

**题目：** 某企业对税务机关确认的纳税金额有异议。下列做法正确的是（ ）。

A. 可以直接向法院提起行政诉讼
B. 必须先缴纳税款，再申请行政复议
C. 可以先申请行政复议，对复议不服再诉讼
D. 可以选择复议或诉讼

**解析：**

**复议前置（必经复议）**：对**征税行为**不服的
- 必须先缴纳税款/滞纳金或提供担保
- 然后申请行政复议
- 对复议不服才能提起行政诉讼

**自由选择**：对征税行为以外的其他行为不服的
- 可以选择行政复议或行政诉讼

本题涉及"纳税金额"确认 → 征税行为 → **复议前置**

**答案：** B、C

---

### 2.5 起诉期限

**题目：** 某企业收到税务机关的行政处罚决定书后，对该处罚不服。请说明企业的法律救济途径及期限。

**解析：**

**途径一：行政复议**
- 期限：知道具体行政行为之日起**60日内**
- 管辖：作出处罚的税务机关的上一级税务机关

**途径二：行政诉讼**
- 直接起诉：知道作出行政行为之日起**6个月内**
- 复议后起诉：收到复议决定书之日起**15日内**

行政处罚（非征税行为）→ **可以选择复议或直接诉讼**

**答案：** 可在60日内申请复议或在6个月内直接起诉


## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|--------|------|----------|
| **复议前置 vs 自由选择** | 征税行为→必经复议；其他→自由选择 | "征税必经，其他可选" |
| **简易程序 vs 听证条件** | 简易：公民≤200/法人≤3000；听证：公民>2000/法人>10000 | "简易小额，听证大额" |
| **直接起诉 vs 复议后起诉** | 直接6个月；复议后15日 | "直六复十五" |
| **处罚时效 vs 追征时效** | 处罚时效2年；偷税追征无限期 | "处罚两年，偷税无限" |
| **一事不再罚 vs 从重处罚** | 不再罚针对罚款；从重是量罚幅度 | "不再罚≠不处罚" |
