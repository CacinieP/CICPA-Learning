# 关税法和船舶吨税法 —— 第一性原理教程

## 一、关税法

### 1.1 征税对象与纳税人

- **征税对象**：进出境的货物和物品
- **纳税人**：进口货物的收货人、出口货物的发货人、进出境物品的所有人

### 1.2 进出口税则

- **进口税率**：最惠国税率、协定税率、特惠税率、普通税率、关税配额税率等
- **出口税率**：对少数资源性产品征收出口关税
- **暂定税率**：在特定期间适用的税率

**税率适用原则：**
- 同时适用最惠国税率和暂定税率→适用暂定税率
- 同时适用协定税率和暂定税率→从低适用
- 同时适用特惠税率和暂定税率→从低适用

### 1.3 关税计税价格

#### 进口货物完税价格

**一般方法（成交价格估价）：**

$$完税价格 = 成交价格 + 佣金（经纪费）+ 包装费 + 容器费 + 协助价值 + 特许权使用费 + 进口后转售/使用的应付费用 - 进口后发生的费用$$

**成交价格应满足的条件：**
- 对货物没有处置/使用限制（合理限制除外）
- 价格不受使成交价格无法确定的条件/因素影响
- 卖方不得获得买方后续转售/使用所产生的收益（合理除外）
- 买卖双方没有特殊关系或虽有特殊关系但不影响价格

**其他估价方法（依次）：**
1. 相同货物成交价格
2. 类似货物成交价格
3. 倒扣价格法
4. 计算价格法
5. 合理方法

#### 出口货物完税价格

$$完税价格 = 成交价格 - 出口关税$$

$$成交价格 = 离岸价格（FOB）\div (1 + 出口税率)$$

### 1.4 应纳税额计算

| 计征方式 | 公式 |
|----------|------|
| **从价税** | 应纳税额 = 完税价格 × 关税税率 |
| **从量税** | 应纳税额 = 货物数量 × 单位税额 |
| **复合税** | 应纳税额 = 完税价格 × 从价税率 + 货物数量 × 单位税额 |
| **滑准税** | 根据价格高低适用不同税率 |

### 1.5 减免规定

| 类型 | 内容 |
|------|------|
| **法定减免** | 关税税额<50元、无商业价值的广告品/货样、外国政府/国际组织无偿赠送、残损/短少的进口货物 |
| **特定减免** | 科教用品、残疾人专用品、扶贫/慈善捐赠物资等 |
| **临时减免** | 国务院批准 |

### 1.6 征收管理

- **纳税义务发生时间**：报关进口/出口的当日
- **纳税期限**：填发税款缴款书之日起15日内
- **滞纳金**：按日加收滞纳税款万分之五
- **追征/补征**：因纳税人原因→3年内追征；非纳税人原因→1年内补征

## 二、船舶吨税法

### 2.1 纳税人

自中国**境外港口进入境内港口**的船舶。

### 2.2 计税依据

船舶的**净吨位**。

### 2.3 税率

| 净吨位 | 普通税率（30日） | 优惠税率（30日） |
|--------|-----------------|-----------------|
| ≤2000吨 | 2.9元/净吨 | 2.1元/净吨 |
| 2001-10000吨 | 4.7元/净吨 | 3.3元/净吨 |
| 10001-50000吨 | 7.1元/净吨 | 4.9元/净吨 |
| >50000吨 | 8.1元/净吨 | 5.5元/净吨 |

可按1年、90日、30日缴纳。

### 2.4 税收优惠

- 应纳税额<50元免征
- 自境外受让/租入的船舶、吨税执照期满后24小时内不上下客货的船舶等免征
