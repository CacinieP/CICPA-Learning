# 资源税法和环境保护税法 —— 第一性原理教程

## 一、资源税法

### 1.1 纳税人

在**中华人民共和国领域**和**管辖的其他海域**开发应税资源的单位和个人。

### 1.2 税目与税率

| 税目 | 税率形式 |
|------|----------|
| 原油 | 6%-10%（从价） |
| 天然气 | 6%-10%（从价） |
| 煤炭 | 2%-10%（从价） |
| 铁矿 | 1%-9%（从价） |
| 铜矿 | 2%-8%（从价） |
| 金矿 | 2%-6%（从价） |
| 稀土 | 7%-12%（从价） |
| 海盐 | 2%-5%（从价） |
| 其他非金属矿 | 从价或从量 |
| 地热 | 从量 |
| 砂石、石灰石 | 从量 |

### 1.3 计税依据

**从价计征：**

$$应纳税额 = 销售额 \times 比例税率$$

**销售额**为不含增值税的销售额。

**从量计征：**

$$应纳税额 = 销售数量 \times 定额税率$$

### 1.4 特殊规定

| 情形 | 处理 |
|------|------|
| 开采或生产应税产品自用 | 视同销售，缴纳资源税 |
| 开采或生产应税产品用于连续生产 | 不缴纳资源税（最终产品不是应税产品的除外） |
| 共伴生矿 | 分别核算；未分别核算的从高 |
| 水资源试点 | 按实际取用水量计征 |

### 1.5 税收优惠

- 开采原油过程中用于加热/修井的原油免税
- 纳税人开采/生产应税产品过程中因意外事故/自然灾害遭受重大损失的可减税/免税
- 从衰竭期矿山开采的矿产品减征30%
- 从低丰度油气田开采的油气减征20%
- 对增值税小规模纳税人可在50%幅度内减征

## 二、环境保护税法

### 2.1 纳税人

在**中华人民共和国领域**和**管辖的其他海域**直接向环境排放应税污染物的企业事业单位和其他生产经营者。

**不缴纳的情形：** 排放至依法设立的污水集中处理/生活垃圾集中处理场所。

### 2.2 税目与税额

| 税目 | 计征方式 |
|------|----------|
| **大气污染物** | 污染当量数 × 适用税额（1.2-12元/污染当量） |
| **水污染物** | 污染当量数 × 适用税额（1.4-14元/污染当量） |
| **固体废物** | 排放量 × 适用税额（5-1000元/吨） |
| **噪声** | 超标分贝数 × 适用税额（350-11200元/月） |

### 2.3 计算方法

$$污染当量数 = 排放量 \div 污染当量值$$

$$应纳税额 = 污染当量数 \times 适用税额$$

- 大气/水污染物：每一排放口的**前3项**污染物征收
- 噪声：**超过标准**才征税

### 2.4 税收优惠

| 情形 | 优惠 |
|------|------|
| 排放浓度低于标准30% | 减按75%征收 |
| 排放浓度低于标准50% | 减按50%征收 |
| 农业生产（规模化养殖除外）排放 | 免税 |
| 机动车/船舶/航空器排放 | 免税 |
| 城镇污水处理厂达标排放 | 免税 |

### 2.5 征收管理

- **纳税义务发生时间**：排放当日
- **纳税期限**：按月计算，按季申报（可按次）
- **纳税地点**：应税污染物排放地

## 考试要点

1. **资源税**：从价为主，从量为辅
2. **资源税自用视同销售**
3. **资源税优惠**：衰竭期矿山减30%
4. **环保税四大税目**：大气/水/固体废物/噪声
5. **环保税大气/水只征前3项**
6. **环保税优惠**：低于标准30%按75%，低于50%按50%
7. **环保税不适用于间接排放**（排入集中处理设施的）
