# 税法总论 —— 第一性原理教程

## 一、税法概念

### 1.1 税收与税法

**税收的本质**：税收是国家为实现其职能，凭借政治权力，按照法律规定的标准，强制地、无偿地取得财政收入的一种分配形式。

**税收的特征（三性）**：
- **强制性**：国家凭借政治权力依法强制征收，不以纳税人意志为转移
- **无偿性**：国家征税后不向纳税人支付任何报酬
- **固定性**：征税前以法律形式规定课征对象和征收数额之间的比例，不经批准不能随意改变

**税法的概念**：税法是国家制定的用以调整国家与纳税人之间在征纳税方面权利与义务关系的法律规范的总称。

**税收与税法的关系**：
- 税收是经济活动（实质），税法是法律形式（保障）
- 有税必有法，无法不成税
- 税收决定税法，税法规范税收

### 1.2 税收法律关系

**税收法律关系的构成要素**：

| 要素 | 内容 |
|------|------|
| **主体** | 征税主体（税务机关等）和纳税主体（纳税人、扣缴义务人） |
| **客体** | 征税对象（货物、劳务、所得、财产等） |
| **内容** | 主体所享有的权利和承担的义务 |

**税收法律关系的特征**：
- 主体一方只能是国家（或税务机关）
- 体现国家单方面意志
- 权利义务不对等（征税主体享有较多权力）
- 具有财产所有权转移的性质

### 1.3 税法与其他法律的关系

**税法与宪法**：宪法是税法的立法依据，税法不得与宪法相抵触。

**税法与民法**：
- 民法调整平等主体关系，税法调整征纳双方不平等关系
- 税法可参照民法的某些概念（如合同、代理等）

**税法与刑法**：
- 刑法规定涉税犯罪及刑罚，税法规定违法行为及行政处罚
- 偷税/逃税情节严重构成犯罪的，适用刑法

**税法与行政法**：
- 税法属于特殊行政法
- 税务行政行为受行政法基本原则约束

## 二、税法原则

### 2.1 税法基本原则

| 原则 | 含义 |
|------|------|
| **税收法定原则** | 税种的设立、税率的确定、征税程序等都必须由法律规定（核心原则） |
| **税收公平原则** | 税收负担应在纳税人之间公平分配，量能课税 |
| **税收效率原则** | 税收应有利于资源有效配置和经济运行，包括行政效率和经济效率 |
| **实质课税原则** | 根据纳税人的真实负担能力决定纳税数额，不受形式外观约束 |

> **重点**：税收法定原则是税法的首要基本原则，包括征税要素法定、征税要素明确、征税程序合法三个层次。

### 2.2 税法适用原则

| 原则 | 含义 |
|------|------|
| **法律优位原则** | 税收法律的效力高于税收行政法规和规章 |
| **法律不溯及既往原则** | 新法不适用于其生效前发生的事件和行为 |
| **新法优于旧法原则** | 对同一事项新法与旧法规定不同时，适用新法 |
| **特别法优于一般法原则** | 特别规定与一般规定不一致时，适用特别规定 |
| **实体从旧、程序从新原则** | 实体法适用行为发生时的法，程序法适用新法 |
| **程序优于实体原则** | 税收争讼时先履行纳税义务再进行争议解决 |

## 三、税法要素

税法要素是构成税法的必要因素，是区分不同税种的主要标志。

### 3.1 纳税人（纳税义务人）

**概念**：税法规定的直接负有纳税义务的单位和个人。

**相关概念**：
- **负税人**：实际负担税款的单位和个人（与纳税人可能不同）
- **代扣代缴义务人**：有义务从纳税人收入中扣除其应纳税款并代为缴纳的单位
- **代收代缴义务人**：有义务借助经济往来向纳税人收取应纳税款并代为缴纳的单位
- **代征人**：受税务机关委托代征税款的单位

### 3.2 征税对象（课税对象）

**概念**：税法规定的征税的目的物，是区分不同税种的主要标志。

**征税对象与税目的关系**：
- 征税对象是大的分类（如商品、所得、财产）
- 税目是征税对象的具体化（如消费税下的烟、酒、化妆品等）

### 3.3 税目

**概念**：税法规定的征税对象的具体项目，是征税对象的具体化。

### 3.4 税率

**概念**：应纳税额与征税对象数额之间的法定比例，是计算税额的尺度。

**税率的基本形式**：

| 税率形式 | 特点 | 适用税种举例 |
|----------|------|-------------|
| **比例税率** | 不随征税对象数额变化 | 增值税、企业所得税 |
| **累进税率** | 随征税对象数额增大而提高 | 个人所得税（综合所得） |
| **定额税率（固定税额）** | 按征税对象单位直接规定固定税额 | 城镇土地使用税、车船税 |

**累进税率的分类**：
- **超额累进税率**：将征税对象按数额大小划分为若干等级，每个等级适用不同税率（如个人所得税综合所得）
- **超率累进税率**：以征税对象数额的相对率为累进依据（如土地增值税）

> **速算扣除数** = 按全额累进税率计算的税额 − 按超额累进税率计算的税额

### 3.5 纳税环节

**概念**：税法规定的征税对象在从生产到消费的流转过程中应当缴纳税款的环节。

分为：生产环节、批发环节、零售环节、进口环节等。

### 3.6 纳税期限

**概念**：税法规定的纳税人发生纳税义务后向国家缴纳税款的期限。

包括：纳税义务发生时间、纳税计算期、税款缴库期。

### 3.7 纳税地点

**概念**：税法规定的纳税人（包括代征人、扣缴义务人）缴纳税款的具体地点。

## 四、税收立法与税法体系

### 4.1 税收立法

**税收立法权划分**：
- **中央**：全国性税种的立法权（中央税、共享税、全国统一实行的地方税）
- **地方**：在中央授权范围内行使地方税的立法权

**税收法律**：由全国人大及其常委会制定（如《个人所得税法》《企业所得税法》等）

**税收行政法规**：由国务院制定（如《增值税暂行条例》等）

**税收部门规章**：由财政部、国家税务总局制定（如《增值税暂行条例实施细则》等）

**税收地方性法规**：由地方人大制定

### 4.2 税法体系

**按征税对象分类（最重要的分类）**：

| 类别 | 具体税种 |
|------|----------|
| **商品和劳务税类（流转税）** | 增值税、消费税、关税 |
| **所得税类** | 企业所得税、个人所得税 |
| **财产和行为税类** | 房产税、契税、土地增值税、印花税、车辆购置税、车船税 |
| **资源税类** | 资源税、城镇土地使用税、耕地占用税 |
| **特定目的税类** | 城市维护建设税、环境保护税、船舶吨税、烟叶税 |

**按管理权限分类**：
- **中央税**：消费税、关税、车辆购置税、船舶吨税
- **地方税**：房产税、城镇土地使用税、耕地占用税、契税、土地增值税、车船税、烟叶税
- **共享税**：增值税（50:50）、企业所得税（60:40）、个人所得税（60:40）、资源税（海洋石油归中央，其余归地方）、印花税（证券交易归中央，其余归地方）、城市维护建设税

## 五、税收执法

### 5.1 税收执法主体

- **国家税务总局**：国务院主管税收工作的直属机构
- **省级及以下税务机关**：税务局、税务分局、税务所
- **海关**：负责关税、船舶吨税及进口环节增值税、消费税的征收

### 5.2 税收执法的特征

- 具有国家强制性
- 具体行政行为
- 单方性
- 可救济性（可复议、可诉讼）

### 5.3 税务管辖

- **地域管辖**：按纳税人所在地划分
- **级别管辖**：按税务机关级别划分管辖权限

## 六、税务权利与义务

### 6.1 纳税人的权利

| 权利 | 说明 |
|------|------|
| 知情权 | 了解税收法律法规和纳税程序 |
| 要求保密权 | 要求税务机关为其保密 |
| 申请减税免税权 | 依法申请税收优惠 |
| 申请退税权 | 多缴税款可申请退还 |
| 陈述申辩权 | 对税务处理提出异议 |
| 复议诉讼权 | 对税务决定不服可复议或诉讼 |
| 控告检举权 | 检举税收违法行为 |
| 申请延期申报权 | 因特殊原因可申请延期申报 |
| 申请延期缴纳税款权 | 因特殊困难可申请延期缴纳 |
| 委托税务代理权 | 可委托税务代理人办理税务事宜 |

### 6.2 纳税人的义务

- 依法纳税义务
- 代扣代缴义务（扣缴义务人）
- 安装使用税控装置义务
- 依法开具发票义务
- 依法提供纳税信息义务
- 配合税务检查义务

## 七、国际税收关系

### 7.1 国际税收的概念

国际税收是指两个或两个以上国家政府，各自基于其课税主权，在对跨国纳税人进行课税时，因各课税权主体之间征税行为的矛盾而产生的国家间税收分配关系。

### 7.2 税收管辖权

| 类型 | 含义 | 行使依据 |
|------|------|----------|
| **地域管辖权（来源地管辖权）** | 对来源于本国境内的所得征税 | 领土原则 |
| **居民管辖权** | 对本国居民的全球所得征税 | 居民身份 |
| **公民管辖权** | 对本国公民的全球所得征税 | 国籍 |

**中国实行**：居民管辖权和地域管辖权相结合的双重管辖权。

### 7.3 国际重复征税及其消除

**国际重复征税产生原因**：两个或两个以上国家对同一纳税人的同一所得同时行使征税权。

**消除方法**：
- **免税法**：居住国对本国居民来源于境外的所得免予征税
- **扣除法**：将已缴国外税款作为费用扣除
- **抵免法**：居住国允许在本国应纳税额中抵扣已在境外缴纳的税款（最常用）

**抵免法的分类**：
- **全额抵免** vs **限额抵免**（中国采用限额抵免）
- **分国抵免** vs **综合抵免**

### 7.4 国际税收协定

- 以联合国范本（UN范本）和经济合作与发展组织范本（OECD范本）为蓝本
- 主要内容：征税权划分、消除双重征税、无差别待遇、情报交换等

## 考试要点总结

1. **税收三性**：强制性、无偿性、固定性
2. **税法基本原则**（4个）vs**适用原则**（6个）：区分并理解各自含义
3. **税法要素**中税率的分类（比例、累进、定额），超额累进与速算扣除数
4. **税种分类**：按征税对象分为五大类，按管理权限分为中央税、地方税、共享税
5. **税收管辖权**：中国采用居民管辖权+地域管辖权双重管辖
6. **消除国际重复征税的三种方法**：免税法、扣除法、抵免法
