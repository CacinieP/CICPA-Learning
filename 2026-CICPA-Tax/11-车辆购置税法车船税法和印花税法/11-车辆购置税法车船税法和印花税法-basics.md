# 车辆购置税法、车船税法和印花税法 —— 第一性原理教程

## 一、车辆购置税法

### 1.1 纳税人

在**境内购置**汽车、有轨电车、汽车挂车、排气量超过150毫升的摩托车的单位和个人。

**购置方式**：购买、进口、自产、受赠、获奖或以其他方式取得。

### 1.2 计税依据

| 购置方式 | 计税依据 |
|----------|----------|
| 购买自用 | 全部价款（不含增值税） |
| 进口自用 | 关税完税价格 + 关税 + 消费税 |
| 自产自用 | 同类应税车辆销售价格（不含增值税） |
| 其他方式 | 按购置时相关凭证载明价格 |

### 1.3 税率与应纳税额

$$应纳税额 = 计税价格 \times 10\%$$

### 1.4 税收优惠

**免征：**
- 外国驻华使馆/领事馆和国际组织驻华机构及其外交人员自用车辆
- 中国人民解放军/武装警察部队列入装备订货计划的车辆
- 悬挂应急救援专用号牌的国家综合性消防救援车辆
- 设有固定装置的非运输专用作业车辆
- 城市公交企业购置的公共汽电车辆

**减征：**
- 纳税人购置新能源汽车→免征
- 回收企业收购废弃电器电子产品处理符合条件的车辆

### 1.5 征收管理

- **纳税义务发生时间**：购置应税车辆的当日
- **纳税期限**：纳税义务发生之日起60日内
- **一次征收**：车辆购置税一次性缴纳
- **纳税地点**：车辆登记地

## 二、车船税法

### 2.1 纳税人

在**境内**属于车船税法所附《车船税税目税额表》规定的车辆/船舶的**所有人或管理人**。

### 2.2 税目与税率

**乘用车（按排气量分档）：**

| 排气量 | 年基准税额 |
|--------|-----------|
| ≤1.0L | 60-360元 |
| 1.0-1.6L | 300-540元 |
| 1.6-2.0L | 360-660元 |
| 2.0-2.5L | 660-1200元 |
| 2.5-3.0L | 1200-2400元 |
| 3.0-4.0L | 2400-3600元 |
| >4.0L | 3600-5400元 |

**商用车/其他车辆/船舶**按整备质量/净吨位/艇身长度计征。

### 2.3 应纳税额

$$应纳税额 = 计税单位 \times 年基准税额$$

**新车购置当年**：$$应纳税额 = 年基准税额 \div 12 \times 应纳税月份数$$

### 2.4 税收优惠

**免征：**
- 捕捞/养殖渔船
- 军队/武装警察部队专用的车船
- 警用车船
- 新能源车船
- 外国驻华使领馆/国际组织驻华机构及外交人员自用车船

**减征：**
- 节约能源车船→减半

### 2.5 征收管理

- **纳税义务发生时间**：取得车船所有权/管理权的当月
- **纳税期限**：按年申报缴纳
- **纳税方式**：保险机构代收代缴（与交强险一并）

## 三、印花税法

### 3.1 纳税人

在**境内**书立应税凭证/进行证券交易的单位和个人。

### 3.2 税目与税率

| 税目 | 税率 |
|------|------|
| **合同** | |
| — 借款合同 | 0.05‰ |
| — 融资租赁合同 | 0.05‰ |
| — 买卖合同 | 0.3‰ |
| — 承揽合同 | 0.3‰ |
| — 建设工程合同 | 0.3‰ |
| — 运输合同 | 0.3‰ |
| — 技术合同 | 0.3‰ |
| — 租赁合同 | 1‰ |
| — 保管合同 | 1‰ |
| — 仓储合同 | 1‰ |
| — 财产保险合同 | 1‰ |
| **产权转移书据** | |
| — 股权转让书据 | 0.5‰ |
| — 其他 | 0.5‰ |
| **营业账簿** | 0.25‰ |
| **证券交易** | 1‰ |

### 3.3 计税依据

| 凭证类型 | 计税依据 |
|----------|----------|
| 合同 | 合同金额（列明的不含税金额） |
| 产权转移书据 | 所列金额 |
| 营业账簿 | 实收资本+资本公积合计金额 |
| 证券交易 | 成交金额 |

### 3.4 应纳税额

$$应纳税额 = 计税依据 \times 适用税率$$

### 3.5 税收优惠

**免征（主要）：**
- 农产品收购合同
- 无息/贴息借款合同
- 个人与电子商务经营者订立的电子订单
- 外国驻华使领馆/国际组织驻华机构等书立的凭证
- 财产所有人将财产赠给政府/社会福利单位/学校所立的书据

### 3.6 征收管理

- **纳税义务发生时间**：书立应税凭证/完成证券交易的当日
- **纳税期限**：
  - 按季/按年计征→季度/年度终了15日内
  - 按次计征→纳税义务发生之日起15日内
- **纳税地点**：纳税人机构所在地/居住地

## 考试要点

1. **车辆购置税**：10%税率，一次性缴纳，60日内申报
2. **车船税**：按年缴纳，保险机构代收代缴
3. **车船税排气量分档**：7档
4. **印花税税率**：记住各合同税率（0.05‰/0.3‰/1‰/0.5‰/0.25‰）
5. **印花税营业账簿**：仅对实收资本+资本公积征税
6. **证券交易印花税**：1‰
