# 增值税法 —— 典型考题解析

## 一、核心考法分类

本章是CPA税法考试中**分值最高**的章节（P0级别），核心考法包括：

1. **计算问答题**：销项税额、进项税额、应纳税额的综合计算
2. **单选题**：税率适用、不得抵扣情形、视同销售判定
3. **多选题**：税收优惠、进项抵扣规则、征收管理
4. **综合题**：与消费税、企业所得税联合出题

## 二、典型例题解析

### 2.1 销项税额计算

**题目（计算问答题）：** 甲企业为增值税一般纳税人，2024年3月发生下列业务：

（1）销售货物取得含税销售收入113万元，并开具增值税专用发票；
（2）将自产产品用于集体福利，成本8万元，无同类售价，成本利润率10%；
（3）收回委托加工的货物一批，取得增值税专用发票，注明加工费3万元，税额0.39万元；
（4）购进一批原材料用于简易计税项目，取得增值税专用发票注明税额2万元。

已知：增值税税率13%，不考虑其他因素。

要求：计算甲企业当月应缴纳的增值税。

**解析：**

**Step 1：计算销项税额**

业务（1）销售货物：
销售额 = 113 ÷ (1 + 13%) = 100万元
销项税额 = 100 × 13% = 13万元

业务（2）视同销售（用于集体福利）：
组成计税价格 = 成本 × (1 + 成本利润率) = 8 × (1 + 10%) = 8.8万元
销项税额 = 8.8 × 13% = 1.144万元

**销项税额合计** = 13 + 1.144 = 14.144万元

**Step 2：计算进项税额**

业务（3）委托加工收回：
取得的增值税专用发票 → 可以抵扣
进项税额 = 0.39万元

业务（4）购进原材料用于简易计税项目：
**不得抵扣进项税额**
进项税额 = 0万元

**进项税额合计** = 0.39万元

**Step 3：计算应纳税额**

应纳税额 = 销项税额 - 进项税额 = 14.144 - 0.39 = 13.754万元

**答案：13.754万元**

### 2.2 进项税额抵扣规则

**题目（单选）：** 下列进项税额中，准予从销项税额中抵扣的是（ ）。

A. 增值税一般纳税人购进贷款服务的进项税额
B. 购进用于集体福利的货物的进项税额
C. 取得增值税专用发票注明税额3万元，用于接受境外单位提供的研发服务
D. 因管理不善造成的非正常损失货物的进项税额

**解析：**

不得抵扣的进项税额（重点记忆）：
1. 用于简易计税、免征增值税、集体福利、个人消费的购进
2. 非正常损失的购进货物及相关劳务
3. 非正常损失的在产品、产成品耗用的购进货物
4. 贷款服务、餐饮服务、居民日常服务、娱乐服务

选项分析：
- A：贷款服务 → **不得抵扣**
- B：用于集体福利 → **不得抵扣**
- C：接受境外研发服务 → 取得完税凭证可以抵扣（按规定计算抵扣） → **可以抵扣**
- D：管理不善 → 非正常损失 → **不得抵扣**

**答案：C**

### 2.3 视同销售判定

**题目（多选）：** 下列行为中，应当视同销售货物缴纳增值税的有（ ）。

A. 某服装厂将自产服装用于交际应酬
B. 某商场将外购的食品用于职工福利
C. 某企业将委托加工的货物分配给投资者
D. 某酒厂将自产白酒用于勾兑生产高档葡萄酒
E. 某公司无偿提供增值税应税服务

**解析：**

视同销售货物的情形：
1. 将货物交付其他单位或个人代销
2. 销售代销货物
3. 设有两个以上机构并实行统一核算，将货物移送其他机构（相关机构在同一县市的除外）
4. 将自产、委托加工的货物用于**非应税项目、集体福利、个人消费、投资、分配、无偿赠送**
5. 将外购的货物用于**投资、分配、无偿赠送**

选项分析：
- A：用于交际应酬 → 无偿赠送 → **视同销售**
- B：外购食品用于职工福利 → 属于"用于集体福利" → **不视同销售，进项税额不得抵扣**（注意！外购货物用于集体福利是进项转出，不是视同销售）
- C：分配给投资者 → **视同销售**
- D：自产白酒用于勾兑 → 用于连续生产应税消费品 → **不视同销售**
- E：无偿提供应税服务 → **视同销售**

**答案：A、C、E**

### 2.4 销售额的确定

**题目（计算问答题）：** 乙商场为增值税一般纳税人，2024年4月采用"以旧换新"方式销售金项链，消费者用旧项链可抵顶500元。当月销售金项链20件，每件新项链零售价3390元（含税），消费者实际支付的现金为2890元/件。计算乙商场当月销售金项链的增值税销项税额。

**解析：**

以旧换新销售：
- **一般货物**：按新货同期销售价格确定销售额
- **金银首饰**：以实际收取的不含税差额作为销售额

本题销售的是金项链，属于金银首饰，应按实际收取的不含税差额确定销售额。

**Step 1：计算实际收取的不含税销售额**

每件新项链零售价（含税）= 3390元
消费者旧项链抵顶 = 500元
实际收取现金 = 2890元

含税销售额 = 2890元/件 × 20件 = 57800元

不含税销售额 = 57800 ÷ (1 + 13%) = 51150.44元

**Step 2：计算销项税额**

销项税额 = 51150.44 × 13% = 6649.56元

**答案：6649.56元**

### 2.5 进口环节增值税

**题目（计算问答题）：** 丙公司进口一批应税消费品，关税完税价格为200万元，关税80万元，消费税税率20%。计算进口环节应缴纳的增值税。

**解析：**

**Step 1：计算组成计税价格**

进口环节增值税 = 组成计税价格 × 税率

组成计税价格 = 关税完税价格 + 关税 + 消费税

其中，消费税 = 组成计税价格 × 消费税税率

设组成计税价格为P：
P = 200 + 80 + P × 20%
P - P × 20% = 280
P × 80% = 280
P = 350万元

**Step 2：计算进口环节增值税**

进口增值税 = 350 × 13% = 45.5万元

**答案：45.5万元**

### 2.6 出口退税计算

**题目（单选）：** 下列关于出口退（免）税的说法，正确的是（ ）。

A. 生产企业出口自产货物适用免抵退税办法
B. 外贸企业出口货物适用免退税办法
C. 适用免抵退税办法的企业，退税退还的是进项税额
D. 免退税办法下，退税额=出口货物的进项税额-免抵退税不得免征和抵扣税额

**解析：**

出口退（免）税方式：

| 企业类型 | 适用方式 | 说明 |
|----------|----------|------|
| 生产企业 | 免抵退税 | 免征出口销项税，抵减内销应纳税，退还剩余进项税 |
| 外贸企业 | 免退税 | 免征出口销项税，退还购进货物的进项税 |

选项分析：
- A：正确，生产企业出口自产货物适用免抵退税
- B：正确，外贸企业出口货物适用免退税
- C：错误，免抵退退还的是"抵减+退还"后的净额
- D：错误，这是免抵退税的计算公式；免退税是直接退还进项税

**答案：A、B**

## 三、计算模板

### 一般纳税人应纳税额计算模板

```
┌─────────────────────────────────────────────────────────────┐
│                    一般计税方法                              │
├─────────────────────────────────────────────────────────────┤
│ 应纳税额 = 当期销项税额 - 当期进项税额                       │
│                                                             │
│ 销项税额 = 销售额 × 税率                                     │
│          = 含税销售额 ÷ (1 + 税率) × 税率                     │
│                                                             │
│ 进项税额抵扣：                                               │
│ ① 专用发票：发票注明税额                                      │
│ ② 海关缴款书：缴款书上注明税额                                │
│ ③ 农产品：买价 × 扣除率(9%/10%)                              │
│ ④ 旅客运输：票价+燃油附加费 ÷ (1+5%) × 5%                    │
│ ⑤ 收费公路通行费：通行费发票 ÷ (1+5%) × 5%                   │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│                    不得抵扣情形                               │
├─────────────────────────────────────────────────────────────┤
│ ✗ 简易计税/免税/集体福利/个人消费                            │
│ ✗ 非正常损失（管理不善/违法）                                 │
│ ✗ 贷款服务/餐饮服务/居民日常服务/娱乐服务                     │
│ ✓ 已抵扣后改变用途 → 进项税额转出                            │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│                    视同销售（无销售额时）                      │
├─────────────────────────────────────────────────────────────┤
│ 组价 = 成本 × (1 + 成本利润率) ÷ (1 - 消费税税率)            │
│ 视同销售货物的销项税额 = 组价 × 税率                          │
└─────────────────────────────────────────────────────────────┘
```

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|-------|------|---------|
| 自产货物用于集体福利 vs 外购货物用于集体福利 | 前者视同销售，后者进项转出 | "自产"→卖给自己人，算销售；"外购"→买来发福利，算消费 |
| 视同销售 vs 进项税额转出 | 视同销售有销项税额；进项转出无销项 | 视同销售→有收入/分配→要算销项；进项转出→只抵扣不销售 |
| 以旧换新（一般货物） vs 以旧换新（金银首饰） | 前者按新货全价；后者按实收差额 | "金"字头特殊对待 |
| 包装物押金（酒类） vs 包装物押金（非酒类） | 酒类收取时即并入；其他逾期或1年并入 | "酒"字提前入账 |
| 简易计税 vs 一般计税 | 简易计税不得抵扣进项 | "简易"→简单方法，不能抵扣 |

## 五、速记口诀

**不得抵扣进项**：简免集个非正常，贷款餐饮居民娱

**视同销售**：代销移送非个投分赠

**出口退（免）税**：生产免抵退，外贸免退税

**税率记忆**：13%基本货劳，9%交邮建基础，不动租赁6%服，无形土地9%算
