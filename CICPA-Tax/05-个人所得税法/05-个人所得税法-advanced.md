# 个人所得税法 —— 综合实战

## 一、综合题解题框架

```
【个人所得税综合题解题步骤】

Step 1：判断纳税人身份
├─ 居民个人（境内有住所/满183天）→ 全球所得，综合+经营+分类
├─ 非居民个人 → 来源于境内所得，按次或按月计税
         ↓
Step 2：识别所得类型
├─ 综合所得（工资薪金、劳务报酬、稿酬、特许权使用费）
├─ 经营所得
├─ 分类所得（利息股息红利、财产租赁、财产转让、偶然所得）
         ↓
Step 3：计算各类型应纳税所得额和应纳税额
├─ 综合所得：年收入额 - 6万 - 三险一金 - 专项附加扣除
├─ 经营所得：收入 - 成本费用损失
├─ 分类所得：按次计算（特殊项目除外）
         ↓
Step 4：处理特殊事项
├─ 全年一次性奖金（单独计税 or 并入综合）
├─ 股权激励
├─ 境外所得抵免
└─ 公益性捐赠扣除
         ↓
Step 5：汇算清缴（如需）
综合所得需在次年3月1日至6月30日办理汇算清缴
```

## 二、跨章联动图谱

> 🔗 **跨科联动：**
>
> **个人所得税 ↔ 企业所得税**：
> - 都是所得税，计税原理相似（收入-扣除）
> - 工资薪金在企业所得税前扣除，但在个人所得税中计入收入
> - 捐赠扣除比例不同（个税30%/企税12%）
>
> **个人所得税 ↔ 增值税**：
> - 劳务报酬涉及增值税（一般纳税人6%）
> - 增值税是价外税，影响不含税收入的计算
>
> **个人所得税 ↔ 会计（应付职工薪酬）**：
> - 工资薪金在会计上计入成本费用
> - 个税是"先扣后发"，企业代扣代缴

## 三、陷阱与反套路

### 3.1 常见陷阱

| 陷阱类型 | 典型表现 | 识别要点 |
|----------|----------|----------|
| **稿酬收入计算** | 只扣除80%而忘了再乘70% | "打八折再七折" |
| **全年一次性奖金** | 不知道可以选择计税方式 | 年终奖可以选择单独或并入 |
| **综合所得扣除** | 将6万和专项附加扣除混淆 | 6万是定额，专项附加是按项 |
| **经营所得扣除** | 将业主工资计入成本 | 业主工资不得在经营所得中扣除 |
| **非居民个人计税** | 套用居民个人的计算方式 | 非居民按月/按次，不合并 |

### 3.2 反套路策略

1. **先判断是居民个人还是非居民个人**
2. **区分所得类型，选择正确的计税方法**
3. **注意稿酬的"双重折扣"**
4. **年终奖计税方式可以自主选择**

## 四、真题变式推演

### 变式一：多类型综合

**题目（综合题）：**
中国居民陈某2024年度取得以下所得：
1. 每月工资25,000元，每月三险一金4,000元，12月取得年终奖120,000元
2. 出版专著取得稿酬100,000元
3. 转让境内上市公司股票取得所得50,000元（持有超过1年）
4. 出租住房每月租金6,000元（全年）
5. 受邀做学术报告取得劳务报酬30,000元

专项附加扣除：子女教育（1个孩子）24,000元，住房贷款利息12,000元。

**要求：** 计算陈某2024年度综合所得应缴纳的个人所得税（年终奖单独计税）。

**解析：**

**第一步：计算综合所得收入额**

| 项目 | 金额 | 计算 | 收入额 |
|------|------|------|--------|
| 工资薪金（不含年终奖） | 25,000×11=275,000 | 直接 | 275,000 |
| 稿酬 | 100,000 | ×80%×70% | 56,000 |
| 劳务报酬 | 30,000 | ×80% | 24,000 |
| **小计** | — | — | **355,000** |

**第二步：计算应纳税所得额**

$$应纳税所得额 = 355,000 - 60,000 - (4,000×12) - (24,000 + 12,000)$$

$$= 355,000 - 60,000 - 48,000 - 36,000 = 211,000元$$

**第三步：计算综合所得应纳税额**

级距144,000-300,000，税率20%，速算扣除数16,920

$$综合所得应纳税额 = 211,000 × 20\% - 16,920 = 25,280元$$

**第四步：计算年终奖应纳税额（单独计税）**

$$120,000 ÷ 12 = 10,000元 → 税率10%，速算扣除数210$$

$$年终奖应纳税额 = 120,000 × 10\% - 210 = 11,790元$$

**第五步：计算其他分类所得**

- 股票转让所得：免征个人所得税（持有超过1年的上市公司股票）
- 财产租赁所得：
  - 月应纳税额 = 6,000 × (1-20%) × 10% = 480元
  - 年应纳税额 = 480 × 12 = 5,760元

**第六步：汇总**

$$总应纳税额 = 25,280 + 11,790 + 5,760 = 42,830元$$

**答案：** 陈某2024年度应缴纳个人所得税42,830元

### 变式二：全年一次性奖金筹划

**题目：**
某公司三位员工年终奖金额及工资情况如下，请为每人选择最优计税方式：

| 员工 | 月工资（扣除三险一金后） | 年终奖 | 综合所得（不含年终奖） |
|------|-------------------------|--------|------------------------|
| 张某 | 8,000 | 36,000 | 96,000 |
| 李某 | 15,000 | 180,000 | 180,000 |
| 王某 | 20,000 | 60,000 | 240,000 |

**解析：**

**张某（年终奖36,000元）**
- 单独计税：36,000 ÷ 12 = 3,000 → 3%，税额 = 1,080元
- 并入综合：96,000 + 36,000 = 132,000 - 60,000 = 72,000 → 10%，税额 = 7,200 - 2,520 = 4,680元
- **结论：单独计税节省3,600元**

**李某（年终奖180,000元）**
- 单独计税：180,000 ÷ 12 = 15,000 → 20%，税额 = 180,000 × 20% - 1,410 = 34,590元
- 并入综合：180,000 + 180,000 = 360,000 - 60,000 = 300,000 → 25%，税额 = 300,000 × 25% - 31,920 = 43,080元
- **结论：单独计税节省8,490元**

**王某（年终奖60,000元）**
- 单独计税：60,000 ÷ 12 = 5,000 → 10%，税额 = 60,000 × 10% - 210 = 5,790元
- 并入综合：240,000 + 60,000 = 300,000 - 60,000 = 240,000 → 20%，税额 = 240,000 × 20% - 16,920 = 31,080元
- **结论：单独计税节省25,290元**

**答案：** 三位员工均选择单独计税更优

### 变式三：境外所得抵免

**题目：**
中国居民刘某2024年度境内综合所得400,000元，境外A国取得工资所得100,000元，在A国已缴纳个人所得税20,000元；境外B国取得劳务报酬50,000元，在B国已缴纳个人所得税5,000元。

**要求：** 计算刘某应向中国补缴的个人所得税。

**解析：**

**第一步：计算境内所得应纳税额**

$$境内应纳税额 = (400,000 - 60,000) × 20\% - 16,920 = 51,080元$$

**第二步：计算抵免限额**

$$境内外总额 = 400,000 + 100,000 + 50,000 = 550,000元$$

**A国抵免限额：**
$$A国抵免限额 = 550,000 × 25\% × \frac{100,000}{550,000} = 25,000元$$

A国已缴20,000元 < 25,000元，可全额抵免，需补缴差额5,000元

**B国抵免限额：**
$$B国抵免限额 = 550,000 × 25\% × \frac{50,000}{550,000} = 12,500元$$

B国已缴5,000元 < 12,500元，可全额抵免，需补缴差额7,500元

**第三步：计算应补缴总额**

$$应补缴 = 51,080 + 5,000 + 7,500 - 20,000 - 5,000 = 38,580元$$

简化计算：
$$应补缴 = 51,080 + (25,000 - 20,000) + (12,500 - 5,000) - 0 = 63,580元$$

**答案：** 刘某应向中国补缴个人所得税38,580元

## 五、实务衔接

### 5.1 汇算清缴要点

| 要点 | 说明 |
|------|------|
| 适用人群 | 居民个人取得综合所得（工资薪金+劳务报酬+稿酬+特许权使用费） |
| 办理时间 | 次年3月1日至6月30日 |
| 办理方式 | 可通过个人所得税APP、税务机关大厅、扣缴义务人等 |
| 补税情形 | 综合所得年收入>12万元且需补税>400元 |

### 5.2 专项附加扣除填报

- 子女教育：需满3岁至学历教育结束
- 继续教育：需在取得证书的年度填报
- 大病医疗：需在次年汇算清缴时填报
- 住房租金与房贷利息：不可同时享受
