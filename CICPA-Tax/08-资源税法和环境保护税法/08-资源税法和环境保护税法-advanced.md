# 资源税法和环境保护税法 —— 综合实战

## 一、综合题解题框架

```
【资源税+环保税综合题解题步骤】

Step 1：判断税种（资源税 or 环保税）
├─ 资源税：开采应税资源 → 销售或自用
└─ 环保税：直接向环境排放应税污染物
         ↓
Step 2：确定计征方式
├─ 资源税：从价/从量
└─ 环保税：污染当量数×税额 / 排放量×税额
         ↓
Step 3：处理特殊事项
├─ 资源税：共伴生矿分别核算、衰竭期矿山减30%
└─ 环保费：前3项、优惠（75%/50%）
         ↓
Step 4：计算应纳税额
```

## 二、跨章联动图谱

> 🔗 **跨科联动：**
>
> **资源税 ↔ 增值税**：
> - 资源税是价内税，计入销售额，但增值税的销售额不含增值税
> - 资源税销售额 = 不含增值税的销售额
>
> **环保税 ↔ 企业所得税**：
> - 环保税计入"税金及附加"，可在企业所得税前扣除
>
> **资源税 ↔ 消费税**：
> - 成品油既要缴纳资源税又要缴纳消费税（不同环节）

## 三、陷阱与反套路

| 陷阱类型 | 典型表现 | 识别要点 |
|----------|----------|----------|
| **含增值税销售额** | 直接用含税价格计算资源税 | 需先换算为不含税价格 |
| **连续生产误征税** | 将用于连续生产的资源征税 | 连续生产不征税 |
| **环保税前3项遗漏** | 对所有污染物都征税 | 每一排放口只征前3项 |
| **噪声未超标征税** | 噪声未超标也征税 | 超标才征 |

## 四、真题变式推演

### 变式一：资源税+增值税综合

**题目：**
某煤矿（一般纳税人）2024年6月：
1. 销售原煤50,000吨，含增值税价格565元/吨（增值税税率13%）
2. 将原煤5,000吨用于连续生产洗煤（不缴纳资源税）
3. 将原煤3,000吨用于职工食堂（视同销售）

资源税税率6%，成本300元/吨，成本利润率10%。

**解析：**

**业务1：销售原煤**
- 不含税价格 = 565 ÷ 1.13 = 500元/吨
- 应纳税额 = 50,000 × 500 × 6% = 1,500,000元

**业务2：连续生产洗煤**
- 不缴纳资源税

**业务3：职工食堂（视同销售）**
- 组价 = 300 × (1+10%) ÷ (1-6%) = 330 ÷ 0.94 = 351.06元/吨
- 应纳税额 = 3,000 × 351.06 × 6% = 63,190.68元

**合计：** 1,500,000 + 63,190.68 = **1,563,190.68元**

### 变式二：环保税综合

**题目：**
某化工厂2024年第三季度排放以下水污染物：
- 第一排放口：COD 200千克（当量值1千克），氨氮30千克（当量值0.7千克）
- 第二排放口：COD 100千克（当量值1千克），总磷10千克（当量值0.25千克）

适用税额：水污染物3元/污染当量。经检测，排放浓度低于国家标准35%。

**解析：**

**各排放口当量数：**
- 第一排放口：COD 200÷1=200；氨氮30÷0.7=42.86
- 第二排放口：COD 100÷1=100；总磷10÷0.25=40

**各排放口取前3项（不够3项的全征）：**
- 第一排放口：200 + 42.86 = 242.86
- 第二排放口：100 + 40 = 140

**优惠：低于标准35%（30%<35%<50%）→ 减按75%**

$$应纳税额 = (242.86 + 140) × 3 × 75\%$$
$$= 382.86 × 3 × 0.75 = 861.44元$$

## 五、实务衔接

| 场景 | 要点 |
|------|------|
| **绿色税制改革** | 资源税和环保税构成绿色税制的核心 |

| **资源税改革** | 从从量到从价，更好反映资源稀缺性 |

## 六、速记总结

```
┌──────────────────────────────────────────┐
│        资源税和环保税速记图              │
├──────────────────────────────────────────┤
│  【资源税】                              │
│  从价为主：销售额×税率                   │
│  自用视同销售，连续生产不征              │
│  衰竭期矿山减30%，未分核算从高          │
│                                          │
│  【环保税】                              │
│  大气/水：污染当量数×税额（前3项）      │
│  固废：排放量×税额                      │
│  噪声：超标才征                          │
│  优惠：低30%→75%，低50%→50%            │
└──────────────────────────────────────────┘
```
