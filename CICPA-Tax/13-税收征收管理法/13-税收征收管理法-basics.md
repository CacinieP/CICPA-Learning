# 税收征收管理法 —— 第一性原理教程

## 一、概述

### 1.1 适用范围

税收征收管理法适用于由**税务机关征收的各种税收**的征收管理。

**不适用：** 关税、船舶吨税（由海关征收）。

### 1.2 税收征管的原则

- 税收法定原则
- 税收优先原则
- 国家优先原则
- 税收征收管理与纳税服务并重

---

## 二、税务管理

### 2.1 税务登记

**"多证合一"：** 企业在办理市场主体登记时同步完成税务登记。

**变更登记：** 工商登记内容发生变化→自变更之日起30日内办理税务变更。

**注销登记：** 纳税人发生解散/破产/撤销等情形→在注销工商登记前办理税务注销。

### 2.2 账簿凭证管理

| 要求 | 内容 |
|------|------|
| 设置账簿 | 自领取营业执照/发生纳税义务之日起15日内 |
| 备案 | 财务会计制度/处理办法自领取税务登记证件之日起15日内 |
| 保管 | 账簿/记账凭证/报表等保管期限10年 |
| 发票 | 通过增值税发票管理系统开具 |

### 2.3 纳税申报

- **申报方式**：直接申报、邮寄申报、电子申报
- **申报期限**：按各税种规定
- **延期申报**：因不可抗力不能按期申报→在不可抗力消除后立即申报

---

## 三、税款征收

### 3.1 征收方式

| 方式 | 适用 |
|------|------|
| 查账征收 | 账簿健全的企业 |
| 查定征收 | 账簿不健全但能控制原材料/进销货的小型厂矿 |
| 查验征收 | 经营品种比较单一/经营地点/时间/商品来源不固定的纳税人 |
| 定期定额征收 | 生产经营规模小/达不到建账标准的个体工商户 |
| 代扣代缴/代收代缴 | 支付人/收取人代扣代收 |
| 委托征收 | 委托有关单位代征 |

### 3.2 纳税期限与延期缴纳

- **纳税期限**：按各税种法律规定
- **延期缴纳**：因特殊困难（不可抗力/当期货币资金扣除应付工资社保后不足以缴纳税款）→经省级税务机关批准，可延期缴纳，但**最长不超过3个月**

### 3.3 税收保全措施

**条件：** 税务机关责令限期缴纳税款→逾期未缴→在纳税期限前可采取。

**措施：**
- 书面通知银行冻结纳税人金额相当于应纳税款的存款
- 扣押/查封纳税人的价值相当于应纳税款的商品/货物/财产

**限制：** 个人及其所扶养家属维持生活必需的住房和用品不在税收保全范围。

### 3.4 税收强制执行

**条件：** 纳税人/扣缴义务人未按规定期限缴纳/解缴税款→税务机关责令限期缴纳→逾期仍未缴纳。

**措施：**
- 书面通知银行从其存款中扣缴税款
- 扣押/查封/拍卖/变卖价值相当于应纳税款的商品/货物/财产
- **可加收滞纳金**：万分之五/日

### 3.5 税款的退还与追征

| 情形 | 处理 |
|------|------|
| 纳税人多缴税款 | 自结算缴纳税款之日起3年内可要求退还（加算银行同期存款利息） |
| 因税务机关责任少缴税款 | 3年内追征（不加收滞纳金） |
| 因纳税人计算错误少缴税款 | 3年内追征（加收滞纳金）；特殊情况延长至5年 |
| 偷税/抗税/骗税 | **无限期追征** |

### 3.6 税收优先权

- 税收优先于**无担保债权**
- 税收优先于**欠缴税款后设定的担保债权**
- 税收优先于**罚款/没收违法所得**

---

## 四、税务检查

### 4.1 税务机关的职权

- 查账权：检查纳税人的账簿/记账凭证/报表
- 场地检查权：到纳税人的生产/经营场所/货物存放地检查
- 责成提供资料权
- 询问权
- 检查存款账户权（需经县以上税务局（分局）局长批准）
- 取证权

### 4.2 纳税人的权利

- 要求检查人员出示税务检查证
- 要求保守商业秘密
- 对违法检查行为可以拒绝

---

## 五、法律责任

### 5.1 主要违法行为及处罚

| 违法行为 | 处罚 |
|----------|------|
| **未按规定办理税务登记** | 责令限期改正，可处2000元以下罚款；情节严重的处2000-10000元 |
| **未按规定设置/保管账簿** | 责令限期改正，可处2000元以下罚款；情节严重的处2000-10000元 |
| **偷税** | 追缴税款+滞纳金，并处不缴/少缴税款50%以上5倍以下罚款 |
| **逃避追缴欠税** | 追缴欠税+滞纳金，并处欠缴税款50%以上5倍以下罚款 |
| **骗取出口退税** | 追缴骗取的退税款，并处骗取税款1倍以上5倍以下罚款 |
| **抗税** | 追缴税款+滞纳金，并处拒缴税款1倍以上5倍以下罚款 |

### 5.2 偷税的认定

- 伪造/变造/隐匿/擅自销毁账簿/记账凭证
- 在账簿上多列支出/不列/少列收入
- 经税务机关通知申报而拒不申报
- 进行虚假纳税申报

## 六、纳税担保和抵押

### 6.1 纳税担保

**适用情形：**
- 税务机关有根据认为纳税人有逃避纳税义务行为
- 欠缴税款的纳税人需要出境
- 纳税人同税务机关在纳税上发生争议而未缴清税款

### 6.2 担保方式

| 方式 | 说明 |
|------|------|
| 纳税保证 | 由纳税保证人承担连带责任 |
| 纳税抵押 | 以财产抵押 |
| 纳税质押 | 以动产/权利凭证质押 |

---

## 七、纳税缴费信用管理

- **纳税信用等级**：A、B、M、C、D五级
- A级纳税人：享受绿色通道/放宽发票限量等便利
- D级纳税人：加强监控、严格审核、公开涉税信息

---

## 八、涉税专业服务管理

- **涉税专业服务机构**：税务师事务所、会计师事务所、律师事务所等
- **业务范围**：纳税申报代理、一般税务咨询、专业税务顾问、税收策划、涉税鉴证、纳税情况审查
- **监管**：税务机关对涉税专业服务机构实行行政监管+行业自律

---

## 考试要点

1. **税收保全vs强制执行**：保全在纳税期限前，强制在限期缴纳后
2. **滞纳金**：万分之五/日
3. **追征期限**：税务机关原因3年/纳税人原因3年（特殊5年）/偷骗抗无限期
4. **税收优先权**：优先于无担保债权、欠税后担保债权、罚款
5. **偷税处罚**：50%-5倍罚款
6. **延期缴纳**：省级批准，最长3个月
7. **纳税信用等级**：A/B/M/C/D五级
