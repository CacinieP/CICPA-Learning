## 二、典型例题解析

### 2.1 税收保全 vs 强制执行

**题目：** 下列关于税收保全措施和强制执行措施的说法，正确的是（ ）。

A. 税收保全措施在纳税期限之后实施
B. 强制执行措施可以扣押纳税人的商品
C. 税收保全措施可以冻结纳税人存款
D. 个人生活必需品也在保全/强制执行范围内

**解析：**

- A错误：税收保全措施在**纳税期限前**实施
- B正确：强制执行措施包括扣押/查封/拍卖/变卖
- C正确：税收保全措施包括书面通知银行**冻结存款**
- D错误：个人及其所扶养家属维持生活必需的住房和用品**不在**保全/强制执行范围内

**答案：** B、C

---

### 2.2 追征期限

**题目：** 下列关于税款追征的说法，正确的是（ ）。

A. 因税务机关责任导致少缴税款的，追征期为5年
B. 因纳税人计算错误导致少缴税款的，追征期为3年
C. 偷税/抗税/骗税的追征期为10年
D. 特殊情况下（累计金额10万元以上），追征期延长至5年

**解析：**

| 情形 | 追征期限 | 是否加收滞纳金 |
|------|----------|---------------|
| 税务机关责任 | 3年 | 不加收 |
| 纳税人计算错误 | 3年 | 加收 |
| 纳税人计算错误（特殊） | 5年 | 加收 |
| 偷税/抗税/骗税 | **无限期** | 加收 |

- A错误：税务机关责任 → 3年（非5年）
- B正确：纳税人计算错误 → 3年
- C错误：偷税/抗税/骗税 → **无限期**
- D正确：特殊情况（累计>10万）→ 延长至5年

**答案：** B、D

---

### 2.3 滞纳金计算

**题目：** 某企业应缴纳增值税500,000元，纳税期限为2024年4月15日，企业于2024年5月10日才缴纳。计算应缴纳的滞纳金。

**解析：**

**逾期天数：**
- 到期日：4月15日
- 缴纳日：5月10日
- 逾期天数：4月16日至5月10日 = **25天**

$$滞纳金 = 500,000 × 0.05\% × 25 = 6,250元$$

**答案：** 6,250元

---

### 2.4 偷税认定与处罚

**题目：** 某企业通过在账簿上多列支出的方式，少缴增值税200,000元。税务机关查处后，除追缴税款和滞纳金外，还应处以多少罚款？

**解析：**

**偷税行为认定：**
在账簿上多列支出 → 属于偷税行为

**处罚标准：**
处不缴/少缴税款**50%以上5倍以下**罚款

$$罚款幅度 = 200,000 × 50\% 至 200,000 × 500\%$$
$$= 100,000元 至 1,000,000元$$

**答案：** 追缴税款200,000元+滞纳金，并处100,000元至1,000,000元罚款

---

### 2.5 税收优先权

**题目：** 某企业欠缴税款1,000,000元（发生于2024年3月），同时有如下债务：
1. 银行贷款5,000,000元（2024年1月设定抵押）
2. 供应商货款2,000,000元（无担保，2024年4月）
3. 行政罚款500,000元

说明税收优先权如何适用。

**解析：**

**税收优先权规则：**
1. 税收优先于**无担保债权** → 优先于供应商货款
2. 税收优先于**欠税后设定的担保债权** → 抵押在欠税前（1月），不优先
3. 税收优先于**罚款/没收违法所得** → 优先于行政罚款

**结论：**
- 银行贷款：抵押在先 → 税收不具有优先权
- 供应商货款：无担保 → 税收优先
- 行政罚款 → 税收优先

**答案：** 税收优先于供应商货款和行政罚款，但不优先于先设定的银行抵押权

## 三、计算模板

```
【滞纳金计算模板】
滞纳金 = 滞纳税款 × 0.05% × 逾期天数

【追征期限速查】
税务机关原因 → 3年（不加滞纳金）
纳税人计算错误 → 3年（加滞纳金）
特殊情况（>10万）→ 5年（加滞纳金）
偷税/抗税/骗税 → 无限期

【偷税处罚】
罚款 = 少缴税款 × (50% - 500%)

【延期缴纳】
条件：不可抗力/资金不足
审批：省级税务机关
期限：最长3个月
```

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|--------|------|----------|
| **税收保全 vs 强制执行** | 保全：纳税期限前冻结/扣押；强制：限期后扣缴/拍卖 | "保前执后" |
| **追征3年 vs 5年** | 一般3年，特殊（>10万）5年 | "三般五特" |
| **偷税 vs 逃税** | 税法称"偷税"，刑法称"逃税罪" | 同一行为不同叫法 |
| **税收优先权顺序** | 有担保>税收>无担保>罚款 | "担保先税后，无保罚款最后" |
| **账簿保管期限** | 10年 | "账簿保存十年整" |
