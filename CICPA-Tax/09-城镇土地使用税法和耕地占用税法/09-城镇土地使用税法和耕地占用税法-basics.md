# 城镇土地使用税法和耕地占用税法 —— 第一性原理教程

## 一、城镇土地使用税法

### 1.1 纳税人

在城市、县城、建制镇、工矿区范围内使用土地的单位和个人。

**纳税人确定：**
- 拥有土地使用权的→土地使用权人
- 土地使用权未确定/权属纠纷未解决→实际使用人
- 土地使用权共有→由共有各方分别缴纳

### 1.2 计税依据

**实际占用的土地面积**（平方米）。

### 1.3 税率（定额税率）

| 地区 | 年税额（元/平方米） |
|------|-------------------|
| 大城市 | 1.5 - 30 |
| 中等城市 | 1.2 - 24 |
| 小城市 | 0.9 - 18 |
| 县城/建制镇/工矿区 | 0.6 - 12 |

各省在上述幅度内确定本地区适用税额。

### 1.4 应纳税额

$$应纳税额 = 实际占用土地面积 \times 适用税额$$

### 1.5 税收优惠

**法定免税：**
- 国家机关/人民团体/军队自用土地
- 由财政拨付事业经费的单位自用土地
- 宗教寺庙/公园/名胜古迹自用土地
- 市政街道/广场/绿化地带等公共用地
- 直接用于农林牧渔业的生产用地
- 经批准开山填海整治的土地/改造的废弃土地（5-10年免税）

**特定减免：**
- 企业办学校/医院/托儿所/幼儿园用地
- 个人所有的居住房屋及院落用地
- 民政部门举办的福利工厂用地

### 1.6 征收管理

- **纳税义务发生时间**：
  - 购置新建商品房→房屋交付使用之次月
  - 购置存量房→办理房屋权属转移登记手续之次月
  - 出租出借房产→交付出租出借之次月
- **纳税期限**：按年计算，分期缴纳
- **纳税地点**：土地所在地

## 二、耕地占用税法

### 2.1 纳税人

在**中华人民共和国境内**占用耕地建设建筑物/构筑物/从事非农业建设的单位和个人。

### 2.2 征税范围

- **耕地**：用于种植农作物的土地
- 占用园地/林地/草地/农田水利用地/养殖水面/渔业水域滩涂等→参照耕地征收

### 2.3 税率

| 地区（人均耕地面积） | 税率（元/平方米） |
|-------------------|-----------------|
| ≤0.5亩 | 10-50 |
| 0.5-1亩 | 8-40 |
| 1-2亩 | 6-30 |
| 2-3亩 | 4-20 |
| >3亩 | 2-10 |

### 2.4 应纳税额

$$应纳税额 = 实际占用耕地面积 \times 适用税额$$

### 2.5 税收优惠

**免征：**
- 军事设施占用耕地
- 学校/幼儿园/养老院/医院占用耕地

**减征：**
- 铁路线路/公路线路/飞机场跑道等交通设施占用耕地→减按2元/平方米
- 农村居民在规定标准内占用耕地新建住宅→减半征收
- 农村烈士家属/残疾军人/鳏寡孤独/少数民族居民在规定标准内新建住宅→减半征收

**临时占用：**
- 临时占用耕地→缴纳耕地占用税
- 在批准临时占用耕地期限内恢复种植条件→全额退还

### 2.6 征收管理

- **纳税义务发生时间**：收到办理占用耕地手续的书面通知的当日
- **纳税期限**：自纳税义务发生之日起30日内
- **一次性缴纳**：耕地占用税一次性征收

## 考试要点

1. **城镇土地使用税**：按面积×定额税额，按年征收
2. **城镇土地使用税法定免税**：机关/军队/财政拨款单位/宗教/公园/公共用地/农林牧渔
3. **耕地占用税**：占用耕地从事非农业建设
4. **耕地占用税一次性征收**
5. **耕地占用税免征**：军事/学校/幼儿园/养老院/医院
6. **临时占用耕地**：先缴后退（恢复种植条件）
