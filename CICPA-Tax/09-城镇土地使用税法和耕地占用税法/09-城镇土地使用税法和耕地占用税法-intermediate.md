# 城镇土地使用税法和耕地占用税法 —— 典型考题解析

## 一、核心考法分类

| 考法类型 | 出现频率 | 典型特征 |
|----------|----------|----------|
| **城镇土地使用税计算** | ★★★★ | 实际占用面积×适用税额 |
| **税收优惠** | ★★★★★ | 法定免税项目的识别 |
| **纳税义务发生时间** | ★★★★ | 交付/登记之"次月"起 |
| **耕地占用税计算** | ★★★★ | 实际占用面积×适用税额 |
| **临时占用耕地** | ★★★ | 先缴后退（恢复种植条件） |

## 二、典型例题解析

### 2.1 城镇土地使用税基本计算

**题目：** 某企业位于大城市，实际占用土地面积10,000平方米，适用税额20元/平方米。计算年应缴纳的城镇土地使用税。

**解析：**

$$应纳税额 = 实际占用面积 × 适用税额$$

$$= 10,000 × 20 = 200,000元/年$$

**答案：** 200,000元

---

### 2.2 税收优惠应用

**题目：** 某企业位于市区，实际占用土地面积20,000平方米，其中：
- 厂区生产经营用地：12,000平方米
- 企业自办医院用地：3,000平方米
- 企业自办学校用地：2,000平方米
- 厂区内绿化用地：1,000平方米
- 厂区外公共道路用地：2,000平方米

适用税额15元/平方米。计算该企业年应缴纳的城镇土地使用税。

**解析：**

**免税项目判断：**
- 厂区生产经营用地：12,000㎡ → **应税**
- 自办医院用地：3,000㎡ → **免税**
- 自办学校用地：2,000㎡ → **免税**
- 厂区内绿化用地：1,000㎡ → **应税**（厂区内绿化不免税）
- 厂区外公共道路用地：2,000㎡ → **免税**（市政公共用地）

**应税面积：** 12,000 + 1,000 = 13,000㎡

$$应纳税额 = 13,000 × 15 = 195,000元$$

**答案：** 195,000元

---

### 2.3 纳税义务发生时间

**题目：** 某企业2024年5月购置新建商品房，6月1日交付使用。计算该房产的城镇土地使用税纳税义务发生时间及当年应纳税月份数。

**解析：**

**纳税义务发生时间规则：**
- 购置新建商品房 → 房屋交付使用之**次月**起

**计算：**
- 交付时间：2024年6月1日
- 纳税义务发生：2024年**7月**起
- 当年应纳税月份数：**6个月**（7-12月）

$$年应纳税额 = 应税面积 × 税额 × 6/12$$

**答案：** 纳税义务自2024年7月起，当年应缴6个月

---

### 2.4 耕地占用税计算

**题目：** 某企业经批准占用耕地50,000平方米建设厂房，适用税额30元/平方米。计算应缴纳的耕地占用税。

**解析：**

$$应纳税额 = 实际占用耕地面积 × 适用税额$$

$$= 50,000 × 30 = 1,500,000元$$

**注意：** 耕地占用税是**一次性征收**。

**答案：** 1,500,000元

---

### 2.5 临时占用耕地

**题目：** 某施工企业因工程建设需要，经批准临时占用耕地5,000平方米，适用税额25元/平方米。工程完工后在规定期限内恢复了种植条件。

**解析：**

**第一步：缴纳耕地占用税**
$$应纳税额 = 5,000 × 25 = 125,000元$$

**第二步：恢复种植条件后退税**
在批准临时占用耕地期限内恢复种植条件 → **全额退还**

**答案：** 先缴125,000元，恢复后全额退还

## 三、计算模板

```
【城镇土地使用税计算模板】
年应纳税额 = 实际占用面积(㎡) × 适用税额(元/㎡)

注意：
1. 扣除免税面积
2. 按年计算，分期缴纳
3. 新购置从次月起算

【耕地占用税计算模板】
应纳税额 = 实际占用耕地面积(㎡) × 适用税额(元/㎡)

注意：
1. 一次性征收
2. 临时占用先缴后退
3. 30日内申报
```

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|--------|------|----------|
| **城镇土地使用税 vs 耕地占用税** | 前者按年征收，后者一次性征收 | "城镇年年缴，耕地一次清" |
| **法定免税 vs 特定减免** | 法定免税是法律明确规定的；特定减免需审批 | 法定免/特定减 |
| **新建房 vs 存量房** | 新建：交付次月；存量：登记次月 | "新建交付，存量登记" |
| **厂内绿化 vs 公共绿化** | 厂内绿化应税，市政公共绿化免税 | "厂内不免，厂外免" |
