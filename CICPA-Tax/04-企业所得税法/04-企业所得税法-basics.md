# 企业所得税法 —— 第一性原理教程

## 一、纳税人、征税对象与税率

### 1.1 纳税人

| 类型 | 判定标准 | 征税对象 |
|------|----------|----------|
| **居民企业** | 境内成立，或境外成立但实际管理机构在境内 | **全球所得** |
| **非居民企业** | 境外成立且管理机构不在境内，但在境内有机构/场所，或来源于境内所得 | 来源于中国境内所得 |

### 1.2 税率

| 税率 | 适用 |
|------|------|
| **25%** | 居民企业、在中国境内设立机构场所的非居民企业 |
| **20%** | 小型微利企业（实际有效税率更低） |
| **15%** | 高新技术企业、集成电路企业等 |
| **10%** | 非居民企业取得的来源于境内的特定所得（股息、利息、特许权使用费等） |

---

## 二、应纳税所得额

$$应纳税所得额 = 收入总额 - 不征税收入 - 免税收入 - 各项扣除 - 以前年度亏损$$

### 2.1 收入总额

| 收入类型 | 说明 |
|----------|------|
| 销售货物收入 | 销售商品、产品 |
| 提供劳务收入 | 提供服务 |
| 转让财产收入 | 转让固定资产、无形资产、股权等 |
| 股息红利等权益性投资收益 | — |
| 利息收入 | — |
| 租金收入 | — |
| 特许权使用费收入 | — |
| 接受捐赠收入 | — |
| 其他收入 | — |

### 2.2 不征税收入

- 财政拨款
- 行政事业性收费/政府性基金
- 其他（国务院规定）

### 2.3 免税收入

- 国债利息收入
- 符合条件的居民企业之间的股息红利等权益性投资收益
- 非居民企业从居民企业取得的与该机构场所有实际联系的股息红利
- 符合条件的非营利组织的收入

### 2.4 税前扣除项目

| 扣除项目 | 扣除标准 |
|----------|----------|
| **职工工资** | 据实扣除 |
| **职工福利费** | ≤工资薪金总额14% |
| **工会经费** | ≤工资薪金总额2% |
| **职工教育经费** | ≤工资薪金总额8%（超过部分结转以后年度） |
| **社会保险费** | 按规定缴纳的据实扣除 |
| **利息费用** | 非金融企业向金融借款据实扣除；非关联方借款不超过金融企业同期同类贷款利率 |
| **借款费用** | 资本化/费用化 |
| **业务招待费** | 发生额60%与销售收入5‰孰低 |
| **广告和业务宣传费** | ≤销售收入15%（超过部分结转以后年度） |
| **公益性捐赠** | ≤年度利润总额12%（超过部分结转3年） |
| **劳动保护费** | 据实扣除 |
| **手续费及佣金** | 一般≤5%（保险企业18%） |

### 2.5 不得扣除项目

- 向投资者支付的股息红利
- 企业所得税税款
- 税收滞纳金
- 罚金、罚款和被没收财物的损失
- 超过标准的捐赠支出
- 赞助支出
- 未经核定的准备金支出
- 与取得收入无关的其他支出

### 2.6 亏损弥补

- 企业纳税年度发生的亏损，准予向以后年度结转，**最长不超过5年**
- 高新技术企业/科技型中小企业：结转年限延长至**10年**

## 三、资产的税务处理

### 3.1 固定资产

**折旧方法：** 直线法。

$$年折旧额 = (固定资产原值 - 残值) \div 折旧年限$$

| 资产类别 | 最低折旧年限 |
|----------|-------------|
| 房屋建筑物 | 20年 |
| 飞机火车轮船/机器机械 | 10年 |
| 与生产经营有关的器具工具 | 5年 |
| 运输工具（除飞机火车轮船外） | 4年 |
| 电子设备 | 3年 |

### 3.2 无形资产

- 摊销年限≥10年
- 外购商誉支出在企业整体转让/清算时扣除

### 3.3 长期待摊费用

- 已足额提取折旧的固定资产改建支出：按预计尚可使用年限分期摊销
- 租入固定资产的改建支出：按合同约定的剩余租赁期限分期摊销
- 固定资产的大修理支出：按尚可使用年限分期摊销
- 其他长期待摊费用：摊销年限≥3年

### 3.4 存货

- 按实际成本计价，可在先进先出法、加权平均法、个别计价法中选用一种
- 计价方法一经选用不得随意变更

### 3.5 投资资产

- 企业对外投资期间投资资产的成本不得扣除
- 转让或处置时扣除投资资产的成本

---

## 四、资产损失的所得税处理

| 损失类型 | 申报方式 |
|----------|----------|
| 实际资产损失 | 应当在其实际发生且会计上已作损失处理的年度申报扣除 |
| 法定资产损失 | 应当在企业向主管税务机关提供证据资料证明已符合法定资产损失确认条件且会计上已作损失处理的年度申报扣除 |

---

## 五、企业重组的所得税处理

### 5.1 一般性税务处理

按**公允价值**确认转让所得或损失。

### 5.2 特殊性税务处理（满足5个条件）

**条件：**
1. 具有合理商业目的
2. 被收购/合并/分立资产/股权比例≥50%
3. 重组后12个月内不改变实质性经营活动
4. 原主要股东在重组后12个月内不转让所取得股权
5. 交易中股权支付金额≥其交易支付总额的85%

**处理方式：** 暂不确认所得或损失，以**原有计税基础**确定新计税基础。

## 六、税收优惠

| 优惠 | 内容 |
|------|------|
| **高新技术企业** | 15%税率 |
| **小型微利企业** | 年应纳税所得额≤300万，从业人数≤300人，资产总额≤5000万 |
| **研发费用加计扣除** | 一般企业100%加计扣除 |
| **创投企业** | 按投资额70%抵扣应纳税所得额 |
| **加速折旧** | 缩短年限/双倍余额递减法/年数总和法 |
| **技术转让所得** | 所得≤500万免税，>500万部分减半征收 |
| **集成电路/软件企业** | 两免三减半等 |
| **西部大开发** | 15%税率 |
| **环保/节能节水项目** | 三免三减半 |

---

## 七、应纳税额的计算

$$应纳税额 = 应纳税所得额 \times 适用税率 - 减免税额 - 抵免税额$$

**境外所得抵免：**

$$抵免限额 = 境内外所得按中国税法计算的应纳税总额 \times (来源于某国所得 \div 境内外所得总额)$$

- 境外已纳税款<抵免限额→补缴差额
- 境外已纳税款>抵免限额→超过部分可在以后5年内抵免

---

## 八、征收管理

- **纳税年度**：公历1月1日至12月31日
- **预缴**：按月或按季预缴
- **汇算清缴**：年度终了后5个月内
- **非居民企业源泉扣缴**：支付人代扣代缴，税率10%

## 考试要点

1. **税率**：25%为主，注意优惠税率15%/20%
2. **扣除限额**：福利费14%、工会2%、教育经费8%、招待费60%与5‰孰低、广告费15%、捐赠12%
3. **亏损弥补**：一般5年，高新10年
4. **固定资产折旧年限**：20/10/5/4/3
5. **特殊性税务处理5条件**：目的+比例≥50%+12月不改变+12月不转让+股权支付≥85%
6. **研发费用加计扣除100%**
7. **境外所得抵免限额**计算
