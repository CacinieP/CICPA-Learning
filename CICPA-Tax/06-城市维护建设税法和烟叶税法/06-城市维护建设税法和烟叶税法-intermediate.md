| 考法类型 | 出现频率 | 典型特征 |
|----------|----------|----------|
| **城建税计税依据** | ★★★★★ | 以实际缴纳的增值税+消费税为依据 |

## 二、典型例题解析

### 2.1 城建税基本计算

**题目：** 某企业位于市区，2024年5月实际缴纳增值税200,000元，消费税100,000元。计算该企业应缴纳的城市维护建设税、教育费附加和地方教育附加。

**解析：**

**第一步：确定计税依据**
- 实际缴纳增值税：200,000元
- 实际缴纳消费税：100,000元
- **计税依据合计：300,000元**

**第二步：确定适用税率**
- 企业位于市区 → 城建税税率：7%

**第三步：计算各项税费**

**城市维护建设税：**
$$300,000 × 7\% = 21,000元$$

**教育费附加：**
$$300,000 × 3\% = 9,000元$$

**地方教育附加：**
$$300,000 × 2\% = 6,000元$$

**合计：** 21,000 + 9,000 + 6,000 = **36,000元**

**答案：** 城建税21,000元，教育费附加9,000元，地方教育附加6,000元，合计36,000元

---

### 2.2 进口不征出口不退

**题目：** 某外贸公司2024年6月进口货物缴纳进口增值税500,000元，出口货物退还增值税200,000元。当月国内销售实际缴纳增值税100,000元。计算该公司应缴纳的城建税和教育费附加。

**解析：**

**关键规则：**
- **进口不征**：进口环节缴纳的增值税、消费税不征收城建税
- **出口不退**：出口退还增值税、消费税的，不退还已缴纳的城建税

**计算：**
- 进口增值税500,000元 → **不征城建税**
- 出口退税200,000元 → **不退城建税**
- 国内销售实缴增值税100,000元 → **计征城建税**

$$城建税 = 100,000 × 7\% = 7,000元（假设在市区）$$
$$教育费附加 = 100,000 × 3\% = 3,000元$$

**答案：** 城建税7,000元，教育费附加3,000元

---

### 2.3 烟叶税计算

**题目：** 某烟草公司在境内收购烟叶，支付收购价款800,000元。计算应缴纳的烟叶税。

**解析：**

**第一步：计算价款总额**

$$价款总额 = 收购价款 × (1 + 10\%)$$

$$= 800,000 × 1.10 = 880,000元$$

**第二步：计算烟叶税**

$$烟叶税 = 价款总额 × 20\%$$

$$= 880,000 × 20\% = 176,000元$$

**答案：** 烟叶税176,000元

---

### 2.4 综合计算题

**题目：** 某化妆品生产企业位于县城，2024年8月发生以下业务：
1. 国内销售化妆品实际缴纳增值税150,000元，消费税80,000元
2. 进口原材料缴纳进口增值税60,000元
3. 因先征后返政策获得退还增值税30,000元

计算该企业8月应缴纳的城建税和教育费附加。

**解析：**

**城建税计税依据：**
- 国内销售实缴增值税：150,000元 ✓
- 国内销售实缴消费税：80,000元 ✓
- 进口增值税60,000元 → **不征**
- 先征后返30,000元 → 除另有规定外，**城建税不退**

$$计税依据 = 150,000 + 80,000 = 230,000元$$

$$城建税 = 230,000 × 5\% = 11,500元（县城）$$
$$教育费附加 = 230,000 × 3\% = 6,900元$$
$$地方教育附加 = 230,000 × 2\% = 4,600元$$

**答案：** 城建税11,500元，教育费附加6,900元，地方教育附加4,600元

---

### 2.5 税率适用特殊情况

**题目：** 某企业注册地在A市市区，但实际经营地在B县。该企业实际缴纳增值税500,000元。城建税应适用哪个税率？

**解析：**

城建税税率按纳税人**所在地**确定：
- 如果企业在B县有固定经营场所 → 适用B县税率5%
- 如果企业只是临时在B县经营 → 适用注册地A市税率7%

**一般规则：** 按纳税人实际经营所在地适用税率。

**答案：** 如果长期在B县经营，适用5%税率

## 三、计算模板

```
【城建税+教育附加计算模板】

Step 1：确定计税依据
计税依据 = 实际缴纳增值税 + 实际缴纳消费税
注意：进口不征、出口不退

Step 2：确定适用税率
市区 → 7%；县城/镇 → 5%；其他 → 1%

Step 3：计算
城建税 = 计税依据 × 税率
教育费附加 = 计税依据 × 3%
地方教育附加 = 计税依据 × 2%
总计 = 计税依据 × (税率 + 3% + 2%)

【烟叶税计算模板】
价款总额 = 收购价款 × (1 + 10%)
烟叶税 = 价款总额 × 20%
```

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|--------|------|----------|
| **进口不征 vs 出口不退** | 进口：不征城建税；出口：不退城建税 | "进不征出不清" |
| **城建税vs教育费附加** | 城建税是税，税率因地而异；教育附加是费，费率全国统一 | 城建看地，附加看率 |
| **先征后返** | 增值税先征后返的，城建税一般不退 | "增值税退，城建税不退" |
| **代扣代缴** | 代扣代缴增值税/消费税的，同时代扣城建税 | "跟着老大走" |
| **烟叶价外补贴** | 价款总额 = 收购价×(1+10%)，其中10%是补贴 | 10%补贴统一计 |
