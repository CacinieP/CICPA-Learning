# 城市维护建设税法和烟叶税法 —— 第一性原理教程

## 一、城市维护建设税法

### 1.1 纳税人

实际缴纳**增值税、消费税**的单位和个人。

### 1.2 计税依据

$$计税依据 = 实际缴纳的增值税 + 实际缴纳的消费税$$

**注意：** 不包括非税款项（滞纳金、罚款等）。

### 1.3 税率

| 纳税人所在地 | 税率 |
|-------------|------|
| 市区 | **7%** |
| 县城或镇 | **5%** |
| 不在市区/县城/镇的 | **1%** |

### 1.4 应纳税额

$$应纳税额 = (实际缴纳增值税 + 实际缴纳消费税) \times 适用税率$$

### 1.5 税收优惠

- 对进口货物缴纳的增值税、消费税不征收城建税
- 对出口货物退还增值税、消费税的，不退还已缴纳的城建税
- 增值税/消费税实行先征后返/退/即征即退的，除另有规定外，城建税一律不予退还

## 二、烟叶税法

### 2.1 纳税人

在**境内收购烟叶的单位**。

### 2.2 征税对象

收购的烟叶（包括晒烟叶和烤烟叶）。

### 2.3 计税依据与税率

$$应纳税额 = 实际支付的价款总额 \times 税率$$

$$价款总额 = 收购价款 \times (1 + 10\%)$$

- **税率**：20%

### 2.4 举例

收购烟叶支付100万元：
- 价款总额 = 100 × (1+10%) = 110万元
- 烟叶税 = 110 × 20% = 22万元

---

## 三、教育费附加和地方教育附加

### 3.1 教育费附加

$$应缴金额 = (实际缴纳增值税 + 实际缴纳消费税) \times 3\%$$

### 3.2 地方教育附加

$$应缴金额 = (实际缴纳增值税 + 实际缴纳消费税) \times 2\%$$

### 3.3 减免规定

- 进口环节不征收
- 出口不退

---

## 考试要点

1. **城建税计税依据**：实际缴纳的增值税+消费税
2. **城建税税率**：市区7%/县城镇5%/其他1%
3. **进口不征，出口不退**
4. **烟叶税**：收购单位缴纳，价款×(1+10%)×20%
5. **教育费附加3%，地方教育附加2%**
