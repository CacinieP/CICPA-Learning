# 税务行政法制 —— 第一性原理教程

## 一、税务行政处罚

### 1.1 概述

**税务行政处罚**是指税务机关依法对违反税收法律规范的公民、法人或其他组织给予的行政制裁。

**原则：**
- 法定原则
- 公正公开原则
- 处罚与教育相结合原则
- 一事不再罚原则（对同一违法行为不得给予两次以上罚款）

### 1.2 处罚种类

| 处罚种类 | 适用 |
|----------|------|
| **罚款** | 最常用的处罚方式 |
| **没收违法所得/非法财物** | 骗取出口退税等 |
| **停止出口退税权** | 骗取出口退税 |
| **吊销税务行政许可证件** | 严重违法行为 |

### 1.3 处罚的设定

| 设定机关 | 权限 |
|----------|------|
| **全国人大及其常委会** | 设定所有种类 |
| **国务院** | 除限制人身自由外 |
| **国家税务总局** | 警告、罚款（一定数额内） |

### 1.4 处罚的程序

#### 简易程序

**条件：** 违法事实确凿并有法定依据，对公民处200元以下/对法人处3000元以下罚款或警告。

**程序：** 当场作出处罚决定→出具处罚决定书→备案。

#### 一般程序

**程序：** 立案→调查取证→审查→告知→听取陈述申辩→作出决定→送达。

#### 听证程序

**条件：** 税务机关作出较大数额罚款（公民>2000元/法人>10000元）或没收较大数额违法所得等决定。

**程序：**
1. 当事人在收到告知后3日内提出听证申请
2. 税务机关在收到申请后15日内组织听证
3. 听证公开进行（涉及国家秘密/商业秘密/个人隐私除外）
4. 听证后作出决定

### 1.5 处罚时效

**违法行为在2年内未被发现的，不再给予行政处罚**（法律另有规定的除外）。

- 从违法行为发生之日起计算
- 违法行为有连续/继续状态的，从行为终了之日起计算

## 二、税务行政复议

### 2.1 概述

**税务行政复议**是纳税人/扣缴义务人等对税务机关的具体行政行为不服，向上一级税务机关申请复议的制度。

### 2.2 复议范围

**可以申请复议的具体行政行为：**
- 征税行为（确认纳税主体/征税对象/征税范围/减税/免税/退税/抵扣税款/适用税率/计税依据/应纳税额/纳税环节/纳税期限/纳税地点/税款征收方式）
- 行政许可/行政审批
- 发票管理行为
- 税收保全措施/强制执行措施
- 行政处罚
- 不依法履行职责

### 2.3 复议前置（必经复议）

对**征税行为**不服的，必须先缴纳税款/滞纳金或提供担保，然后申请行政复议，对复议决定不服的才能提起行政诉讼。

**其他行为**可以自由选择行政复议或行政诉讼。

### 2.4 复议管辖

| 被申请人 | 复议机关 |
|----------|----------|
| 税务所（分局） | 所属税务局 |
| 税务局 | 上一级税务局 |
| 国家税务总局 | 国家税务总局 |

### 2.5 申请与受理

- **申请期限**：知道具体行政行为之日起60日内
- **申请方式**：书面/口头
- **受理**：复议机关收到申请后5日内决定是否受理

### 2.6 审理与决定

**审理方式：** 书面审查为原则，可听取意见/实地调查/听证。

**决定类型：**

| 决定 | 条件 |
|------|------|
| 维持 | 行为合法适当 |
| 撤销/变更/确认违法 | 行为违法/不当 |
| 责令履行 | 不作为违法 |
| 责令重新作出 | 原行为违法 |

**复议期限**：自受理之日起60日内（法律规定的除外）。

## 三、税务行政诉讼

### 3.1 概述

**税务行政诉讼**是纳税人等对税务机关的具体行政行为不服，向人民法院提起诉讼的制度。

### 3.2 起诉条件

- 原告是具体行政行为的相对人/利害关系人
- 有明确的被告
- 有具体的诉讼请求和事实根据
- 属于法院受案范围和受诉法院管辖

### 3.3 起诉期限

| 情形 | 起诉期限 |
|------|----------|
| 直接起诉 | 知道作出具体行政行为之日起**6个月**内 |
- 复议后起诉 | 收到复议决定书之日起**15日**内

### 3.4 管辖

| 管辖级别 | 受理案件 |
|----------|----------|
| 基层法院 | 一般税务行政案件 |
| 中级法院 | 对国务院部门/县级以上地方政府提起的案件 |
| 高级法院 | 本辖区内重大/复杂案件 |

**地域管辖：** 一般由最初作出行政行为的行政机关所在地法院管辖。

### 3.5 审理与判决

**审理原则：** 合法性审查。

**举证责任：** 被告（税务机关）承担举证责任。

**判决类型：**

| 判决 | 条件 |
|------|------|
| 驳回诉讼请求 | 行政行为证据确凿、适用法律正确 |
| 撤销/部分撤销 | 主要证据不足/适用法律错误/违反法定程序/超越职权/滥用职权 |
| 责令履行 | 被告不履行法定职责 |
| 变更判决 | 行政处罚明显不当 |

### 3.6 执行

- 公民/法人拒不执行→税务机关申请法院强制执行
- 税务机关拒不执行→法院可以采取措施强制执行

## 考试要点

1. **税务行政处罚**：罚款、没收违法所得、停止出口退税权、吊销许可证
2. **一事不再罚原则**
3. **简易程序**：公民≤200元/法人≤3000元
4. **听证条件**：公民>2000元/法人>10000元罚款
5. **处罚时效**：2年
6. **复议前置**：征税行为必须先缴税/担保→复议→诉讼
7. **复议申请期限**：60日，复议决定期限60日
8. **诉讼起诉期限**：直接6个月，复议后15日
9. **举证责任**：行政诉讼中被告（税务机关）举证
