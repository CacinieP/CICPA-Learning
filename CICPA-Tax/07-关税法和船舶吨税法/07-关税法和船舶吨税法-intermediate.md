## 二、典型例题解析

### 2.1 进口完税价格计算

**题目：** 某公司从境外进口一台设备，成交价格（CIF）为500,000美元。此外，另支付卖方佣金20,000美元，包装费5,000美元，进口后设备安装调试费10,000美元（单独列明）。汇率1美元=7.0元人民币，关税税率10%。

**要求：** 计算该设备的关税完税价格和应纳关税。

**解析：**

**第一步：确定完税价格应包含和排除的项目**

| 项目 | 金额 | 是否计入完税价格 |
|------|------|-----------------|
| CIF成交价格 | 500,000 | ✓ 计入 |
| 卖方佣金 | 20,000 | ✓ 计入（经纪费） |
| 包装费 | 5,000 | ✓ 计入 |
| 进口后安装调试费 | 10,000 | ✗ 不计入（进口后发生的费用） |

**第二步：计算完税价格**

$$完税价格 = (500,000 + 20,000 + 5,000) × 7.0 = 3,675,000元$$

**第三步：计算关税**

$$关税 = 3,675,000 × 10\% = 367,500元$$

**答案：** 完税价格3,675,000元，关税367,500元

---

### 2.2 出口完税价格计算

**题目：** 某公司出口一批货物，FOB价格为1,000,000元人民币，出口关税税率20%。计算应纳出口关税。

**解析：**

**出口完税价格公式：**

$$完税价格 = FOB价格 ÷ (1 + 出口税率)$$

$$= 1,000,000 ÷ (1 + 20\%)$$

$$= 1,000,000 ÷ 1.2$$

$$= 833,333.33元$$

$$关税 = 833,333.33 × 20\% = 166,666.67元$$

**答案：** 出口关税166,666.67元

---

### 2.3 关税滞纳金计算

**题目：** 某企业进口货物应缴纳关税500,000元，填发税款缴款书日期为2024年3月1日，企业于2024年3月20日才缴纳税款。计算应缴纳的滞纳金。

**解析：**

**第一步：确定纳税期限**
- 填发税款缴款书之日起15日内缴纳
- 到期日：2024年3月16日
- 逾期天数：3月17日至3月20日 = **4天**

**第二步：计算滞纳金**

$$滞纳金 = 滞纳税款 × 万分之五 × 逾期天数$$

$$= 500,000 × 0.05\% × 4$$

$$= 1,000元$$

**答案：** 滞纳金1,000元

---

### 2.4 税率适用原则

**题目：** 某进口货物同时适用最惠国税率和暂定税率，下列说法正确的是？

**解析：**

**关税税率适用原则：**
- 最惠国税率与暂定税率同时适用 → **适用暂定税率**
- 协定税率与暂定税率同时适用 → **从低适用**
- 特惠税率与暂定税率同时适用 → **从低适用**

**答案：** 适用暂定税率

---

### 2.5 船舶吨税计算

**题目：** 某外籍船舶净吨位为8,000吨，从境外港口进入中国境内港口，申请30天吨税执照。该船舶适用普通税率。计算应缴纳的船舶吨税。

**解析：**

**第一步：确定税额标准**
- 净吨位8,000吨 → 属于2,001-10,000吨档
- 普通税率30天：4.7元/净吨

**第二步：计算应纳税额**

$$吨税 = 8,000 × 4.7 = 37,600元$$

**答案：** 船舶吨税37,600元

## 三、计算模板

```
【进口完税价格计算模板】
完税价格 = 成交价格(CIF)
         + 佣金（经纪费）
         + 包装费
         + 容器费
         + 协助价值
         + 特许权使用费
         + 进口后转售/使用的应付费用
         - 进口后发生的费用（单独列明的安装调试费等）

【出口完税价格计算模板】
完税价格 = FOB ÷ (1 + 出口税率)

【关税计算模板】
从价税：完税价格 × 税率
从量税：数量 × 单位税额
复合税：完税价格 × 从价税率 + 数量 × 单位税额

【滞纳金】
滞纳金 = 滞纳税款 × 0.05% × 逾期天数
```

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|--------|------|----------|
| **进口完税价格 vs 出口完税价格** | 进口：CIF为基础加项；出口：FOB÷(1+税率) | "进加出除" |
| **卖方佣金 vs 买方佣金** | 卖方佣金计入完税价格；买方佣金不计入 | "卖方佣金归入价" |
| **追征 vs 补征** | 纳税人原因→3年追征；非纳税人原因→1年补征 | "错3漏1" |
| **关税配额 vs 暂定税率** | 配额内适用配额税率，配额外适用最惠国税率 | "内配外最惠" |
