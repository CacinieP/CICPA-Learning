# 关税法和船舶吨税法 —— 综合实战

## 一、综合题解题框架

```
【关税综合题解题步骤】

Step 1：确定进出口贸易方式
├─ 进口 → 确定完税价格（CIF+加项-减项）
├─ 出口 → 确定完税价格（FOB÷(1+税率)）
         ↓
Step 2：选择计征方式
├─ 从价：完税价格 × 税率
├─ 从量：数量 × 单位税额
├─ 复合：从价 + 从量
└─ 滑准：根据价格定税率
         ↓
Step 3：处理减免优惠
├─ 法定减免（<50元、无商业价值等）
├─ 特定减免（科教用品等）
└─ 临时减免（国务院批准）
         ↓
Step 4：征收管理
├─ 15日内缴纳
├─ 滞纳金万分之五/日
└─ 追征3年/补征1年
```

## 二、跨章联动图谱

> 🔗 **跨科联动：**
>
> **关税 ↔ 增值税**：
> - 进口增值税的组成计税价格 = 关税完税价格 + 关税 + 消费税
> - 关税是增值税组价的组成部分
>
> **关税 ↔ 消费税**：
> - 进口消费税的组成计税价格 = (关税完税价格 + 关税)÷(1-消费税率)
> - 关税影响消费税的组价
>
> **关税 ↔ 企业所得税**：
> - 关税计入进口货物的成本，影响销售成本和企业所得税

## 三、陷阱与反套路

### 3.1 常见陷阱

| 陷阱类型 | 典型表现 | 识别要点 |
|----------|----------|----------|
| **买方佣金计入完税价格** | 将买方佣金也加到完税价格中 | 买方佣金不计入 |
| **进口后费用不排除** | 将安装调试费等进口后费用计入 | 单独列明的应排除 |
| **出口完税价格直接用FOB** | 不除以(1+税率) | FOB含关税，需剔除 |
| **税率适用错误** | 不了解从低原则 | 同时适用多税率时从低 |

### 3.2 反套路策略

1. **进口完税价格：逐项判断是否计入**
2. **出口完税价格：记住FOB÷(1+税率)**
3. **注意进口后费用是否单独列明**

## 四、真题变式推演

### 变式一：进口多税种综合

**题目：**
某公司进口一批高档手表（关税税率20%，消费税税率20%，增值税税率13%），CIF价格2,000,000元。另支付卖方佣金50,000元，特许权使用费100,000元。关税税率题目给定20%。

**要求：** 计算关税、消费税、增值税。

**解析：**

**（1）完税价格**
$$完税价格 = 2,000,000 + 50,000 + 100,000 = 2,150,000元$$

**（2）关税**
$$关税 = 2,150,000 × 20\% = 430,000元$$

**（3）消费税（组成计税价格）**
$$组成计税价格 = (2,150,000 + 430,000) ÷ (1 - 20\%)$$
$$= 2,580,000 ÷ 0.8 = 3,225,000元$$
$$消费税 = 3,225,000 × 20\% = 645,000元$$

**（4）增值税**
$$增值税 = (2,150,000 + 430,000 + 645,000) × 13\%$$
$$= 3,225,000 × 13\% = 419,250元$$

**答案：** 关税430,000元，消费税645,000元，增值税419,250元

---

### 变式二：出口关税综合

**题目：**
某企业出口一批矿产品，FOB价格5,000,000元，出口关税税率10%。同时出口另一批货物，FOB价格3,000,000元，免征出口关税。

**要求：** 计算出口关税。

**解析：**

**应税货物：**
$$完税价格 = 5,000,000 ÷ (1 + 10\%) = 4,545,454.55元$$
$$关税 = 4,545,454.55 × 10\% = 454,545.45元$$

**免税货物：** 关税 = 0

**合计：** 454,545.45元
