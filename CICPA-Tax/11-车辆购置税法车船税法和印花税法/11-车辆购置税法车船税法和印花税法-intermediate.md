# 车辆购置税法、车船税法和印花税法 —— 典型考题解析

## 一、核心考法分类

| 考法类型 | 出现频率 | 典型特征 |
|----------|----------|----------|
| **车辆购置税计算** | ★★★★ | 计税价格×10%，一次性缴纳 |
| **车船税计算** | ★★★ | 计税单位×年基准税额 |
| **印花税税率适用** | ★★★★★ | 各合同税率（0.05‰/0.3‰/1‰等） |
| **印花税计税依据** | ★★★★ | 合同金额、实收资本+资本公积 |
| **印花税免税项目** | ★★★ | 农产品收购合同、无息借款合同等 |

## 二、典型例题解析

### 2.1 车辆购置税计算

**题目：** 张某购买一辆排气量2.0升的小汽车自用，含增值税价格226,000元。计算张某应缴纳的车辆购置税。

**解析：**

**第一步：确定计税价格**
$$不含税价格 = 226,000 ÷ (1 + 13\%) = 200,000元$$

**第二步：计算车辆购置税**
$$应纳税额 = 200,000 × 10\% = 20,000元$$

**答案：** 20,000元

---

### 2.2 进口车辆购置税

**题目：** 某公司进口一辆小汽车自用，关税完税价格300,000元，关税税率25%，消费税税率10%。

**解析：**

**第一步：计算关税**
$$关税 = 300,000 × 25\% = 75,000元$$

**第二步：计算消费税（组成计税价格）**
$$组成计税价格 = (300,000 + 75,000) ÷ (1 - 10\%) = 416,666.67元$$
$$消费税 = 416,666.67 × 10\% = 41,666.67元$$

**第三步：计算车辆购置税**
$$计税价格 = 关税完税价格 + 关税 + 消费税 = 300,000 + 75,000 + 41,666.67 = 416,666.67元$$
$$车辆购置税 = 416,666.67 × 10\% = 41,666.67元$$

**答案：** 41,666.67元

---

### 2.3 车船税计算

**题目：** 某企业拥有乘用车2辆（排气量2.0升），年基准税额480元/辆；商用车货车3辆（整备质量分别为10吨、8吨、12吨），年基准税额60元/吨。计算该企业年应缴纳的车船税。

**解析：**

**乘用车：**
$$2 × 480 = 960元$$

**商用车货车：**
$$(10 + 8 + 12) × 60 = 30 × 60 = 1,800元$$

**合计：** 960 + 1,800 = **2,760元**

**答案：** 2,760元

---

### 2.4 印花税税率应用

**题目：** 某企业2024年签订以下合同：
1. 借款合同：金额5,000,000元
2. 买卖合同：金额10,000,000元
3. 技术合同：金额2,000,000元
4. 租赁合同：金额3,000,000元
5. 财产保险合同：保险费500,000元

计算该企业应缴纳的印花税。

**解析：**

| 合同类型 | 金额 | 税率 | 应纳税额 |
|----------|------|------|----------|
| 借款合同 | 5,000,000 | 0.05‰ | 250 |
| 买卖合同 | 10,000,000 | 0.3‰ | 3,000 |
| 技术合同 | 2,000,000 | 0.3‰ | 600 |
| 租赁合同 | 3,000,000 | 1‰ | 3,000 |
| 财产保险合同 | 500,000 | 1‰ | 500 |
| **合计** | | | **7,350元** |

**答案：** 7,350元

---

### 2.5 营业账簿印花税

**题目：** 某企业2024年新设立，实收资本5,000,000元，资本公积2,000,000元。计算营业账簿应缴纳的印花税。

**解析：**

**计税依据：** 实收资本 + 资本公积 = 5,000,000 + 2,000,000 = 7,000,000元

**税率：** 0.25‰

$$应纳税额 = 7,000,000 × 0.25‰ = 1,750元$$

**答案：** 1,750元

## 三、计算模板

```
【车辆购置税】计税价格 × 10%
  购买：全部价款（不含增值税）
  进口：关税完税价+关税+消费税
  一次性缴纳，60日内申报

【车船税】计税单位 × 年基准税额
  新车当年：年税额 ÷ 12 × 应纳税月份数
  按年缴纳，保险机构代收代缴

【印花税】计税依据 × 适用税率
  借款/融资租赁：0.05‰
  买卖/承揽/建设/运输/技术：0.3‰
  租赁/保管/仓储/财产保险：1‰
  产权转移书据：0.5‰
  营业账簿：0.25‰
  证券交易：1‰
```

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|--------|------|----------|
| **车辆购置税 vs 车船税** | 购置税一次性，车船税按年 | "购置一次，车船年年" |
| **印花税税率档位** | 0.05‰/0.3‰/1‰/0.5‰/0.25‰ | "借款五，买卖三，租赁保险都是一" |
| **车辆购置税纳税人** | 购置者（不论新车旧车） | "谁买谁缴" |
| **营业账簿印花税** | 只对实收资本+资本公积征税 | "实收+资本公积" |
