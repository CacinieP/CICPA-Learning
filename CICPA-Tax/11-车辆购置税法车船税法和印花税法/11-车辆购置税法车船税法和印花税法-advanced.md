# 车辆购置税法、车船税法和印花税法 —— 综合实战

## 一、综合题解题框架

```
【解题步骤】

Step 1：识别涉及的税种
├─ 车辆购置：购买/进口/自产/受赠车辆 → 车辆购置税
├─ 车船持有：拥有/管理车辆船舶 → 车船税
└─ 凭证书立：签订合同/产权转移 → 印花税
         ↓
Step 2：分别计算
├─ 车辆购置税：计税价格×10%（一次性）
├─ 车船税：计税单位×年基准税额（按年）
└─ 印花税：计税依据×税率
         ↓
Step 3：处理优惠和特殊事项
```

## 二、跨章联动图谱

> 🔗 **跨科联动：**
>
> **车辆购置税 ↔ 增值税**：
> - 购买车辆的计税价格不含增值税
> - 进口车辆组价包含关税完税价+关税+消费税
>
> **印花税 ↔ 企业所得税**：
> - 印花税计入"税金及附加"，企业所得税前扣除
>
> **车船税 ↔ 会计**：
> - 车船税计入管理费用/税金及附加

## 三、陷阱与反套路

| 陷阱类型 | 典型表现 | 识别要点 |
|----------|----------|----------|
| **含增值税价格直接计算** | 未扣除增值税就计算购置税 | 先换算不含税价 |
| **印花税税率记错** | 将买卖合同0.3‰记成1‰ | 按合同类型对应税率 |
| **车船税新车首年** | 新车按全年计算 | 按实际月份数折算 |
| **免税车辆判断** | 不知道新能源车辆免税 | 关注最新免税政策 |

## 四、真题变式推演

### 变式一：车辆购置税+增值税+消费税综合

**题目：**
某公司进口一辆排气量3.5升的乘用车自用，CIF价格500,000元，关税税率25%，消费税税率25%，增值税税率13%。

**要求：** 计算关税、消费税、增值税、车辆购置税。

**解析：**

**关税：** 500,000 × 25% = 125,000元

**消费税：**
$$组价 = (500,000 + 125,000) ÷ (1-25\%) = 833,333.33元$$
$$消费税 = 833,333.33 × 25\% = 208,333.33元$$

**增值税：** 833,333.33 × 13% = 108,333.33元

**车辆购置税：** 833,333.33 × 10% = 83,333.33元

---

### 变式二：印花税多合同综合

**题目：**
某企业2024年度签订以下凭证：
1. 与银行签订借款合同，金额10,000,000元
2. 与供应商签订买卖合同三份，金额分别为3,000,000元、5,000,000元、2,000,000元
3. 与房东签订房屋租赁合同，年租金600,000元，租期3年
4. 转让一项专利权，签订产权转移书据，金额4,000,000元
5. 实收资本增加5,000,000元

**计算：** 该企业应缴纳的印花税合计。

**解析：**

| 凭证 | 计税依据 | 税率 | 税额 |
|------|----------|------|------|
| 借款合同 | 10,000,000 | 0.05‰ | 500 |
| 买卖合同(1) | 3,000,000 | 0.3‰ | 900 |
| 买卖合同(2) | 5,000,000 | 0.3‰ | 1,500 |
| 买卖合同(3) | 2,000,000 | 0.3‰ | 600 |
| 租赁合同 | 600,000×3=1,800,000 | 1‰ | 1,800 |
| 产权转移书据 | 4,000,000 | 0.5‰ | 2,000 |
| 营业账簿 | 5,000,000 | 0.25‰ | 1,250 |
| **合计** | | | **8,550元** |

**答案：** 8,550元

## 五、实务衔接

| 场景 | 要点 |
|------|------|
| **购车流程** | 4S店代收车辆购置税，车辆登记前须缴纳 |
| **车船税缴纳** | 与交强险一并由保险机构代收 |
| **合同管理** | 印花税需要在签订合同时缴纳 |
