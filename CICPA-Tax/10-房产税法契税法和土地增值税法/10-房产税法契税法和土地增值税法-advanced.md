# 房产税法、契税法和土地增值税法 —— 综合实战

## 一、综合题解题框架

```
【房产税+契税+土地增值税综合题框架】

Step 1：识别涉及的税种
├─ 房产税：持有房产期间缴纳（从价/从租）
├─ 契税：取得房产/土地时一次性缴纳
└─ 土地增值税：转让房地产时缴纳
         ↓
Step 2：分别计算各税种
├─ 房产税：判断计税方式→计算
├─ 契税：确定计税依据→适用税率→计算
└─ 土地增值税：确定扣除项目→计算增值额→确定税率→计算
         ↓
Step 3：处理优惠和特殊事项
```

## 二、跨章联动图谱

> 🔗 **跨科联动：**
>
> **房产税 ↔ 会计（投资性房地产）**：
> - 投资性房地产持有的房产需缴纳房产税
> - 从租计征的房产税影响投资性房地产的收益
>
> **土地增值税 ↔ 企业所得税**：
> - 土地增值税在转让房地产时缴纳，可作为税金在企业所得税前扣除
> - 两者的收入确认和成本扣除可能存在差异
>
> **契税 ↔ 企业所得税**：
> - 契税计入取得资产的成本（房产/土地），通过折旧/摊销影响企业所得税

## 三、陷阱与反套路

| 陷阱类型 | 典型表现 | 识别要点 |
|----------|----------|----------|
| **房产税计税方式选择** | 将自用房产按从租计算 | 自用→从价；出租→从租 |
| **契税纳税主体** | 认为卖方缴纳契税 | 承受方（买方）缴纳 |
| **土地增值税扣除遗漏** | 忘了加计扣除20% | 仅限房地产开发企业 |
| **开发费用计算方式** | 不判断利息能否分清 | 先判断再选公式 |
| **普通住宅优惠条件** | 增值率超过20%也免税 | 必须≤20%才免税 |

## 四、真题变式推演

### 变式一：房产税+契税综合

**题目：**
某企业2024年3月购买一栋办公楼，成交价格50,000,000元，建筑面积3,000平方米，4月1日交付使用。该房产原值40,000,000元，扣除比例30%。

**要求：** 计算2024年应缴纳的契税和房产税。

**解析：**

**契税（承受方缴纳）：**
$$契税 = 50,000,000 × 4\% = 2,000,000元$$（税率题目给定）

**房产税（从价计征）：**
- 纳税义务发生：交付次月（5月）起
- 计税房产原值 = 50,000,000元（购买价格即为原值）
$$年应纳税额 = 50,000,000 × (1-30\%) × 1.2\% = 420,000元$$
$$2024年应纳税额 = 420,000 × 8/12 = 280,000元$$（5-12月共8个月）

**答案：** 契税2,000,000元，房产税280,000元

---

### 变式二：土地增值税完整计算

**题目：**
某房地产开发企业建造并出售一栋写字楼，取得转让收入200,000,000元。
1. 取得土地使用权支付30,000,000元
2. 房地产开发成本50,000,000元
3. 开发费用：利息支出不能按项目分清
4. 与转让有关的税金11,000,000元

**要求：** 计算应缴纳的土地增值税。

**解析：**

**扣除项目：**
1. 土地使用权：30,000,000元
2. 开发成本：50,000,000元
3. 开发费用（利息不能分清）：(30,000,000+50,000,000)×10% = 8,000,000元
4. 转让税金：11,000,000元
5. 加计扣除：(30,000,000+50,000,000)×20% = 16,000,000元

**扣除项目合计：** 30,000,000+50,000,000+8,000,000+11,000,000+16,000,000 = **115,000,000元**

**增值额：** 200,000,000-115,000,000 = **85,000,000元**

**增值率：** 85,000,000÷115,000,000 = **73.91%**

适用税率：50%-100%档 → **税率40%，速算扣除系数5%**

$$应纳税额 = 85,000,000 × 40\% - 115,000,000 × 5\%$$
$$= 34,000,000 - 5,750,000 = 28,250,000元$$

**答案：** 28,250,000元

---

### 变式三：个人转让住房

**题目：**
王某2024年8月转让其自用6年的唯一住房，取得收入5,000,000元。该房产购入价格2,000,000元，支付契税60,000元，转让时支付中介费50,000元。

**要求：** 判断是否缴纳土地增值税。

**解析：**

**判断条件：**
- 个人转让自用5年以上唯一住房 → **免征土地增值税**

**结论：** 王某自用6年（>5年），且为唯一住房 → 免征

**答案：** 免征土地增值税

## 五、实务衔接

| 场景 | 要点 |
|------|------|
| **房地产投资** | 持有期间需缴纳房产税和城镇土地使用税 |
| **房产交易** | 买方缴契税，卖方缴土地增值税（企业） |
| **房地产开发** | 预征土地增值税→清算 |
