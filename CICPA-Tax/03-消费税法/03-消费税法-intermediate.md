# 消费税法 —— 典型考题解析

## 一、核心考法分类

本章考试重点包括：

1. **计算问答题**：应纳税额的三种计征方式（从价/从量/复合）
2. **单选题**：税目范围、计征方式判定
3. **多选题**：已纳消费税扣除、组成计税价格
4. **综合题**：与增值税、所得税联合出题

## 二、典型例题解析

### 2.1 税目判定

**题目（单选）：** 下列应缴纳消费税的是（ ）。

A. 商场销售的金银首饰
B. 销售农用拖拉机
C. 涂料生产企业销售本厂生产的涂料
D. 电池生产企业销售本厂生产的电池

**解析：**

消费税税目（15类）：
- 烟：卷烟、雪茄烟、烟丝
- 酒：白酒、黄酒、啤酒、其他酒
- 高档化妆品
- 贵重首饰及珠宝玉石
- 鞭炮焰火
- 成品油
- **小汽车**：乘用车、中轻型商用客车
- 摩托车：气缸容量>250ml
- 高尔夫球及球具
- 高档手表：销售价格≥10000元
- 游艇
- 木制一次性筷子
- 实木地板
- **电池**（2015年新增）
- **涂料**（2015年新增）

选项分析：
- A：金银首饰在零售环节缴纳消费税 → **征收消费税**
- B：农用拖拉机不属于消费税税目 → 不征
- C：涂料需"施工状态下"挥发性有机物含量达到标准才征 → **需看具体含量**，但涂料在生产环节征收，本题可能不选
- D：电池在生产环节征收消费税 → **征收消费税**

**答案：A、D**（若C选项明确为应税涂料则也选）

---

### 2.2 计征方式判定

**题目（多选）：** 下列应税消费品中，采用复合计征方式计算消费税的有（ ）。

A. 卷烟
B. 白酒
C. 啤酒
D. 高档化妆品
E. 电池

**解析：**

消费税三种计征方式：

| 方式 | 适用 | 公式 |
|------|------|------|
| **从价计征** | 大多数应税消费品 | 销售额 × 比例税率 |
| **从量计征** | 黄酒、啤酒、成品油 | 销售数量 × 定额税率 |
| **复合计征** | 卷烟、白酒 | 销售额 × 比例税率 + 销售数量 × 定额税率 |

选项分析：
- 卷烟 → **复合计征**
- 白酒 → **复合计征**
- 啤酒 → **从量计征**
- 高档化妆品 → **从价计征**
- 电池 → **从价计征**

**答案：A、B**

### 2.3 委托加工应纳税额

**题目（计算问答题）：** 甲企业提供原材料委托乙企业加工应税消费品。已知：材料成本30万元，加工费10万元，增值税税率13%，消费税税率20%。计算受托方（乙企业）代收代缴的消费税。

**解析：**

**Step 1：确定计税依据**

委托加工应税消费品，由受托方在交货时代收代缴消费税。

组成计税价格 = （材料成本 + 加工费）÷（1 - 消费税税率）

**Step 2：计算组成计税价格**

组价 = (30 + 10) ÷ (1 - 20%) = 40 ÷ 0.8 = 50万元

**Step 3：计算消费税**

代收代缴消费税 = 50 × 20% = 10万元

**答案：10万元**

---

### 2.4 自产自用应纳税额

**题目（计算问答题）：** 丙酒厂将自产粮食白酒20箱用于奖励优秀员工。已知：每箱成本500元，无同类售价，成本利润率15%，每箱500ml，每箱12瓶。计算应缴纳的消费税。

**解析：**

**Step 1：确定计征方式**

白酒采用复合计征方式（从价20% + 从量0.5元/500ml）

**Step 2：计算从量计征部分**

每箱500ml × 12瓶 = 6000ml = 6L
总数量 = 20箱 × 6L = 120L

从量消费税 = 120 × 0.5 = 60元

**Step 3：计算从价计征部分**

组价 = 成本 × (1 + 成本利润率) = 20 × 500 × (1 + 15%) = 11500元
= 1.15万元

从价消费税 = 1.15 ÷ (1 - 20%) × 20%
= 1.4375 × 20% = 0.2875万元 = 2875元

**Step 4：计算应纳税额**

应纳税额 = 从价 + 从量 = 2875 + 60 = 2935元

**答案：2935元**

### 2.5 已纳消费税扣除

**题目（单选）：** 下列情形中，准予扣除已纳消费税的是（ ）。

A. 某首饰厂用外购的已税珠宝玉石生产金银镶嵌首饰
B. 某酒厂用外购的已税粮食白酒生产高档葡萄酒
C. 某化妆品厂用委托加工收回的已税香水生产化妆品
D. 某烟厂用外购的已税烟丝生产电子烟

**解析：**

已纳消费税扣除的范围：

| 扣除范围 | 具体情形 |
|----------|----------|
| **可以扣除** | 外购或委托加工收回的应税消费品，用于继续生产应税消费品 |
| **酒类产品** | 外购葡萄酒、酒精已纳消费税不得扣除 |
| **金银首饰** | 金银首饰、钻石首饰在零售环节征消费税，生产环节不征，已纳消费税不得扣除 |

扣除范围具体包括：
- 烟丝 → 卷烟
- 化妆品原料 → 化妆品
- 珠宝玉石 → 贵重首饰（但金银首饰除外）
- 鞭炮焰火原料 → 鞭炮焰火
- 实木地板原料 → 实木地板
- 木制一次性筷子原料 → 木制一次性筷子
- 涂料 → 涂料（需同一税目）

选项分析：
- A：外购珠宝玉石生产金银镶嵌首饰 → 金银首饰在零售环节征税，扣除不适用 → **不得扣除**
- B：外购白酒生产葡萄酒 → 酒类产品已纳消费税不得扣除 → **不得扣除**
- C：委托加工收回香水生产化妆品 → 同一税目（化妆品）→ **可以扣除**
- D：外购烟丝生产电子烟 → 电子烟是否属于消费税范围需确认 → 存疑

**答案：C**

---

### 2.6 批发环节加征

**题目（单选）：** 某烟草批发企业将一批卷烟销售给另一烟草批发企业，则该业务（ ）。

A. 不缴纳消费税
B. 按5%税率缴纳消费税
C. 按56%加150元/箱缴纳消费税
D. 按36%加150元/箱缴纳消费税

**解析：**

消费税批发环节规定：
- **卷烟**：在批发环节加征5%消费税（从价）
- 税率：5%
- **注意**：只能抵扣**生产环节**已纳消费税，不能抵扣**批发环节**已纳消费税

选项分析：
- 烟草批发企业销售给另一批发企业 → **属于批发环节** → 适用5%税率
- 不能适用56%+150元/箱（生产环节税率）

**答案：B**

## 三、分录/计算模板

### 消费税计税模板

```
┌─────────────────────────────────────────────────────────────┐
│                   消费税计税依据确定                          │
├─────────────────────────────────────────────────────────────┤
│ 正常销售：销售额（含消费税、不含增值税）                      │
│ 不含税销售额 = 含税销售额 ÷ (1 + 增值税税率/征收率)          │
│                                                             │
│ 自产自用/委托加工/进口：使用组成计税价格                      │
│ ┌─────────────────────────────────────────────────────────┐ │
│ │ 从价计征：                                               │ │
│ │   组价 = 成本 ÷ (1 - 消费税税率)                        │ │
│ │   或：组价 = (材料成本 + 加工费) ÷ (1 - 消费税税率)     │ │
│ │   或：组价 = (关税完税价格 + 关税) ÷ (1 - 消费税税率)   │ │
│ │                                                         │ │
│ │ 复合计征：                                               │ │
│ │   组价 = (成本 + 利润 + 从量税) ÷ (1 - 消费税税率)      │ │
│ │   或：组价 = (材料成本 + 加工费 + 从量税) ÷ (1 - 比例税率)│ │
│ └─────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│                   消费税应纳税额计算                          │
├─────────────────────────────────────────────────────────────┤
│ 从价计征：应纳税额 = 销售额 × 比例税率                        │
│ 从量计征：应纳税额 = 销售数量 × 单位税额                      │
│ 复合计征：应纳税额 = 销售额 × 比例税率 + 销售数量 × 单位税额   │
│                                                             │
│ 已纳消费税扣除：                                            │
│ 当期准予扣除 = 当期生产领用数量 × 单位已纳税款                │
└─────────────────────────────────────────────────────────────┘
```

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|-------|------|---------|
| 从价计征 vs 从量计征 vs 复合计征 | 从价看价格，从量看数量，复合两者兼有 | 记住"黄酒啤酒油"是从量，"烟酒"是复合 |
| 委托加工 vs 自产自用 | 委托加工组价公式中无利润，自产自用有利润 | "委托"别人加工没有利润加成 |
| 外购扣除 vs 委托加工收回扣除 | 两者都可扣除，但计算方式不同 | "外购"按领用数量×单位已纳税款 |
| 卷烟生产 vs 批发环节 | 生产环节56%+150元/箱；批发环节5% | "批"发5%，"生"产56 |
| 金银首饰 vs 其他首饰 | 金银首饰零售征；其他首饰生产征 | "金"→零"银"售 |

## 五、速记口诀

**消费税15税目**：烟酒油，化宝珠，鞭炮车艇筷子地，电池涂料加一起

**复合计征税目**：烟酒 → 20%+0.5

**从量计征税目**：黄酒啤酒油 → 按升/吨计算

**已纳扣除范围**：烟丝化妆品，珠宝鞭炮地，筷子涂料可扣除；金银首饰酒不扣

**组价公式**：
- 自产：成本÷(1-税率)
- 委托：材料加工费÷(1-税率)
- 进口：完税价格加关税÷(1-税率)
