# 消费税法 —— 第一性原理教程

## 一、纳税义务人与税目

### 1.1 纳税义务人

在**中华人民共和国境内**生产、委托加工、进口、零售（部分）应税消费品的单位和个人。

### 1.2 税目（15类）

| 类别 | 税目 |
|------|------|
| **烟** | 卷烟、雪茄烟、烟丝 |
| **酒** | 白酒、黄酒、啤酒、其他酒 |
| **高档化妆品** | 高档美容/修饰类化妆品、高档护肤类化妆品 |
| **贵重首饰及珠宝玉石** | 金银珠宝、珠宝玉石 |
| **鞭炮焰火** | 鞭炮、焰火 |
| **成品油** | 汽油、柴油、航空煤油、石脑油等 |
| **小汽车** | 乘用车、中轻型商用客车 |
| **摩托车** | 气缸容量>250ml的摩托车 |
| **高尔夫球及球具** | 高尔夫球、球杆、包 |
| **高档手表** | 销售价格≥10000元的手表 |
| **游艇** | — |
| **木制一次性筷子** | — |
| **实木地板** | — |
| **电池** | — |
| **涂料** | — |

## 二、税率

### 2.1 三种计征方式

| 方式 | 公式 | 适用 |
|------|------|------|
| **从价计征** | 应纳税额 = 销售额 × 比例税率 | 大多数应税消费品 |
| **从量计征** | 应纳税额 = 销售数量 × 定额税率 | 黄酒、啤酒、成品油 |
| **复合计征** | 应纳税额 = 销售额 × 比例税率 + 销售数量 × 定额税率 | 卷烟、白酒 |

### 2.2 主要税率

| 税目 | 税率 |
|------|------|
| 卷烟 | 56% + 150元/箱（生产）/ 5%加征（批发） |
| 白酒 | 20% + 0.5元/500ml |
| 啤酒 | 220-250元/吨 |
| 高档化妆品 | 15% |
| 乘用车 | 1%-40%（按排气量分档） |
| 成品油 | 1.2-1.52元/升 |

## 三、计税依据

### 3.1 销售额

**销售额**为不含增值税但含消费税的销售额。

$$不含税销售额 = 含税销售额 \div (1 + 增值税税率或征收率)$$

### 3.2 销售数量

- 销售应税消费品→实际销售数量
- 自产自用→移送使用数量
- 委托加工→收回数量
- 进口→海关核定数量

---

## 四、应纳税额的计算

### 4.1 生产销售环节

直接按上述公式计算。

### 4.2 自产自用

| 用途 | 计税 |
|------|------|
| 用于连续生产应税消费品 | 不纳税 |
| 用于其他方面（福利、广告、样品等） | 视同销售，需纳税 |

**同类消费品价格→组成计税价格：**

- 从价：组成计税价格 = (成本 + 利润) ÷ (1 - 消费税税率)
- 复合：组成计税价格 = (成本 + 利润 + 自产自用数量 × 定额税率) ÷ (1 - 比例税率)

### 4.3 委托加工

**由受托方交货时代收代缴。**

组成计税价格：
- 从价：组成计税价格 = (材料成本 + 加工费) ÷ (1 - 比例税率)
- 复合：组成计税价格 = (材料成本 + 加工费 + 委托加工数量 × 定额税率) ÷ (1 - 比例税率)

### 4.4 进口环节

组成计税价格：
- 从价：组成计税价格 = (关税完税价格 + 关税) ÷ (1 - 消费税税率)
- 复合：组成计税价格 = (关税完税价格 + 关税 + 进口数量 × 定额税率) ÷ (1 - 比例税率)

### 4.5 已纳消费税的扣除

以**外购**或**委托加工收回**的应税消费品为原料继续生产应税消费品的，已纳税款可扣除。

**扣除范围：**
- 烟丝→卷烟
- 化妆品原料→化妆品
- 珠宝玉石→贵重首饰
- 等等

**扣除公式：**

$$当期准予扣除的已纳税款 = 当期生产领用数量 \times 单位已纳税款$$

### 4.6 批发环节

**卷烟在批发环节加征5%消费税**（不能扣除生产环节已纳税款）。

### 4.7 零售环节

- **超豪华小汽车**（零售价格≥130万元）：加征10%
- **金银首饰**：零售环节征收5%

## 五、出口退税

| 政策 | 适用 |
|------|------|
| **出口免税并退税** | 外贸企业出口 |
| **出口免税不退税** | 生产企业自营出口（免抵退方式） |
| **出口不免税不退税** | 限制出口的应税消费品 |

---

## 六、征收管理

- **纳税义务发生时间**：与增值税基本一致
- **纳税地点**：纳税人机构所在地/居住地
- **纳税期限**：与增值税一致

---

## 考试要点

1. **15个税目**：重点关注烟、酒、汽车、化妆品
2. **三种计征方式**：从价/从量/复合（卷烟+白酒）
3. **组成计税价格**：自产自用、委托加工、进口各有不同公式
4. **已纳消费税扣除**：只限特定税目，按领用量扣除
5. **特殊环节**：卷烟批发加征5%、金银首饰零售、超豪华汽车零售
6. **增值税与消费税的关系**：消费税是价内税，增值税是价外税
