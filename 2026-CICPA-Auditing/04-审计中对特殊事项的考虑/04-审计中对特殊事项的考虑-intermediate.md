## 二、典型例题解析

### 2.1 舞弊风险识别类（多选题）

**题目：** 舞弊行为通常具有以下特征（ ）。

A. 舞弊是故意的行为
B. 舞弊涉及隐瞒或伪造事实
C. 舞弊三角包括动机、机会和态度
D. 舞弊包括编制虚假财务报告和侵占资产

**解析：**
- 选项A：正确。舞弊是故意的、刻意隐瞒真相的行为。
- 选项B：正确。舞弊的手段包括隐瞒、伪造、变造相关文件和记录。
- 选项C：正确。舞弊三角（fraud triangle）是识别舞弊风险的理论框架。
- 选项D：正确。舞弊的两种主要类型。

**答案：** A、B、C、D

**考点延伸：** 舞弊三角的三个要素：
- **动机/压力**（Motive）：管理层或员工面临的压力
- **机会**（Opportunity）：可以利用内部控制缺陷实施舞弊
- **态度/借口**（Rationalization）：为舞弊行为寻找合理化的理由

### 2.2 集团财务报表审计类（单选题）

**题目：** 下列关于集团财务报表审计的说法中，正确的是（ ）。

A. 组成部分注册会计师对集团项目组负责
B. 组成部分重要性由组成部分注册会计师确定
C. 重要组成部分包括财务重大的组成部分和存在特别风险的组成部分
D. 集团项目组对集团财务报表审计负全部责任

**解析：**
- 选项A：错误。组成部分注册会计师对集团项目组的工作负责，但最终对集团审计报告负责的是集团项目合伙人。
- 选项B：错误。组成部分重要性由**集团项目组**确定。
- 选项C：**正确**。重要组成部分的判断标准有两个维度：财务重大性和特别风险。
- 选项D：错误。集团项目合伙人对集团财务报表审计负总体责任，但不能替代组成部分注册会计师对其工作的责任。

**答案：** C

**易错点：** 集团项目中，集团项目组负责确定组成部分重要性，但各组成部分注册会计师负责执行具体工作。

### 2.3 会计估计审计类（简答题）

**题目：** 注册会计师在审计被审计单位的会计估计时，应实施哪些审计程序？

**解析：**

**标准答题框架：**

**程序一：评价管理层作出会计估计的方法**
- 评价会计估计方法是否符合会计准则
- 评价方法的一贯性
- 评价输入数据的合理性

**程序二：测试管理层会计估计所依据的数据**
- 检查支持性证据
- 验证数据的完整性和准确性
- 确认数据的截止日期

**程序三：独立作出点估计或区间估计**
- 注册会计师独立评估会计估计的合理性
- 将注册会计师的点估计与管理层的估计进行比较
- 分析差异原因

**程序四：复核期后事项**
- 检查期后实际结果是否支持期初估计
- 考虑是否存在需要在财务报表中调整的事项

**程序五：评价会计估计的披露**
- 确认会计估计的披露是否充分、适当

### 2.4 关联方交易审计类（多选题）

**题目：** 注册会计师识别超出正常经营过程的重大关联方交易时，应实施的审计程序包括（ ）。

A. 获取关联方交易的相关合同或协议
B. 检查交易的批准程序
C. 检查交易是否按照市场价格进行
D. 向治理层通报

**解析：**
- 选项A：正确。合同或协议是确认关联方交易的基础证据。
- 选项B：正确。检查批准程序以评价交易的合规性。
- 选项C：正确。检查交易价格的公允性，判断是否存在利益输送。
- 选项D：正确。超出正常经营过程的重大关联方交易应向治理层通报。

**答案：** A、B、C、D

**考点延伸：** 关联方交易的审计重点：
1. 识别和了解关联方关系
2. 评价关联方交易的披露完整性
3. 测试关联方交易的授权批准
4. 评价交易价格的公允性

### 2.5 持续经营假设类（单选题）

**题目：** 下列关于持续经营假设的说法中，错误的是（ ）。

A. 持续经营假设是财务报表编制的基础
B. 注册会计师有责任对被审计单位的持续经营能力进行评估
C. 管理层对持续经营能力的评估期间是资产负债表日后12个月
D. 如果存在重大不确定性，注册会计师应当在审计报告中增加强调事项段

**解析：**
- 选项A：正确。持续经营假设是会计基本假设之一。
- 选项B：错误。注册会计师的责任是**评价**管理层的评估，而非对持续经营能力进行评估。
- 选项C：正确。评估期间是自资产负债表日起的12个月。
- 选项D：正确。存在重大不确定性时，应在审计报告中沟通。

**答案：** B

**易错点：** 注册会计师的责任是"评价"而非"评估/保证"管理层的持续经营评估。

## 三、分录/计算模板

### 3.1 集团审计中组成部分重要性计算模板

```
【模板】组成部分重要性确定

一、确定集团整体重要性
   集团财务报表整体重要性 = ____万元

二、确定组成部分重要性
   组成部分重要性 = 集团整体重要性 × 比例（通常低于100%）
                   = ____万元 × 50%~80%
                   = ____万元

三、注意事项
   - 组成部分重要性通常低于集团整体重要性
   - 各组成部分重要性之和可能超过集团整体重要性
   - 组成部分重要性用于确定对组成部分执行的审计工作
```

### 3.3 持续经营评估检查表

```
【模板】持续经营能力评估检查表

一、财务方面迹象
   □ 净资产为负或接近负数
   □ 营运资本为负数
   □ 即将到期的重大债务无法展期或偿还
   □ 过度依赖短期借款为长期资产融资
   □ 重要客户丧失
   □ 关键管理人员离职且无替代人选

二、经营方面迹象
   □ 关键业务终止或大幅萎缩
   □ 行业前景发生重大不利变化
   □ 重要法规或监管环境发生重大变化
   □ 主要供应商不再供货
   □ 无法获得开发业务所需的关键资源

三、其他迹象
   □ 违反债务契约条款
   □ 诉讼或监管程序可能导致无法偿还债务
   □ 计划进行重组或清算
```

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|-------|------|---------|
| 组成部分"财务重大"vs"特别风险" | 前者是规模大；后者是风险高 | "重大看规模，风险看波动" |
| 舞弊vs错误 | 舞弊=故意；错误=无意 | "有心为舞，无心为错" |
| 持续经营"重大不确定性"vs"强调事项段" | 前者涉及审计报告；后者是提醒 | "不确定是风险，提醒用强调" |
| 内部审计工作vs专家工作 | 内审是内部人员；专家是外部专业人员 | "内部用内审，外部用专家" |
| 期初余额审计vs持续经营 | 前者关注期初报表；后者关注期末报表 | "期初看过去，持续看未来" |

> "舞弊三角三要素，动机压力是首位；机会利用内控缺，态度借口自我骗"

**集团审计重要性：**
> "集团定整体，成分定子级；子级通常低于母，重要成分要审计"

**持续经营：**
> "十二个月评估，财务经营双关注；重大不确定性，审计报告要披露"

**关联方交易：**
> "关联方要识别，交易价格要公允；超常交易向治理，披露充分要完整"
