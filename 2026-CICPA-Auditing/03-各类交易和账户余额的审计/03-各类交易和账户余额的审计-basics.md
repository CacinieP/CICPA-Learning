# 各类交易和账户余额的审计 —— 第一性原理教程

## 一、销售与收款循环的审计

### 1.1 循环概述

**涉及的主要账户：** 营业收入、应收账款、坏账准备、预收账款、营业税金及附加。

### 1.2 主要内部控制

- 适当的职责分离（销售、发货、收款分离）
- 授权审批
- 凭证预先编号
- 定期对账和账龄分析

### 1.3 关键审计程序

| 认定 | 审计程序 |
|------|----------|
| 发生 | 从账到证（逆查）：选取收入记录追查至发运凭证和销售合同 |
| 完整性 | 从证到账（顺查）：选取发运凭证追查至收入记录 |
| 准确性 | 重新计算金额、复核折扣和折让 |
| 截止 | 检查资产负债表日前后的收入确认，确认归属期间正确 |
| 存在 | 函证应收账款 |
| 计价和分摊 | 分析坏账准备计提的合理性、账龄分析 |

### 1.4 收入截止测试

**核心程序：**
- 选取资产负债表日前后各若干天的收入记录
- 检查收入确认所附的销售合同、发运凭证
- 确认商品控制权转移是否在正确的会计期间

## 二、采购与付款循环的审计

### 2.1 循环概述

**涉及的主要账户：** 应付账款、预付账款、固定资产、累计折旧。

### 2.2 关键审计程序

| 认定 | 审计程序 |
|------|----------|
| 完整性 | 从供应商对账单追查至应付账款明细账（查找未入账负债） |
| 存在 | 函证应付账款（非强制但通常执行） |
| 计价 | 检查付款条件、折扣处理 |
| 权利和义务 | 检查采购合同和验收单 |

### 2.3 查找未入账应付账款

**关键程序：**
- 检查资产负债表日后付款凭证
- 检查资产负债表日后收到的发票
- 检查供应商对账单
- 检查未凭单收据报告

---

## 三、生产与存货循环的审计

### 3.1 循环概述

**涉及的主要账户：** 存货、主营业务成本、应付职工薪酬。

### 3.2 关键审计程序

| 程序 | 目的 |
|------|------|
| 存货监盘 | 验证存货的存在性和数量 |
| 存货计价测试 | 验证存货的成本计算是否正确 |
| 存货截止测试 | 确认存货收发的截止正确 |
| 存货分析程序 | 分析毛利率、存货周转率异常变动 |

### 3.3 存货监盘

**监盘程序：**
1. 制定监盘计划
2. 评价管理层盘点指令
3. 观察盘点现场（盘点前和盘点中）
4. 检查存货（抽盘）
5. 执行抽盘程序：从盘点记录追查至实物（存在性）和从实物追查至盘点记录（完整性）

---

## 四、货币资金的审计

### 4.1 主要账户

库存现金、银行存款、其他货币资金。

### 4.2 关键审计程序

**库存现金：**
- 盘点库存现金（突击检查）

**银行存款：**
- **银行函证**（必须执行！）
- 获取银行对账单
- 检查银行存款余额调节表
- 检查银行存款收支的截止
- 检查定期存款和保证金

**银行函证要点：**
- 向被审计单位在本期存过款的所有银行发函，包括零余额账户和已结清账户
- 函证由注册会计师亲自发出和收回
- 函证内容包括存款、借款、担保、信用证等

---

## 考试要点总结

1. **销售循环**：截止测试是核心（前后查）
2. **采购循环**：查找未入账应付账款（日后检查）
3. **存货循环**：监盘程序（双向抽盘）
4. **货币资金**：银行函证必须执行
5. **顺查vs逆查**：顺查→完整性，逆查→发生/存在
