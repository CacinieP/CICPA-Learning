## 二、典型例题解析

### 2.1 重要性确定类（单选题）

**题目：** 确定财务报表整体重要性的基准时，下列各项中通常不应采用的是（ ）。

A. 经常性业务的税前利润
B. 资产总额
C. 营业收入
D. 非经常性收益

**解析：**
- 财务报表整体重要性的基准应当选择最稳定的、与被审计单位性质和规模相适应的指标。
- 选项A：正确。经常性业务的税前利润是盈利企业最常用的基准。
- 选项B：正确。资产总额适用于资产占比较大的企业（如金融机构）。
- 选项C：正确。营业收入适用于微利或亏损企业。
- 选项D：**错误**。非经常性收益不稳定、不持续，不应作为确定重要性的基准。

**答案：** D

**易错点提醒：** 重要性基准应选择"稳定、持续、可预测"的财务指标。

### 2.2 重要性水平计算类（计算题）

**题目：** A公司2025年度财务报表数据如下：营业收入8,000万元，税前利润1,500万元，资产总额20,000万元。要求：根据风险评估结果，确定财务报表整体重要性和实际执行的重要性。

**假设条件：**
- 审计项目组评估A公司为盈利企业
- 适用的经验百分比为税前利润的5%

**解析：**

**步骤一：确定财务报表整体重要性**
```
财务报表整体重要性 = 税前利润 × 5%
                   = 1,500万元 × 5%
                   = 75万元
```

**步骤二：确定实际执行的重要性**
```
实际执行的重要性 = 财务报表整体重要性 × 50%~75%
                 = 75万元 × 50%~75%
                 = 37.5万元 ~ 56.25万元

通常取中间值：75万元 × 75% = 56.25万元（保守估计）
```

**答案：** 财务报表整体重要性为75万元；实际执行的重要性为37.5万-56.25万元（通常取56万元）。

**常见错误：** 混淆"财务报表整体重要性"和"实际执行的重要性"的关系。

### 2.3 内部控制五要素类（多选题）

**题目：** 下列各项中，属于内部控制要素的有（ ）。

A. 控制环境
B. 风险评估过程
C. 信息系统与沟通
D. 控制活动
E. 监控

**解析：**
根据COSO框架和审计准则，内部控制包括五要素：
1. **控制环境**：治理层和管理层对内部控制的态度、认识和措施
2. **风险评估过程**：识别和分析风险的过程
3. **信息系统与沟通**：与财务报告相关的信息系统
4. **控制活动**：有助于确保管理层指令得以执行的政策和程序
5. **监控**：对内部控制运行质量进行评价的过程

**答案：** A、B、C、D、E（全选）

**考点延伸：** 注册会计师了解内部控制时，主要关注与财务报表相关的内部控制，包括上述五要素。

### 2.4 风险评估程序类（单选题）

**题目：** 下列审计程序中，属于风险评估程序的是（ ）。

A. 对应收账款实施函证
B. 检查销售合同和销售订单
C. 分析毛利率变动趋势
D. 对固定资产实施监盘程序

**解析：**
- 选项A：函证是实质性程序，用于获取审计证据发现错报
- 选项B：检查合同属于风险评估程序中的"检查文件和记录"
- 选项C：**正确**。分析程序在风险评估阶段用于识别异常变动，属于风险评估程序
- 选项D：监盘程序是实质性程序，用于验证存货存在性

**答案：** C

**易混点：** 同一审计程序在不同阶段可能发挥不同作用：
- 分析程序在风险评估阶段→识别异常
- 分析程序在实质性程序阶段→获取证据
- 分析程序在总体复核阶段→最终评价

### 2.5 重大错报风险评估类（简答题）

**题目：** A公司为一家大型零售商，本期新增线上销售渠道。请分析注册会计师可能面临的重大错报风险领域，并说明应实施的总体应对措施。

**解析：**

**判断：存在重大错报风险**

**风险识别：**

| 风险类型 | 具体风险 | 影响认定 |
|---------|---------|---------|
| 财务报表层次 | 新渠道带来内部控制不完善 | 收入完整性、准确性 |
| 认定层次-固有风险 | 线上交易量大、交易速度快 | 收入发生、完整性 |
| 认定层次-固有风险 | 复杂的信息系统集成 | 收入准确性 |
| 认定层次-控制风险 | 线上订单审批流程不健全 | 收入发生 |

**总体应对措施（针对财务报表层次）：**

1. **强调职业怀疑**：提醒项目组成员关注新业务领域的舞弊风险
2. **分派经验丰富的成员**：安排具有零售行业经验的审计人员
3. **提供更多督导**：对新业务领域给予更多指导
4. **实施不可预见的审计程序**：避免被审计单位预判审计重点
5. **修改审计程序**：
   - 增加分析程序比重
   - 更多依赖实质性程序而非控制测试
   - 实施更多细节测试

**标准答题框架：** 识别风险领域→判断层次→制定应对措施

## 三、分录/计算模板

### 3.1 重要性水平确定模板

```
【模板】财务报表整体重要性确定

一、确定基准
   ├─ 盈利企业：经常性业务的税前利润（首选）
   ├─ 微利/亏损企业：营业收入
   └─ 资产主导型企业：资产总额

二、确定百分比
   ├─ 税前利润：通常5%
   ├─ 营业收入：通常0.5%~1%
   └─ 资产总额：通常0.5%~1%

三、计算公式
   财务报表整体重要性 = 基准 × 百分比

四、确定实际执行的重要性
   实际执行的重要性 = 财务报表整体重要性 × 50%~75%
```

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|-------|------|---------|
| 财务报表整体重要性 vs 实际执行的重要性 | 前者用于计划；后者用于指导实际执行 | "计划用整体，执行用实际" |
| 风险评估程序 vs 风险应对程序 | 前者了解风险；后者应对已识别风险 | "先评估后应对" |
| 了解内部控制 vs 测试内部控制 | 前者评价设计；后者测试运行 | "了解设计，测试运行" |
| 财务报表层次 vs 认定层次 | 前者影响整体；后者影响特定科目 | "整体vs局部" |
| 固有风险 vs 控制风险 | 前者不考虑内控；后者考虑内控 | "固有不考虑，控制考虑内" |
| 总体应对措施 vs 具体应对措施 | 前者针对报表层次；后者针对认定层次 | "报表层次用总体，认定层次用具体" |

## 五、速记口诀

**重要性基准选择：**
> "盈利看利润，微利看收入，资产主导看资产"

**内部控制五要素：**
> "控环风险信沟动，监在内控五兄弟"（控制环境、风险评估、信息与沟通、控制活动、监控）

**风险评估程序：**
> "询问观察加检查，分析程序不可少"

**总体应对措施：**
> "怀疑强调人升级，督导增加程序变"

**实际执行重要性：**
> "整体五成到七五，实际执行是范围"
