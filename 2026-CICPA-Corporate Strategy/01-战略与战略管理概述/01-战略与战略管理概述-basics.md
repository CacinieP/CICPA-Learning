# 战略与战略管理概述 —— 第一性原理教程

## 一、公司战略的基本理论

### 1.1 战略的定义

**公司战略**是公司为了适应外部环境的变化，实现长期目标，而对全局性、长远性问题进行的谋划和决策。

### 1.2 公司的使命与目标

| 层次 | 内容 |
|------|------|
| **使命** | 公司存在的理由和目的 |
| **目标** | 使命的具体化，可量化、有时限 |
| **战略** | 实现目标的路径和方法 |

### 1.3 公司战略的层次

| 层次 | 负责人 | 内容 |
|------|--------|------|
| **总体战略** | 最高管理层 | 做什么业务？发展/稳定/收缩 |
| **业务单位战略** | 事业部经理 | 如何竞争？成本领先/差异化 |
| **职能战略** | 职能部门 | 如何支持？营销/研发/财务 |

## 二、公司战略管理

### 2.1 战略管理的内涵与特征

**特征：**
- 全局性
- 长远性
- 纲领性
- 竞争性
- 风险性

### 2.2 战略管理过程

```
战略分析 → 战略选择 → 战略实施
   ↑                        |
   └──────── 战略控制 ←──────┘
```

**战略分析：** 外部环境分析+内部环境分析
**战略选择：** 制定、评估、选择战略方案
**战略实施：** 组织结构、企业文化、资源配置

### 2.3 创新与创新战略管理

**创新类型：**
- 产品创新
- 工艺创新
- 商业模式创新

**创新战略的关键：**
- 建立创新文化
- 投入研发资源
- 管理创新风险

### 2.4 权力与利益相关者

**利益相关者分类：**

| 类型 | 利益诉求 | 管理策略 |
|------|----------|----------|
| 股东 | 投资回报、股价 | 价值最大化 |
| 管理层 | 薪酬、权力 | 激励约束 |
| 员工 | 待遇、发展 | 公平激励 |
| 客户 | 产品/服务质量 | 满足需求 |
| 供应商 | 稳定合作 | 互利共赢 |
| 政府 | 税收、就业、合规 | 合规经营 |

**权力与利益冲突的协调：** 通过治理结构、激励机制、法律法规等手段平衡各方利益。

## 考试要点

1. **三个层次**：总体/业务/职能战略
2. **战略管理过程**：分析→选择→实施→控制
3. **使命→目标→战略**的逻辑关系
4. **利益相关者**：识别和管理各方诉求
