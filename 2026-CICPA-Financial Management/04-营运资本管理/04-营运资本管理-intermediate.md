## 二、典型例题解析

### 2.1 Baumol模型计算

**题目：** 某公司年现金需求总量为200万元，每次交易成本为1000元，持有现金的机会成本率为8%。

**要求：** 计算最佳现金持有量C*和最佳交易次数。

**解析：**

**最佳现金持有量公式：**
```
C* = √(2×T×F/K)

其中：
- T = 年现金需求总量 = 200万
- F = 每次交易成本 = 1000元
- K = 持有成本率 = 8%

C* = √(2×2000000×1000/0.08)
   = √(5000000000/0.08)
   = √(62500000000)
   = 250000元
```

**最佳交易次数：**
```
N* = T/C* = 2000000/250000 = 8次
```

**平均现金余额：**
```
平均现金余额 = C*/2 = 250000/2 = 125000元
```

**总成本验证：**
```
交易成本 = N×F = 8×1000 = 8000元
持有成本 = (C*/2)×K = 125000×0.08 = 10000元
总成本 = 18000元
```

**答案：** 最佳现金持有量25万元；最佳交易次数8次

### 2.2 Miller-Orr模型计算

**题目：** 某公司现金余额控制采用Miller-Orr模型：
- 下限L = 10000元
- 方差δ² = 4000000
- 每次交易成本F = 200元
- 日持有成本率K = 0.02%

**要求：** 计算回归点R、上限H。

**解析：**

**回归点R计算：**
```
R = 3√(3×δ²×F/4K) + L

首先计算：3×δ²×F/4K = 3×4000000×200/(4×0.0002)
                        = 2400000000/(0.0008)
                        = 3000000000000

R = 3 × (3000000000000)^(1/3)
  = 3 × √[√(3000000000000)]
  = 3 × √(1732050.8)
  = 3 × 1315.99
  = 3948元

等等，计算有误，重新计算：

3×δ²×F/4K = 3×4000000×200/(4×0.0002)
          = 2400000000/0.0008
          = 3000000000000

³√(3000000000000) = ³√(3×10^12) 
                  = ³√3 × 10^4
                  = 1.442 × 10000
                  = 14420

R = 3 × 14420 + 10000
  = 43260 + 10000
  = 53260元
```

**上限H计算：**
```
H = 3R - 2L
  = 3×53260 - 2×10000
  = 159780 - 20000
  = 139780元
```

**答案：** 回归点53260元；上限139780元

### 2.3 EOQ计算

**题目：** 某公司年需A零件10000件，每次订货成本100元，单位年储存成本20元。

**要求：** 计算经济订货量、最佳订货次数、订货间隔期。

**解析：**

**经济订货量公式：**
```
EOQ = √(2×D×S/H)

其中：
- D = 年需求 = 10000件
- S = 每次订货成本 = 100元
- H = 单位储存成本 = 20元

EOQ = √(2×10000×100/20)
    = √(2000000/20)
    = √100000
    = 316.23件
```

**最佳订货次数：**
```
N* = D/EOQ = 10000/316.23 = 31.62次
```

**订货间隔期：**
```
间隔期 = 360/N* = 360/31.62 = 11.39天
```

**总成本验证：**
```
订货成本 = N*×S = 31.62×100 = 3162元
储存成本 = (EOQ/2)×H = (316.23/2)×20 = 3162元
总成本 = 6324元
```

**答案：** EOQ≈316件；订货次数32次；间隔期11天

### 2.4 再订货点计算

**题目：** 承接上题，A零件日均需求量100件，订货至到货时间5天，安全储备200件。

**要求：** 计算再订货点。

**解析：**

**再订货点公式：**
```
再订货点 = 日均需求 × 交货时间 + 安全储备
         = 100 × 5 + 200
         = 500 + 200
         = 700件
```

**答案：** 再订货点700件

### 2.5 信用政策决策

**题目：** 某公司考虑改变信用政策：
- 当前政策：信用期30天，销售1000万
- 新政策：信用期45天，销售预计增至1200万
- 变动成本率60%
- 资本成本10%
- 坏账率：当前1%，新政策预计2%

**要求：** 判断新政策是否可行。

**解析：**

**增加的销售收益：**
```
边际贡献增加 = (1200-1000) × (1-60%) = 200 × 40% = 80万
```

**增加的应收账款机会成本：**
```
当前应收账款 = 1000/360 × 30 = 83.33万
新政策应收账款 = 1200/360 × 45 = 150万
应收账款增加 = 150 - 83.33 = 66.67万

机会成本 = 66.67 × 60% × 10% = 4万
```

**增加的坏账成本：**
```
当前坏账 = 1000 × 1% = 10万
新坏账 = 1200 × 2% = 24万
增加坏账 = 24 - 10 = 14万
```

**净收益计算：**
```
增加边际贡献 = 80万
减：机会成本增加 = 4万
减：坏账增加 = 14万
净增加收益 = 80 - 4 - 14 = 62万
```

**答案：** 新政策可行，净增加收益62万元

### 2.6 放弃折扣成本计算

**题目：** 某公司采购货物，原付款条件"2/10, n/30"（10天内付款可获2%折扣）。

**要求：** 
(1) 若放弃折扣，在第30天付款，隐含年利率是多少？
(2) 若银行短期贷款利率12%，应否放弃折扣？

**解析：**

**放弃折扣成本公式：**
```
放弃折扣成本 = 折扣率/(1-折扣率) × 360/(信用期-折扣期)

= 2%/(1-2%) × 360/(30-10)
= 2/98 × 360/20
= 0.02041 × 18
= 36.73%
```

**验证：**
```
若享受折扣，10天付款，省2%
若不享受折扣，30天付款，相当于多使用20天
年化成本 = 2% × (360/20) = 36%
（与精确值36.73%接近）
```

**决策：**
```
放弃折扣成本 = 36.73% > 银行贷款利率12%
结论：不应放弃折扣，应向银行借款在10天内付款
```

**答案：** 放弃折扣成本36.73%；应享受折扣

### 2.7 存货周转分析

**题目：** 某公司存货相关数据：
- 期初存货200万，期末存货400万
- 销货成本800万

**要求：** 计算存货周转率和周转天数。

**解析：**

**存货周转率：**
```
存货周转率 = 销货成本/平均存货
           = 800/[(200+400)/2]
           = 800/300
           = 2.67次
```

**存货周转天数：**
```
周转天数 = 360/周转率 = 360/2.67 = 134.8天
```

**答案：** 存货周转率2.67次；周转天数135天

### 2.8 营运资本策略选择

**题目：** 判断以下企业的营运资本策略：

| 企业 | 流动资产/总资产 | 流动负债/总资产 |
|-----|---------------|---------------|
| A | 50% | 30% |
| B | 40% | 35% |
| C | 45% | 20% |

**要求：** 指出各企业的策略类型。

**解析：**

**判断标准：**
```
- 保守型：高流动资产/低流动负债（安全性高，收益低）
- 适中型：匹配型
- 激进型：低流动资产/高流动负债（风险高，收益高）
```

**企业A：**
```
流动资产比率50%，流动负债比率30%
→ 流动资产大于流动负债
→ 属于适中型或略偏保守
```

**企业B：**
```
流动资产比率40%，流动负债比率35%
→ 流动资产略高于流动负债
→ 属于适中型
```

**企业C：**
```
流动资产比率45%，流动负债比率20%
→ 流动资产是流动负债的2.25倍
→ 属于保守型（留有大量流动资金）
```

**答案：** A-适中型；B-适中型；C-保守型

## 三、计算模板

### 模板1：Baumol模型

```
最佳现金持有量：C* = √(2×T×F/K)

其中：
- T = 年现金需求总量
- F = 每次交易成本
- K = 持有成本率

最佳交易次数 = T/C*
平均现金余额 = C*/2
```

### 模板2：Miller-Orr模型

```
回归点 R = ³√(3×δ²×F/4K) + L
上限 H = 3R - 2L

其中：
- δ² = 现金净流量方差
- L = 下限
- F = 每次交易成本
- K = 日持有成本率
```

### 模板3：EOQ模型

```
EOQ = √(2×D×S/H)

其中：
- D = 年需求
- S = 每次订货成本
- H = 单位储存成本

订货次数 = D/EOQ
```

### 模板4：信用政策决策

```
决策 = Σ(边际贡献增加 - 应收账款机会成本增加 - 坏账增加)

应收账款机会成本 = 销售增加额 × 变动成本率 × 资本成本 × 平均收账期/360
```

### 模板5：放弃折扣成本

```
放弃折扣成本 = 折扣率/(1-折扣率) × 360/(信用期-折扣期)

若放弃折扣成本 > 银行贷款利率 → 享受折扣
```

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|-------|------|---------|
| Baumol vs Miller-Orr | Baumol假设确定性，Miller-Orr允许随机波动 | "B"像确定棒，"M"像随机弯 |
| EOQ vs 再订货点 | EOQ决定每次订多少，再订货点决定何时订 | "量"决定多少，"点"决定何时 |
| 放弃折扣成本 vs 银行贷款利率 | 放弃折扣成本是隐含利率，决策时比较 | 高隐含成本不划算 |
| 存货周转率 vs 应收账款周转率 | 存货用销货成本，应收用赊销额 | "存"本算，"应"赊算 |

## 五、速记口诀

**Baumol模型：**
> 最佳现金持有量，根号二TFK除K

**Miller-Orr模型：**
> 回归点加立方根，安全下限要记清

**EOQ：**
> 经济订货量，根号二DS除H

**放弃折扣成本：**
> 折扣除一减折扣，乘以三六零天数，除以信用减折扣

**信用政策判断：**
> 边际贡献减去成本，增量收益为正可行
