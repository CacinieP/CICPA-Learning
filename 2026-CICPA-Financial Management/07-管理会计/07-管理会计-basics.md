# 管理会计 —— 第一性原理教程

## 一、本量利分析

### 1.1 基本模型
```
利润 = (P-V)×Q - F = 边际贡献 - 固定成本

边际贡献 = P-V（单位边际贡献）
边际贡献率 = (P-V)/P
```

### 1.2 保本分析
```
保本量 = F / (P-V)
保本额 = F / 边际贡献率
```

### 1.3 保利分析
```
保利量 = (F+目标利润) / (P-V)
保利额 = (F+目标利润) / 边际贡献率
```

### 1.4 利润敏感分析
```
敏感系数 = 利润变动% / 参数变动%
```

## 二、短期经营决策

### 2.1 生产决策

| 决策类型 | 关键分析 |
|----------|----------|
| 保留或关闭分部 | 分部边际贡献是否为正 |
| 自制或外购 | 比较相关成本（含机会成本） |
| 特殊订单 | 订单收入>变动成本+专属成本 |
| 约束资源优化 | 按单位约束资源边际贡献排序 |
| 出售或深加工 | 进一步加工增加的收入>增加的成本 |

### 2.2 定价决策
- **成本加成定价**：价格=成本×(1+加成率)
- **目标定价**：目标价格-目标利润=目标成本
- **边际成本定价**：价格=边际成本

## 三、全面预算

### 3.1 编制方法

| 方法 | 特点 |
|------|------|
| 增量预算 | 在上年基础上增减 |
| 零基预算 | 从零开始（不受历史束缚） |
| 固定预算 | 按固定业务量编制 |
| 弹性预算 | 按不同业务量编制 |
| 滚动预算 | 逐期向后滚动 |

### 3.2 营业预算编制

**销售预算→生产预算→直接材料预算→直接人工预算→制造费用预算→产品成本预算**

### 3.3 财务预算
- 现金预算
- 预计利润表
- 预计资产负债表

## 四、责任会计

### 4.1 责任中心

| 中心 | 考核指标 |
|------|----------|
| 成本中心 | 标准成本、可控成本 |
| 利润中心 | 部门边际贡献、部门可控边际贡献 |
| 投资中心 | ROI、RI（剩余收益） |

```
ROI = 部门营业利润 / 部门平均资产
RI = 部门营业利润 - 部门资产 × 资本成本
```

### 4.2 内部转移价格

| 方法 | 说明 |
|------|------|
| 市场价格 | 最优（存在外部市场时） |
| 协商价格 | 双方协商确定 |
| 变动成本+固定费 | 合理但操作复杂 |
| 全部成本+利润 | 简单但可能扭曲决策 |
| 双重价格 | 买卖双方用不同价格 |

## 五、业绩评价

### 5.1 关键指标

| 指标 | 公式/说明 |
|------|----------|
| **EVA** | NOPAT - 资本×WACC（经济增加值） |
| **平衡计分卡** | 财务+客户+内部流程+学习成长 |
| **KPI** | 抓住关键少数指标 |
| **绩效棱柱** | 利益相关者满意度+贡献+战略+流程+能力 |
| **标杆管理** | 与行业最优比较 |

### 5.2 平衡计分卡四个维度

| 维度 | 核心问题 | 典型指标 |
|------|----------|----------|
| 财务 | 股东怎么看我们？ | ROE、EVA、收入增长 |
| 客户 | 客户怎么看我们？ | 满意度、市场份额 |
| 内部流程 | 我们擅长什么？ | 质量率、交货时间 |
| 学习成长 | 我们如何进步？ | 员工培训、创新 |

## 考试要点

1. **保本/保利分析**：F/(P-V)
2. **特殊订单**：收入>相关成本即可接受
3. **约束资源**：按单位约束资源边际贡献排序
4. **ROI vs RI**：RI避免拒绝有利投资
5. **平衡计分卡**：四维度因果关系链
6. **EVA** = NOPAT - 资本×WACC
