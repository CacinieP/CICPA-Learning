# 长期投资决策 —— 第一性原理教程

## 一、资本成本

### 1.1 债务成本
```
税后Kd = 税前Kd × (1-T)
```

### 1.2 普通股成本
- **CAPM：** Ke = Rf + β(Rm-Rf)
- **股利增长模型：** Ke = D1/P0 + g

### 1.3 WACC
```
WACC = Wd×Kd×(1-T) + We×Ke    按目标市场价值权重
```

## 二、投资项目资本预算

### 2.1 评价方法

| 方法 | 判断标准 | 特点 |
|------|----------|------|
| **NPV** | >0可行 | 最优，与股东财富一致 |
| **IRR** | >资本成本可行 | 不依赖折现率，但可能有多个 |
| **PI** | >1可行 | 适用资本限量决策 |
| 回收期 | <基准回收期 | 简单但忽视时间价值 |

### 2.2 现金流量
```
营业CF = (收入-成本)(1-T) + 折旧×T = 净利润+折旧
```

### 2.3 敏感分析
敏感系数 = 目标变动% / 参数变动%

---

## 三、期权价值评估

### 3.1 基本概念

| 类型 | 权利 |
|------|------|
| 看涨期权(Call) | 以约定价**买入** |
| 看跌期权(Put) | 以约定价**卖出** |

### 3.2 投资策略
- **保护性看跌**：持股+买看跌→限制下跌
- **抛补看涨**：持股+卖看涨→增收限涨

### 3.3 看涨-看跌平价
```
C - P = S - K/(1+r)^t
```

### 3.4 实物期权
- **扩张期权**：未来可追加投资
- **延迟期权**：等待更多信息
- **放弃期权**：中途退出回收残值

---

## 四、企业价值评估

### 4.1 DCF模型
```
企业价值 = Σ[FCFt/(1+WACC)^t] + TV/(1+WACC)^n

FCF = EBIT(1-T) + 折旧 - 资本支出 - 营运资本增加
```

### 4.2 相对价值法
- **PE法**：股价=可比PE × EPS
- **PB法**：股价=可比PB × BPS
- **PS法**：股价=可比PS × SPS

---

## 考试要点

1. **WACC**是投资决策基准折现率
2. **NPV**是最优评价方法
3. **营业CF** = 净利润+折旧
4. **实物期权**：扩张/延迟/放弃
5. **DCF**核心：预测FCF+WACC折现
