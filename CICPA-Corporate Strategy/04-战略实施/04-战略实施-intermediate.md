# 战略实施 —— 典型考题解析

## 一、核心考法分类

本章常见的考法包括：
1. **组织结构类型选择**：职能制/事业部制/矩阵制的特征与适用条件
2. **钱德勒命题**：结构追随战略的理解
3. **平衡计分卡**：四个维度的指标设计
4. **战略控制方法**：预算控制、业绩衡量的区分
5. **企业文化层次**：精神层/制度层/物质层
6. **ESG绩效衡量**：环境/社会/治理指标

## 二、典型例题解析

### 2.1 组织结构类型（单选题）

**题目：** 甲公司是一家多元化集团企业，旗下拥有家电、房地产、金融等多个业务板块。该公司最适合采用的组织结构是（ ）。

A. 创业型结构
B. 职能型结构
C. 事业部制结构
D. 矩阵制结构

**解析：**
组织结构类型及其适用条件：

| 结构类型 | 适用场景 | 特点 |
|----------|----------|------|
| 创业型 | 初创企业 | 业主直接管理 |
| 职能型 | 单一业务企业 | 按专业分工 |
| 事业部制 | 多元化企业 | 按产品/地区设事业部 |
| 矩阵制 | 项目制企业 | 双重汇报线 |
| SBU型 | 大型多元化集团 | 事业部+管理层次 |

甲公司是多元化集团企业，适合事业部制结构，各业务板块独立运营、单独考核。

**答案：** C

---

### 2.2 钱德勒命题理解（单选题）

**题目：** 根据钱德勒的"结构追随战略"命题，下列理解正确的是（ ）。

A. 战略决定组织结构
B. 组织结构决定战略
C. 战略和组织结构相互独立
D. 组织结构比战略更重要

**解析：**
钱德勒命题的核心观点：
- **结构追随战略**：组织结构应当根据战略的需要来设计和调整
- 战略在前，结构在后
- 战略变化 → 组织结构相应调整

例如：企业采用多元化战略 → 从职能制转为事业部制

**答案：** A

---

### 2.3 平衡计分卡维度（多选题）

**题目：** 在平衡计分卡中，下列属于财务维度的指标有（ ）。

A. 投资回报率（ROI）
B. 客户满意度
C. 员工流失率
D. 营业利润率

**解析：**
平衡计分卡（BSC）四个维度：

| 维度 | 关注问题 | 典型指标 |
|------|----------|----------|
| 财务维度 | 股东如何看待我们 | ROI、ROE、利润率、增长率 |
| 客户维度 | 客户如何看待我们 | 满意度、市场份额、忠诚度 |
| 内部流程维度 | 我们必须擅长什么 | 质量、效率、创新 |
| 学习成长维度 | 我们能否持续改进 | 员工满意度、技能提升 |

选项分析：
- A ROI → 财务维度 ✓
- B 客户满意度 → 客户维度 ✗
- C 员工流失率 → 学习成长维度 ✗
- D 营业利润率 → 财务维度 ✓

**答案：** AD

### 2.4 企业文化层次（单选题）

**题目：** 某企业强调"以客户为中心"的核心价值观，同时制定了详细的客户服务规范，并统一了员工着装和工作场所标识。这分别体现了企业文化的（ ）层次。

A. 精神层、制度层、物质层
B. 物质层、精神层、制度层
C. 制度层、精神层、物质层
D. 精神层、物质层、制度层

**解析：**
企业文化三层次：

| 层次 | 内容 | 示例 |
|------|------|------|
| **精神层** | 核心价值观、企业精神、使命 | "以客户为中心" |
| **制度层** | 规章制度、工作规范 | 客户服务规范 |
| **物质层 | 外观标识、工作环境 | 统一着装、标识 |

对应本题：
- "以客户为中心" → 精神层
- 客户服务规范 → 制度层
- 统一着装、标识 → 物质层

**答案：** A

### 2.5 战略控制方法（多选题）

**题目：** 下列关于战略控制方法的说法中，正确的有（ ）。

A. 预算控制属于事前控制
B. 平衡计分卡是一种综合性的战略控制工具
C. 战略控制与财务控制没有区别
D. 滚动预算是一种动态的预算控制方法

**解析：**
战略控制的特点：
- **事前控制**：规划阶段设立标准（预算、目标）
- **事中控制**：执行中监控（平衡计分卡）
- **事后控制**：结果出来后评价（业绩报告）

选项分析：
- A正确：预算是事先设定的标准
- B正确：平衡计分卡从四个维度综合衡量战略执行
- C错误：战略控制关注长期目标，财务控制关注短期财务指标
- D正确：滚动预算根据最新情况不断调整

**答案：** ABD

### 2.6 ESG绩效衡量（单选题）

**题目：** 在ESG绩效衡量中，下列指标属于公司治理（G）维度的是（ ）。

A. 碳排放量
B. 员工培训投入
C. 独立董事比例
D. 能源消耗强度

**解析：**
ESG三个维度：

| 维度 | 关注点 | 典型指标 |
|------|--------|----------|
| 环境（E） | 环境影响 | 碳排放、能源消耗、废弃物 |
| 社会（S） | 社会责任 | 员工安全、社区贡献、供应链 |
| 治理（G） | 公司治理 | 独立董事比例、透明度、合规 |

选项分析：
- A 碳排放量 → 环境（E）
- B 员工培训投入 → 社会（S）
- C 独立董事比例 → 治理（G）
- D 能源消耗 → 环境（E）

**答案：** C

### 2.7 数智化转型（简答题）

**题目：** 简述企业数字化转型的主要方面及其对战略实施的影响。

**解析：**
数字化转型对战略实施的影响：

**1. 技术驱动层面**
- AI、大数据、云计算、物联网等技术应用
- 数据成为核心资产
- 决策从经验驱动转向数据驱动

**2. 业务变革层面**
- 数字化运营：流程自动化
- 数字化营销：精准营销、用户运营
- 数字化产品：智能产品、服务化转型

**3. 组织变革层面**
- 敏捷组织结构
- 数字化人才队伍建设
- 数据驱动的企业文化

**战略影响：**
- 支持新业务模式创新
- 提升运营效率
- 增强客户体验
- 创造新的竞争优势

## 三、组织结构速查表

| 结构类型 | 适用战略 | 优点 | 缺点 |
|----------|----------|------|------|
| 职能制 | 单一业务战略 | 专业分工、规模经济 | 协调困难、创新不足 |
| 事业部制 | 多元化战略 | 分权管理、专业化 | 资源重复、管理复杂 |
| 矩阵制 | 复杂项目战略 | 灵活配置、资源共享 | 双重汇报、权责不清 |
| SBU | 大型集团战略 | 战略协调、绩效管理 | 层次过多 |

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|--------|------|----------|
| 战略控制 vs 财务控制 | 战略控制看长期，财务控制看短期 | "战略看远方，财务看眼前" |
| 事业部制 vs 矩阵制 | 事业部是永久性分部，矩阵是临时项目组 | "事业部是家，矩阵是团队" |
| ESG三维度 | E是环境，G是治理，S是社会 | "G就是Governance治理" |
| 预算控制 vs 滚动预算 | 预算是静态的，滚动预算是动态的 | "滚动=滚动的预算" |
