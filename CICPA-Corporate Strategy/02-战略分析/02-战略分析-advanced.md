# 战略分析 —— 综合实战

## 一、综合题解题框架

**标准解题步骤：**
1. **审题定题型** — 判断是分析型题目还是选择型题目
2. **搭建分析框架** — 选择合适的分析工具（PEST/五力/波士顿/SWOT）
3. **信息分类提取** — 从材料中识别并归类关键信息
4. **代入模型分析** — 将信息代入相应框架
5. **得出战略结论** — 基于分析给出战略建议

**战略分析综合题万能框架：**
> 首先，通过【XX分析】可以发现......；
> 其次，从【XX角度】看，......；
> 再次，综合考虑内外部因素，建议采取【XX战略】；
> 最后，需要关注的风险是......。

## 三、陷阱与反套路

### 陷阱1：五力判断方向错误
**陷阱表现：** 将降低供应商议价能力的因素误认为增强因素
**识别方法：** 五力强度与产业吸引力负相关；判断时看"谁强"而非"谁有利"
**反套路：** 画一个坐标系，横轴是力量强度，纵轴是吸引力，强度越高吸引力越低

### 陷阱2：波士顿矩阵象限定错
**陷阱表现：** 将"高增长+低份额"误认为明星业务
**识别方法：** 明星业务的两个指标都高，波士顿矩阵是横纵轴交叉
**反套路：** 画坐标轴：横坐标是相对市场份额（低→高），纵坐标是市场增长率（低→高）

### 陷阱3：SWOT战略匹配混淆
**陷阱表现：** SO和ST战略混淆
**识别方法：** SO是"优势+机会"（用优势抓机会），ST是"优势+威胁"（用优势避威胁）
**反套路：** 记住口诀"SO是进攻，ST是防御"

## 四、真题变式推演

### 变式1：综合环境分析题

**题目：** 丙公司是一家传统服装制造企业，面临消费升级和电商冲击的双重影响。请分析该企业面临的内外部环境，并提出战略建议。

**解题框架：**

**一、外部环境分析**

**1.1 宏观环境（PEST）**
- 政治法律：环保法规趋严、智能制造政策支持
- 经济：居民收入提高、消费升级趋势
- 社会文化：个性化需求增加、环保意识增强、网购习惯普及
- 技术：柔性制造技术、智能仓储、直播电商

**1.2 产业环境（五力）**
- 新进入者威胁：中等（资金门槛降低但品牌门槛高）
- 供应商议价能力：中等（原材料价格波动）
- 购买者议价能力：高（消费者选择多、信息透明）
- 替代品威胁：高（海外品牌、设计师品牌）
- 现有竞争：激烈（产能过剩、价格战）

**二、内部环境分析**

**2.1 资源能力**
- 有形资源：土地厂房、生产设备
- 无形资源：品牌积累、渠道网络
- 人力资源：熟练工人队伍
- 核心能力：供应链管理、质量控制

**2.2 价值链分析**
- 优势：生产制造、供应链管理
- 劣势：设计研发、数字化营销

**三、SWOT与战略建议**

| | 优势（S） | 劣势（W） |
|---|---------|---------|
| **机会（O）** | SO：品牌升级、智能制造 | WO：数字化转型、直播电商 |
| **威胁（T）** | ST：供应链优化、柔性生产 | WT：关停低效产能、出售资产 |

**综合建议：** 采取"品牌升级+数字化转型"双轮驱动战略，从传统制造向品牌运营转型。

### 变式2：波士顿矩阵+资源配置

**题目：** 丁公司拥有四类业务，请根据下表信息进行波士顿矩阵分析，并说明各类业务的资源配置策略。

| 业务 | 市场增长率 | 相对市场份额 |
|------|-----------|-------------|
| A | 15% | 0.8 |
| B | 8% | 1.5 |
| C | 3% | 0.6 |
| D | 20% | 1.2 |

**解题：**
- A：低份额+高增长 → 问题业务 → 选择性投资
- B：低增长+高份额 → 现金牛 → 维持收割
- C：低增长+低份额 → 瘦狗 → 撤退
- D：高增长+高份额 → 明星 → 重点投资

**资源配置建议：** 将现金牛业务产生的现金用于支持明星业务和部分问题业务。

### 变式3：核心能力+价值链综合分析

**题目：** 戊公司是一家奶茶连锁企业，具备强大的供应链整合能力和独特的产品配方。请分析该企业的核心能力，并说明如何在价值链中发挥这一优势。

**解题框架：**

**核心能力VRIN分析：**
- V有价值：供应链整合降低成本，配方提升产品吸引力
- R稀缺：同行中具备如此完善供应链的不多
- I难以模仿：长期积累的供应商关系和研发体系
- N不可替代：独特的口味和成本优势难以复制

**价值链定位：**
- 供应链整合能力 → 属于支持活动中的采购 + 基本活动中的内部后勤
- 产品配方 → 属于支持活动中的技术开发

**竞争优势发挥：**
1. 利用供应链优势实现快速扩张
2. 利用配方优势建立品牌差异化
3. 通过标准化的供应链输出保证品质一致性

## 五、实务衔接

### 场景：上市公司年报战略分析

A股上市公司年报中，"经营情况讨论与分析"章节需要对行业环境进行战略分析：

**典型分析框架：**
1. **宏观环境变化**：政策导向、经济形势
2. **行业发展趋势**：市场规模、竞争格局、技术变革
3. **公司战略定位**：核心竞争优势、战略选择
4. **风险与机遇**：主要风险因素、发展机遇

投资者需要通过分析这些内容判断公司的战略前景。

## 六、速记总结

| 核心工具 | 分析维度 | 战略输出 |
|----------|----------|----------|
| PEST | 外部宏观 | 环境机会与威胁 |
| 五力模型 | 产业竞争 | 产业吸引力 |
| 波士顿矩阵 | 业务组合 | 投资优先级 |
| SWOT | 综合 | 四种战略匹配 |
| VRIN | 内部能力 | 核心竞争力 |
| 价值链 | 价值创造 | 成本优势 |

**综合分析答题模板：**
> 首先，对外部环境进行分析...；
> 其次，对内部资源能力进行评估...；
> 再次，通过SWOT矩阵进行战略匹配...；
> 最后，建议采取XX战略。
