# 战略分析 —— 典型考题解析

## 一、核心考法分类

本章是战略科目最核心的章节，综合题必考内容包括：
1. **PEST四要素分析**：政治/经济/社会/技术因素的识别
2. **波特五力模型**：五种竞争力量的强度判断
3. **波士顿矩阵（BCG矩阵）**：业务组合分析
4. **SWOT分析**：内外部因素与战略匹配
5. **核心能力VRIN判断**：资源与能力的稀缺性分析
6. **价值链分析**：基本活动与支持活动的识别

## 二、典型例题解析

### 2.1 PEST分析（单选题）

**题目：** 近年来，国家陆续出台多项支持新能源汽车产业发展的政策，同时对燃油车实施更严格的排放标准。这一政策变化最可能属于PEST分析中的（ ）因素。

A. 政治（Political）
B. 经济（Economic）
C. 社会（Social）
D. 技术（Technological）

**解析：**
PEST分析四个维度：
- P政治法律：政府政策、法规、政治稳定性
- E经济：经济增长、利率、通胀、汇率
- S社会文化：人口统计、生活方式、价值观
- T技术：技术变革、研发投入、创新

本题涉及"国家出台政策""排放标准"，这是政府通过法规和政策对产业的引导，属于典型的政治法律因素。

**答案：** A

### 2.2 波特五力模型（多选题）

**题目：** 下列因素中，能够降低供应商议价能力的包括（ ）。

A. 供应商数量众多，分散采购
B. 存在替代性原材料
C. 供应商提供的产品差异化程度高
D. 企业是供应商的大客户

**解析：**
供应商议价能力强弱的判断：
- 议价能力强：供应商数量少、产品差异化程度高、无替代品、企业非大客户
- 议价能力弱：供应商众多、存在替代品、产品标准化、企业是大客户

选项A：供应商众多→议价能力弱
选项B：存在替代品→议价能力弱
选项C：产品差异化程度高→议价能力强（排除）
选项D：企业是大客户→议价能力弱

**答案：** ABD

### 2.3 波士顿矩阵分析（单选题）

**题目：** 甲公司的业务组合中，A业务市场增长率低但相对市场份额高，B业务市场增长率高但相对市场份额低。根据波士顿矩阵，A业务属于（ ），B业务属于（ ）。

A. 明星业务；问题业务
B. 现金牛业务；问题业务
C. 现金牛业务；明星业务
D. 瘦狗业务；明星业务

**解析：**
波士顿矩阵四象限：
- **明星**：高增长+高份额 → 投资发展
- **问题**：高增长+低份额 → 选择性投资
- **现金牛**：低增长+高份额 → 收割利润
- **瘦狗**：低增长+低份额 → 撤退

A业务：低增长+高份额 → 现金牛
B业务：高增长+低份额 → 问题

**答案：** B

### 2.4 SWOT战略匹配（简答题）

**题目：** 某手机制造商具备强大的研发能力和完善的专利布局，但面临国内市场竞争激烈、人工成本上升的挑战。同时，国家大力支持芯片产业自主创新，5G技术带来新的市场机会。请运用SWOT分析框架，为该公司制定相应的战略。

**解析：**
SWOT分析的战略匹配：

| | 优势（S） | 劣势（W） |
|---|---------|---------|
| **机会（O）** | SO战略（增长型） | WO战略（扭转型） |
| **威胁（T）** | ST战略（防御型） | WT战略（防御型） |

**识别要素：**
- 优势（S）：研发能力强、专利布局完善
- 劣势（W）：竞争激烈、人工成本上升
- 机会（O）：国家支持芯片产业、5G新市场
- 威胁（T）：国内竞争（已在劣势中隐含）

**战略建议：**
1. **SO战略（增长型）**：利用研发优势抓住芯片国产化机会
   - 加大自研芯片投入
   - 抓住5G换机潮

2. **WO战略（扭转型）**：利用机会弥补劣势
   - 布局海外市场分散竞争风险
   - 智能制造降低人工成本

3. **ST战略（多元化）**：利用优势应对竞争
   - 差异化竞争：高端旗舰机
   - 专利许可创造收入

**答题结构：** 先列出SWOT，再逐项匹配战略，最后给出综合建议。

**答案：** （见上述解析）

### 2.5 VRIN核心能力判断（多选题）

**题目：** 乙公司是一家餐饮连锁企业，下列资源中，可能构成其核心能力的有（ ）。

A. 统一标准的中央厨房配送系统
B. 行业领先的产品配方
C. 普通员工的服务意识培训
D. 独特的装修风格

**解析：**
VRIN判断标准：
- V有价值：能为顾客创造价值
- R稀缺：竞争对手很少拥有
- I难以模仿：不易被复制或超越
- N不可替代：没有战略等价物

选项分析：
- A中央厨房：标准化有价值，但很多企业都有，难以构成稀缺（不选）
- B产品配方：配方通常是商业秘密，有价值、稀缺、难模仿、不可替代（选）
- C员工培训：一般性培训可复制，不稀缺（不选）
- D独特装修：可被模仿，不稀缺（不选）

**答案：** B

### 2.6 价值链分析（单选题）

**题目：** 在企业价值链分析中，下列活动属于支持活动的是（ ）。

A. 原材料采购
B. 生产制造
C. 市场营销
D. 人力资源管理

**解析：**
价值链两类活动：
- **基本活动**（直接创造价值）：内部后勤、生产运营、外部后勤、市场营销、服务
- **支持活动**（支撑基本活动）：采购、技术开发、人力资源管理、企业基础设施

选项分析：
- A原材料采购 → 支持活动（采购）
- B生产制造 → 基本活动（生产运营）
- C市场营销 → 基本活动
- D人力资源管理 → 支持活动

**答案：** AD

## 三、分析工具速查表

| 工具 | 维度 | 核心问题 |
|------|------|----------|
| PEST | 政治/经济/社会/技术 | 外部宏观环境如何？ |
| 五力模型 | 进入者/供应商/购买者/替代品/现有竞争 | 产业吸引力如何？ |
| 波士顿矩阵 | 增长率+份额 | 业务组合如何优化？ |
| SWOT | 优势/劣势/机会/威胁 | 如何匹配内外部因素？ |
| VRIN | 有价值/稀缺/难模仿/不可替代 | 什么是核心能力？ |
| 价值链 | 基本活动/支持活动 | 价值如何创造？ |

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|--------|------|----------|
| 五力强度高 vs 低 | 高五力=低吸引力=低利润 | "五力越强，企业越难" |
| 波士顿 vs GE矩阵 | 波士顿看增长率和份额，GE看产业吸引力和竞争实力 | "波士顿看现状，GE看潜力" |
| 基本活动 vs 支持活动 | 基本直接创造价值，支持间接支撑 | "基本是前线，支持是后勤" |
| 明星 vs 现金牛 | 明星高增长，现金牛低增长 | "明星是成长股，现金牛是蓝筹股" |
