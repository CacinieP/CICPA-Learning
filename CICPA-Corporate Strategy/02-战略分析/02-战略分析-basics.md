# 战略分析 —— 第一性原理教程

## 一、外部环境分析

### 1.1 宏观环境分析（PEST）

| 维度 | 关键要素 |
|------|----------|
| **P政治法律** | 法规、政策、税收、贸易政策 |
| **E经济** | GDP、利率、通胀、汇率 |
| **S社会文化** | 人口、生活方式、价值观 |
| **T技术** | 创新速度、技术变革、研发 |

### 1.2 产业环境分析

**产品生命周期：**
| 阶段 | 特征 |
|------|------|
| 导入期 | 高风险、低竞争、亏损 |
| 成长期 | 快速增长、竞争加剧 |
| 成熟期 | 增长放缓、竞争最激烈 |
| 衰退期 | 需求下降、退出增多 |

**波特五力模型：**
```
         新进入者威胁
             |
供应商议价─ 现有竞争 ─买方议价
   能力     程度     能力
             |
         替代品威胁
```

**五力强度越高→产业吸引力越低→利润越低。**

**成功关键因素（KSF）：** 在特定产业中取得成功必须具备的条件。

### 1.3 市场环境分析
- **市场集中度**：HHI指数、CR4
- **市场结构**：完全竞争/垄断竞争/寡头/垄断

### 1.4 竞争环境分析
- **竞争对手分析**：未来目标、假设、现行战略、能力
- **战略群组**：在同一战略空间中采用相似战略的企业集合

## 二、内部环境分析

### 2.1 资源与能力分析

| 概念 | 说明 |
|------|------|
| 有形资源 | 实物资产、财务资产 |
| 无形资源 | 品牌、专利、声誉 |
| 人力资源 | 员工知识、技能 |

**核心能力判断标准（VRIN）：**
- V=Value（有价值）
- R=Rare（稀缺）
- I=Inimitable（难以模仿）
- N=Non-substitutable（不可替代）

### 2.2 钻石模型（国家竞争优势）

```
        生产要素
           |
需求条件─ 企业战略/结构/竞争 ─相关与支持性产业
```

### 2.3 价值链分析

**基本活动：** 内部后勤→生产运营→外部后勤→市场营销→服务

**支持活动：** 采购、技术开发、人力资源管理、企业基础设施

### 2.4 业务组合分析

**波士顿矩阵：**

| 象限 | 市场增长率 | 相对市场份额 | 策略 |
|------|-----------|-------------|------|
| **明星** | 高 | 高 | 投资 |
| **问题** | 高 | 低 | 选择性投资 |
| **现金牛** | 低 | 高 | 收割 |
| **瘦狗** | 低 | 低 | 撤退 |

**通用矩阵（GE矩阵）：** 9格矩阵，横轴竞争实力、纵轴产业吸引力。

## 三、SWOT分析

| | 优势(S) | 劣势(W) |
|---|---------|---------|
| **机会(O)** | SO战略（增长型） | WO战略（扭转型） |
| **威胁(T)** | ST战略（多元化） | WT战略（防御型） |

---

## 考试要点

1. **PEST**：政治/经济/社会/技术
2. **五力模型**：决定产业竞争强度和利润
3. **核心能力VRIN**：有价值/稀缺/难模仿/不可替代
4. **波士顿矩阵**：明星/问题/现金牛/瘦狗
5. **SWOT**：四种战略组合
