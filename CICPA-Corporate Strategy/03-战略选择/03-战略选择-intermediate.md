# 战略选择 —— 典型考题解析

## 一、核心考法分类

本章是综合题的核心章节，必考内容包括：
1. **一体化战略判断**：前向/后向/横向一体化的识别
2. **安索夫矩阵**：密集型战略的类型判断
3. **基本竞争战略**：成本领先/差异化/集中化的特征区分
4. **蓝海战略**：四步动作框架的应用
5. **国际化战略类型**：四种国际化战略的特点
6. **并购vs内部发展vs战略联盟**：选择依据

## 二、典型例题解析

### 2.1 一体化战略判断（单选题）

**题目：** 甲公司是一家汽车制造商，为降低零部件采购成本并确保供应稳定性，决定收购一家上游零部件企业。这一战略属于（ ）。

A. 前向一体化
B. 后向一体化
C. 横向一体化
D. 多元化战略

**解析：**
一体化战略的方向判断：
- **前向一体化**：向产业链下游延伸（更接近客户），如制造商自建销售渠道
- **后向一体化**：向产业链上游延伸（更接近原材料），如制造商收购供应商
- **横向一体化**：在同行业进行延伸，如并购竞争对手

本题：制造商收购零部件企业 → 向产业链上游走 → 后向一体化

**答案：** B

### 2.2 安索夫矩阵（多选题）

**题目：** 某乳制品企业在深耕现有市场的同时，推出了一系列新产品以满足消费者多样化的需求。该企业实施的战略包括（ ）。

A. 市场渗透战略
B. 市场开发战略
C. 产品开发战略
D. 多元化战略

**解析：**
安索夫矩阵（产品-市场矩阵）：

| | 现有产品 | 新产品 |
|---|---------|--------|
| **现有市场** | 市场渗透 | 产品开发 |
| **新市场** | 市场开发 | 多元化 |

"深耕现有市场" → 现有市场+现有产品 → 市场渗透
"推出新产品" → 现有市场+新产品 → 产品开发

**答案：** AC

---

### 2.3 基本竞争战略（单选题）

**题目：** 下列关于成本领先战略的说法中，错误的是（ ）。

A. 成本领先战略的核心是获取相对于竞争对手的成本优势
B. 成本领先战略通常适用于广阔的目标市场
C. 成本领先企业需要不断进行差异化投资以保持竞争力
D. 成本领先战略的风险是可能被模仿或被技术变革颠覆

**解析：**
三种基本竞争战略的特征：

| 战略 | 竞争优势 | 市场范围 | 典型行业 |
|------|----------|----------|----------|
| 成本领先 | 低成本 | 广阔市场 | 沃尔玛、格兰仕 |
| 差异化 | 独特性 | 广阔市场 | 苹果、奔驰 |
| 集中化 | 低成本或独特性 | 细分市场 | 定制服务 |

选项C的错误在于：成本领先战略的核心是成本优势，而非差异化；持续进行差异化投资反而会削弱成本优势。

**答案：** C

---

### 2.4 蓝海战略四步动作（简答题）

**题目：** 简述蓝海战略的四步动作框架，并说明其核心思想。

**解析：**
蓝海战略（Blue Ocean Strategy）的四步动作框架：

**1. 剔除（Eliminate）**
- 问：哪些被行业认为是理所当然的因素应当被剔除？
- 将行业中普遍存在但实际价值有限的部分去除

**2. 减少（Reduce）**
- 问：哪些因素应当减少到行业标准以下？
- 将过度服务的部分简化

**3. 增加（Create）**
- 问：哪些因素应当增加到行业标准以上？
- 增加行业普遍不足但有价值的部分

**4. 创造（Raise）**
- 问：哪些因素从未被行业提供过？
- 创造全新的价值元素

**核心思想：** 价值创新（Value Innovation）——同时追求差异化和低成本，开辟全新的市场空间。

**答题结构：** 先说明四步动作，再点明核心思想是价值创新。

**答案：** （见上述解析）

### 2.5 国际化战略类型（单选题）

**题目：** 某跨国企业在全球范围内采用标准化的产品和服务，追求规模经济和成本优势，同时保持全球协调一致的战略。该企业最可能采用的是（ ）国际化战略。

A. 国际战略
B. 多国战略
C. 全球战略
D. 跨国战略

**解析：**
巴特利特-戈歇尔模型的四种国际化战略：

| 战略 | 全球整合程度 | 本地响应程度 | 特征 |
|------|-------------|-------------|------|
| 国际战略 | 低 | 低 | 母国中心，向海外转移能力 |
| 多国战略 | 低 | 高 | 东道国中心，适应本地 |
| 全球战略 | 高 | 低 | 全球标准化，成本优先 |
| 跨国战略 | 高 | 高 | 两者兼顾，最优配置 |

"全球范围内采用标准化""追求规模经济和成本优势""全球协调一致" → 全球战略

**答案：** C

### 2.6 发展战略途径比较（多选题）

**题目：** 下列关于企业发展战略三种主要途径的说法中，正确的有（ ）。

A. 并购的优点是速度快，可以快速获得市场份额
B. 内部发展的缺点是风险较大，可能面临较大不确定性
C. 战略联盟可以实现资源共享和风险分担
D. 战略联盟的控制力较强，适合需要高度控制的战略

**解析：**
三种途径的比较：

| 途径 | 优点 | 缺点 |
|------|------|------|
| 并购 | 速度快、获得市场份额和资源 | 整合风险、高溢价、文化冲突 |
| 内部发展 | 控制力强、学习效应、避免整合问题 | 速度慢、投入大、风险高 |
| 战略联盟 | 风险共担、资源共享、灵活性 | 控制力弱、文化冲突、机会主义风险 |

选项分析：
- A正确：并购确实速度快
- B错误：内部发展的缺点是"速度慢"，"风险大"是并购的缺点
- C正确：战略联盟的优势
- D错误：战略联盟的控制力弱而非强

**答案：** AC

### 2.7 商业模式画布（单选题）

**题目：** 在商业模式画布中，"客户群体""价值主张""核心资源"分别属于（ ）。

A. 价值创造模块
B. 基础设施模块
C. 客户模块
D. 成本结构模块

**解析：**
商业模式画布九要素分类：

| 模块 | 构成要素 |
|------|----------|
| 客户模块 | 客户细分、渠道、客户关系、收入来源 |
| 价值模块 | 价值主张 |
| 基础设施模块 | 核心资源、关键业务、重要合作 |
| 成本模块 | 成本结构 |

"客户群体"属于客户模块，"价值主张"属于价值模块，"核心资源"属于基础设施模块。

**答案：** C

## 三、战略选择速查表

| 战略类型 | 核心问题 | 适用条件 |
|----------|----------|----------|
| 一体化 | 产业链延伸方向 | 产业链利润丰厚、整合有价值 |
| 密集型 | 产品-市场组合 | 现有业务有增长空间 |
| 多元化 | 进入新业务领域 | 现有业务吸引力下降 |
| 成本领先 | 如何降低成本 | 标准化产品、价格敏感市场 |
| 差异化 | 如何与众不同 | 研发能力、品牌能力 |
| 集中化 | 专注细分市场 | 大企业不屑于进入的市场 |

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|--------|------|----------|
| 前向 vs 后向一体化 | 前向向下游，后向向上游 | "前=钱=向前走=接近客户" |
| 成本领先 vs 差异化 | 一个省钱，一个花钱 | "成本领先省钱，差异化花钱" |
| 全球 vs 多国战略 | 全球标准化，多国本地化 | "全=全部标准，多=多样化" |
| 并购 vs 联盟 | 并购是合并，联盟是合作 | "并=合并，并=一起" |
