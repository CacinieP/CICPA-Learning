# 公司法律制度 —— 典型考题解析

## 一、核心考法分类

本章是P0高优先级章节，案例题高发，在历年真题中的主要考法归纳：

| 考法类型 | 常见题型 | 考查特点 |
|---------|---------|---------|
| 公司设立条件 | 单选题 | 人数、注册资本要求 |
| 股东出资 | 单选题、多选题 | 出资形式、出资瑕疵责任 |
| 股东权利 | 单选题、多选题 | 表决权、分红权、知情权 |
| 公司决议效力 | 单选题、案例题 | 无效/可撤销/不成立 |
| 董监高义务 | 单选题、多选题、案例题 | 忠实义务、勤勉义务 |
| 股权转让 | 单选题、案例题 | 有限公司对外转让限制 |
| 公司合并分立 | 单选题 | 决议要求、债权人保护 |
| 公司清算 | 单选题 | 清算程序、清偿顺序 |

## 二、典型例题解析

### 2.1 公司类型（单选题）—— P0重点

**题目：** 下列关于有限责任公司与股份有限公司区别的说法中，正确的是（ ）。

A. 有限责任公司股东以其认缴出资额为限承担责任，股份有限公司股东以其持有的股份为限承担责任
B. 有限责任公司注册资本实行认缴制，股份有限公司注册资本实行实缴制
C. 有限责任公司股东人数有上限，股份有限公司股东人数无限制
D. 两种公司都可以发行公司债券

**解析：** A选项正确。有限责任公司股东以其认缴出资额为限对公司承担责任；股份有限公司股东以其持有的股份为限对公司承担责任。B选项错误。股份有限公司的注册资本也实行认缴制（除法律、行政法规对注册资本实缴有特别规定的行业外）。C选项错误。有限责任公司股东人数为50人以下，无上限；股份有限公司股东人数无上限，但发起人应为2人以上200人以下。D选项不够准确。股份有限公司发行债券需要符合特定条件，且上市公司公开发行债券需符合相关规定。

**答案：** A

### 2.2 股东出资（单选题）—— P0重点

**题目：** 甲、乙、丙共同设立一家有限责任公司，甲以货币出资50万元，乙以实物出资30万元（评估作价），丙以知识产权出资20万元。公司成立后发现，甲的实际出资是挪用公司的资金。以下说法正确的是（ ）。

A. 丙的知识产权出资有效
B. 乙的实物出资有效
C. 甲应当向公司补足50万元，并承担违约责任
D. 甲应当向公司补足出资，并对公司造成损害承担赔偿责任

**解析：** 根据《公司法》规定，股东应当按期足额缴纳公司章程中规定的各自所认缴的出资额。股东以货币出资的，应当将货币出资足额存入有限责任公司在银行开设的账户；以非货币财产出资的，应当依法办理其财产权的转移手续。股东不按照规定缴纳出资的，除应当向公司足额缴纳外，还应当向已按期足额缴纳出资的股东承担违约责任。同时，股东抽逃出资的，应当返还抽逃的出资，给公司造成损失的，应当承担赔偿责任。

**答案：** C、D

### 2.3 决议效力（单选题）—— P0重点

**题目：** 某有限责任公司召开股东会会议，关于会议决议效力的下列说法，正确的是（ ）。

A. 股东会会议召集程序违反法律规定的，决议无效
B. 股东会会议决议内容违反公司章程的，决议无效
C. 股东会会议决议内容损害公司利益的，决议无效
D. 股东会会议未召开但全体股东书面同意的，决议有效

**解析：** 根据《公司法》规定，公司股东会（或股东大会）的决议效力分为三种：（1）无效决议：决议内容违反法律、行政法规的无效；（2）可撤销决议：会议召集程序、表决方式违反法律、行政法规或公司章程，或者决议内容违反公司章程的，股东可以自决议作出之日起60日内请求法院撤销；（3）不成立决议：未召开会议、出席会议的人数或所持表决权不符合公司法或章程规定、会议的表决结果未达到公司法或章程规定的通过比例等情形。

A选项错误：召集程序违法属于可撤销情形，非无效。
B选项错误：决议内容违反公司章程属于可撤销情形，非无效。
C选项错误：损害公司利益的决议内容，如果是违反法律、行政法规的才无效，损害公司利益本身不是无效的法定事由。
D选项正确：全体股东书面同意可以视为已召开会议并作出决议，属于有效的决议形式。

**答案：** D

### 2.4 董监高忠实义务（单选题）—— P0重点

**题目：** 某股份有限公司董事张某，在任期内拟进行下列行为，其中违反《公司法》规定的是（ ）。

A. 将公司的一项商业机会告知其朋友的公司
B. 以市场价从公司购买一辆汽车
C. 将公司资金借贷给他人
D. 接受他人与公司交易的佣金归为己有

**解析：** 根据《公司法》规定，董事、监事、高级管理人员应当遵守法律、行政法规和公司章程，对公司负有忠实义务和勤勉义务。不得有以下行为：（1）挪用公司资金；（2）将公司资金以其个人名义或以其他个人名义开立账户存储；（3）违反公司章程的规定，将公司资金借贷给他人或者以公司财产为他人提供担保；（4）违反公司章程或未经股东会同意，与本公司订立合同或进行交易；（5）未经股东会同意，将公司商业机会谋取为己有；（6）接受他人与公司交易的佣金归为己有；（7）擅自披露公司秘密等。

A选项：擅自将公司商业机会告知他人，属于违反忠实义务。
B选项：以市场价购买公司汽车，如公司章程未禁止或经股东会同意，可能涉及自我交易，但以市场价购买一般不损害公司利益，关键是程序是否合法。
C选项：违反公司章程或未经股东会同意，将公司资金借贷给他人，违反规定。
D选项：接受他人与公司交易的佣金归为己有，属于违反忠实义务。

**答案：** A、C、D

### 2.5 股权转让（单选题）—— P0重点

**题目：** 甲是某有限责任公司的股东，持股比例为30%。甲拟将其持有的股份转让给非股东的乙。下列说法正确的是（ ）。

A. 须经其他股东过半数同意
B. 须经其他股东2/3以上同意
C. 其他股东有优先购买权
D. 须经全体股东一致同意

**解析：** 根据《公司法》规定，有限责任公司股东向股东以外的人转让股权，应当经其他股东过半数同意。其他股东自知道或应当知道转让条件之日起30日内，或自首次就转让条件通知之日起30日内行使优先购买权。两个以上股东主张行使优先购买权的，协商确定各自的购买比例；协商不成的，按照转让时各自的出资比例行使优先购买权。

A选项正确，须经其他股东"过半数"同意，而非"2/3以上"或"一致"同意。
C选项正确，其他股东有优先购买权。

**答案：** AC

### 2.6 公司合并分立（单选题）

**题目：** 甲公司拟与乙公司合并。下列程序中，符合《公司法》规定的是（ ）。

A. 经董事会决议通过即可
B. 经出席股东大会的股东所持表决权的2/3以上通过
C. 须通知债权人并公告，债权人有权要求清偿债务或提供担保
D. 合并后的公司对合并前公司的债务不承担责任

**解析：** A选项错误，公司合并属于特别决议事项，须经股东会（股东大会）决议通过，而非董事会。B选项错误，有限责任公司须经代表2/3以上表决权的股东通过；股份有限公司须经出席股东大会的股东所持表决权的2/3以上通过。注意有限公司是"表决权"2/3以上，股份公司是"出席股东大会股东所持表决权"的2/3以上。C选项正确，公司合并须通知债权人并公告，债权人有权要求清偿债务或提供担保。D选项错误，公司合并的，合并后的公司继承合并前公司的债权债务。

**答案：** C

## 三、法条要点速记

### 3.1 公司设立条件对比

| 项目 | 有限责任公司 | 股份有限公司 |
|-----|------------|-------------|
| 股东人数 | 1-50人 | 发起人2-200人 |
| 注册资本 | 认缴制 | 认缴制 |
| 出资方式 | 货币+非货币 | 货币+非货币 |
| 组织机构 | 股东会+董事会+监事会 | 股东大会+董事会+监事会 |

### 3.2 决议效力类型

| 类型 | 情形 | 救济方式 |
|-----|------|---------|
| 无效 | 内容违反法律、行政法规 | 无效之诉（无期限限制） |
| 可撤销 | 程序违法/违反章程/内容违反章程 | 撤销之诉（60日内） |
| 不成立 | 未开会/未表决/未达法定人数/未达表决权 | 确认不成立之诉 |

### 3.3 董监高义务

| 义务 | 禁止行为 |
|-----|---------|
| 忠实义务 | 挪用资金、违规借贷、关联交易、商业机会、佣金归己、违规担保 |
| 勤勉义务 | 怠于行使职权、决策失误造成损失 |

### 3.4 股权转让规则

| 类型 | 规则 |
|-----|------|
| 有限公司 | 对外转让须过半数同意，其他股东有优先购买权 |
| 股份公司 | 自由转让（发起人股份有锁定期） |

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|-------|------|---------|
| 决议无效 vs 可撤销 | 违反法律无效，违反章程可撤销 | "法"比"章"大 |
| 解散 vs 清算 | 解散是程序开始，清算是清偿程序 | "解"开始，"清"结束 |
| 合并 vs 分立 | 合并是两个变一个，分立是一个变两个 | "合"变多，"分"变少 |
| 减资 vs 撤资 | 减资是公司减少注册资本，撤资是股东退出 | "减"改公司，"撤"改股东 |

## 五、速记口诀

**决议效力口诀：**
"违法无效，违章可撤销；未开会/未表决/未达人数→不成立"

**股东出资口诀：**
"货币要足额，非货币要评估转移；瑕疵出资要补足+违约"

**股权转让口诀：**
"有限公司对外转，过半数同意优先买；股份公司自由转，发起人有锁定期"

**董监高禁止口诀：**
"挪用资金违规借，关联交易窃机会，佣金归己违忠实"
