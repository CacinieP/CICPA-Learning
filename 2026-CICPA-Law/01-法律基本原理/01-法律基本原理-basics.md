# 法律基本原理 —— 第一性原理教程

> 从最基础的法律概念出发，逐步构建对法律体系的完整认知，覆盖注会考试全部考点。

---

## 一、法律基本概念

### 1.1 法律的概念与特征

**什么是法律？**

法律是由国家制定或认可，由国家强制力保证实施的行为规范体系。它通过对权利与义务的规定，确认、保护和发展有利于统治阶级的社会关系和社会秩序。

**法律的特征（五大特征）：**

| 特征 | 说明 |
|------|------|
| **规范性** | 法律为人们的行为提供模式、标准或方向 |
| **国家意志性** | 法律是由国家制定或认可的，体现国家意志 |
| **国家强制性** | 法律由国家强制力（军队、警察、法庭、监狱等）保证实施 |
| **普遍性** | 法律在国家主权范围内普遍有效，对一切主体适用 |
| **程序性** | 法律的制定、执行和遵守都有严格的程序规定 |

**核心原理：** 法律的本质是统治阶级意志的体现，但这种意志的内容是由统治阶级的物质生活条件决定的。

### 1.2 法律体系

**法律体系的概念：**

法律体系是指一国现行全部法律规范按照一定标准分类组合为不同法律部门而形成的有机联系的整体。

**中国特色社会主义法律体系的七大部门法：**

1. **宪法及宪法相关法** —— 国家的根本大法及相关组织法
2. **民法商法** —— 调整平等主体之间的人身关系和财产关系（注会考试核心）
3. **行政法** —— 调整行政管理活动中的社会关系
4. **经济法** —— 国家对市场经济进行宏观调控和规制的法律
5. **社会法** —— 保护弱势群体、维护社会保障的法律
6. **刑法** —— 规定犯罪与刑罚的法律
7. **诉讼与非诉讼程序法** —— 规定解决纠纷程序的法律

> **理解要点：** 法律体系是"现行"法律构成的"有机"整体，不包括已废止的法律，也不包括国际法。

### 1.3 法律渊源

**法律渊源的概念：**

法律渊源是指法律规范的具体表现形式，即法律出自哪些机关、通过什么方式表现出来。

**我国法律渊源（按效力等级排列）：**

| 渊源 | 制定机关 | 效力等级 |
|------|---------|---------|
| **宪法** | 全国人民代表大会 | 最高 |
| **法律** | 全国人大及其常委会 | 仅次于宪法 |
| **行政法规** | 国务院 | 低于法律 |
| **地方性法规** | 地方人大及其常委会 | 低于行政法规 |
| **部门规章** | 国务院各部委 | 低于行政法规 |
| **地方政府规章** | 省/市政府 | 低于地方性法规 |
| **司法解释** | 最高人民法院/最高检察院 | 配套法律适用 |
| **国际条约和协定** | 国家间缔结 | 另有规定者除外 |

**效力冲突解决规则：**
- 上位法优于下位法
- 特别法优于一般法（同一机关制定）
- 新法优于旧法（同一机关制定）
- 无法判断时报请有权机关裁决

### 1.4 法律规范

**法律规范的概念：**

法律规范是组成法律的最基本单元，是国家制定或认可的、以规定权利义务为内容、具有国家强制性的行为规则。

**法律规范的三要素（逻辑结构）：**

1. **假定（条件）** —— 规范适用的条件或情形
2. **模式（处理）** —— 允许、禁止或要求的行为
   - 可为模式（授权性规范）：可以……
   - 勿为模式（禁止性规范）：不得……
   - 应为模式（命令性规范）：应当……
3. **后果（制裁/奖励）** —— 违反或遵守规范的法律后果

**法律规范的分类：**

| 分类标准 | 类型 | 说明 |
|---------|------|------|
| 内容 | 授权性规范 | 赋予主体某种权利 |
| | 义务性规范（命令性/禁止性） | 规定主体必须做或不做的事 |
| 强制性 | 强行性规范 | 不得以个人意志变更 |
| | 任意性规范 | 允许当事人协商确定 |
| 确定性 | 确定性规范 | 明确规定了行为规则 |
| | 委任性规范 | 委托其他机关制定具体规则 |
| | 准用性规范 | 参照适用其他规范 |

> **考试技巧：** 区分强行性规范与任意性规范是常考知识点——强行性规范不可协商排除，任意性规范可由当事人约定。

## 二、法律关系

### 2.1 法律关系的概念与特征

**什么是法律关系？**

法律关系是法律规范在调整人们行为过程中形成的权利和义务关系。

**三大特征：**
1. **以法律规范为前提** —— 没有法律规范就没有法律关系
2. **以权利义务为内容** —— 法律关系本质上是权利义务关系
3. **以国家强制力为保障** —— 法律关系受法律保护

**法律关系与一般社会关系的区别：**

并非所有的社会关系都是法律关系。朋友关系、恋爱关系一般不属于法律关系，只有法律加以调整的社会关系才是法律关系。

### 2.2 法律关系的种类

| 分类标准 | 类型 | 举例 |
|---------|------|------|
| 产生依据 | 调整性法律关系（合法行为产生） | 买卖合同关系 |
| | 保护性法律关系（违法行为产生） | 侵权赔偿关系 |
| 主体数量 | 双方法律关系 | 买卖关系 |
| | 多方法律关系 | 合伙关系 |
| 权利义务 | 双务法律关系 | 买卖关系（双方互有权利义务） |
| | 单务法律关系 | 赠与关系（仅一方承担义务） |
| 对应程度 | 第一性法律关系（主法律关系） | 买卖合同关系 |
| | 第二性法律关系（从法律关系） | 担保合同关系 |

### 2.3 法律关系的基本构成（三要素）

法律关系由**主体、客体、内容**三大要素构成。

#### （一）法律关系主体

法律关系的参与者，即享有权利、承担义务的人。

**主体类型：**
1. **自然人** —— 基于出生而获得主体资格
2. **法人** —— 具有民事权利能力和行为能力的组织
3. **非法人组织** —— 合伙企业、个人独资企业等
4. **国家** —— 特殊主体（如发行国债时）

**重要概念：**
- **权利能力**：主体享有权利和承担义务的资格（自然人的权利能力始于出生、终于死亡）
- **行为能力**：主体通过自己的行为取得权利、承担义务的资格
  - 完全民事行为能力人：≥18周岁，或16-18周岁以自己劳动收入为主要生活来源
  - 限制民事行为能力人：8-18周岁的未成年人，或不能完全辨认自己行为的成年人
  - 无民事行为能力人：<8周岁，或完全不能辨认自己行为的成年人

#### （二）法律关系客体

法律关系主体享有权利和承担义务所指向的对象。

**客体类型：**
1. **物** —— 物权关系的客体（如房屋、汽车）
2. **行为** —— 债权关系的客体（如交付货物、提供服务）
3. **人格利益** —— 人身权的客体（如生命、健康、名誉）
4. **智力成果** —— 知识产权的客体（如发明、作品）

#### （三）法律关系内容

法律关系主体所享有的权利和承担的义务。

- **法律权利**：主体依法享有的某种利益和自由
- **法律义务**：主体依法必须为或不为某种行为的责任

> 权利与义务具有对应性，一方的权利往往是他方的义务。

### 2.4 法律关系的变动原因——法律事实

**什么是法律事实？**

法律事实是法律规范规定的、能够引起法律关系产生、变更或消灭的客观情况。

**分类：**

```
法律事实
├── 法律事件（不以当事人意志为转移）
│   ├── 绝对事件（自然现象）：地震、洪水、人的出生死亡
│   └── 相对事件（社会现象）：战争、罢工、政策变化
└── 法律行为（以当事人意志为转移）
    ├── 合法行为：签订合同、立遗嘱
    └── 违法行为：侵权、违约
```

**判断方法：** 关键看该事实是否以当事人的意志为转移——不以意志为转移的是事件，以意志为转移的是行为。

## 三、习近平法治思想

### 3.1 核心要义

习近平法治思想是全面依法治国的根本遵循和行动指南，核心要义包括：

1. **坚持党对全面依法治国的领导** —— 党的领导是推进全面依法治国的根本保证
2. **坚持以人民为中心** —— 人民是依法治国的主体和力量源泉
3. **坚持中国特色社会主义法治道路** —— 坚定不移走中国特色社会主义法治道路
4. **坚持依宪治国、依宪执政** —— 宪法是国家的根本法
5. **坚持在法治轨道上推进国家治理体系和治理能力现代化**
6. **坚持建设中国特色社会主义法治体系** —— 包括法律规范体系、法治实施体系、法治监督体系、法治保障体系、党内法规体系
7. **坚持依法治国、依法执政、依法行政共同推进**
8. **坚持全面推进科学立法、严格执法、公正司法、全民守法**
9. **坚持统筹推进国内法治和涉外法治**
10. **坚持建设德才兼备的高素质法治工作队伍**
11. **坚持抓住领导干部这个"关键少数"**

### 3.2 法治与市场经济的关系

- 市场经济本质上是**法治经济**
- 法治是最好的**营商环境**
- 以法治保障**市场在资源配置中起决定性作用**和更好发挥政府作用

## 四、市场经济法律调整

### 4.1 市场经济与法律的关系

**基本原理：** 市场经济需要法律来规范和调整，法律为市场经济提供运行规则和制度保障。

**市场经济法律调整的三大维度：**

| 维度 | 功能 | 典型法律 |
|------|------|---------|
| **民商法** | 确立市场主体的平等地位和交易规则 | 民法典、公司法、合伙企业法 |
| **经济法** | 国家对市场经济进行宏观调控和规制 | 反垄断法、税法、企业国有资产法 |
| **社会法** | 保护劳动者等弱势群体 | 劳动法、劳动合同法 |

### 4.2 市场经济法律调整的基本原则

1. **意思自治原则** —— 市场主体在法定范围内自由表达意志
2. **公平竞争原则** —— 反对垄断和不正当竞争
3. **诚实信用原则** —— 市场主体应诚实守信
4. **等价有偿原则** —— 交易应遵循价值规律
5. **守法原则** —— 经营活动不得违反法律强制性规定

### 4.3 民法调整的对象

根据《民法典》第2条，民法调整的是**平等主体**之间的**人身关系**和**财产关系**。

- **平等主体**：自然人与自然人、法人与法人、自然人与法人之间地位平等
- **财产关系**：基于财产的归属和流转形成的社会关系（物权、债权）
- **人身关系**：基于人格和身份形成的社会关系（人格权、婚姻家庭等）

> **注意：** 行政管理关系、刑事关系不属于民法调整范围。

## 考试要点总结

| 考点 | 核心记忆 |
|------|---------|
| 法律特征 | 规范性、国家意志性、国家强制性、普遍性、程序性 |
| 法律渊源 | 宪法 > 法律 > 行政法规 > 地方性法规/部门规章 |
| 法律规范三要素 | 假定、模式、后果 |
| 法律关系三要素 | 主体、客体、内容 |
| 行为能力分类 | 完全（≥18）、限制（8-18）、无（<8） |
| 法律事实分类 | 事件（不依意志）vs 行为（依意志） |
| 习近平法治思想 | 十一个坚持 |
| 民法调整对象 | 平等主体间的人身关系和财产关系 |
