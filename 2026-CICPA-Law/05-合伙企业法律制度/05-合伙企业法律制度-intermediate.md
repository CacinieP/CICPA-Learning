| 考法类型 | 常见题型 | 考查特点 |

| 普通合伙与有限合伙的区分 | 单选题、多选题 | 责任形式、人数限制 |

## 二、典型例题解析

### 2.1 合伙类型与责任形式（单选题）

**题目：** 关于普通合伙企业和有限合伙企业的说法中，正确的是（ ）。

A. 普通合伙企业的合伙人均承担有限责任
B. 有限合伙企业中至少有1个普通合伙人
C. 有限合伙企业的合伙人均承担有限责任
D. 普通合伙企业的人数不得超过50人

**解析：**
- A错误：普通合伙企业的全体合伙人均承担无限连带责任（Unlimited Joint and Several Liability）。
- B正确：有限合伙企业由普通合伙人（General Partner, GP）和有限合伙人（Limited Partner, LP）组成，其中至少有1个普通合伙人和1个有限合伙人。
- C错误：有限合伙企业中的普通合伙人承担无限连带责任，有限合伙人以其认缴的出资额为限承担责任。
- D错误：普通合伙企业无人数上限（≥2人即可），有限合伙企业为2-50人。

**答案：** B

### 2.2 入伙与退伙的责任（单选题）

**题目：** 张某、李某、王某三人共同设立一家普通合伙企业。经营一年后，新合伙人赵某入伙。同日，合伙人王某退伙。对于王某退伙前和赵某入伙前合伙企业所负的债务，下列说法正确的是（ ）。

A. 赵某对入伙前债务不承担责任
B. 赵某对入伙前债务承担无限连带责任
C. 王某对退伙前债务不再承担责任
D. 王某对退伙后产生的债务承担责任

**解析：**
- A错误：新合伙人对入伙前合伙企业的债务承担无限连带责任，这是法律强制性规定。
- B正确：新合伙人入伙后，对入伙前合伙企业的债务承担无限连带责任。
- C错误：退伙人对退伙前合伙企业的债务仍承担无限连带责任。
- D错误：退伙人对退伙后合伙企业产生的债务不承担责任。

**答案：** B

### 2.3 特殊普通合伙企业的责任（单选题）

**题目：** 甲、乙、丙三家会计师事务所共同设立一家特殊的普通合伙企业。在执业过程中，合伙人甲因故意出具虚假审计报告造成客户损失100万元。关于该笔债务的承担，下列说法正确的是（ ）。

A. 甲、乙、丙三人均承担无限连带责任
B. 甲承担无限责任，乙、丙以其在合伙企业中的财产份额为限承担有限责任
C. 甲、乙、丙按出资比例分担
D. 合伙企业不承担责任，由甲个人赔偿

**解析：** 特殊的普通合伙企业（Special General Partnership）中，一个合伙人在执业活动中因故意或者重大过失造成合伙企业债务的，应当承担无限责任或者无限连带责任，其他合伙人以其在合伙企业中的财产份额为限承担有限责任。本题中甲因"故意"出具虚假审计报告，属于故意行为造成的债务，甲应承担无限责任，乙、丙以其财产份额为限承担有限责任。

**答案：** B

### 2.4 有限合伙人的特殊规则（多选题）

**题目：** 根据合伙企业法律制度的规定，关于有限合伙人的权利，下列说法正确的有（ ）。

A. 有限合伙人可以自营与本合伙企业相竞争的业务（合伙协议另有约定除外）
B. 有限合伙人可以与本合伙企业进行交易（合伙协议另有约定除外）
C. 有限合伙人可以将其在合伙企业中的财产份额出质（合伙协议另有约定除外）
D. 有限合伙人可以执行合伙事务

**解析：**
- A正确：有限合伙人可以自营或者同他人合作经营与本有限合伙企业相竞争的业务，但合伙协议另有约定的除外。注意与普通合伙人的区别：普通合伙人绝对禁止同业竞争。
- B正确：有限合伙人可以与本有限合伙企业进行交易，但合伙协议另有约定的除外。
- C正确：有限合伙人可以将其在有限合伙企业中的财产份额出质，但合伙协议另有约定的除外。
- D错误：有限合伙人不执行合伙事务，不得对外代表有限合伙企业。这是有限合伙人的核心限制。

**答案：** ABC

### 2.5 合伙企业财产份额转让（案例分析题）

**题目：** 甲、乙、丙三人共同出资设立一家普通合伙企业，从事餐饮经营。经营两年后，合伙人甲拟将其在合伙企业中的财产份额转让给丁。合伙人乙同意，合伙人丙不同意。

请分析：
1. 甲能否将其财产份额转让给丁？为什么？
2. 如果丙同意转让，丁能否成为新的合伙人？需要什么条件？
3. 如果甲拟将其财产份额转让给乙，需要经过谁的同意？

**解析：**

1. 甲不能将其财产份额转让给丁。根据《合伙企业法》规定，合伙人向合伙人以外的人转让其在合伙企业中的全部或者部分财产份额时，须经其他合伙人一致同意（合伙协议另有约定除外）。本题中，丙不同意转让，未达到"一致同意"的要求。

2. 如果丙同意转让（即全体合伙人一致同意），丁可以成为新的合伙人。丁需要满足：完全民事行为能力人、书面签署合伙协议。同时，丁作为新合伙人，对入伙前合伙企业的债务承担无限连带责任。

3. 甲将其财产份额转让给乙（合伙人内部转让），仅需通知其他合伙人（丙），无需丙的同意。但丙在同等条件下不享有优先购买权（内部转让不触发优先购买权规则）。

**答案：** 见上述解析。

## 三、法条要点速记

### 3.1 合伙企业对比

| 要点 | 普通合伙企业 | 有限合伙企业 |
|------|-------------|-------------|
| 合伙人人数 | ≥2人 | 2-50人 |
| 合伙人类型 | 均为普通合伙人 | GP≥1+LP≥1 |
| 责任形式 | 无限连带责任 | GP无限连带+LP有限责任 |
| 事务执行 | 全体合伙人 | 普通合伙人执行 |
| 同业竞争 | 禁止 | LP可以（协议另有约定除外） |
| 劳务出资 | 允许 | LP不得以劳务出资 |

### 3.2 入伙退伙责任

| 情形 | 责任承担 |
|------|----------|
| 新合伙人入伙 | 对入伙前债务承担无限连带责任 |
| 退伙人 | 对退伙前债务承担无限连带责任 |
| 退伙人 | 对退伙后债务不承担责任 |

### 3.3 清偿顺序

```
清算费用 → 职工工资社保 → 税款 → 债务 → 剩余财产分配
```

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|-------|------|---------|
| 普通合伙 vs 有限合伙 | 普通合伙全无限；有限合伙GP无限+LP有限 | GP=管事担大责，LP=出钱担小责 |
| 入伙责任 vs 退伙责任 | 入伙对之前负责；退伙对之前负责 | 入退都对"之前"负责 |
| 特殊普通合伙 vs 普通合伙 | 特殊：故意/重大过失个人担责 | 特殊=专业+过失隔离 |
| 份额对外转让 vs 内部转让 | 对外一致同意；内部仅通知 | 外人难进，内部自由 |
| 普通合伙人同业 vs 有限合伙人同业 | 普通合伙人禁止；有限合伙人可以（约定除外） | LP更自由 |

## 五、速记口诀

**合伙企业类型口诀：**
"普通全无限，有限GP无限LP有限，特殊普通过失隔离"

**入伙退伙责任口诀：**
"入伙对前负责，退伙也对前负责，退后不负责"

**有限合伙人规则口诀：**
"不执行、可同业、可交易、可出质（均可协议排除）"
