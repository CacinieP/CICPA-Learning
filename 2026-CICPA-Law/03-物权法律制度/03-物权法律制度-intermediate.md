# 物权法律制度 —— 典型考题解析

## 一、核心考法分类

本章在历年真题中的主要考法归纳：

| 考法类型 | 常见题型 | 考查特点 |
|---------|---------|---------|
| 物权变动规则 | 单选题、多选题 | 不动产登记生效，动产交付生效 |
| 善意取得构成 | 单选题、多选题 | 五要件缺一不可 |
| 担保物权类型 | 单选题 | 抵押/质押/留置的区别 |
| 善意取得与物权变动 | 案例题 | 结合具体情形判断 |
| 物权法定原则 | 单选题 | 不能创设新物权类型 |

## 二、典型例题解析

### 2.1 物权变动规则（单选题）

**题目：** 甲将自有的房屋出售给乙，双方签订了买卖合同，但尚未办理过户登记。下列说法正确的是（ ）。

A. 房屋所有权已经转移给乙
B. 房屋所有权仍归甲所有
C. 乙可以主张对该房屋的所有权
D. 该买卖合同无效

**解析：** 根据《民法典》规定，不动产物权的设立、变更、转让和消灭，经依法登记，发生效力；未经登记，不发生效力。甲乙之间的买卖合同有效，但因未办理过户登记，房屋所有权不发生转移，仍归甲所有。乙取得的是合同上的债权请求权，而非所有权。

**答案：** B

### 2.2 善意取得构成（单选题）

**题目：** 甲将借来的手表以合理价格卖给不知情的乙，乙当场付款并取得手表。甲的手表原主人（所有权人）可以（ ）。

A. 要求乙返还手表
B. 要求甲赔偿损失
C. 要求乙支付合理对价
D. 确认乙取得手表所有权

**解析：** 善意取得的构成要件包括：（1）出让人无处分权；（2）受让人善意；（3）以合理价格有偿受让；（4）已完成法定公示（交付）。本题中，甲借来的手表是无权处分，但乙符合善意取得的要件：善意（不知甲无处分权）、合理价格（有偿）、已交付。乙可以依据善意取得制度取得手表所有权。手表原主人只能向无权处分人甲请求损害赔偿，不能要求乙返还。

**答案：** B

### 2.3 动产抵押与登记（单选题）

**题目：** 甲公司以自己的一批生产设备向银行设定抵押，双方签订抵押合同。下列说法正确的是（ ）。

A. 抵押权自抵押合同生效时设立
B. 抵押权自登记时设立
C. 该抵押权可以对抗善意第三人
D. 该抵押权不得对抗正常经营活动中已支付合理价款的买受人

**解析：** 根据《民法典》规定，以动产设定抵押的，抵押权自抵押合同生效时设立；未经登记的，不得对抗善意第三人。因此，A正确。动产抵押不以登记为设立要件，B错误。未登记的动产抵押权不能对抗善意第三人，C错误。根据《民法典》关于正常经营买受人的保护规则，即使抵押权已登记，出卖人（抵押人）出卖抵押财产属于正常经营活动，且买受人已支付合理价款并取得抵押财产的，抵押权人对该财产不具有追及效力，D正确。但D表述的是对抗效力问题，与题目问法"正确的是"相符。

**答案：** A

### 2.4 质权设立（单选题）

**题目：** 甲向乙借款50万元，以自己持有的一张100万元的银行存单设定质押。下列关于质权设立的说法正确的是（ ）。

A. 质权自抵押合同生效时设立
B. 质权自乙实际控制存单时设立
C. 质权自登记时设立
D. 质权自甲交付存单时设立

**解析：** 根据《民法典》规定，以汇票、支票、本票、存款单、仓单、提单出质的，质权自权利凭证交付质权人时设立；没有权利凭证的，质权自办理出质登记时设立。存单是权利凭证，质权自交付存单时设立。

**答案：** D

### 2.5 留置权成立条件（单选题）

**题目：** 甲将汽车送到乙修理厂修理，约定修理费1万元。甲取车时拒绝支付修理费，乙可以行使留置权。下列说法正确的是（ ）。

A. 乙只能留置该汽车
B. 乙留置汽车后，甲超过60日仍不支付修理费，乙可以就该汽车优先受偿
C. 如果该汽车价值明显低于修理费，乙不能留置
D. 企业之间的留置不受"同一法律关系"限制

**解析：** 留置权是法定担保物权。留置权成立的条件包括：（1）债权人合法占有债务人的动产；（2）债务人不履行到期债务；（3）留置的动产与债权属于同一法律关系（企业之间留置的除外）。A错误，乙可以依法留置该汽车，但并非"只能"留置汽车。B正确，留置后应给债务人60日以上的履行期限，逾期不履行的可以优先受偿。C错误，留置权不要求留置财产的价值必须高于债权。D正确，企业之间的留置不要求属于同一法律关系。

**答案：** BD

### 2.6 善意取得适用范围（多选题）

**题目：** 下列情形中，可以适用善意取得的是（ ）。

A. 张某将他人委托保管的名贵手表卖给他人
B. 李某将租来的汽车卖给他人
C. 王某将捡到的钱包据为己有并卖给他人
D. 赵某将自己的房屋卖给多人

**解析：** 善意取得适用于无权处分的情形。A：张某受委托保管手表，属于无权处分，可以适用善意取得（但须符合善意取得其他要件）。B：李某租用汽车，属于无权处分，可以适用善意取得。C：捡到钱包并卖出，属于无权处分，可以适用善意取得（遗失物、盗赃物有特殊规则：权利人可在2年内请求返还原物，但不能因此否定善意取得的适用，只是在2年内可以要求返还）。D：将自己的房屋卖给多人，可能涉及"一房二卖"，但如果已经办理过户登记，则不涉及善意取得问题；如果未登记，则需要看具体情况。无论如何，这不属于"善意取得"的典型问题，而是合同履行问题。

**答案：** ABC

## 三、法条要点速记

### 3.1 物权变动规则

| 类型 | 公示方式 | 效力 |
|-----|---------|------|
| 不动产物权 | 登记 | 登记生效主义 |
| 动产物权 | 交付 | 交付生效主义 |
| 船舶、航空器、机动车 | 交付 | 登记为对抗要件 |

### 3.2 交付方式

| 方式 | 说明 | 何时生效 |
|-----|------|---------|
| 现实交付 | 直接交付标的物 | 交付时 |
| 简易交付 | 受让人已占有动产 | 法律行为生效时 |
| 指示交付 | 让与返还原物请求权 | 通知占有人时 |
| 占有改定 | 出让人继续占有 | 约定生效时 |

### 3.3 担保物权比较

| 类型 | 设立要件 | 是否转移占有 | 优先顺序 |
|-----|---------|-------------|---------|
| 抵押权（不动产） | 登记 | 否 | 第1位 |
| 抵押权（动产） | 合同生效 | 否 | 第2位（登记优先） |
| 质权 | 交付 | 是 | 第2位 |
| 留置权 | 法定 | 是 | 第1位 |

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|-------|------|---------|
| 善意取得 vs 普通买卖 | 善意取得是无权处分+善意第三人保护 | "善意取得多一要件：无权处分" |
| 抵押 vs 质押 | 抵押不转移占有，质押转移占有 | "押"不转移，"质"要转移 |
| 动产抵押 vs 不动产抵押 | 动产登记对抗，不动产登记生效 | "动产登记为对抗，不动产登记是生效" |
| 善意取得 vs 遗失物 | 遗失物2年内可请求返还（盗赃物同） | "遗失物有追及，善意取得无追及" |
| 最高额抵押 vs 一般抵押 | 最高额抵押债权不确定 | "最高额：债权不确定" |
