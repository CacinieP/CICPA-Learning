# 反垄断法律制度 —— 第一性原理教程

## 一、概述

**反垄断法**是为了预防和制止垄断行为，保护市场公平竞争，提高经济运行效率，维护消费者利益和社会公共利益。

**执法机构：** 国家市场监督管理总局（反垄断局）。

---

## 二、垄断协议规制制度

### 2.1 横向垄断协议（竞争者之间）

**禁止的协议：**
- 固定或变更商品价格
- 限制产量或销量
- 分割销售市场或原材料采购市场
- 限制购买新技术/新设备/限制开发新技术/新产品
- 联合抵制交易

### 2.2 纵向垄断协议（上下游之间）

**禁止的协议：**
- 固定向第三人转售商品的价格
- 限定向第三人转售商品的最低价格

### 2.3 豁免情形

| 豁免条件 | 说明 |
|----------|------|
| 改进技术/研究开发 | 促进技术进步 |
| 提高质量/降低成本 | 提高效率 |
| 统一规格标准 | 实现专业化协作 |
| 提高中小企业竞争力 | 增强竞争 |
| 公共利益 | 节能环保等 |

**举证要求：** 经营者应证明协议不会严重限制竞争+消费者能分享利益。

---

## 三、滥用市场支配地位规制制度

### 3.1 市场支配地位的认定

**考虑因素：**
- 市场份额
- 控制销售/原材料市场的能力
- 财力和技术条件
- 交易相对人的依赖程度
- 进入市场的难易程度

**推定：** 一个经营者市场份额≥1/2，或两个≥2/3，或三个≥3/4。

### 3.2 禁止的行为

| 行为 | 说明 |
|------|------|
| 不公平定价 | 高价销售或低价购买 |
| 低于成本销售 | 没有正当理由 |
| 拒绝交易 | 没有正当理由 |
| 限定交易 | 没有正当理由 |
| 搭售 | 没有正当理由 |
| 差别待遇 | 没有正当理由 |

---

## 四、经营者集中反垄断审查制度

### 4.1 申报标准

达到下列标准之一的应事先申报：
- 参与集中的经营者全球营业额合计>100亿元人民币+中国境内营业额>4亿元
- 参与集中的经营者中国境内营业额合计>20亿元+其中至少两个经营者各>4亿元

### 4.2 审查程序

```
初步审查（30日）→ 进一步审查（90日，可延长60日）
```

### 4.3 审查结果

| 决定 | 说明 |
|------|------|
| 不予禁止 | 不具有排除限制竞争效果 |
| 附条件不予禁止 | 具有效果但可通过条件消除 |
| 禁止 | 具有排除限制竞争效果且无法消除 |

---

## 五、滥用行政权力排除、限制竞争规制制度

**禁止的行为：**
- 限定经营购买使用指定商品
- 设置不合理准入条件
- 强制经营者从事垄断行为
- 制定含有排除限制竞争内容的规定

---

## 考试要点

1. **横向垄断协议**：价格/产量/市场分割
2. **纵向垄断协议**：固定转售价格
3. **滥用支配地位**：6种行为（无正当理由）
4. **经营者集中**：达到标准需申报
5. **行政垄断**：政府不得限制竞争
