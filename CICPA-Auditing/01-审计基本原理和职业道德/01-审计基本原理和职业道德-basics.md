# 审计基本原理和职业道德 —— 从第一性原理出发

> 本文件从最基本的概念出发，系统构建审计基本原理和职业道德的知识体系，覆盖 2026 年 CICPA 审计科目考试大纲第一部分全部考点。

---

## 第一章 审计概述

### 1.1 审计的概念与保证程度

**什么是审计？**

审计是一种**保证服务**(assurance service)。注册会计师通过系统化的过程，对财务报表是否在所有重大方面按照适用的财务报告编制基础编制发表审计意见，从而提高财务报表的可信赖程度。

**核心逻辑链条：**
- 财务报表由管理层编制 → 管理层可能有动机粉饰报表 → 报表使用者无法亲自验证 → 需要独立的第三方来审查 → 注册会计师执行审计并出具报告

**保证程度的分类：**

| 类型 | 保证水平 | 表达方式 | 典型业务 |
|------|---------|---------|---------|
| 合理保证（审计） | 高水平 | 积极方式（"我们认为...在所有重大方面公允反映"） | 财务报表审计 |
| 有限保证（审阅） | 中等水平 | 消极方式（"我们没有注意到...未能在所有重大方面公允反映"） | 财务报表审阅 |
| 无保证 | 无 | 不提供保证结论 | 商定程序、代编财务信息 |

**考试要点：** 合理保证不等于绝对保证。审计存在固有局限性：选择性测试、内部控制的固有局限、管理层可能串通舞弊等。

### 1.2 审计要素（五要素）

审计包含五个核心要素：

1. **三方关系人**
   - **注册会计师**（审计者）：执行审计工作、出具审计报告
   - **管理层**（责任方）：编制财务报表，并按法规要求保持内部控制
   - **预期使用者**（利益相关方）：股东、债权人、监管机构等

2. **财务报表**：审计的对象（通常是整套通用目的财务报表）

3. **编制基础**（标准）：财务报表按照什么准则编制（如中国企业会计准则、IFRS等）

4. **审计证据**：注册会计师为了得出审计结论所使用的信息

5. **审计报告**：审计的最终产品，传递审计意见

**关键理解：** 审计关系中的"三方"是理解审计独立性的基础——注册会计师独立于管理层，服务于预期使用者。

### 1.3 审计目标

#### 总体目标（两个）
1. 对财务报表整体是否不存在由于舞弊或错误导致的重大错报获取**合理保证**，使注册会计师能够对财务报表是否在所有重大方面按照适用的财务报告编制基础编制发表审计意见
2. 按照审计准则的规定，根据审计结果对财务报表出具审计报告，并与管理层和治理层沟通

#### 认定与具体审计目标

**认定**(assertion)是指管理层在财务报表中作出的明确或隐含的表达。注册会计师将管理层认定转化为具体审计目标。

**各类交易和事项的认定：**
| 认定类别 | 含义 | 具体审计目标 |
|---------|------|------------|
| 发生 | 记录的交易确实发生了 | 确认交易真实存在，非虚构 |
| 完整性 | 所有应记录的交易都已记录 | 确认无遗漏 |
| 准确性 | 金额及其他数据已恰当记录 | 确认金额正确 |
| 截止 | 交易记入正确的会计期间 | 确认归属期间正确 |
| 分类 | 交易已记入正确的账户 | 确认分类无误 |

**期末账户余额的认定：**
| 认定类别 | 含义 |
|---------|------|
| 存在 | 记录的资产/负债在资产负债表日确实存在 |
| 权利和义务 | 资产属于被审计单位，负债是被审计单位的义务 |
| 完整性 | 所有应记录的余额都已记录 |
| 计价和分摊 | 资产负债以恰当金额反映 |

**列报和披露的认定：** 发生及权利和义务、完整性、分类和可理解性、准确性和计价

**实务举例：**
- "发生"认定关注的是"多计"风险（虚构销售）
- "完整性"认定关注的是"少计"风险（隐瞒负债）
- 这两个认定是**方向相反**的关系

### 1.4 审计基本要求

执行审计工作应遵守以下基本要求：

1. **遵守审计准则**：按照中国注册会计师审计准则执行审计工作
2. **遵守职业道德守则**：恪守独立、客观、公正等原则
3. **保持职业怀疑**：对引起疑虑的情形保持警觉，对获取的审计证据进行批判性评价
4. **合理运用职业判断**：在获取充分、适当的审计证据基础上作出判断

**职业怀疑的核心要义：**
- 不假定管理层是诚实可信的，也不假定其不诚信
- 对引起疑虑的情形保持警觉（如相互矛盾的审计证据、涉嫌舞弊等）
- 不满足于说服力不足的审计证据

### 1.5 审计风险

**审计风险模型：**
```
审计风险 = 重大错报风险 × 检查风险
```

**重大错报风险**(RMM)——注册会计师**无法控制**：
- **财务报表层次**：与财务报表整体广泛相关，影响多项认定（如管理层诚信问题、经营环境恶化）
- **认定层次**：与特定的交易、账户余额或披露相关

**认定层次重大错报风险的进一步分类：**
- **固有风险**(IR)：在不考虑内部控制的情况下，某类认定易于发生重大错报的可能性
- **控制风险**(CR)：某类认定发生重大错报，没有被内部控制及时防止或发现纠正的可能性

```
重大错报风险 = 固有风险 × 控制风险
```

**检查风险**(DR)——注册会计师**可以控制**：
- 通过适当设计审计程序的性质、时间安排和范围来控制
- 检查风险与审计程序的有效性成**反向**关系

**关键关系：**
- 重大错报风险越高 → 可接受的检查风险越低 → 需要实施更多的审计程序
- 重大错报风险越低 → 可接受的检查风险越高 → 可以减少审计程序

### 1.6 审计过程

审计过程通常包括以下阶段：

1. **接受业务委托** → 评价客户、签订业务约定书
2. **计划审计工作** → 制定总体策略和具体计划
3. **识别和评估重大错报风险** → 风险评估程序
4. **应对重大错报风险** → 进一步审计程序
5. **完成审计工作并出具审计报告** → 汇总结果、形成意见

### 1.7 注册会计师审计的执业责任

- **财务报表审计责任 VS 财务报表编制责任**：两者不能混淆
- 管理层负责编制财务报表和设计、执行、维护必要的内部控制
- 注册会计师负责对财务报表发表审计意见
- 注册会计师的审计不能替代管理层对财务报表编制的责任
- 审计意见不是对未来经营能力的保证，也不是对管理层经营效率效果的保证

## 第二章 职业道德基本原则和解决思路

### 2.1 职业道德基本原则（六项）

#### (1) 诚信(Integrity)
- 在所有职业活动和商业关系中保持正直、诚实
- **禁止**：与虚假报告有关、提供含有虚假或误导性信息的报告

#### (2) 客观公正(Objectivity)
- 不让偏见、利益冲突或他人影响职业判断
- 适用于所有专业人士，不限于审计项目合伙人和团队成员

#### (3) 独立性(Independence)
- 分为**实质上的独立性**（精神状态）和**形式上的独立性**（外在表现）
- 独立性是对审计业务的特殊要求
- 在执行鉴证业务时，注册会计师必须独立于鉴证客户

#### (4) 专业胜任能力和应有的关注(Due Care)
- 保持专业胜任能力：通过教育、培训获得，并持续保持
- 应有的关注：勤勉尽责，遵守准则要求
- **不提供无法胜任的服务**

#### (5) 保密(Confidentiality)
- 未经适当授权不得泄露因职业关系获取的涉密信息
- 即使在社交场合也应注意不无意泄露涉密信息
- **允许披露的情形**：法律法规要求、职业权利或义务要求、已取得授权

#### (6) 良好职业行为(Professional Behavior)
- 遵守相关法律法规，避免损害职业声誉的行为
- 不得夸大宣传、贬低同行

### 2.2 职业道德概念框架

**概念框架**是解决职业道德问题的系统化方法，其核心思路：

```
识别对职业道德基本原则的不利影响 → 评价不利影响的严重程度 → 应对不利影响
```

**不利影响的分类（不利影响的来源）：**

1. **自身利益**：注册会计师或其近亲属在经济利益上与客户有关联
   - 例：持有客户股票、收费过度依赖某一客户
2. **自我评价**：注册会计师评价自己以前的工作或由他人代为完成的工作
   - 例：为客户设计内部控制后又审计该内控
3. **过度推介**：注册会计师过度推介客户的某种立场或意见
   - 例：担任客户法律顾问的同时提供审计服务
4. **密切关系**：注册会计师与客户存在亲密关系
   - 例：审计项目组成员的配偶在客户处担任财务总监
5. **外在压力**：注册会计师受到来自外部的实际压力或感知压力
   - 例：客户以解聘相威胁要求出具无保留意见

**应对措施：**
- 在会计师事务所层面：制定政策和程序（如合伙人轮换制度）
- 在项目层面：增加项目组成员、由独立合伙人复核、与治理层沟通

### 2.3 注册会计师和非执业会员的具体运用

- 注册会计师应对各种情形下的不利影响进行识别、评价和应对
- 非执业会员（如在企业工作的CIMA/ACCA会员）同样需要遵守职业道德基本原则
- 非执业会员面临的不利影响场景与执业会员有所不同，但概念框架的应用方法一致

## 第三章 审计业务的独立性要求

### 3.1 基本概念和要求

**独立性包括两个层面：**
- **实质上的独立性**：注册会计师在提出结论时不受损害职业判断的因素影响
- **形式上的独立性**：一个理性且掌握充分信息的第三方会认为会计师事务所或项目组成员保持了独立性

**网络事务所**(Network Firm)：属于同一网络的各事务所应视为单一事务所处理独立性事项。判断标准包括：共享收益/风险、共同质量控制、共同品牌等。

**公众利益实体**(PIE)：包括上市公司、法律法规界定的实体等。对公众利益实体的独立性要求**更严格**。

**关联实体**：与审计客户同受一方控制的实体，均应纳入独立性考量范围。

**关键审计合伙人**：包括项目合伙人、项目质量复核人员、在审计报告中签字的注册会计师等。关键审计合伙人的任职期限、冷却期等有严格规定。

### 3.2 收费

**审计收费水平：**
- 收费水平本身不产生不利影响，但收费过低可能导致注册会计师缩减必要审计程序
- 应评价低收费是否对专业胜任能力和应有的关注产生不利影响

**或有收费：**
- 审计业务**禁止**或有收费（如"审计通过才付费"）
- 非鉴证服务在某些情况下允许或有收费，但需评价不利影响

**逾期收费：**
- 长期未收回的审计费用视同向客户贷款，可能产生自身利益不利影响
- 通常要求在出具审计报告前收回上期的审计费用

** комиссион (佣金)：** 收取佣金或介绍费会损害客观公正和良好职业行为。

### 3.3 经济利益

**核心原则：** 在审计客户中拥有直接经济利益或重大间接经济利益会产生自身利益不利影响。

**经济利益的主要情形及应对：**

| 持有人 | 直接经济利益 | 间接经济利益 |
|-------|-----------|-----------|
| 项目组成员及其近亲属 | 不得拥有 | 重大间接经济利益应处置或退出项目 |
| 事务所及其网络 | 不得拥有 | 不得拥有重大经济利益 |
| 项目合伙人及其近亲属 | 不得拥有 | 不得拥有 |
| 其他合伙人的近亲属（非项目成员） | 应评价影响 | 应评价影响 |

**特殊情况：**
- 通过退休金计划、投资基金等持有间接经济利益——如果不重大且无重大影响，可能可以接受
- 继承或受赠获得经济利益——应在合理期限内处置

### 3.4 贷款、担保、商业关系、家庭和私人关系

**贷款和担保：**
- 从属于银行等金融机构的审计客户取得贷款：按正常程序、正常条件可以接受
- 从非银行客户取得贷款或为其提供担保：**禁止**
- 向审计客户或其高管提供贷款或担保：**禁止**

**商业关系：**
- 与审计客户或其高管存在密切商业关系（如共同经营、联合推广）：通常**禁止**
- 仅为正常商业往来（按一般商业条件）：可以接受

**家庭和私人关系：**
- 项目组成员的配偶/伴侣/子女在客户处担任高管：应调离项目组
- 项目组成员的近亲属在客户处负责对审计有重大影响的岗位：应评价不利影响
- 项目组外部人员与客户存在私人关系：应评价是否影响独立性

### 3.5 与审计客户之间的人员交流

**审计客户雇佣前任审计人员：**
- 关键审计合伙人加入审计客户担任高管：冷却期后（通常12个月）才能接受
- 前项目组成员加入客户后仍在审计中与其联系：产生不利影响

**临时借调人员：**
- 向审计客户临时借调人员：可能产生自我评价不利影响
- 应确保借调人员不参与审计，且不承担管理层职责

**兼任或接任高管：**
- 事务所合伙人或员工同时兼任审计客户的高管或董事：**禁止**
- 近期曾任审计客户高管或董事的人员加入项目组：应考虑冷却期

### 3.6 长期业务关系

**关键审计合伙人轮换制度：**

| 实体类型 | 关键审计合伙人任职期限 | 冷却期 |
|---------|-------------------|-------|
| 一般审计客户 | 不超过5年 | 2年冷却期 |
| 公众利益实体 | 不超过5年 | 5年冷却期 |

- 长期关系可能导致密切关系和自身利益不利影响
- 对于公众利益实体，还要求定期更换项目质量复核人员

### 3.7 为审计客户提供非鉴证服务

**总原则：** 不得承担审计客户的管理层职责，否则将产生自我评价不利影响。

**主要非鉴证服务类型及独立性影响：**

| 服务类型 | 独立性影响 | 基本要求 |
|---------|----------|---------|
| 会计和记账服务 | 重大不利影响 | 公众利益实体的审计客户**禁止**提供 |
| 行政事务 | 可能可接受 | 属于日常琐碎事务，不涉及管理层决策 |
| 评估/估值服务 | 自我评价不利影响 | 如评估结果对财务报表重大，**禁止** |
| 税务服务 | 需评价 | 计算税额通常可接受，但税收筹划应关注 |
| 内部审计服务 | 自我评价不利影响 | 公众利益实体**禁止**；其他客户需确保不承担管理层职责 |
| IT系统服务 | 可能产生不利影响 | 不得参与设计、执行或维护与财务报告相关的系统 |
| 诉讼支持服务 | 需评价 | 如涉及法律问题的鉴证服务应特别关注 |
| 招聘高管 | 可能不利 | 为审计客户招聘高管或董事：通常**禁止** |

### 3.8 违反独立性要求的应对措施

当发现违反独立性要求的情况时：

1. **立即报告**：向项目合伙人、事务所质量管理负责人报告
2. **评价影响**：评估违反行为对审计意见和事务所声誉的影响
3. **采取补救措施**：调整项目组成员、增加复核程序等
4. **书面记录**：记录违反情况、评估结果和采取的措施
5. **沟通治理层**：必要时向治理层通报

## 第四章 审计证据

### 4.1 审计证据的性质

**审计证据的充分性与适当性：**

- **充分性**(Sufficiency)——**数量**维度：审计证据的数量是否足以支持审计结论
- **适当性**(Appropriateness)——**质量**维度：包括**相关性**和**可靠性**

```
审计证据的适当性 = 相关性 × 可靠性
```

**影响审计证据充分性的因素：**
- 重大错报风险越高 → 需要的审计证据越多
- 审计证据质量越高 → 需要的审计证据越少（但不能以质量替代数量）

**审计证据可靠性的判断原则：**

| 可靠性较高 | 可靠性较低 |
|----------|----------|
| 外部证据（从第三方直接获取） | 内部证据 |
| 书面/纸质证据 | 口头证据 |
| 审计人员直接获取的证据 | 被审计单位提供的证据 |
| 原件 | 复印件/传真件 |
| 内部控制有效时生成的内部证据 | 内部控制薄弱时生成的内部证据 |

**考试重点：** 充分性和适当性之间既相互关联又有区别——审计证据质量存在缺陷，仅靠增加数量无法弥补。

### 4.2 审计程序

**按获取审计证据的目的分类：**

1. **风险评估程序**：了解被审计单位及其环境，识别和评估重大错报风险（必须执行）
2. **控制测试**：测试内部控制运行的有效性（选择执行）
3. **实质性程序**：发现认定层次的重大错报（必须执行）

**按审计程序的性质分类（七种类型）：**

| 程序类型 | 说明 | 适用场景 |
|---------|------|---------|
| 检查（记录/文件） | 审查凭证、账簿、合同等 | 各类交易和余额 |
| 检查（有形资产） | 实地查看有形资产 | 存货、固定资产 |
| 观察 | 察看过程或程序的实施 | 内控执行情况 |
| 询问 | 以书面或口头方式向被审计单位内外部人员获取信息 | 所有场景（通常与其他程序结合使用） |
| 函证 | 从第三方获取书面确认 | 银行存款、应收账款等 |
| 重新计算 | 对记录进行验算 | 折旧、利息等计算 |
| 重新执行 | 独立执行被审计单位的程序或控制 | 控制测试 |
| 分析程序 | 通过分析数据关系进行评价 | 风险评估、总体复核 |

**实务要点：** 询问本身不足以提供充分、适当的审计证据，必须辅以其他程序。

### 4.3 函证

**函证的定义：** 注册会计师直接从第三方（被询证者）获取书面答复作为审计证据的过程。

**函证的决策：**
- **应当函证的项目**：银行存款、借款及与金融机构往来的其他信息
- **可以函证的项目**：应收账款、应付账款等
- 是否函证考虑因素：认定层次重大错报风险评估水平、替代程序能否提供充分适当证据

**函证的类型：**
| 类型 | 特点 | 适用场景 |
|------|------|---------|
| 积极式函证 | 要求被询证者在任何情况下都回函 | 应收账款金额大、争议多 |
| 消极式函证 | 仅要求不同意时回函 | 重大错报风险评估为低水平、余额小的债务人数量多 |

**函证过程的控制（核心考点）：**
- 注册会计师应当**全程控制**函证过程
- **发函**：注册会计师直接发出，不得经客户转交
- **收函**：回函应直接寄至会计师事务所
- **跟催**：对未回函的积极式函证应实施跟催
- **电子函证**：应验证发件人身份，确认安全性

**未回函的处理：**
- 对积极式函证未回函 → 应实施**替代程序**（如检查期后收款、销售合同、发运凭证等）
- 对消极式函证未回函 → 不必实施替代程序

### 4.4 分析程序

**分析程序的定义：** 通过分析财务数据之间、财务数据与非财务数据之间的关系来评价财务信息。

**分析程序的三个应用阶段：**

| 阶段 | 目的 | 要求 |
|------|------|------|
| 风险评估 | 识别异常或意外变动 | **强制执行** |
| 实质性程序 | 获取认定层次的审计证据 | **选择执行**（适合大量小额交易、可预测性强的数据） |
| 总体复核 | 最终综合评价财务报表 | **强制执行** |

**分析程序的方法：**
- **比较法**：本期与上期比较、本期与预算/预测比较、同行业比较
- **比率法**：毛利率、存货周转率等
- **趋势分析法**：多期数据的趋势分析

**分析程序作为实质性程序的前提：**
- 数据之间具有**可预期的关系**
- 数据具有**足够的准确性**
- 预期结果的**偏差幅度**足够小

**数据分析的深度：** 分析程序发现异常差异时，应调查原因并考虑是否表明存在重大错报风险。

## 第五章 审计抽样方法

### 5.1 审计抽样的相关概念

**什么是审计抽样？**
审计抽样是指注册会计师对具有审计相关性的总体中低于百分之百的项目实施审计程序，使所有抽样单元都有被选取的机会，从而使注册会计师能够获取和评价有关所选项目某些特征的审计证据，并在一定程度上根据样本结果对总体特征得出结论。

**为什么需要抽样？**
- 审计资源有限，不可能检查100%的交易
- 在合理保证的框架下，抽样可以在成本和效果之间取得平衡

**抽样风险与非抽样风险：**

| 风险类型 | 含义 | 影响 |
|---------|------|------|
| 抽样风险 | 因样本不能代表总体特征导致得出错误结论 | 通过**扩大样本量**降低 |
| 非抽样风险 | 因抽样以外的因素（如程序设计不当、执行偏差）导致得出错误结论 | 通过**改进审计程序设计和执行**降低 |

**抽样风险的分类：**

| | 影响审计效果（错误接受审计风险） | 影响审计效率（错误拒绝审计风险） |
|---|---|---|
| 控制测试 | 信赖过度风险（过度信赖内控） | 信赖不足风险（未能发现有效内控） |
| 细节测试 | 误受风险（未能发现重大错报） | 误拒风险（错误认定存在重大错报） |

- 影响审计效果的风险（信赖过度、误受）→ 更为严重 → 注册会计师更应关注
- 影响审计效率的风险（信赖不足、误拒）→ 仅影响效率

**统计抽样 VS 非统计抽样：**
- 统计抽样：运用概率论和数理统计，能量化抽样风险
- 非统计抽样：依靠注册会计师的职业判断
- 两种方法都要求注册会计师运用职业判断进行设计和评价

### 5.2 审计抽样在控制测试中的应用

**适用场景：** 当控制留下书面轨迹（如签字、盖章、审批记录）时，可以使用审计抽样来测试内部控制运行的有效性。

**基本步骤：**

#### 步骤一：确定测试目标
- 测试某项控制在整个测试期间内是否有效运行

#### 步骤二：定义总体和抽样单元
- **总体**：构成被测试控制的所有项目（如所有经审批的采购订单）
- **抽样单元**：总体中的单个项目
- 总体应具备**完整性**

#### 步骤三：定义偏差
- 明确什么情况构成控制偏差（如缺少审批签字、审批金额超出权限）

#### 步骤四：确定样本量
影响因素：
- 可接受的信赖过度风险：越低 → 样本量越大
- 可容忍偏差率：越低 → 样本量越大
- 预计总体偏差率：越高 → 样本量越大
- 总体规模：大规模总体对样本量的影响较小

#### 步骤五：选取样本
- 随机数表选样
- 系统选样（等距选样）
- 随机选样

#### 步骤六：实施测试并评价结果
- 对每个选中的样本项目实施测试
- 计算样本偏差率 = 样本中发现的偏差数 / 样本量

**结果评价：**
| 情况 | 处理 |
|------|------|
| 样本偏差率 ≤ 可容忍偏差率 | 可以信赖该控制 |
| 样本偏差率 > 可容忍偏差率 | 不能信赖该控制，需增加实质性程序 |

### 5.3 审计抽样在细节测试中的应用

**适用场景：** 测试交易或账户余额中的金额是否正确（如应收账款的存在性和计价）。

**基本步骤：**

#### 步骤一：确定测试目标
- 测试某一认定（如存在性、完整性、准确性）是否存在重大错报

#### 步骤二：定义总体
- 定义抽样总体和个体项目（单个交易或单个余额）

#### 步骤三：确定可容忍错报
- 可容忍错报 = 实际执行的重要性水平或低于该水平的一定金额
- 可容忍错报越低 → 样本量越大

#### 步骤四：确定样本量
影响因素：
- 可接受的误受风险：越低 → 样本量越大
- 可容忍错报：越低 → 样本量越大
- 预计总体错报：越高 → 样本量越大
- 总体变异性（总体中各项目金额差异程度）：越高 → 样本量越大
- 总体规模：对大总体影响较小

#### 步骤五：选取样本并测试
- 传统变量抽样：均值法、差额法、比率法
- 概率比例规模抽样(PPS)：以金额为基础选取样本

#### 步骤六：评价结果
- 推断总体错报：根据样本错报推断总体错报
- 比较推断的总体错报与可容忍错报

**结果评价：**
| 情况 | 处理 |
|------|------|
| 推断总体错报 < 可容忍错报 | 总体可以接受 |
| 推断总体错报 ≥ 可容忍错报 | 总体不可接受，需采取进一步措施 |

**PPS抽样（概率比例规模抽样）的特点：**
- 以金额单元为抽样单元，金额越大的项目被选中的概率越高
- 自动体现"重要性"理念——大金额项目受到更多关注
- 适用于总体变异性不大、零余额和负余额较少的情况

## 总结：核心概念脉络

```
审计目标（合理保证）
    ├── 通过遵守职业道德 → 独立性/客观公正/专业胜任能力
    ├── 通过运用审计风险模型 → 评估重大错报风险 → 控制检查风险
    ├── 通过获取充分适当的审计证据 → 七种审计程序
    │     ├── 函证（外部书面证据）
    │     └── 分析程序（数据关系分析）
    └── 通过审计抽样 → 在成本和效果之间取得平衡
          ├── 控制测试抽样（偏差率评价）
          └── 细节测试抽样（错报金额评价）
```

**备考建议：**
1. 本章是整个审计学科的基石，概念之间的逻辑关系比死记硬背更重要
2. 特别关注"独立性"相关内容，这是每年必考的高分值考点
3. 审计抽样部分要理解统计逻辑，但不必深究数学公式，重在理解影响因素的方向和原理
4. 审计证据的性质（充分性与适当性）是贯穿全科的底层思维
