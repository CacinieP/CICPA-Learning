## 二、典型例题解析

### 2.1 销售循环认定类（单选题）

**题目：** 下列审计程序中，用于测试营业收入"发生"认定的是（ ）。

A. 从销售明细账追查至发运凭证和销售合同
B. 从发运凭证追查至销售明细账
C. 检查期后收到的款项
D. 分析退货率变动

**解析：**
- **发生认定**：防止多计虚构的交易（"从账到证"的逆查）
- **完整性认定**：防止少计遗漏的交易（"从证到账"的顺查）

| 选项 | 程序方向 | 验证认定 |
|-----|---------|---------|
| A | 账→证（逆查） | **发生** |
| B | 证→账（顺查） | 完整性 |
| C | 检查收款 | 应收账款存在 |
| D | 分析程序 | 准确性/计价 |

**答案：** A

**记忆口诀：** "逆查发生，顺查完整"

---

### 2.2 函证程序类（多选题）

**题目：** 下列关于函证的表述中，正确的有（ ）。

A. 函证是获取外部书面证据的审计程序
B. 消极式函证适用于重大错报风险评估为低水平的情况
C. 函证银行存款必须采用积极式函证
D. 函证应当由注册会计师直接发出、直接收回

**解析：**
- 选项A：正确。函证是从第三方获取的书面证据，属于外部证据。
- 选项B：正确。消极式函证适用于：余额较小、笔数较多、重大错报风险评估为低的情况。
- 选项C：错误。银行存款必须函证，但函证方式可以是积极式或消极式（实务中通常积极式）。
- 选项D：正确。函证的全过程控制要求注册会计师直接发出和收回。

**答案：** A、B、D

**易错点：** 函证"必须执行"但方式可选；函证控制要求"全程控制"。

### 2.3 存货监盘类（单选题）

**题目：** 注册会计师在监盘存货时，下列做法中正确的是（ ）。

A. 仅观察管理层盘点，而不执行抽盘程序
B. 从盘点记录追查至实物，以验证存在性
C. 从实物追查至盘点记录，以验证完整性
D. 监盘时应当让被审计单位停止生产

**解析：**
- 选项A：错误。仅观察不够，必须执行双向抽盘。
- 选项B：正确。从盘点记录追查至实物（从记录到实物）验证存在性。
- 选项C：正确。从实物追查至盘点记录（从事实到记录）验证完整性。
- 选项D：错误。监盘时通常不要求停止生产（除非特殊情况），否则会影响正常经营。

**答案：** B、C

**关键考点：** 存货监盘的双向抽盘程序：
- **逆查**（盘点记录→实物）：验证存在性
- **顺查**（实物→盘点记录）：验证完整性

### 2.4 采购循环审计类（简答题）

**题目：** 简述注册会计师为查找被审计单位是否存在未入账应付账款而应实施的审计程序。

**解析：**

**标准答题框架：**

**程序一：检查日后付款事项**
- 检查资产负债表日后的付款凭证
- 确认是否存在期末应付款项在日后才支付的情况

**程序二：检查日后收到的发票**
- 检查资产负债表日后收到的采购发票
- 确认是否存在期末已入库但未入账的采购

**程序三：函证应付账款**
- 向主要供应商函证期末应付账款余额
- 特别注意金额重大或可能存在争议的款项

**程序四：检查供应商对账单**
- 获取供应商对账单
- 将对账单与应付账款明细账核对

**程序五：检查未凭单收据报告**
- 检查是否存在货物已到但单据未到的暂估入库
- 确认是否已入账

**核心原理：** 未入账应付账款违反了"完整性"认定，审计程序应围绕"是否遗漏了应该记录的负债"展开。

**答案要点：** 资产负债表日后的付款、收到的发票、供应商对账单、未凭单收据报告、函证。

### 2.5 货币资金审计类（单选题）

**题目：** 下列审计程序中，属于银行存款实质性程序的是（ ）。

A. 评价银行存款内部控制的有效性
B. 观察被审计单位的银行存款日记账与银行对账单的核对
C. 检查银行预留印鉴的管理情况
D. 函证银行存款余额

**解析：**
- 选项A：评价内部控制——属于"了解/测试内部控制"，是风险应对程序
- 选项B：观察核对程序——属于"观察"，是风险评估或控制测试程序
- 选项C：检查印鉴管理——属于"检查记录"，是控制测试程序
- 选项D：**正确**。函证银行存款余额——属于实质性程序，是必须执行的

**答案：** D

**关键考点：** 银行函证是必须执行的实质性程序，无论重大错报风险水平如何。

## 三、分录/计算模板

### 3.1 截止测试关键日期检查表

```
【模板】收入/存货截止测试

一、测试目的
   验证交易是否记录在正确的会计期间

二、关键日期
   资产负债表日：____年____月____日

三、检查范围
   资产负债表日前后各____天

四、检查内容
   ┌─────────────┬─────────────────┬─────────────────┐
   │   日期      │    检查内容     │    预期结果     │
   ├─────────────┼─────────────────┼─────────────────┤
   │ 截止日前____天│ 销售发票、发运凭证│ 商品控制权转移  │
   │             │                 │ 在截止日前      │
   ├─────────────┼─────────────────┼─────────────────┤
   │ 截止日后____天│ 销售发票、发运凭证│ 商品控制权转移  │
   │             │                 │ 在截止日后      │
   └─────────────┴─────────────────┴─────────────────┘

五、判断标准
   商品控制权转移时点=收入确认时点=截止点
```

### 3.2 函证决策表

| 科目 | 函证必要性 | 函证方式选择 | 备注 |
|-----|----------|------------|------|
| 银行存款 | **必须** | 积极式 | 包括零余额账户和已结清账户 |
| 借款 | **必须** | 积极式 | 与金融机构往来的其他信息 |
| 应收账款 | 通常应该 | 积极式/消极式 | 金额大/风险高→积极式 |
| 应付账款 | 通常可以 | 积极式 | 特别关注金额重大的供应商 |
| 存货 | 一般不函证 | - | 通常采用监盘程序 |

### 3.3 审计方向与认定关系

| 审计方向 | 测试认定 | 逻辑 |
|---------|---------|------|
| 顺查（从证到账） | 完整性 | 确保所有已发生的交易都被记录 |
| 逆查（从账到证） | 发生/存在 | 确保所有记录的交易都真实发生 |
| 截止测试 | 截止 | 确保交易记录在正确期间 |

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|-------|------|---------|
| 销售循环"发生"vs"完整性" | 发生=逆查防多计；完整性=顺查防少计 | "发多完少" |
| 积极式函证vs消极式函证 | 积极=必须回；消极=不回默认同意 | "积极必须，消极随缘" |
| 控制测试vs实质性程序 | 前者测内控；后者直接查错报 | "内控测控制，实质查报表" |
| 存货监盘vs存货函证 | 监盘是实地查看；存货一般不函证 | "存货实地盘，其他可以函" |
| 截止测试"前"vs"后" | 前=确认没有提前确认；后=确认没有推迟确认 | "前防早，后防晚" |

## 五、速记口诀

**销售循环审计：**
> "发生逆查完整性顺查，截止测试前后要查；函证应收计价分析，毛利率异常要警惕"

**采购循环审计：**
> "查找未入账要关注，日后付款和发票；供应商对账单检查，完整性认定重点抓"

**存货监盘：**
> "双向抽盘不可少，记录追物验存在；物追记录验完整，盘点观察全程在"

**银行函证：**
> "银行存款必须函，零余额要包括；注册会计师亲自发，全程控制不能落"
