# 财务报告 —— 典型考题解析

## 一、核心考法分类

本章在历年真题中的主要考法归纳如下：

1. **资产负债表的填列方法**（单选题、多选题）：综合运用多种方法的项目
2. **现金流量表的分类**（单选题）：经营/投资/筹资活动的判断
3. **间接法的调节项目**（计算分析题）：净利润调节至经营活动现金流量
4. **关联方关系的认定**（多选题）：控制、共同控制、重大影响
5. **分部报告的重要性测试**（多选题）：10%标准

## 二、典型例题解析

### 2.1 资产负债表项目的填列

**题目：**
单选题——下列资产负债表项目中，应根据明细账科目余额计算填列的是（ ）

A. 货币资金
B. 应付账款
C. 应收账款
D. 固定资产

**解析：**
资产负债表的填列方法分类：

| 填列方法 | 举例 |
|----------|------|
| 根据总账科目余额直接填列 | 短期借款、实收资本、应付票据 |
| 根据明细科目余额计算填列 | **应收账款**=应收账款借方+预收账款借方-坏账准备<br>**应付账款**=应付账款贷方+预付账款贷方 |
| 根据总账科目余额计算填列 | 货币资金=库存现金+银行存款+其他货币资金 |
| 根据有关科目余额减去备抵科目后的净额填列 | 固定资产、无形资产、应收账款（净） |
| 综合运用上述方法 | 存货 |

选项A：货币资金——根据总账科目余额计算填列
选项B：应付账款——根据明细科目余额计算填列
选项C：应收账款——根据明细科目余额计算填列（借方+借方-坏账准备）
选项D：固定资产——根据有关科目余额减去备抵科目后的净额填列

**答案：** B、C

### 2.2 现金流量分类

**题目：**
多选题——下列各项中，属于经营活动现金流量的有（ ）

A. 销售商品收到现金
B. 支付给职工的工资
C. 购建固定资产支付的现金
D. 分配现金股利支付的现金
E. 收到税费返还

**解析：**
现金流量三大类：

| 类别 | 内容 |
|------|------|
| 经营活动 | 日常生产经营（销售、购买、支付薪酬、税费） |
| 投资活动 | 长期资产购建、投资收回、利息收入 |
| 筹资活动 | 吸收投资、借款、偿还债务、分配股利 |

选项C：购建固定资产——投资活动
选项D：分配现金股利——筹资活动

**答案：** A、B、E

### 2.3 间接法调节

**题目：**
计算分析题——甲公司2024年度净利润为8,000,000元。已知：
（1）计提固定资产折旧2,000,000元
（2）无形资产摊销500,000元
（3）处置固定资产收益300,000元
（4）存货减少1,000,000元
（5）应收账款增加600,000元
（6）应付账款减少200,000元
（7）财务费用800,000元（均为利息费用）

要求：计算甲公司2024年度经营活动现金流量净额。

**解析：**

间接法下，将净利润调节为经营活动现金流量：

```
净利润                                 8,000,000
加：固定资产折旧                       2,000,000
   无形资产摊销                         500,000
   财务费用（利息）                     800,000
减：处置固定资产收益                   300,000
   存货减少（减：增加）              1,000,000
   应收账款增加（减：减少）           600,000
   应付账款减少（减：增加）           200,000
= 经营活动现金流量净额                11,200,000
```

**记忆口诀：**
- 加回：折旧、摊销、投资损失、财务费用
- 减：收益
- 存货减少→加回；存货增加→减去
- 应收增加→减去；应付减少→减去

**答案：** 11,200,000元

### 2.4 关联方认定

**题目：**
单选题——下列各项中，不属于甲公司关联方的是（ ）

A. 甲公司的母公司
B. 甲公司控股50%的子公司
C. 甲公司的合营企业
D. 甲公司财务总监的妻子

**解析：**
关联方主要包括：
1. 该企业的母公司
2. 该企业的子公司
3. 与该企业受同一母公司控制的**其他企业**
4. 对该企业实施共同控制的投资方
5. 对该企业施加重大影响的投资方
6. 该企业的合营企业
7. 该企业的联营企业
8. 该企业的**主要投资者个人**及与其关系密切的家庭成员
9. 该企业的**关键管理人员**（包括董事、总经理等）及与其关系密切的家庭成员
10. 该企业的**关键管理人员或主要投资者个人**控制的或共同控制的其他企业

选项D：财务总监是关键管理人员，其妻子是关系密切的家庭成员，但妻子本人不是关联方

**答案：** D

### 2.5 分部报告的重要性测试

**题目：**
单选题——甲公司有两个分部：A分部收入3,000万元，利润300万元，资产1,500万元；B分部收入800万元，利润50万元，资产400万元。甲公司分部总数为5个，其他分部收入合计2,000万元。下列关于分部报告的判断中，正确的是（ ）

A. A分部应作为报告分部，B分部不应作为报告分部
B. 两个分部均应作为报告分部
C. A分部应作为报告分部，B分部需要看其他条件才能确定
D. 两个分部均不应作为报告分部

**解析：**
报告分部的确定条件（满足其一即可）：

| 测试 | 标准 |
|------|------|
| 收入占比 | 收入占所有分部收入合计的**10%以上** |
| 利润占比 | 利润占所有盈利分部合计的**10%以上**，或亏损分部合计的**10%以上** |
| 资产占比 | 资产占所有分部资产合计的**10%以上** |

**计算：**
- 总收入 = 3,000 + 800 + 2,000 = 5,800万元
- 总资产 = 1,500 + 400 = 1,900万元（假设其他分部资产0或已知）

A分部：
- 收入占比：3,000/5,800 = 51.7% > 10% ✓
- 利润占比：300/350（盈利分部利润）= 85.7% > 10% ✓
- 资产占比：1,500/1,900 = 78.9% > 10% ✓
→ 属于报告分部

B分部：
- 收入占比：800/5,800 = 13.8% > 10% ✓
- 资产占比：400/1,900 = 21.1% > 10% ✓
→ 属于报告分部

**答案：** B

## 三、分录/计算模板

### 模板：间接法调节项目汇总

```
经营活动现金流量净额 = 净利润
  + 资产减值损失
  + 信用减值损失
  + 固定资产折旧
  + 无形资产摊销
  + 长期待摊费用摊销
  + 处置固定资产/无形资产的损失（-收益）
  + 公允价值变动损失（-收益）
  + 财务费用（-利息收入）
  + 投资损失（-投资收益）
  + 递延所得税资产减少（-增加）
  + 递延所得税负债增加（-减少）
  + 存货减少（-增加）
  + 经营性应收减少（-增加）
  + 经营性应付增加（-减少）
```

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|-------|------|---------|
| 应收账款填列 | 借方余额相加+预收借方-坏账；贷方余额在预收账款填列 | "借借借，贷贷贷" |
| 经营活动 vs 投资活动 | 经营：日常买卖；投资：买卖资产 | "买产品卖产品是经营，买厂房卖股票是投资" |
| 间接法调节方向 | 存货减少→加回（钱回来了）；应收增加→减去（钱没回来） | "钱到手了加回，钱没到手减去" |
| 关联方认定 | 关键管理人员的家庭成员≠关联方 | "关键人物"≠家庭成员 |

## 五、速记口诀

**现金流量分类：**
- 经营：买卖商品、支付工资、交税
- 投资：买设备、买股票、利息收入
- 筹资：借钱、还钱、发股利

**间接法调节：**
- 折旧摊销要加回
- 投资收益要减去
- 存货减少要加回
- 应收增加要减去
