## 二、典型例题解析

### 2.1 非同一控制购买日抵销

**题目：** 甲公司以5000万元购买乙公司80%股权，购买日乙公司可辨认净资产公允价值6000万元（账面5500万元，差异：固定资产增值500万元，尚可使用10年）。编制购买日合并抵销分录。

**答案：**
```
// 调公允差异
借：固定资产  500
  贷：资本公积  500

// 抵销分录
借：净资产（乙公司，公允）  6000
    商誉  200（5000-6000×80%=200）
  贷：长期股权投资  5000
      少数股东权益  1200（6000×20%）
```

### 2.2 内部存货交易抵销（当期）

**题目：** 甲向乙销售商品，售价400万元，成本300万元。乙当年将该商品的60%对外出售，40%形成期末存货。

**答案：**
```
// 抵销内部销售收入和成本
借：营业收入  400
  贷：营业成本  400

// 抵销期末存货中的未实现利润
借：营业成本  40（100×40%）
  贷：存货  40
```
简化版：
```
借：营业收入  400
  贷：营业成本  360
      存货  40
```

### 2.3 连续编制合并报表——内部存货交易

**题目：** 上年甲向乙销售商品，售价400万元，成本300万元，乙年末仍有40%未售。本年乙将上年剩余存货全部售出，且本年甲又向乙销售商品，售价500万元，成本350万元，乙年末仍有30%未售。

**答案：**
```
// 抵销上年存货未实现利润（已转入本年营业成本）
借：年初未分配利润  40
  贷：营业成本  40

// 抵销本年内部交易
借：营业收入  500
  贷：营业成本  500

// 抵销本年期末存货未实现利润
借：营业成本  45（150×30%）
  贷：存货  45
```

### 2.4 内部固定资产交易抵销

**题目：** 甲向乙销售一台设备，售价600万元，成本400万元。乙将该设备作为管理用固定资产，按5年直线法折旧，残值为0。

**答案：**
```
// 抵销内部销售
借：营业收入  600
  贷：营业成本  400
      固定资产——原价  200

// 抵销多提折旧（当年200/5=40万元）
借：固定资产——累计折旧  40
  贷：管理费用  40
```
第2年：
```
借：年初未分配利润  200
  贷：固定资产——原价  200

借：固定资产——累计折旧  40（上年）
  贷：年初未分配利润  40

借：固定资产——累计折旧  40（本年）
  贷：管理费用  40
```

### 2.5 内部债权债务抵销

**题目：** 甲应收乙200万元，乙应付甲200万元。甲对该应收账款计提坏账准备10万元。

**答案：**
```
// 抵销债权债务
借：应付账款  200
  贷：应收账款  200

// 抵销坏账准备
借：应收账款——坏账准备  10
  贷：信用减值损失  10

// 抵销递延所得税（因坏账准备产生的可抵扣差异）
借：递延所得税资产  2.5（10×25%）
  贷：所得税费用  2.5
```

## 三、分录模板

### 3.1 内部存货交易（通用模板）

| 情形 | 当期分录 | 连续编制分录 |
|------|---------|-------------|
| 抵销收入/成本 | 借：营业收入；贷：营业成本+存货(未实现) | 借：年初未分配利润；贷：营业成本(上年存货已售) |
| 存货跌价准备 | 借：存货——跌价准备；贷：资产减值损失 | 借：年初未分配利润；贷：存货跌价准备(上年) |

### 3.2 内部固定资产交易（通用模板）

| 年份 | 原价抵销 | 折旧抵销 |
|------|---------|---------|
| 交易当年 | 借：营业收入→贷：营业成本+固定资产原价 | 借：累计折旧→贷：管理费用 |
| 交易后第N年 | 借：年初未分配利润→贷：固定资产原价 | 借：累计折旧(N×年折旧)→贷：年初未分配利润((N-1)×折旧)+管理费用(本年折旧) |
| 清理当年(期满) | 无需抵销原价 | 借：年初未分配利润→贷：管理费用(最后一笔折旧) |

### 3.3 少数股东分担未实现损益

- 顺流交易：全部由母公司承担，少数股东不分担
- 逆流交易：未实现损益按持股比例由少数股东分担
```
借：少数股东权益（未实现损益 × 少数比例）
  贷：少数股东损益
```

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|-------|------|----------|
| 同一 vs 非同一合并日抵销 | 同一控制按账面价值抵销；非同一控制按公允价值抵销 | "同账非公" |
| 顺流 vs 逆流交易 | 顺流=母→子；逆流=子→母。逆流需少数股东分担 | "逆流少数分" |
| 存货跌价准备抵销限额 | 最多抵销到内部利润额，不能超过 | "跌价不超过内部利润" |
| 期满清理 vs 提前清理 | 期满：未实现利润全部实现；提前：仍有未实现利润需抵销 | "期满全实现，提前仍抵销" |

## 五、速记口诀

- **"内部三抵"**：收入成本抵销、存货/固定资产抵销、债权债务抵销
- **"连续编制看年初"**：上年未实现利润转入年初未分配利润
- **"逆流少数分"**：逆流交易的未实现损益需按比例由少数股东分担
- **"商誉不减值抵销"**：商誉在合并报表中单独列示，不参与内部交易抵销
