# 合并财务报表 —— 第一性原理教程

## 一、合并范围的确定

### 1.1 控制的判断

**控制的三要素（同时满足）：**
1. 拥有对被投资方的**权力**
2. 享有可变回报
3. 有能力运用权力影响回报金额

### 1.2 投资性主体

**投资性主体**同时满足：
1. 从投资者处取得资金
2. 唯一目的是让投资者获得投资收益或资本增值
3. 以公允价值计量和评价

**特殊规定：** 投资性主体对子公司投资的公允价值计量，一般不纳入合并范围（仅为投资目的持有的子公司除外）。

---

## 二、合并财务报表编制原则与程序

### 2.1 编制原则
- 以个别财务报表为基础
- 一体性原则
- 重要性原则

### 2.2 编制程序
1. 统一会计政策和会计期间
2. 编制合并工作底稿
3. 编制调整分录和抵销分录
4. 计算合并金额
5. 填列合并报表

---

## 三、同一控制下合并处理

**合并日的处理：**
- 将被合并方的净资产按账面价值并入
- 抵销母公司长期股权投资与子公司所有者权益

```
借：股本（子公司）
    资本公积（子公司）
    盈余公积（子公司）
    未分配利润（子公司）
  贷：长期股权投资（母公司）
      少数股东权益
```

---

## 四、非同一控制下合并处理

**购买日的处理：**
- 将子公司可辨认资产/负债调整为**公允价值**
- 抵销母公司长期股权投资与子公司调整后的所有者权益

```
借：存货（公允-账面）
    固定资产（公允-账面）
    股本
    资本公积
    盈余公积
    未分配利润
    商誉（差额）
  贷：长期股权投资
      少数股东权益
```

---

## 五、内部商品交易的合并处理

### 5.1 当期内部销售

**抵销分录：**
```
借：营业收入（内部销售方的收入）
  贷：营业成本（内部销售方的成本）
      存货（未实现内部销售利润）
```

### 5.2 连续编制合并报表

**期初未实现利润：**
```
借：未分配利润——年初
  贷：存货（上年未实现利润仍在存货中的部分）
```

**当期销售：**
```
借：营业收入
  贷：营业成本
      存货
```

---

## 六、内部债权债务的合并处理

```
借：应付账款/应付票据/应付债券
  贷：应收账款/应收票据/持有至到期投资

借：应收账款——坏账准备
  贷：信用减值损失（当期）
      未分配利润——年初（前期）
```

---

## 七、内部固定资产交易的合并处理

```
借：资产处置收益/营业收入
  贷：固定资产——原价

借：固定资产——累计折旧（多提的折旧）
  贷：管理费用（当期）
      未分配利润——年初（前期）
```

---

## 八、内部无形资产交易

处理逻辑同固定资产：抵销未实现利润 + 抵销多提的摊销。

---

## 九、特殊交易的合并处理

### 9.1 追加投资（分步实现合并）

| 原持股 | 增至 | 处理 |
|--------|------|------|
| FVTPL → 控制 | 5%→60% | 公允价值作为合并成本（非同控） |
| 权益法 → 控制 | 20%→60% | 原投资账面价值+新增对价作为合并成本（同控） |

### 9.2 处置投资（丧失控制权）

| 变化 | 处理 |
|------|------|
| 控制→权益法 | 剩余投资按丧失控制权日公允价值重新计量，差额计入投资收益 |
| 控制→FVTPL | 剩余投资按公允价值计量，差额计入投资收益 |

### 9.3 逆流交易

子公司向母公司销售的未实现利润，按母公司持股比例抵销母公司份额，少数股东分担的部分：

```
借：少数股东权益
  贷：少数股东损益
```

## 十、所得税会计相关的合并处理

- 内部交易产生的未实现利润对应的递延所得税
- 公允价值调整产生的递延所得税
- 抵销时确认递延所得税资产/负债

---

## 十一、合并现金流量表

- 在母子公司个别现金流量表基础上编制
- 抵销内部交易产生的现金流量
- 子公司少数股东分配的股利在"筹资活动"中单独列示

---

## 考试要点总结

1. **控制三要素**：权力+可变回报+影响能力
2. **同控合并**：按账面价值，视同一直存在
3. **非同控合并**：按公允价值，确认商誉
4. **内部交易抵销**：商品/债权/固定资产/无形资产
5. **特殊交易**：追加/处置投资的合并处理
6. **逆流交易**：少数股东分担未实现利润
