# 会计政策、会计估计及其变更和差错更正 —— 第一性原理教程

## 一、会计政策及其变更

### 1.1 会计政策的定义

**会计政策**是指企业在会计确认、计量和报告中所采用的原则、基础和会计处理方法。

### 1.2 常见会计政策

- 发出存货的计价方法
- 长期股权投资的核算方法
- 投资性房地产的计量模式
- 固定资产的折旧方法
- 收入确认的方法
- 外币折算方法

### 1.3 会计政策变更

**会计政策变更**是指企业对相同的交易或事项由原来采用的会计政策改用另一会计政策的行为。

**变更条件（满足之一）：**
1. 法律或会计准则等要求变更
2. 变更能提供更可靠、更相关的会计信息

**不属于会计政策变更的情形：**
- 本期发生的交易与以前相比有本质差别
- 对初次发生的或不重要的交易采用新的会计政策

---

## 二、会计估计及其变更

### 2.1 会计估计的定义

**会计估计**是指企业对其结果不确定的交易或事项以最近可利用的信息为基础所作的判断。

### 2.2 常见会计估计

- 坏账准备的计提比例
- 固定资产的使用寿命和净残值
- 无形资产的使用寿命
- 预计负债的金额
- 可收回金额的估计

### 2.3 会计估计变更

**原因：** 赖以进行估计的基础发生了变化，或取得了新信息。

**会计处理：** 采用**未来适用法**，不调整以前期间。

---

## 三、会计政策与会计估计的划分

### 3.1 判断原则

| 问题 | 性质 |
|------|------|
| 涉及会计确认、计量基础或列报项目的选择 | **会计政策** |
| 涉及对不确定事项的判断或估计 | **会计估计** |

### 3.2 常见例子

| 变更事项 | 分类 |
|----------|------|
| 发出存货计价方法由先进先出法改为月末一次加权平均法 | **会计政策变更** |
| 固定资产折旧方法由年限平均法改为双倍余额递减法 | **会计估计变更** |
| 坏账准备计提比例由5%改为10% | **会计估计变更** |
| 投资性房地产由成本模式改为公允价值模式 | **会计政策变更** |
| 存货可变现净值确定方法的变更 | **会计估计变更** |

---

## 四、会计处理方法

### 4.1 会计政策变更的处理

**追溯调整法（一般情形）：**
1. 计算会计政策变更的累积影响数
2. 调整期初留存收益
3. 调整比较报表

```
累积影响数 = 按新政策计算的变更日资产/负债金额
            - 按原政策计算的变更日资产/负债金额
```

**未来适用法（无法追溯调整时）：**
- 不调整以前期间，从变更日起采用新政策

### 4.2 会计估计变更的处理

**未来适用法：** 不调整以前期间的会计估计，在变更当期和以后期间采用新的会计估计。

---

## 五、会计差错更正

### 5.1 差错的类型

| 类型 | 处理 |
|------|------|
| 当期发现的当期差错 | 直接更正当期相关项目 |
| 当期发现的前期重大差错 | **追溯重述法** |
| 当期发现的前期非重大差错 | 直接调整当期 |

### 5.2 前期重大差错的追溯重述

**处理步骤：**
1. 确定前期差错的影响数
2. 调整期初留存收益和比较报表

```
借/贷：相关资产/负债
  贷/借：以前年度损益调整
          应交税费——应交所得税

借/贷：以前年度损益调整
  贷/借：盈余公积
          利润分配——未分配利润
```

---

## 考试要点总结

1. **会计政策变更**→追溯调整法（一般）；未来适用法（无法追溯时）
2. **会计估计变更**→未来适用法
3. **划分关键**：是"选择确认计量方法"还是"对不确定事项估计"
4. **前期重大差错**→追溯重述法
5. **累积影响数**调整期初留存收益
