# 金融工具 —— 第一性原理教程

## 一、金融工具概述

### 1.1 什么是金融工具

**金融工具**是指形成一方的金融资产并形成其他方的金融负债或权益工具的合同。

**三方关系：**
```
金融资产（投资方持有） ←——合同——→ 金融负债 或 权益工具（发行方）
```

### 1.2 金融资产

**金融资产**包括：
- 现金
- 持有的其他方的权益工具（如股票）
- 合同权利（收取现金或金融资产的合同权利）
- 交换金融资产的合同权利（在潜在有利条件下）

### 1.3 衍生工具

**衍生工具**是指价值取决于基础变量的金融合同，如远期、期货、期权、互换。

**特征：**
- 价值随基础变量变动
- 不要求初始净投资（或较少）
- 在未来某日结算

## 二、金融资产和金融负债的分类和重分类

### 2.1 金融资产的分类（三类）

企业根据**管理金融资产的业务模式**和**金融资产的合同现金流量特征**进行分类：

| 类别 | 业务模式 | 现金流量特征 | 简称 |
|------|----------|-------------|------|
| 以摊余成本计量 | 收取合同现金流量 | 仅本金和利息（SPPI） | **AMC** |
| 以公允价值计量且变动计入其他综合收益 | 收取+出售 | 仅本金和利息（SPPI） | **FVTOCI** |
| 以公允价值计量且变动计入当期损益 | 其他 | 其他 | **FVTPL** |

**分类判断流程：**
```
第一步：合同现金流量是否仅为本金和利息（SPPI测试）？
  否 → FVTPL
  是 → 第二步：业务模式是什么？
         收取合同现金流量 → AMC
         收取+出售 → FVTOCI
         其他 → FVTPL
```

### 2.2 金融负债的分类

- **以摊余成本计量**（大多数金融负债）
- **以公允价值计量且变动计入当期损益**（交易性金融负债、衍生金融负债）

### 2.3 重分类

企业改变管理金融资产的业务模式时，应当对所有受影响的相关金融资产进行重分类。

**重分类日：** 主体首个报告期间的首日。

| 重分类方向 | 会计处理 |
|-----------|----------|
| FVTPL → AMC | 以公允价值作为新的摊余成本 |
| FVTPL → FVTOCI | 以公允价值作为新的账面价值 |
| AMC → FVTPL | 以账面价值作为新的公允价值（差额为零） |
| AMC → FVTOCI | 以账面价值作为新的公允价值 |
| FVTOCI → AMC | 以公允价值作为新的摊余成本，之前累计OCI转入当期损益 |
| FVTOCI → FVTPL | 以账面价值作为新的公允价值，之前累计OCI转入当期损益 |

## 三、金融负债和权益工具的区分

### 3.1 区分原则

**核心判断：** 发行方是否存在**无条件避免交付现金或其他金融资产**的合同义务。

| 情形 | 分类 |
|------|------|
| 必须交付现金/金融资产 | **金融负债** |
| 可以无条件避免交付 | **权益工具** |
| 以自身权益工具结算（固定换固定） | **权益工具** |
| 以自身权益工具结算（非固定换固定） | **金融负债** |

### 3.2 "固定换固定"原则

- 交付的权益工具数量**固定**，且换取的现金金额**固定** → 权益工具
- 其他情况（数量变动或金额变动）→ 金融负债

### 3.3 复合金融工具

**可转换债券**等既含负债成分又含权益成分的工具：

```
负债成分 = 未来现金流量的现值（按市场利率折现）
权益成分 = 实际发行价格 - 负债成分的公允价值
```

## 四、金融工具的计量

### 4.1 初始计量

| 类别 | 初始计量 | 交易费用 |
|------|----------|----------|
| AMC | 公允价值 + 交易费用 | 计入初始成本 |
| FVTOCI | 公允价值 + 交易费用 | 计入初始成本 |
| FVTPL | 公允价值 | 计入当期损益 |

### 4.2 后续计量

| 类别 | 后续计量 | 减值 |
|------|----------|------|
| AMC | 摊余成本（实际利率法） | 预期信用损失模型 |
| FVTOCI（债务工具） | 公允价值（公允价值变动计入OCI，减值和利息计入损益） | 预期信用损失模型 |
| FVTOCI（权益工具） | 公允价值（变动计入OCI，不转损益） | 不计提减值 |
| FVTPL | 公允价值（变动计入当期损益） | 不计提减值 |

### 4.3 金融资产减值（预期信用损失模型）

**三阶段模型：**

| 阶段 | 信用风险状况 | 减值确认 | 利息收入 |
|------|-------------|---------|---------|
| 第一阶段 | 信用风险未显著增加 | 12个月预期信用损失 | 账面余额×实际利率 |
| 第二阶段 | 信用风险显著增加 | 整个存续期预期信用损失 | 账面余额×实际利率 |
| 第三阶段 | 已发生信用减值 | 整个存续期预期信用损失 | 摊余成本（净额）×实际利率 |

## 五、金融资产转移

### 5.1 转移的类型

| 类型 | 是否终止确认 |
|------|-------------|
| 转移了几乎所有风险和报酬 | **终止确认** |
| 保留了几乎所有风险和报酬 | **不终止确认**（继续确认） |
| 既未转移也未保留 | 判断是否保留了控制（未保留→终止确认；保留→按继续涉入处理） |

### 5.2 终止确认的会计处理

```
终止确认损益 = 收到的对价 - 终止确认部分的账面价值 + 累计OCI转入
```

## 六、套期会计

**套期的本质：** 用套期工具的公允价值或现金流量变动，抵销被套期项目的公允价值或现金流量变动。

**三种套期类型：**
1. **公允价值套期**：对已确认资产/负债的公允价值变动风险套期
2. **现金流量套期**：对现金流量变动风险套期
3. **境外经营净投资套期**：对境外经营净投资的外汇风险套期

---

## 七、保险合同概述

**保险合同**是签发人同意在特定不确定未来事项发生时进行赔付的合同。

**关键特征：** 承担了重大保险风险。

---

## 考试要点总结

1. **三类金融资产**：AMC / FVTOCI / FVTPL，分类依据是业务模式+SPPI测试
2. **负债vs权益**：核心是"能否无条件避免交付现金"+"固定换固定"
3. **预期信用损失模型**：三阶段，12个月ECL vs 整个存续期ECL
4. **金融资产转移**：判断是否转移了风险和报酬
5. **复合工具拆分**：可转债拆分为负债成分和权益成分
