# 金融工具 —— 综合实战

## 一、综合题解题框架

### 1.1 金融资产综合题标准解题步骤

```
第一步：识别金融工具类型
        ├─ 基本金融工具（股票、债券）
        ├─ 衍生工具（远期、期货、期权、互换）
        └─ 复合金融工具（可转债）

第二步：金融资产分类
        ├─ SPPI测试：合同现金流量是否仅为本金和利息？
        │    ├─ 通过 → 业务模式测试
        │    └─ 未通过 → FVTPL
        └─ 业务模式测试：
             ├─ 只收合同现金流 → AMC
             ├─ 收+出售 → FVTOCI
             └─ 其他 → FVTPL

第三步：初始计量
        ├─ AMC/FVTOCI：公允价值+交易费用
        └─ FVTPL：公允价值（交易费用计入损益）

第四步：后续计量
        ├─ AMC：摊余成本，实际利率法
        ├─ FVTOCI：公允价值变动
        └─ FVTPL：公允价值变动

第五步：减值（如适用）
        └─ 预期信用损失模型
```

### 1.2 典型综合题模板

**题目框架：**
```
背景：企业购入多种金融资产，包括债券、股票、衍生工具等
要求：（1）判断各金融资产的分类
      （2）计算初始确认金额
      （3）编制资产负债表日相关分录
      （4）计算处置时的投资收益
      （5）说明对报表的影响
```

## 三、陷阱与反套路

### 3.1 常见陷阱

| 陷阱类型 | 出题方式 | 应对方法 |
|----------|----------|----------|
| SPPI测试错误 | 将含有看涨期权的债券通过SPPI测试 | 分析合同现金流是否"纯粹"取决于基础变量 |
| 业务模式混淆 | 将"持有以备出售"理解为"短期出售" | 业务模式是管理层意图，不是实际交易 |
| 三阶段判断错误 | 将信用风险显著增加等同于已发生减值 | 信用风险显著增加≠已减值，仍按账面余额算利息 |
| FVTOCI处置 | 忘记将OCI转入当期损益 | FVTOCI权益工具→不转；FVTOCI债务工具→转 |
| 权益成分转出 | 可转债转股时转出全部负债成分 | 只转剩余未摊销的利息调整 |

### 3.2 反套路要点

1. **金融资产分类两步法：**
   - 第一步：SPPI测试（本金+利息？）
   - 第二步：业务模式（收？收+卖？其他？）

2. **预期信用损失三阶段判断：**
   - 信用风险是否显著增加？
   - 是否已发生信用减值？
   - 不同阶段利息收入的计算基数不同

3. **重分类的处理原则：**
   - 以公允价值作为新的计量基础
   - 差额计入当期损益或OCI

## 四、真题变式推演

### 变式一：金融资产分类+计量+减值综合

**原题特征：** 单一金融资产的分类判断

**变式扩展：**
```
背景：A公司2×21年度发生以下交易：

（1）1月1日，购入B公司发行的债券100万张，每张面值100元，票面利率4%，
    期限5年，每年年末付息，到期还本。购买价格为每张98元，
    另支付交易费用50万元。A公司管理该债券的业务模式是收取合同现金流。

（2）1月1日，购入C公司股票100万股，每股购买价格20元，另支付交易费用30万元。
    A公司将其指定为以公允价值计量且其变动计入其他综合收益的金融资产。
    12月31日，该股票每股市价18元。

（3）7月1日，购入D公司发行的期权合约，期权费200万元。
    12月31日，该期权公允价值350万元。

（4）1月1日向E公司发放贷款5,000万元，合同年利率6%，期限3年。
    2×21年末进行信用风险评估，初始确认时信用风险较低，
    但年末评估显示信用风险显著增加，预计存续期损失率3%。

要求：
（1）判断上述各项金融资产的分类
（2）计算各项金融资产的初始确认金额
（3）编制2×21年度相关会计分录
（4）计算2×21年度确认的投资收益/公允价值变动损益/信用减值损失
```

**解题要点：**
1. 债券（AMC）：初始确认9,850万元，交易费用50万元计入成本
2. 股票（FVTOCI权益工具）：成本2,030万元，公允价值变动计入OCI，不转损益
3. 期权（FVTPL）：初始确认200万元，公允价值变动150万元计入公允价值变动损益
4. 贷款（FVTOCI债务工具）：信用风险显著增加→整个存续期ECL=5,000×3%=150万元

### 变式二：金融工具+财务报表列报

```
背景：甲公司2×21年12月31日部分账户余额如下：
- 交易性金融资产：成本5,000万元，公允价值5,800万元
- 债权投资：账面余额8,000万元，减值准备200万元，利息调整借方余额150万元
- 其他权益工具投资：成本3,000万元，公允价值3,500万元
- 应付债券：面值10,000万元，利息调整贷方余额300万元

要求：
（1）说明上述资产在资产负债表中的列报项目及金额
（2）说明相关损益在利润表中的列报项目
（3）说明其他综合收益的列报
（4）计算相关资产/负债的账面价值
```

### 变式三：金融工具+所得税+所有者权益

```
背景：乙公司2×21年发生以下业务：
（1）以公允价值计量且变动计入其他综合收益的债务工具投资：
    - 成本5,000万元
    - 本期因公允价值上升确认OCI 300万元
    - 本期计提信用减值损失200万元（该损失已包含在OCI中）

（2）以公允价值计量且变动计入当期损益的金融资产：
    - 本期确认公允价值变动收益100万元

（3）本期会计利润8,000万元，适用的所得税税率25%，
    假设除上述事项外无其他暂时性差异

要求：
（1）计算本期应确认的递延所得税
（2）计算本期所得税费用
（3）编制相关会计分录
（4）编制利润表其他综合收益部分
```

## 五、实务衔接

### 5.1 金融工具在银行等金融机构的应用

**贷款业务（AMC/FVTOCI）：**
- 实际利率法计算利息收入
- 预期信用损失模型计提减值
- 银行为信用风险管理的核心工具

**交易性金融资产业务（FVTPL）：**
- 以交易为目的的债券、股票投资
- 公允价值变动计入当期损益
- 银行自营业务的主要形式

### 5.2 套期会计的应用

**套期的三种类型：**
1. 公允价值套期：对已确认资产/负债的公允价值变动风险套期
2. 现金流量套期：对现金流量变动风险套期
3. 境外经营净投资套期：对境外经营净投资的外汇风险套期

**套期有效性评价方法：**
- 关键条款比较法
- 比率分析法
- 回归分析法

> ⚠️ **实务警示：** 套期会计的应用需要满足严格的适用条件，企业应建立健全的套期风险管理程序。

## 六、速记总结

**金融工具核心知识点：**

| 分类 | 计量基础 | 公允价值变动 | 减值 | 处置时 |
|------|----------|-------------|------|--------|
| AMC | 摊余成本 | 不确认 | 预期信用损失 | 投资收益 |
| FVTOCI-债务 | 公允价值 | OCI | 预期信用损失 | 投资收益+OCI转出 |
| FVTOCI-权益 | 公允价值 | OCI（不转损益） | 不减值 | 不转损益 |
| FVTPL | 公允价值 | 当期损益 | 不减值 | 投资收益 |

**三阶段模型总结：**

| 阶段 | 信用风险 | ECL | 利息收入基数 |
|------|----------|-----|-------------|
| 1 | 未显著增加 | 12个月 | 账面余额 |
| 2 | 显著增加 | 整个存续期 | 账面余额 |
| 3 | 已减值 | 整个存续期 | 摊余成本（净额） |
