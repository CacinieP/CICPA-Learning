# 企业合并 —— 第一性原理教程

## 一、企业合并概述

### 1.1 界定

**企业合并**是将两个或两个以上单独的企业合并形成一个报告主体的交易或事项。

**判断标准：** 取得的业务是否构成"业务"——是否有投入、加工处理过程和产出。

### 1.2 方式

| 方式 | 说明 |
|------|------|
| 控股合并 | A公司取得B公司控制权，B公司仍存续（A+B集团） |
| 吸收合并 | A公司吸收B公司，B公司注销 |
| 新设合并 | A公司和B公司合并成立C公司，A、B均注销 |

### 1.3 类型

| 类型 | 定义 | 特点 |
|------|------|------|
| **同一控制下** | 参与合并的企业在合并前后均受同一方最终控制 | 非市场化交易，按账面价值 |
| **非同一控制下** | 参与合并的企业不受同一方最终控制 | 市场化交易，按公允价值 |

## 二、企业合并的会计处理

### 2.1 同一控制下企业合并

**核心原则：** 按被合并方在最终控制方合并财务报表中的**净资产账面价值**份额计量。

```
合并成本 = 被合并方在最终控制方合并报表中净资产账面价值 × 持股比例
         + 最终控制方此前收购时形成的商誉

差额处理：
  合并成本 > 支付对价账面价值 → 贷记资本公积
  合并成本 < 支付对价账面价值 → 借记资本公积，不足冲减留存收益
```

**合并日合并报表：**
- 视同合并后形成的报告主体自最终控制方开始实施控制时一直存在
- 比较报表需要重述

### 2.2 非同一控制下企业合并

**核心原则：** 按支付对价的**公允价值**计量。

**购买日确定：** 同时满足：
1. 企业合并合同或协议已获批准
2. 企业合并事项已获内部权力机构批准
3. 实际发生控制权转移
4. 支付大部分合并对价
5. 已实质上控制被购买方的财务和经营政策

**可辨认资产和负债：** 按购买日的**公允价值**计量。

**商誉或营业外收入：**
```
支付对价公允价值 > 取得的被购买方可辨认净资产公允价值份额 → 商誉
支付对价公允价值 < 取得的被购买方可辨认净资产公允价值份额 → 营业外收入（负商誉）
```

### 2.3 企业合并涉及的或有对价

**同一控制下：** 或有对价的公允价值不影响合并成本，后续变动计入当期损益。

**非同一控制下：**
- 或有对价构成金融资产/负债的 → 按公允价值计量，后续变动计入公允价值变动损益
- 或有对价构成权益的 → 后续变动不作调整

### 2.4 反向购买

**定义：** 法律上的母公司实际是被购买方，法律上的子公司实际是购买方。

**会计处理：**
- 法律上的子公司为会计上的购买方
- 合并成本 = 法律上的子公司发行权益性证券的公允价值
- 按权益性交换比例确定

---

## 考试要点总结

1. **同控 vs 非同控**：账面价值 vs 公允价值
2. **同控下的差额**：调整资本公积
3. **非同控下的商誉**：支付对价公允价值 - 可辨认净资产公允价值份额
4. **反向购买**：法律母公司是会计上的被购买方
5. **或有对价**：区分同控和非同控的不同处理
