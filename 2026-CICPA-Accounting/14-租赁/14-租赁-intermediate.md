# 租赁 —— 典型考题解析

## 一、核心考法分类

本章是新租赁准则的核心章节（能力等级3），主要考法包括：
1. **租赁的识别**（三要素判断）
2. **承租人的会计处理**（使用权资产+租赁负债）
3. **租赁期的确定**
4. **短期租赁和低价值资产租赁的豁免**
5. **出租人的会计处理**（融资租赁vs经营租赁）
6. **售后租回的判断与处理**

## 二、典型例题解析

### 2.1 租赁识别（单选题）

**题目：** 下列各项中，不属于租赁三要素的是（ ）。

A. 存在一项已识别资产
B. 资产供出租人使用
C. 承租人有权获得在资产使用期间产生的几乎全部经济利益
D. 承租人有权主导资产的使用方式和使用目的

**解析：** 租赁识别的三要素：
1. 存在已识别资产（明确指定或隐性指定）
2. 承租人有权获得在使用期间内因使用资产所产生的**几乎全部经济利益**
3. 承租人有权**主导资产的适用方式和使用目的**

选项B说的是资产供出租人使用，这是错误的。租赁是出租人将资产使用权让与承租人，因此资产应该是供**承租人**使用。

**答案：** B

### 2.2 租赁期确定（计算题）

**题目：** 甲公司于2×21年1月1日租入一台设备，租赁合同规定：
- 不可撤销期间：3年（2×21.1.1-2×23.12.31）
- 选择权1：续租2年（每年租金100万元），管理层合理确定会行使
- 选择权2：终止权1年（每年租金80万元），管理层合理确定不会行使

要求：计算该租赁的租赁期。

**解析：**

**租赁期计算公式：**
```
租赁期 = 不可撤销期间 + 合理确定会行使的续租选择权期间 - 合理确定不会行使的终止选择权期间
```

**本题计算：**
```
租赁期 = 3年 + 2年 - 1年 = 4年
```

**要点提示：**
- 续租选择权：管理层合理确定会行使 → 纳入租赁期
- 终止选择权：管理层合理确定不会行使 → 不纳入租赁期

**答案：** 租赁期为4年。

### 2.3 承租人初始计量（计算题）

**题目：** 乙公司2×21年1月1日租入一台设备，租赁合同主要条款如下：
- 租赁期：5年，每年年末支付租金200万元
- 租赁内含利率：6%
- 购买选择权：2×25.12.31可按500万元购买，管理层无法确定是否行使
- 初始直接费用：10万元
- 预计拆卸费用现值：30万元
- 出租人提供租赁激励：20万元

要求：
（1）计算租赁负债的初始确认金额
（2）计算使用权资产的初始确认金额
（3）编制相关会计分录

**解析：**

**第一步：计算租赁负债**
```
租赁付款额 = 200 × 5 = 1,000万元
租赁付款额现值 = 200 × (P/A,6%,5) = 200 × 4.2124 = 842.48万元
租赁负债 = 842.48万元
```

**第二步：计算使用权资产**
```
使用权资产 = 租赁负债 + 预付租金 + 初始直接费用 + 拆卸费用现值 - 租赁激励
           = 842.48 + 0 + 10 + 30 - 20
           = 862.48万元
```

**第三步：会计分录**
```
借：使用权资产                    862.48
    租赁负债——未确认融资费用      157.52
  贷：租赁负债——租赁付款额        1,000
      银行存款（初始直接费用）     10
      预计负债（拆卸费用）          30
      银行存款（租赁激励）         20
```

**答案：** 租赁负债842.48万元，使用权资产862.48万元。

### 2.4 承租人后续计量（计算题）

**题目：** 承接上题，假设乙公司采用成本模式对使用权资产进行后续计量，使用权资产按直线法在5年内折旧。计算2×21年度：
（1）使用权资产折旧金额
（2）租赁负债利息费用
（3）编制相关会计分录（假设租金于年末支付）

**解析：**

**（1）使用权资产折旧**
```
使用权资产折旧 = 862.48 ÷ 5 = 172.50万元
```

**（2）租赁负债利息（第一年末）**
```
期初租赁负债 = 842.48万元
利息 = 842.48 × 6% = 50.55万元
本金 = 200 - 50.55 = 149.45万元
期末租赁负债 = 842.48 - 149.45 = 693.03万元
```

**（3）会计分录**
```
借：使用权资产累计折旧             172.50
  贷：使用权资产累计折旧

借：租赁负债——利息               50.55
  贷：财务费用                     50.55

借：租赁负债——租赁付款额         200.00
  贷：银行存款                    200.00
```

**答案：** 折旧172.50万元，利息50.55万元。

### 2.5 出租人融资租赁判断（多选题）

**题目：** 下列各项中，应当认定为融资租赁的有（ ）。

A. 租赁期满，资产的所有权转移给承租人
B. 承租人有购买选择权，且购买价格低于行使日资产的公允价值
C. 租赁期占资产使用寿命的80%
D. 租赁收款额的现值几乎相当于资产的公允价值（95%）

**解析：** 融资租赁的判断标准（满足任一即可）：
1. 租赁期满所有权转移给承租人
2. 承租人有购买选择权且合理确定行使
3. 租赁期占资产使用寿命的大部分（≥75%）
4. 租赁收款额现值几乎相当于资产公允价值（≥90%）
5. 资产性质特殊，只有承租人才能使用

| 选项 | 分析 | 判断 |
|------|------|------|
| A | 所有权转移 | 融资租赁 |
| B | 购买价格低于公允价值→购买选择权+合理确定行使 | 融资租赁 |
| C | 80% ≥ 75% | 融资租赁 |
| D | 95% ≥ 90% | 融资租赁 |

**答案：** ACD

## 三、分录/计算模板

### 3.1 承租人初始确认

```
借：使用权资产
    租赁负债——未确认融资费用
  贷：租赁负债——租赁付款额
      预付账款（预付租金）
      银行存款（初始直接费用）
      预计负债（拆卸费用现值）
      其他应付款（租赁激励）
```

### 3.2 承租人后续计量

```
计提折旧：
借：管理费用/制造费用
  贷：使用权资产累计折旧

确认利息：
借：财务费用
  贷：租赁负债——未确认融资费用

支付租金：
借：租赁负债——租赁付款额
  贷：银行存款
```

### 3.3 出租人融资租赁初始确认

```
借：应收融资租赁款——租赁收款额
    贷：融资租赁资产（资产账面价值）
        资产处置损益（公允价值-账面价值，厂商出租人）
        应收融资租赁款——未实现融资收益
```

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|-------|------|---------|
| 承租人vs出租人 | 承租人不区分经营/融资租赁；出租人仍区分 | "承租不区分，出租要区分" |
| 短期租赁豁免 | 租赁期≤12个月，不确认使用权资产和租赁负债 | "12月以内可豁免" |
| 低价值租赁 | 单项全新资产价值较低（如≤5,000美元） | "低价值可豁免" |
| 租赁期确定 | 不可撤销期间+续租-终止选择权 | "续加终减" |
| 售后租回 | 判断是否构成销售→销售则按比例确认 | "售后租回看是否销售" |

## 五、速记口诀

**承租人租赁三步走：**
- 识别：已识别资产+经济利益+主导使用
- 计量：使用权资产=负债+预付+费用+拆卸-激励
- 后续：折旧直线法，利息用摊余

**租赁期确定口诀：**
- 不可撤销期间
- 合理确定续租→加
- 合理确定终止→减

**融资租赁五条件：**
- 所有权转移
- 购买选择权，合理确定行
- 租赁期间占寿命75%以上
- 现值达公允90%
- 性质特殊唯承租人能使用
