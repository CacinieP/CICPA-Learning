# 政府补助 —— 第一性原理教程

## 一、政府补助概述

### 1.1 定义

**政府补助**是指企业从政府无偿取得货币性资产或非货币性资产。

### 1.2 特征
1. 来源于政府的经济资源
2. **无偿性**（不附有对价）

### 1.3 分类

| 分类 | 定义 | 典型形式 |
|------|------|----------|
| 与资产相关 | 用于购建或以其他方式形成长期资产的补助 | 拨款购置设备 |
| 与收益相关 | 除与资产相关以外的政府补助 | 研发费用补贴、稳岗补贴 |

### 1.4 不属于政府补助的情形
- 直接减征、免征、增加计税抵扣额
- 增值税出口退税（属于退还事先缴纳的税款）
- 政府作为投资者投入的资本

## 二、政府补助的会计处理

### 2.1 两种会计处理方法

| 方法 | 处理 | 适用 |
|------|------|------|
| **总额法** | 确认为递延收益，分期计入损益 | 通常情况 |
| **净额法** | 冲减相关资产账面价值或相关费用 | 通常情况 |

### 2.2 与资产相关的政府补助

**总额法：**
```
收到时：借：银行存款，贷：递延收益
分期摊销：借：递延收益，贷：其他收益/营业外收入
```

**净额法：**
```
收到时：借：银行存款，贷：递延收益
购建资产时：借：递延收益，贷：固定资产（冲减资产价值）
```

### 2.3 与收益相关的政府补助

**用于补偿以后期间费用或损失的：**
```
收到时：借：银行存款，贷：递延收益
费用发生时：借：递延收益，贷：其他收益/管理费用（净额法冲减费用）
```

**用于补偿已发生费用或损失的：**
```
直接计入当期损益：借：银行存款，贷：其他收益/营业外收入
```

### 2.4 政府补助的退回

**基本原则：** 在相关资产或费用确认的期间内冲减相关收益。

**退回处理：**
1. 存在相关递延收益的 → 冲减递延收益账面余额
2. 超出递延收益部分 → 计入当期损益
3. 净额法下 → 调增相关资产账面价值或调增相关费用

### 2.5 特定业务的会计处理

**综合性项目政府补助：**
- 需要分解为与资产相关和与收益相关
- 无法区分的 → 整体归类为与收益相关

**政策性优惠贷款贴息：**
- 直接拨付给企业的 → 冲减借款费用
- 拨付给贷款银行、以优惠利率提供的 → 以实际收到的借款金额作为借款的入账价值

## 三、政府补助的列报

- 与日常活动相关的 → 计入"其他收益"或冲减相关成本费用
- 与日常活动无关的 → 计入"营业外收入"
- 在利润表中"其他收益"或"营业外收入"项目列示

---

## 考试要点总结

1. **无偿性**是政府补助的核心特征
2. **总额法 vs 净额法**：两种方法都允许，但一经确定不得随意变更
3. **与资产相关**：递延收益分期摊销或冲减资产
4. **与收益相关**：区分补偿以后期间 vs 已发生
5. **综合性项目**：无法区分的全部归为与收益相关
