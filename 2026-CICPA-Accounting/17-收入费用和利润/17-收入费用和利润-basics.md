# 收入、费用和利润 —— 第一性原理教程

## 一、收入

### 1.1 收入的定义与分类

**收入**是指企业在日常活动中形成的、会导致所有者权益增加的、与所有者投入资本无关的经济利益的总流入。

**分类：**
- 销售商品收入
- 提供劳务收入
- 让渡资产使用权收入

### 1.2 收入确认和计量（五步法模型）

**新收入准则（CAS 14）的核心框架：**

#### 第一步：识别与客户订立的合同
**合同存在的条件（同时满足）：**
1. 合同各方已批准且承诺将履行义务
2. 能识别各项履约义务
3. 能确定交易价格
4. 合同具有商业实质
5. 对价很可能收回

#### 第二步：识别单项履约义务
**判断标准：** 商品或服务是否可明确区分？
- 能单独区分（客户能从该商品/服务单独或与其他资源一起受益）
- 在合同层面可单独区分（转让承诺可与其他承诺单独识别）

#### 第三步：确定交易价格
**考虑因素：**
- 可变对价（折扣、返点、退款等）→ 估计方法：期望值或最可能发生金额
- 合同中存在的重大融资成分
- 非现金对价
- 应付客户对价

#### 第四步：将交易价格分摊至各单项履约义务
**分摊方法：** 按照各单项履约义务的**单独售价**比例分摊。

#### 第五步：履行履约义务时确认收入

| 时点 | 方式 | 判断标准 |
|------|------|----------|
| **某一时段** | 随时间确认 | 满足三个条件之一 |
| **某一时点** | 控制权转移时确认 | 不满足时段条件时 |

**时段确认的三个条件（满足任一）：**
1. 客户在企业履约的同时即取得并消耗经济利益
2. 客户能够控制在建的商品
3. 产出不具有替代用途且企业有权就已完成部分收取款项

**时段内收入计量方法：**
- 产出法（按实际完成进度）
- 投入法（按投入资源的进度）

### 1.3 合同成本

**合同取得成本：** 为取得合同发生的增量成本（如销售佣金），预期能够收回 → 资本化。

**合同履约成本：** 满足条件时资本化：
1. 与合同直接相关
2. 增加了企业未来履约的资源
3. 预期能够收回

**摊销和减值：** 采用与收入确认相同的基础进行摊销，账面价值超过预计可收回金额时计提减值。

### 1.4 特定交易的会计处理

| 交易类型 | 会计处理要点 |
|----------|-------------|
| 附有销售退回条款 | 按预期有权收取的对价确认收入，确认退货负债和退货资产 |
| 附有质量保证条款 | 服务性质保证→单独履约义务；保证性质保证→不单独确认 |
| 主要责任人与代理人 | 主要责任人→总额法；代理人→净额法（判断：控制权） |
| 附有客户额外购买选择权 | 构成重大权利→作为单独履约义务 |
| 授予知识产权许可 | 区分：某一时段 vs 某一时点 |
| 售后回购 | 回购价>原售价→融资交易；回购价≤原售价→租赁 |
| 预收款 | 合同负债，不含增值税部分确认 |
| 无需退回的初始费 | 与商品/服务相关→分摊；无关→在合同开始日确认为收入 |

## 二、费用

**费用**是指企业在日常活动中发生的、会导致所有者权益减少的、与向所有者分配利润无关的经济利益的总流出。

**费用分类：**
- 营业成本（主营业务成本、其他业务成本）
- 税金及附加
- 期间费用（销售费用、管理费用、财务费用）

---

## 三、利润

### 3.1 利润的构成

```
营业利润 = 营业收入 - 营业成本 - 税金及附加 - 销售费用 - 管理费用
          - 财务费用 - 信用减值损失 - 资产减值损失
          + 公允价值变动收益 + 投资收益 + 其他收益 + 资产处置收益

利润总额 = 营业利润 + 营业外收入 - 营业外支出

净利润 = 利润总额 - 所得税费用
```

### 3.2 综合收益

```
综合收益总额 = 净利润 + 其他综合收益税后净额
```

---

## 考试要点总结

1. **五步法**：识别合同→识别履约义务→确定交易价格→分摊→确认收入
2. **时段 vs 时点**：三个条件判断时段确认
3. **主要责任人 vs 代理人**：控制权判断
4. **特定交易**：重点关注售后回购、附退回条款的销售
5. **利润构成**：营业利润→利润总额→净利润→综合收益
