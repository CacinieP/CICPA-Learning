## 二、典型例题解析

### 2.1 某一时段内履行的履约义务

**题目：** 甲公司为乙公司提供一项定制软件开发服务，合同总价500万元，工期2年。甲公司按照实际发生的成本占预计总成本的比例确定履约进度。第1年发生成本180万元，预计总成本400万元。求第1年应确认的收入。

**解析：**
- 履约进度 = 180 / 400 = 45%
- 应确认收入 = 500 × 45% = 225万元
- 应结转成本 = 400 × 45% = 180万元

**答案：**
```
借：合同履约成本  180
  贷：原材料/应付职工薪酬等  180

借：合同结算——收入结转  225
  贷：主营业务收入  225

借：主营业务成本  180
  贷：合同履约成本  180
```

### 2.2 可变对价——期望值法与最可能发生金额法

**题目：** 甲公司销售产品，合同约定：如果产品在交付后6个月内未出现质量问题，甲公司可额外获得50万元奖金。根据历史经验，甲公司估计有70%的概率获得奖金，30%的概率不能获得。求交易价格。

**解析：**
- 采用最可能发生金额法（只有两种结果）
- 最可能发生金额 = 50万元（因为70% > 30%）
- 交易价格 = 基础对价 + 50万元
- 注意：确认的累计收入金额极可能不会发生重大转回

**答案：** 交易价格中应包含可变对价50万元（前提是满足"极可能不会发生重大转回"的限制条件）。

### 2.3 售后回购

**题目：** 甲公司向乙公司销售一批商品，售价300万元，成本200万元。合同约定1年后甲公司以330万元的价格回购该批商品。判断是否确认收入并作出会计处理。

**解析：**
- 回购价格 330 > 原售价 300，差额30万元视为融资利息
- 实质：甲公司以商品为担保进行融资，不确认收入

**答案：**
```
收到款项时：
借：银行存款  300
  贷：其他应付款  300

每月确认利息费用（直线法，12个月）：
借：财务费用  2.5（30/12）
  贷：其他应付款  2.5

回购时：
借：其他应付款  330
  贷：银行存款  330
```

### 2.4 主要责任人 vs 代理人

**题目：** 甲公司在其电商平台上销售商品，商品由供应商直接发货给消费者。甲公司按售价的15%收取佣金。商品售价100万元，甲公司收取15万元佣金。判断甲公司是主要责任人还是代理人。

**解析：**
- 判断指标：甲公司在转让商品前是否控制该商品
- 商品由供应商直接发货，甲公司不承担存货风险
- 甲公司无权决定商品价格（仅为佣金模式）
- 结论：甲公司为代理人

**答案：** 甲公司按净额法确认收入15万元（代理佣金），而非总额100万元。

### 2.5 附销售退回条件的销售

**题目：** 甲公司销售商品1000件，每件售价500元，成本300元。根据经验，预计退回率为5%。求销售时应确认的收入和预计负债。

**解析：**
- 确认收入 = 1000 × (1 - 5%) × 500 = 475,000元
- 预计退回部分不确认收入，确认为预计负债
- 预计负债 = 1000 × 5% × 500 = 25,000元
- 同时确认预计退回商品的成本恢复

**答案：**
```
借：银行存款/应收账款  500,000
  贷：主营业务收入  475,000
      预计负债——应付退货款  25,000

借：主营业务成本  285,000
    应收退货成本  15,000
  贷：库存商品  300,000
```

## 三、分录/计算模板

### 3.1 五步法收入确认模型

```
Step 1: 识别与客户订立的合同
Step 2: 识别合同中的单项履约义务
Step 3: 确定交易价格
Step 4: 将交易价格分摊至各单项履约义务
Step 5: 履行履约义务时确认收入
```

### 3.2 某一时段确认的三种情形

| 情形 | 判断标准 | 典型例子 |
|------|----------|----------|
| 1 | 客户同步取得并消耗利益 | 常规服务（保洁、咨询） |
| 2 | 客户控制履约过程中在建商品 | 在客户场地上建造 |
| 3 | 产出的商品无替代用途且有权收款 | 定制产品制造 |

### 3.3 合同资产 vs 应收账款

- **合同资产**：已履行义务但需等待其他条件满足才能收款（有时间+条件限制）
- **应收账款**：无条件收款权（只有时间流逝限制）

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|-------|------|----------|
| 合同资产 vs 应收账款 | 合同资产有条件限制，应收账款无条件 | "合同有条件，应收无条件" |
| 某一时段 vs 某一时点 | 某一时段满足三条件之一；不满足则某一时点 | "三个条件逐一试" |
| 主要责任 vs 代理人 | 控制商品为主要责任，否则为代理人 | "控制定总额，不控定净额" |
| 合同履约成本 vs 合同取得成本 | 履约成本是履行合同发生的；取得成本是为签订合同发生的（如销售佣金） | "取得签合同时，履约执行中" |
| 可变对价约束 vs 或有对价 | 可变对价是收入确认问题；或有对价是合并中的对价调整 | "收入看约束，合并看对价" |

## 五、速记口诀

- **"五步确认法"**：识合同 → 识别义务 → 定价格 → 分摊 → 确认
- **"时段三条件"**：同步消耗 / 客户控制 / 专用+有权收款
- **"售后回购看价格"**：回购价>售价=融资；回购价≤售价=租赁/待售
- **"总额净额看控制"**：控制商品=总额法，不控制=净额法
