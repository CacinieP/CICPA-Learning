# 无形资产 —— 典型考题解析

## 一、核心考法分类

本章在历年真题中主要考法集中于以下几类：

1. **研究与开发支出的资本化/费用化判断**（主观题高频考点）
2. **土地使用权的不同处理场景**（单选题、多选题）
3. **摊销的起止时间与固定资产折旧的对比**（单选题）
4. **使用寿命不确定的无形资产处理**（单选题、判断题）
5. **无形资产减值不得转回**（单选题、多选题）
6. **无形资产的处置（出售/出租/报废）**（计算分析题）

## 二、典型例题解析

### 2.1 研发支出资本化判断

**题目：**（多选题）甲公司2×23年发生以下研发支出：研究阶段支出200万元；开发阶段支出300万元，其中满足资本化条件的为180万元，不满足资本化条件的为120万元。另有一项研发项目无法区分研究阶段和开发阶段，支出50万元。下列表述正确的有（ ）。

A. 研究阶段支出200万元应计入管理费用
B. 开发阶段满足资本化条件的180万元应计入无形资产
C. 开发阶段不满足资本化条件的120万元应计入管理费用
D. 无法区分阶段的50万元应计入无形资产

**解析：** 本题考查研发支出的分类处理。

选项A：正确。研究阶段支出全部费用化，计入管理费用。
选项B：正确。开发阶段满足资本化五条件的支出资本化，计入无形资产。
选项C：正确。开发阶段不满足资本化条件的支出费用化，计入管理费用。
选项D：错误。无法区分研究阶段和开发阶段的支出，应当在发生时全部费用化，计入管理费用。

**答案：** ABC

### 2.2 土地使用权的处理

**题目：**（单选题）下列关于土地使用权会计处理的表述中，正确的是（ ）。

A. 房地产开发企业用于建造对外出售房屋的土地使用权应计入无形资产
B. 企业外购房屋及建筑物支付的价款无法在地上建筑物与土地使用权之间分配的，应全部确认为无形资产
C. 企业用于出租的土地使用权应转为投资性房地产
D. 自用土地使用权应计入所建造固定资产的成本

**解析：** 本题考查土地使用权在不同场景下的处理。

选项A：错误。房地产开发企业用于建造对外出售的房屋，土地使用权应计入所建造房屋的成本（存货），而非无形资产。
选项B：错误。确实无法分配的，应全部作为固定资产，而非无形资产。
选项C：正确。用于出租或资本增值的土地使用权，应转为投资性房地产。
选项D：错误。自用土地使用权应单独确认为无形资产，不计入固定资产成本。

**答案：** C

### 2.3 摊销时间对比

**题目：**（单选题）甲公司2×23年6月30日购入一项无形资产，价款600万元，预计使用5年。2×23年度该无形资产的摊销额为（ ）万元。

A. 60
B. 120
C. 30
D. 0

**解析：** 本题考查无形资产摊销的起止时间。

关键考点：无形资产"当月增加当月摊销，当月减少当月不再摊销"，与固定资产"当月增加下月折旧"不同。

购入时间6月30日 → 从6月开始摊销 → 2×23年摊销7个月（6月至12月）。

摊销额 = 600 ÷ 5 × 7/12 = 70万元。

但若题目假设7月1日购入（部分考题默认购入日即7月），则摊销6个月：600 ÷ 5 × 6/12 = 60万元。

**答案：** A（按7月1日购入，摊销6个月计算）

---

### 2.4 使用寿命不确定的无形资产

**题目：**（单选题）甲公司2×23年1月1日购入一项商标权，无法合理估计其使用寿命。2×23年末该商标权的公允价值为450万元，初始成本为500万元。下列处理正确的是（ ）。

A. 计提摊销100万元
B. 计提减值准备50万元
C. 不做任何处理
D. 计提摊销并计提减值

**解析：** 本题考查使用寿命不确定无形资产的特殊处理。

使用寿命不确定的无形资产：
- **不计提摊销**
- **每年末必须进行减值测试**

可收回金额 = 450万元（假设公允价值减处置费用净额为450）
账面价值 = 500万元
减值 = 500 - 450 = 50万元

**答案：** B

### 2.5 无形资产处置

**题目：**（计算分析题）甲公司2×23年将一项无形资产出售，该无形资产原值800万元，累计摊销200万元，未计提减值准备。出售价款650万元（不含增值税），增值税率6%。计算出售损益并写出会计分录。

**解析：**

账面价值 = 800 - 200 = 600万元
出售价款 = 650万元
增值税 = 650 × 6% = 39万元
资产处置损益 = 650 - 600 = 50万元

```
借：银行存款                 689
    累计摊销                 200
  贷：无形资产                 800
      应交税费——应交增值税（销项税额）  39
      资产处置损益              50
```

## 三、分录/计算/框架模板

### 研发支出处理模板

```
（1）发生时归集
借：研发支出——费用化支出 / 资本化支出
  贷：原材料 / 银行存款 / 应付职工薪酬

（2）期末结转费用化
借：管理费用
  贷：研发支出——费用化支出

（3）达到预定用途结转资本化
借：无形资产
  贍：研发支出——资本化支出
```

### 摊销模板

```
借：制造费用 / 管理费用 / 其他业务成本
  贷：累计摊销
```

### 减值模板

```
借：资产减值损失
  贷：无形资产减值准备
```

### 处置模板（出售）

```
借：银行存款
    累计摊销
    无形资产减值准备
  贍：无形资产
      应交税费——应交增值税（销项税额）
      资产处置损益 [差额]
```

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|--------|------|----------|
| 无形资产摊销 vs 固定资产折旧起止时间 | 无形资产当月增当月摊销；固定资产当月增下月折旧 | 无形"即时生效"，固定资产"延迟生效" |
| 研究阶段 vs 开发阶段 | 研究全部费用化；开发满足条件可资本化 | "探索"费用化、"成型"可资本化 |
| 土地使用权（自用）vs 土地使用权（房地产开发） | 自用→无形资产；房地产开发→计入房屋成本 | 自用独立，开发并入 |
| 使用寿命有限 vs 不确定 | 有限→摊销+减值测试（有迹象）；不确定→不摊销+每年减值测试 | "不确定"特殊：不摊但必测 |
| 无形资产减值 vs 存货减值 | 无形资产减值不可转回；存货减值可以转回 | "长资不转回，短资可转回" |
| 无法区分研究开发 vs 可区分 | 无法区分→全部费用化 | "分不清就全费" |

## 五、速记口诀

**研发五条件（资本化判断）：**
> 技术可行有意图，市场有用资源足，支出可靠可计量。

**摊销时间口诀：**
> 无形当月即摊销，固定资产下月始折旧。

**土地使用权口诀：**
> 自用→无形资产单独走，房地产开发→并入房屋成本走，出租增值→投资性房地产走。

**减值口诀：**
> 长期资产减值不转回，每年不确定必测试。
