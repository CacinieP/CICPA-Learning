# 无形资产 —— 综合实战

## 一、综合题解题框架

**无形资产综合题通常以三种形式出现：**
1. 以研发项目为主线，考查费用化/资本化的判断及后续摊销减值
2. 以土地使用权为核心，串联固定资产、投资性房地产、存货的分类
3. 以无形资产处置结合所得税、合并报表考查

**解题步骤：**

```
Step 1：识别无形资产的来源（外购/自研/投资者投入）
Step 2：判断初始计量方式（特别关注研发支出和土地使用权）
Step 3：确定后续计量模式（摊销方法+减值测试）
Step 4：处理特殊事项（使用寿命变更/模式转换/处置）
Step 5：验证报表列示的正确性
```

## 二、跨章联动图谱

本章与其他章节的关联考点：

> 🔗 跨章联动：
> - 无形资产摊销 ↔ 固定资产折旧（摊销起止时间不同）
> - 无形资产减值 ↔ 资产减值（CAS 8 资产减值不可转回）
> - 土地使用权 ↔ 投资性房地产（出租/增值用途转换）
> - 土地使用权 ↔ 存货（房地产开发企业建造房屋）
> - 研发支出 ↔ 税法（研发费用加计扣除）

> 🔗 跨科联动：
> - **会计无形资产 ↔ 税法（研发加计扣除）**：
>   - 会计上研发费用化支出计入管理费用
>   - 税法上研发费用享受100%加计扣除（2023年起）
>   - 会计资本化部分在摊销时享受加计扣除
>   - 产生可抵扣暂时性差异 → 确认递延所得税资产

## 三、陷阱与反套路

### 陷阱1：研发支出时间节点混淆

**常见考法：** 给出研发项目全过程支出，要求判断何时开始资本化。

**反套路：**
- 关键在于"开发阶段开始且满足五条件"的那一刻
- 部分考题故意模糊时间节点，需要仔细阅读题干中的措辞
- "开始研发""完成研究""进入开发"含义不同

### 陷阱2：土地使用权场景混淆

**常见考法：** 给出多种土地使用权使用场景，要求分类处理。

**反套路：**
- 自用→无形资产（单独摊销）
- 房地产开发企业建造出售房屋→计入房屋成本
- 企业外购房屋无法分配→全部固定资产
- 出租/增值→投资性房地产

### 陷阱3：摊销与折旧时间混淆

**常见考法：** 同一年度内购入固定资产和无形资产，计算当年折旧和摊销。

**反套路：**
- 固定资产：6月购入 → 7月开始折旧 → 当年折6个月
- 无形资产：6月购入 → 6月开始摊销 → 当年摊7个月
- 这是最常见的计算陷阱！

### 陷阱4：减值转回陷阱

**常见考法：** 无形资产减值后价值回升，是否可以转回减值准备？

**反套路：** CAS 8范围内的资产减值一经计提不得转回。只有存货、应收款项等可以转回。

## 四、真题变式推演

### 变式1：研发支出综合题

**情境：** 甲公司2×23年研发一项新技术，1-3月为研究阶段，支出150万元；4-9月为开发阶段，支出250万元，其中4月起满足资本化条件。7月1日达到预定用途，确认无形资产。该资产预计使用5年，直线法摊销。12月31日可收回金额为180万元。

**问题：**
1. 计算2×23年应费用化的研发支出金额
2. 计算无形资产初始确认金额
3. 计算2×23年摊销额
4. 判断是否需要计提减值并计算金额

**解析：**

问题1：费用化支出 = 研究阶段150万元 + 开发阶段不满足条件部分（4月前无法判断，假设3月后4月初开始满足）→ 研究阶段全部费用化150万元

问题2：资本化支出 = 开发阶段满足条件部分250万元 → 无形资产初始确认250万元

问题3：7月1日达到预定用途 → 从7月开始摊销
摊销额 = 250 ÷ 5 × 6/12 = 25万元

问题4：2×23年末账面价值 = 250 - 25 = 225万元
可收回金额 = 180万元
减值 = 225 - 180 = 45万元
计提减值后新账面价值 = 180万元

---

### 变式2：土地使用权综合题

**情境：** 甲公司为非房地产开发企业，2×23年发生以下业务：
- 1月：购入一块土地使用权用于自建办公楼，支付价款1,000万元，增值税90万元
- 3月：开始建造办公楼，建造支出2,000万元
- 9月：办公楼完工投入使用
- 12月：将另一块原自用土地使用权转为出租，账面价值600万元，公允价值750万元

**问题：**
1. 自建办公楼的土地使用权如何处理？
2. 出租土地使用权转换如何处理？

**解析：**

问题1：非房地产开发企业自建办公楼的土地使用权，单独确认为无形资产（1,000万元），与办公楼（固定资产2,000万元）分别摊销和折旧。

问题2：自用→出租，公允价值模式下转换：
- 公允价值750万元 > 账面价值600万元
- 贷方差额150万元计入**其他综合收益**

```
借：投资性房地产——成本     750
  贍：无形资产                 600
      其他综合收益              150
```

## 五、实务衔接

### 实务场景1：研发支出加计扣除的税会差异

**背景：** 某科技企业2×23年研发支出1,000万元，其中费用化300万元，资本化700万元（形成无形资产，摊销期10年）。

**分析：**
- 会计处理：费用化300万元计入管理费用；资本化700万元形成无形资产，每年摊销70万元
- 税务处理：费用化部分享受100%加计扣除 → 税前可扣除600万元；资本化部分摊销时享受100%加计扣除 → 每年税前可扣除140万元
- 税会差异：费用化部分产生可抵扣暂时性差异300万元；资本化部分产生可抵扣暂时性差异700万元（摊销期内逐步转回）
- 确认递延所得税资产

### 实务场景2：软件行业无形资产的实务认定

**背景：** 某软件公司开发的自主软件产品，研发阶段无法清晰划分。

**分析：** 实务中软件公司往往难以精确区分研究与开发阶段。根据准则规定，无法区分的支出应全部费用化。但在实务中，企业通常在技术方案确定后（即可行性论证通过后）作为开发阶段起点，这需要完善的内部审批记录支撑。

## 六、速记总结

**本章核心考点速记：**

```
研发分两段：研究全费、开发五条件可资
土地使用权：自用→无形、开发→房屋、出租→投资性
摊销时间：当月增当月摊（区别固定资产下月折）
使用寿命：有限→摊销+减值有迹象测；不确定→不摊+每年必测
减值：不可转回
处置三路：出售→资产处置损益、出租→其他业务收入/成本、报废→营业外支出
```

**考试高频陷阱：**
1. 摊销起止时间与固定资产折旧混淆
2. 土地使用权场景分类错误
3. 无法区分研究开发却错误资本化
4. 减值转回（CAS 8范围不可转回）
5. 集团内无形资产交易（合并报表抵销）
