# 存货 —— 综合实战

## 一、综合题解题框架

### Step 1：题目信息提取

| 信息项 | 提取内容 |
|--------|---------|
| 存货类型 | 原材料/在产品/库存商品 |
| 持有目的 | 直接出售/需加工 |
| 合同情况 | 有合同/无合同/混合 |
| 时间节点 | 资产负债表日前后的处理差异 |

### Step 2：可变现净值计算路径

```
┌─────────────────────────────────────────────────────────┐
│                    判断存货类型                          │
└─────────────────────────────────────────────────────────┘
                          ↓
          ┌───────────────┴───────────────┐
          ↓                               ↓
    【直接出售类】                  【需加工类】
    产成品、商品                    原材料、在产品
          ↓                               ↓
    估计售价 -                   先计算产成品
    销售费用和税费                可变现净值
                                    ↓
                          原材料可变现净值 =
                          产成品售价 - 完工成本 - 销售费用
```

### Step 3：跌价准备处理

```
账面价值 > 可变现净值？
     ↓是
计提跌价准备 = 成本 - 可变现净值 - 已有跌价准备

     ↓否
不计提（已有多计提的需转回）
转回金额 = min(已有余额, 成本 - 可变现净值)
```

## 二、跨章联动图谱

### 2.1 与资产减值的联动

> 存货跌价准备与资产减值损失的关系

| 特征 | 存货 | 固定资产/无形资产 |
|------|------|-----------------|
| 减值损失归属 | 资产减值损失 | 资产减值损失 |
| 能否转回 | 可以转回 | 不得转回 |
| 转回限制 | 不超过原已计提金额 | - |

### 2.2 与收入的联动

存货销售时，需结转相应的存货跌价准备：

```
借：主营业务成本（账面价值）
    存货跌价准备（已计提）
    贷：库存商品（成本）
```

### 2.3 与财务报表列报的联动

资产负债表中"存货"项目列示内容：
```
存货 = 原材料 + 在途物资 + 生产成本 + 库存商品
     + 发出商品 + 委托加工物资 + 周转材料
     - 存货跌价准备 - 材料成本差异（贷方）
```

## 三、陷阱与反套路

### 陷阱1：混淆"成本"与"可变现净值"的口径

**经典陷阱题：**
> 甲公司将100万元成本的可变现净值计算为120万元，直接确认资产减值损失为负数。

**识别方法：** 可变现净值永远不会超过成本，超过成本的部分是不合理的。

**反套路：** 检查计算结果是否符合逻辑——跌价准备 ≤ 成本

---

### 陷阱2：未区分有合同与无合同部分

**经典陷阱题：**
> 题目给出混合情况，但考生将两部分合并计算，导致可以互补的错误结论。

**识别方法：** 题目出现"部分有合同约定"或"一部分有合同"等表述时，必须分别计算。

**反套路：** 养成看到合同就要分别计算的习惯

---

### 陷阱3：原材料可变现净值计算错误

**经典陷阱题：**
> 直接用原材料成本与市场售价比较，而不考虑用于生产的产成品情况。

**识别方法：** 原材料的持有目的是加工，因此必须考虑加工后的产成品情况。

**反套路：** 先判断持有目的，再选择计算公式

---

### 陷阱4：跌价准备转回超过限额

**经典陷阱题：**
> 转回时计算出的金额超过原已计提金额。

**识别方法：** 转回后的跌价准备余额 = 成本 - 可变现净值，该值永远为正（成本 > 可变现净值）或零。

**反套路：** 转回后的余额不能为负

## 四、真题变式推演

### 变式1：混合情况下的综合计算

**原题原型：** 有合同与无合同分别计算跌价准备

**变式1：**
> 丙公司20×9年12月31日库存E商品200件，实际成本共计600万元。其中150件有合同约定，单位售价3.5万元，合同总价款525万元；另50件无合同，单位售价2.5万元。估计销售费用及相关税费为合同部分20万元、无合同部分10万元。
>
> 要求：计算E商品应计提的存货跌价准备金额。

**解题要点：**
- 合同部分成本 = 600 × (150/200) = 450（万元）
- 无合同部分成本 = 600 × (50/200) = 150（万元）

| 部分 | 成本 | 售价 | 销售费用 | 可变现净值 | 跌价准备 |
|------|------|------|---------|-----------|---------|
| 有合同 | 450 | 525 | 20 | 505 | 0 |
| 无合同 | 150 | 125 | 10 | 115 | 35 |
| **合计** | 600 | - | - | - | **35** |

---

### 变式2：跌价准备的计提与转回综合

**原题原型：** 存货跌价准备的计提与转回

**变式2：**
> 丁公司按单项计提存货跌价准备。20×8年12月31日，F商品成本100万元，可变现净值70万元，计提跌价准备30万元。20×9年6月30日，F商品可变现净值上升至95万元。20×9年12月31日，F商品可变现净值下降至85万元。
>
> 要求：
> （1）计算20×9年6月30日应转回的存货跌价准备
> （2）计算20×9年12月31日应计提的存货跌价准备

**解题要点：**

| 时间点 | 计算过程 | 结果 |
|--------|---------|------|
| 20×8年末 | 已计提跌价准备 | 30万元 |
| 20×9.6.30 | 应有跌价准备 = 100-95=5；可转回 = 30-5=25 | 转回25万元 |
| 20×9.12.31 | 应有跌价准备 = 100-85=15；应计提 = 15-5=10 | 计提10万元 |

---

### 变式3：存货清查与会计差错结合

**原题原型：** 存货清查盘点的会计处理

**变式3：**
> 戊公司在存货清查中发现盘亏G材料，账面成本40万元。20×9年12月31日发现并报批，原因为仓库管理员失职造成丢失，应由管理员赔偿50%。20×9年1月至12月该材料适用的增值税税率为13%。
>
> 要求：编制相关会计分录。

**解题要点：**
- 增值税进项税额转出 = 40 × 13% = 5.2（万元）
- 待处理财产损溢 = 40 + 5.2 = 45.2（万元）
- 其他应收款 = 45.2 × 50% = 22.6（万元）
- 管理费用 = 45.2 × 50% = 22.6（万元）

## 五、实务衔接

### 5.1 存货期末计量的职业判断

在实务中，可变现净值的确定涉及大量职业判断：

| 项目 | 实务中的判断要点 |
|------|----------------|
| 估计售价 | 最近期的销售价格、合同价格、市场报价 |
| 完工成本 | 历史成本、预期成本变化 |
| 销售费用 | 运费、装卸费、销售佣金等 |
| 数量考虑 | 陈旧过时、损坏、滞销等因素 |

### 5.2 存货成本流转假设

实务中常见的发出存货计价方法：
- **个别计价法**：适用于贵重物品（珠宝、汽车发动机）
- **先进先出法**：适用于易腐变质商品
- **月末一次加权平均法**：适用于价格稳定的大宗商品

### 5.3 存货管理的信息系统

现代企业使用ERP系统管理存货，常见的存货计价方法自动计算：
- SAP的移动平均价
- 用友的成本计价法
- Oracle的成本管理模块

## 六、速记总结

### 核心公式速记

```
┌────────────────────────────────────────────────────────────┐
│  可变现净值（直接出售）= 估计售价 - 销售费用和相关税费        │
│  可变现净值（需加工）  = 产成品售价 - 完工成本 - 销售费用   │
│  跌价准备 = 成本 - 可变现净值 - 已有跌价准备（负数则转回）   │
└────────────────────────────────────────────────────────────┘
```

### 分录速记

```
【计提】借：资产减值损失
          贷：存货跌价准备

【转回】借：存货跌价准备
          贷：资产减值损失

【结转】借：存货跌价准备
          贷：主营业务成本
```

### 考试注意事项

1. **看清题目问法**：是"计提"还是"转回"，是"当期应计提"还是"存货跌价准备余额"
2. **区分存货类型**：直接出售 vs 需加工，计算公式不同
3. **分别计算原则**：有合同与无合同必须分别计算
4. **转回有限额**：转回后余额不能为负
5. **增值税进项转出**：管理不善要转出，自然灾害不转出
