# 02-存货：第一性原理教程

## 一、存货的本质认知

**第一性原理思考**：存货是什么？

存货是企业为了**出售**（商品）或**消耗**（原材料）而持有的资产。它连接着"买入"和"卖出"两个环节，是企业经营循环中处于"加工中"的资源。存货管理的核心问题是：**花了多少钱买入（计量）、何时卖出（发出计量）、还值多少钱（期末计量）**。

---

## 二、确认和初始计量

### 2.1 存货的确认条件

存货必须在同时满足以下两个条件时才能确认：
1. 与该存货有关的经济利益**很可能**流入企业
2. 该存货的成本能够**可靠地计量**

### 2.2 存货的初始计量

**核心原则**：存货应当按照**成本**进行初始计量。

存货成本 = 采购成本 + 加工成本 + 其他成本（使存货达到目前场所和状态所发生的其他支出）

#### （1）采购成本

采购成本包括：
- **购买价款**（扣除商业折扣，不扣除现金折扣）
- **相关税费**：关税、不可抵扣的税费等
- **运输费**、装卸费、保险费
- **其他可归属于存货采购成本的费用**

> **关键区分**：现金折扣采用总价法核算，实际获得时冲减财务费用，不影响存货成本。

**不应计入存货成本的费用**：
- 采购人员的差旅费 → 计入当期损益（管理费用）
- 入库后的仓储费 → 计入当期损益（管理费用）
- 非正常消耗（自然灾害、管理不善） → 计入当期损益（营业外支出）
- 一般纳税人可抵扣的增值税进项税额 → 不计入成本

#### （2）加工成本

加工成本 = 直接人工 + 按照一定方法分配的制造费用

#### （3）其他成本

例如：为特定客户设计产品所发生的设计费用

#### （4）特殊情形

| 情形 | 处理 |
|------|------|
| 非正常消耗的直接材料、人工和其他费用 | 计入当期损益 |
| 仓储费用（入库后） | 计入当期损益 |
| 不能归属于存货达到目前场所和状态的费用 | 计入当期损益 |
| 借款费用（符合资本化条件的） | 计入存货成本 |

## 三、发出存货的计量

### 3.1 发出存货的计价方法

企业可以采用的方法：
1. **先进先出法**（FIFO）
2. **月末一次加权平均法**
3. **移动加权平均法**
4. **个别计价法**

> 注意：**后进先出法（LIFO）已被取消**，不允许使用。

#### 月末一次加权平均法

> **公式**：加权平均单位成本 =（月初存货实际成本 + 本月收入存货实际成本）/（月初存货数量 + 本月收入存货数量）

#### 移动加权平均法

> **公式**：移动加权平均单位成本 =（原有存货实际成本 + 本次收入存货实际成本）/（原有存货数量 + 本次收入存货数量）

每次进货后都要重新计算单位成本。

### 3.2 发出存货的会计处理

| 情形 | 借方科目 | 贷方科目 |
|------|---------|---------|
| 生产经营领用 | 生产成本/制造费用/管理费用等 | 原材料 |
| 对外销售 | 主营业务成本 | 库存商品 |
| 在建工程领用 | 在建工程 | 原材料/库存商品 |

## 四、期末存货计量（核心考点）

### 4.1 核心原则

**第一性原理**：存货的价值不应超过它能带来的经济利益。

> **期末计量原则**：资产负债表日，存货应当按照**成本与可变现净值孰低**计量。

- 成本 < 可变现净值 → 按成本计量（不调整）
- 成本 > 可变现净值 → 按可变现净值计量，差额计提存货跌价准备

### 4.2 可变现净值的确定

> **公式**：可变现净值 = 估计售价 - 估计完工成本 - 估计销售费用和相关税费

#### 确定可变现净值的关键：

**（1）区分存货的持有目的**：

| 持有目的 | 可变现净值的确定 |
|---------|----------------|
| 直接用于出售的存货（商品、产成品） | 估计售价 - 估计销售费用和相关税费 |
| 需要经过加工的存货（原材料） | 产成品估计售价 - 至完工估计将要发生的成本 - 估计销售费用和相关税费 |

**（2）估计售价的确定**：
- 有合同约定 → 按**合同价格**
- 无合同约定 → 按**一般市场销售价格**
- 部分有合同、部分无合同 → **分别确定**

> **重要原则**：有合同部分和无合同部分应当**分别**确定可变现净值，分别计提跌价准备，不得相互弥补。

### 4.3 存货跌价准备的计提与转回

#### 计提

> **公式**：当期应计提的存货跌价准备 = 存货成本 - 可变现净值 - 已有跌价准备余额

会计处理：
```
借：资产减值损失
    贷：存货跌价准备
```

#### 转回

当以前减记存货价值的影响因素已经消失时，减记的金额应当予以恢复，并在原已计提的存货跌价准备金额内转回。

> **限制条件**：转回金额 ≤ 原已计提金额

会计处理：
```
借：存货跌价准备
    贷：资产减值损失
```

#### 结转

已售存货计提了存货跌价准备的，应结转相应的存货跌价准备。

```
借：存货跌价准备
    贷：主营业务成本/其他业务成本
```

**按单项或类别计提**：通常应当按照单个存货项目计提；对于数量繁多、单价较低的存货，可以按存货类别计提。

## 五、存货清查盘点

### 5.1 盘盈

```
借：原材料/库存商品
    贷：待处理财产损溢

经批准后：
借：待处理财产损溢
    贷：管理费用
```

### 5.2 盘亏

根据不同原因处理：

| 原因 | 处理 |
|------|------|
| 管理不善（收发计量差错、一般经营损失） | 管理费用 |
| 自然灾害等非常原因 | 营业外支出 |
| 应由过失人或保险公司赔偿 | 其他应收款 |

会计处理：
```
借：待处理财产损溢
    贷：原材料/库存商品
        应交税费——应交增值税（进项税额转出）[管理不善原因]

经批准后：
借：管理费用/营业外支出/其他应收款
    贷：待处理财产损溢
```

> **注意**：自然灾害导致的存货盘亏，增值税进项税额**不需要转出**。

## 六、存货的列示与披露

### 6.1 资产负债表中的列示

存货项目 = 原材料 + 在途物资 + 生产成本 + 库存商品 + 发出商品 + 委托加工物资 + 周转材料 - 存货跌价准备 - 材料成本差异（如为贷方余额）

### 6.2 披露要求

企业应当在附注中披露：
- 各类存货的期初和期末账面价值
- 确定发出存货成本所采用的方法
- 存货可变现净值的确定依据
- 存货跌价准备的计提方法、本期增减变动情况

---

## 考试要点总结

1. **存货初始计量**重点区分哪些费用计入成本、哪些计入当期损益
2. **可变现净值**的计算是主观题高频考点，注意区分"直接出售"和"需加工"两种情形
3. **有合同与无合同部分应分别处理**，这是重要考点
4. **存货跌价准备的转回**有上限限制（不超过原计提金额）
5. **存货盘亏**时增值税进项税额转出的条件（管理不善需要转出，自然灾害不需要）
6. 发出存货计价方法的应用计算是常见考点
