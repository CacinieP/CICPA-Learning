# 或有事项 —— 综合实战

## 一、综合题解题框架

### 1.1 标准解题步骤

```
第一步：识别或有事项
        ├─ 是否由过去事项形成？
        ├─ 结果是否不确定？
        └─ 是否由未来事项决定？

第二步：判断或有事项类型
        ├─ 或有负债
        ├─ 预计负债（需确认）
        └─ 或有资产

第三步：确认预计负债（如适用）
        ├─ 是否满足三个确认条件
        └─ 确定最佳估计数

第四步：计量与会计处理
        ├─ 计算预计负债金额
        └─ 考虑预期补偿

第五步：列报与披露
```

### 1.2 典型综合题模板

**题目框架：**
```
背景：企业涉及多起未决诉讼/担保/产品质量保证/亏损合同
要求：（1）判断各项是否属于或有事项及类型
      （2）计算应确认的预计负债金额
      （3）编制相关会计分录
      （4）说明报表列报与披露要求
```

## 三、陷阱与反套路

### 3.1 常见陷阱

| 陷阱类型 | 出题方式 | 应对方法 |
|----------|----------|----------|
| 混淆确认条件 | 将"可能"当作"很可能"确认 | 严格按概率区间判断 |
| 补偿抵销错误 | 错误地将补偿和预计负债抵销 | 补偿和预计负债必须分别确认 |
| 亏损合同处理顺序 | 直接确认预计负债，未先测试资产减值 | 必须先对标的资产计提减值 |
| 可能性判断 | 未区分"很可能"与"基本确定" | 基本确定才能确认资产 |
| 未决诉讼未决算 | 将判决金额直接确认 | 注意法院判决是否已生效 |

### 3.2 反套路要点

1. **五步法判断或有事项：**
   - 过去事项？→ 不确定？→ 未来事项决定？→ 区分类型 → 确认/披露

2. **概率区间四分法：**
   - <5%：极小可能（不披露）
   - 5%-50%：可能（披露不确认）
   - 50%-95%：很可能（确认预计负债）
   - >95%：基本确定（确认资产）

3. **亏损合同三步法：**
   - 判断是否亏损
   - 检查是否存在标的资产
   - 先减值，后确认预计负债

## 四、真题变式推演

### 变式一：多事项综合判断

**原题特征：** 单一或有事项的确认与计量

**变式扩展：**
```
背景：甲公司2×21年度发生如下经济业务：

（1）12月1日，甲公司因产品侵犯A公司专利权被起诉。甲公司法律顾问认为：
    - 很可能败诉
    - 最可能赔偿金额为500万元
    - 预计可从保险公司获得补偿200万元（基本确定）

（2）甲公司销售一批商品，合同价格800万元，预计履约成本900万元，
    标的资产成本为600万元，可变现净值550万元。

（3）12月20日，甲公司制定了一项正式重组计划：
    - 关闭一个事业部
    - 预计遣散费500万元
    - 留用人员培训费50万元
    - 市场推广费30万元
    重组计划已通过董事会批准并已通知相关员工。

（4）甲公司销售商品时提供两年质量保证，预计保修费用为销售收入的2%，
    本年度销售收入5,000万元，以前年度累计已确认预计负债800万元，
    本年度实际发生保修费用780万元。

要求：
（1）判断上述各项是否属于或有事项及类型
（2）计算应确认的预计负债金额
（3）编制相关会计分录
```

**解题要点：**
1. 诉讼：满足确认条件，确认预计负债500万元；基本确定补偿200万元确认资产
2. 亏损合同：先对标的资产计提减值50万元，再确认预计负债100万元（亏损250-减值50）
3. 重组义务：详细计划+已通告，确认预计负债500万元（不含培训费和推广费）
4. 质量保证：按销售收入2%计提=100万元，实际发生780万元，期末余额=800-780+100=120万元

### 变式二：或有事项+财务报表列报

```
背景：乙公司2×21年12月31日存在以下或有事项：

（1）为子公司提供债务担保，预计很可能需承担连带责任，
    金额范围300-500万元（各金额可能性相同）

（2）因环境污染被罚款200万元，预计上诉后有60%可能性胜诉

（3）销售商品产生产品质量保证义务，本年度计提预计负债150万元，
    实际发生120万元

要求：
（1）判断各项或有事项应确认/披露/不披露
（2）计算期末预计负债应有余额
（3）说明资产负债表中预计负债的列报位置
（4）说明附注中应披露的内容
```

### 变式三：或有事项+所得税

```
背景：丙公司2×21年度发生以下业务：

（1）因未决诉讼确认预计负债500万元（税务不认可，损失实际发生时才能扣除）

（2）计提产品质量保证预计负债300万元（税务要求实际发生时扣除）

（3）本期会计利润8,000万元，适用的所得税税率25%，假设无其他暂时性差异

要求：
（1）计算2×21年度应确认的递延所得税资产/负债
（2）计算2×21年度所得税费用
（3）编制相关会计分录
```

**关键点：** 预计负债产生可抵扣暂时性差异，应确认递延所得税资产。

## 五、实务衔接

### 5.1 或有事项在审计中的关注点

**审计程序：**
1. 函证银行、律师，获取法律意见书
2. 检查或有负债的完整性
3. 评估预计负债的最佳估计数是否合理
4. 检查担保合同、未决诉讼协议

**常见审计调整事项：**
- 未充分确认预计负债
- 预计负债计量不准确
- 遗漏应披露的或有负债

### 5.2 或有事项在企业管理中的应用

**诉讼管理：**
- 评估诉讼可能性（法律顾问意见）
- 确定最佳估计数（参考类似案件判决）
- 考虑预期补偿的可收回性

**合同风险管理：**
- 定期评估亏损合同的金额
- 及时计提预计负债
- 关注标的资产的减值情况

> ⚠️ **实务警示：** 企业应建立完善的或有事项管理制度，对未决诉讼、担保、产品质量保证等事项进行持续监控和定期评估。

## 六、速记总结

**或有事项确认三步走：**
```
第一步：是不是或有事项？（过去+不确定+未来决定）
第二步：确认还是披露？（很可能→确认；可能→披露；极小可能→不披露）
第三步：计量多少？（连续范围取中间；单一金额取最可能）
```

**预计负债计量规则：**
- 连续范围：取中间值
- 单一项目：取最可能金额
- 多个项目：加权平均

**亏损合同处理顺序：**
```
是否亏损 → 存在标的资产？ → 先计提减值 → 再确认预计负债
```

**跨章记忆：**
- 预计负债 → 负债（单独列示）
- 可抵扣暂时性差异 → 递延所得税资产
- 重组义务 → 预计负债（不含未来支出）
