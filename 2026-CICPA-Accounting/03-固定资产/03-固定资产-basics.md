# 03-固定资产：第一性原理教程

## 一、固定资产的本质认知

**第一性原理思考**：固定资产是什么？

固定资产是企业为了**长期使用**（而非出售）而持有的有形资产。它的价值在多个会计期间内逐步消耗，因此需要通过**折旧**将成本分摊到各期。核心逻辑：**一次性投入，分期消耗**。

---

## 二、确认和初始计量

### 2.1 确认条件

固定资产必须同时满足：
1. 与该固定资产有关的经济利益**很可能**流入企业
2. 该固定资产的成本能够**可靠地计量**

**固定资产的特征**：
- 为生产商品、提供劳务、出租或经营管理而持有
- 使用寿命超过一个会计年度
- 有形资产

### 2.2 初始计量

**核心原则**：固定资产应当按照**成本**进行初始计量。

#### （1）外购固定资产

> **公式**：外购固定资产成本 = 购买价款 + 相关税费 + 运输费 + 装卸费 + 安装费 + 专业人员服务费

**不应计入成本的费用**：员工培训费 → 计入当期损益

**分期付款购买**（具有融资性质）：
> 成本 = 购买价款的**现值**
> 实际支付总额与现值之间的差额 → 确认为**未确认融资费用**，在付款期内按实际利率法摊销

#### （2）自行建造固定资产

| 方式 | 核算要点 |
|------|---------|
| 自营方式 | 通过"在建工程"科目归集；工程物资不计入存货；完工后转入"固定资产" |
| 出包方式 | 通过"在建工程"科目归集；预付工程款通过"预付账款"核算 |

**自行建造固定资产的成本** = 工程物资成本 + 人工成本 + 符合资本化条件的借款费用 + 分摊的间接费用

**试运行销售的处理**（重要更新）：
- 试运行产出产品对外销售的，收入和成本分别确认
- 不再将试运行销售净收入冲减固定资产成本

#### （3）投资者投入

按照投资合同或协议约定的价值确定（不公允的除外）。

#### （4）存在弃置费用的固定资产

> 固定资产成本 = 建造实际成本 + 弃置费用的**现值**

弃置费用现值确认为预计负债，每期按实际利率确认利息费用：
```
借：财务费用
    贷：预计负债
```

## 三、后续计量（折旧与后续支出）

### 3.1 折旧

**第一性原理**：固定资产在使用过程中逐渐磨损消耗，其价值应在使用寿命内系统分摊——这就是折旧。

#### 折旧范围

- **应当计提折旧**：所有固定资产（除已提足折旧仍继续使用的、单独计价入账的土地外）
- **当月增加**：下月开始计提
- **当月减少**：当月照提折旧

> **注意**：未使用、不需用的固定资产也需计提折旧。

#### 折旧方法

**（1）年限平均法（直线法）**

> **公式**：年折旧额 =（原价 - 预计净残值）/ 预计使用年限

**（2）工作量法**

> **公式**：单位工作量折旧额 =（原价 - 预计净残值）/ 预计总工作量

**（3）双倍余额递减法**

> **公式**：年折旧额 = 期初固定资产账面净值 x（2/预计使用年限）

**注意**：最后两年改为**直线法**，考虑净残值。

**（4）年数总和法**

> **公式**：年折旧额 =（原价 - 预计净残值）x 尚可使用年限 / 年数总和

**示例**：某固定资产原值100万元，预计净残值5万元，使用年限5年。

| 年份 | 双倍余额递减法 | 年数总和法 |
|------|--------------|-----------|
| 第1年 | 100x2/5=40 | 95x5/15=31.67 |
| 第2年 | 60x2/5=24 | 95x4/15=25.33 |
| 第3年 | 36x2/5=14.4 | 95x3/15=19.00 |
| 第4年 | （21.6-5）/2=8.3 | 95x2/15=12.67 |
| 第5年 | 8.3 | 95x1/15=6.33 |

#### 折旧的会计处理

```
借：制造费用 / 管理费用 / 销售费用 / 在建工程
    贷：累计折旧
```

#### 折旧政策的变更

固定资产使用寿命、预计净残值和折旧方法的改变，应当作为**会计估计变更**处理。

### 3.2 后续支出

#### 资本化条件

固定资产的后续支出满足以下条件的应当**资本化**（计入固定资产成本）：
- 延长固定资产使用寿命
- 提高产品质量
- 降低成本
- 改善其他性能

**处理方式**：将固定资产账面价值转入在建工程，扣除被替换部分的账面价值，加上新支出。

> **关键公式**：被替换部分的账面价值 = 被替换部分原价 x（1 - 已累计折旧比例）

#### 费用化条件

不满足资本化条件的日常修理维护支出 → 计入当期损益（管理费用/销售费用等）

## 四、固定资产处置

### 4.1 终止确认的条件

固定资产满足以下条件之一的，应当予以终止确认：
1. 该固定资产处于**处置状态**
2. 该固定资产预期通过使用或处置**不能产生经济利益**

### 4.2 处置的账务处理

通过**"固定资产清理"**科目核算：

```
（1）转入清理
借：固定资产清理
    累计折旧
    固定资产减值准备
    贷：固定资产

（2）发生清理费用
借：固定资产清理
    贷：银行存款 / 应交税费等

（3）出售收入/残料
借：银行存款 / 原材料
    贷：固定资产清理
        应交税费——应交增值税（销项税额）

（4）保险赔偿
借：其他应收款
    贷：固定资产清理

（5）结转清理净损益
借：固定资产清理
    贷：资产处置损益 [正常出售、转让]

或
借：资产处置损益
    贷：固定资产清理
```

> **区分**：
> - 正常出售、转让 → **资产处置损益**
> - 报废、毁损 → **营业外收入/营业外支出**

### 4.3 固定资产清查

| 情形 | 处理 |
|------|------|
| 盘盈 | 按前期差错处理，通过"以前年度损益调整" |
| 盘亏 | 通过"待处理财产损溢"，最终计入"营业外支出" |

**盘盈的特殊处理**：
```
借：固定资产
    贷：以前年度损益调整
```
这是按照**重置成本**计量的。

---

## 考试要点总结

1. **初始计量**重点掌握各组成部分的归集（特别是弃置费用的现值处理）
2. **折旧方法**的计算是客观题和主观题的高频考点，特别是双倍余额递减法和年数总和法
3. **后续支出资本化vs费用化**的判断是常考点
4. **被替换部分的账面价值**计算公式务必掌握
5. **处置损益**的分类：正常出售→资产处置损益；报废→营业外收支
6. 盘盈按**前期差错**处理，这个点容易被忽略
