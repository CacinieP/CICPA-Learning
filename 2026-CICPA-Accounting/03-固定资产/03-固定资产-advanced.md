# 固定资产 —— 综合实战

## 一、综合题解题框架

### Step 1：判断题型

```
┌─────────────────────────────────────────────────────────┐
│                    固定资产解题路径                      │
└─────────────────────────────────────────────────────────┘
                          ↓
          ┌───────────────┼───────────────┐
          ↓               ↓               ↓
      【初始计量】    【后续计量】      【处置】
        - 外购        - 折旧计算      - 正常出售
        - 自行建造    - 资本化/费用化  - 报废毁损
        - 分期付款    - 更新改造      - 盘盈盘亏
```

### Step 2：折旧计算核心

```
【第一步】确定折旧范围
- 是否属于应计提折旧的固定资产？
- 当月增加/减少如何处理？

【第二步】选择折旧方法
- 年限平均法（直线法）
- 工作量法
- 双倍余额递减法
- 年数总和法

【第三步】计算年折旧额
- 注意双倍余额递减法最后两年的处理
- 注意年数总和法的公式
```

## 二、跨章联动图谱

### 2.1 与借款费用的联动

> 符合资本化条件的借款费用计入固定资产成本

**资本化条件：**
1. 资产支出已经发生
2. 借款费用已经发生
3. 为使资产达到预定用途所必要的购建活动已经开始

**资本化金额计算：**
```
资本化利息 = 累计资产支出加权平均数 × 资本化率
加权平均利息 = Σ(每笔资产支出金额 × 该支出在资产中所占时间/期间)
```

### 2.2 与资产减值的联动

> 固定资产减值损失一经确认不得转回

**减值后的折旧计算：**
- 减值后账面价值 = 账面价值 - 减值损失
- 未来折旧按新的账面价值计算

### 2.3 与所得税的联动

> 固定资产计税基础与账面价值的差异

**暂时性差异：**
- 折旧方法不同 → 产生应纳税暂时性差异或可抵扣暂时性差异
- 计提减值准备 → 产生可抵扣暂时性差异

## 三、陷阱与反套路

### 陷阱1：双倍余额递减法最后两年计算错误

**经典陷阱题：**
> 考生直接将倒数第二年的账面净值乘以40%计算最后两年折旧，导致折旧总额超过原值。

**识别方法：** 检查折旧总额是否等于原值减净残值

**正确方法：**
```
第(n-1)年折旧 = (账面净值 - 预计净残值) / 2
第n年折旧 = (账面净值 - 预计净残值) / 2
```

---

### 陷阱2：混淆资本化与费用化的边界

**经典陷阱题：**
> 将所有大修理支出都资本化，或将所有维修支出都费用化。

**识别方法：** 判断是否同时满足资本化条件（延长寿命/提高产能/降低成本/改善性能）

**反套路：** 记住"改良资本化，修理费用化"的口诀

---

### 陷阱3：被替换部分的账面价值计算错误

**经典陷阱题：**
> 直接用被替换部分的原价减去已计提折旧。

**正确方法：**
```
被替换部分账面价值 = 被替换部分原价 × (1 - 已计提折旧/原价)
                   = 被替换部分原价 - 被替换部分已计提折旧
                   = 200 × (1 - 80/200) = 120（万元）
```

---

### 陷阱4：忽视"当月增加下月折旧"原则

**经典陷阱题：**
> 对当月增加的固定资产也计提折旧。

**正确方法：**
- 当月增加 → 下月开始计提
- 当月减少 → 当月照提

## 四、真题变式推演

### 变式1：折旧方法综合计算

**原题原型：** 双倍余额递减法与年数总和法的计算

**变式1：**
> 丙公司20×9年6月20日购入一台设备，原值600万元，预计使用年限5年，预计净残值30万元。企业选择双倍余额递减法计提折旧。20×12年1月1日，企业将该设备出售，取得价款100万元。
>
> 要求：
> （1）计算20×9年应计提的折旧额
> （2）计算该设备的处置损益

**解题要点：**

| 项目 | 计算过程 | 结果 |
|------|---------|------|
| 20×9年折旧 | 600×2/5×6/12 | 120万元 |
| 20×10年折旧 | 480×2/5 | 192万元 |
| 20×11年折旧 | 288×2/5 | 115.2万元 |
| 20×12年出售时账面价值 | 600-120-192-115.2 | 172.8万元 |
| 处置损益 | 100-172.8 | -72.8万元（损失） |

---

### 变式2：自行建造固定资产与借款费用结合

**原题原型：** 自行建造固定资产成本的归集

**变式2：**
> 丁公司自行建造一栋办公楼，20×9年1月1日开始施工，20×9年12月31日完工。建造期间发生以下支出：
> - 工程物资200万元
> - 人工费用100万元
> - 符合资本化条件的专门借款利息30万元
> - 一般借款利息20万元（无专门借款部分占用）
> - 分摊间接费用10万元
>
> 专门借款金额500万元，年利率6%；一般借款金额300万元，年利率5%。
>
> 要求：计算该办公楼的入账价值。

**解题要点：**

| 项目 | 金额 | 说明 |
|------|------|------|
| 工程物资 | 200 | 直接计入成本 |
| 人工费用 | 100 | 直接计入成本 |
| 专门借款利息资本化 | 30 | 符合资本化条件 |
| 一般借款利息资本化 | 20 | 全部资本化（占用一般借款） |
| 分摊间接费用 | 10 | 直接计入成本 |
| **入账价值** | **360** | - |

---

### 变式3：更新改造与折旧综合

**原题原型：** 资本化后续支出的会计处理

**变式3：**
> 戊公司对一台设备进行更新改造。该设备原价500万元，已累计折旧300万元，已计提减值准备50万元。更新改造中替换了部分设备，被替换部分原价80万元，已计提折旧60万元。更新改造发生支出100万元。改造完成后，该设备尚可使用年限为5年，预计净残值为20万元。
>
> 要求：
> （1）计算被替换部分的账面价值
> （2）计算更新改造后固定资产的入账价值
> （3）计算更新改造后第一年的折旧额

**解题要点：**

| 项目 | 计算过程 | 结果 |
|------|---------|------|
| 被替换部分账面价值 | 80×(1-60/80) | 20万元 |
| 更新改造后入账价值 | (500-300-50)+100-20 | 230万元 |
| 第一年折旧 | (230-20)/5 | 42万元 |

## 五、实务衔接

### 5.1 固定资产折旧政策的选择

企业可根据以下因素选择折旧方法：

| 因素 | 直线法适用 | 加速法适用 |
|------|----------|----------|
| 经济实质 | 使用强度稳定 | 使用强度前期高 |
| 税收优惠 | 想要前期税前扣除 | 想要递延纳税 |
| 行业特点 | 房屋建筑物 | 机器设备、高科技设备 |

### 5.2 固定资产折旧与所得税

**税法规定：**
- 直线法：各类固定资产的最低折旧年限（房屋20年、机器设备10年等）
- 加速法：需经税务机关批准

**税会差异处理：**
- 会计折旧 > 税法折旧 → 产生可抵扣暂时性差异
- 会计折旧 < 税法折旧 → 产生应纳税暂时性差异

### 5.3 固定资产弃置费用

对于特殊行业（如核电站、油气井），存在弃置义务：

```
弃置费用现值 = Σ(预计未来各期弃置费用/ (1+折现率)^t
```

## 六、速记总结

### 折旧方法对比速记

```
┌─────────────────────────────────────────────────────────┐
│ 直线法：    折旧 =（原值-残值）/年限                      │
│ 工作量法：  单位工作量折旧 =（原值-残值）/总工作量          │
│ 双倍余额：  折旧 = 期初净值 × 2/年限（最后两年直线）         │
│ 年数总和：  折旧 =（原值-残值）× 尚可年限/年数总和          │
└─────────────────────────────────────────────────────────┘
```

### 会计处理速记

```
【购入】借：固定资产（现值）
            未确认融资费用
          贷：长期应付款

【折旧】借：制造费用/管理费用
          贷：累计折旧

【改造】借：在建工程
            累计折旧
          贷：固定资产
        借：在建工程
          贷：银行存款/原材料等

【出售】借：固定资产清理
          累计折旧
          贷：固定资产
        借：银行存款
          贷：固定资产清理
              应交税费
        借/贷：资产处置损益
          贷/借：固定资产清理
```
