# 资产减值 —— 典型考题解析

## 一、核心考法分类

1. **可收回金额的计量**（计算题高频考点）
2. **减值能否转回的判断**（单选题、多选题）
3. **资产组的认定及减值分摊**（综合题）
4. **商誉减值测试**（综合题高频考点）
5. **减值迹象的识别**（判断题）

## 二、典型例题解析

### 2.1 可收回金额的计算
**题目:** 甲公司一台设备账面价值800万元，公允价值减处置费用净额650万元，预计未来现金流量现值720万元。应确认减值损失多少万元？

**解析:** 可收回金额 = max(650, 720) = 720万元。 800 > 720, 减值损失 = 800 - 720 = 80万元。
**答案:** 80万元

### 2.2 减值能否转回
**题目:** （多选题）下列资产中，减值损失可以转回的有（ ）。
A. 存货  B. 固定资产  C. 应收账款  D. 无形资产  E. 商誉
**解析:** 存货(CAS 1)和应收账款(CAS 22)可以转回；固定资产、无形资产、商誉(CAS 8)不可转回。
**答案:** AC

### 2.3 资产组减值分摊
**题目:** 某资产组账面价值1,000万元（含商誉100万元），可收回金额700万元。资产组中A设备账面400万元、B设备账面500万元。分摊减值后各设备新账面价值？
**解析:** 减值总额300万元。 先冲减商誉100万元，剩余200万元按账面比例分摊：
- A分摊: 200×400/900 = 88.9万元 → 新账面311.1万元
- B分摊: 200×500/900 = 111.1万元 → 新账面388.9万元
分摊后单项资产账面不得低于max(公允净额,现金流量现值,0)

### 2.4 商誉减值测试（部分持股）
**题目:** 甲公司持有乙公司80%股权，合并成本1,200万元，享有可辨认净资产公允价值份额800万元，商誉400万元。乙公司全部商誉 = 400/80% = 500万元。资产组账面价值（含全部商誉）= 可辨认净资产1,000 + 500 = 1,500万元，可收回金额1,200万元。
**解析:** 减值300万元，先冲减商誉300万元（全部冲减商誉500万元中的300万元），母公司确认商誉减值 = 300×80% = 240万元。

## 三、分录/计算/框架模板

```
减值确认:
借：资产减值损失
  贷：固定资产减值准备/无形资产减值准备/商誉减值准备等

资产组减值分摊:
1. 确定减值总额 = 资产组账面 - 可收回金额
2. 先冲减商誉
3. 剩余按账面比例分摊
4. 单项资产不得低于三限（公允净额/现值/零）
```

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|-------|------|---------|
| 可收回金额 | max(公允净额, 现值) | 两个维度取高者 |
| 减值转回 | CAS 8范围不可转回；存货/应收可转回 | "长资不回,短资回" |
| 商誉测试 | 含全部商誉（含少数股东份额） | 全部商誉=母公司商誉/持股比例 |
| 茋销起止 | 无形资产当月摊销 | 无形"立即生效" |

## 五、速记口诀

> 可收回金额取最大，公允现值比一比；
> 减值不可转回记，商誉固定无形；
> 资产组先冲商誉后分摊，三限保底别忘掉。
