# 借款费用 —— 典型考题解析

## 一、核心考法分类

本章在历年真题中的主要考法包括：
1. **资本化条件的判断**（开始/暂停/停止）
2. **专门借款与一般借款利息的计算**
3. **借款费用的列报**

## 二、典型例题解析

### 2.1 资本化时点判断（单选题）

**题目：** 甲公司为建造一栋办公楼，于2×21年1月1日向银行借入专门借款5,000万元，借款年利率为6%。2×21年3月1日，甲公司以自有资金支付了工程款项2,000万元，同日开始施工建造。下列关于借款费用资本化开始的时点，正确的是（ ）。

A. 2×21年1月1日
B. 2×21年3月1日
C. 2×21年1月1日或3月1日均可
D. 三个条件同时满足后开始资本化

**解析：** 借款费用资本化需同时满足三个条件：
1. 资产支出已发生
2. 借款费用已发生
3. 购建活动已开始

本题中，1月1日虽然借款费用已发生，但资产支出（2,000万元）在3月1日才发生。因此，资本化开始时点应为3月1日。

**答案：** B

### 2.2 专门借款利息计算（计算题）

**题目：** 乙公司于2×21年1月1日开始建造一大型设备，当日取得专门借款10,000万元，年利率5%，期限3年。该公司于1月1日、4月1日、7月1日分别支付工程款3,000万元、3,000万元、2,000万元。借款闲置资金在支付工程款前存入银行，月利率0.2%。计算2×21年度应资本化的借款费用金额。

**解析：**

**第一步：计算实际利息**
```
专门借款实际利息 = 10,000 × 5% = 500万元
```

**第二步：计算闲置资金投资收益**
- 第1笔闲置：10,000万 × 0.2% × 3个月 = 60万元
- 第2笔闲置：7,000万 × 0.2% × 3个月 = 42万元
- 第3笔闲置：4,000万 × 0.2% × 6个月 = 48万元
- 合计投资收益 = 60 + 42 + 48 = 150万元

**第三步：计算资本化金额**
```
资本化金额 = 500 - 150 = 350万元
```

**答案：** 应资本化的借款费用为350万元。

### 2.3 一般借款利息计算（计算题）

**题目：** 丙公司2×21年度为建造一栋厂房发生如下经济业务：
- 专门借款：2×21年1月1日取得6,000万元，年利率6%，当日全部用于支付工程款
- 一般借款：2×21年1月1日取得4,000万元，年利率8%；7月1日取得2,000万元，年利率7%
- 工程累计支出：3月1日支付4,000万元，8月1日支付3,000万元

计算2×21年度应资本化的借款费用（假设工程于12月31日完工）。

**解析：**

**第一步：计算专门借款利息**
```
专门借款利息 = 6,000 × 6% = 360万元
闲置资金无收益，资本化金额 = 360万元
```

**第二步：计算一般借款资本化部分**
- 累计支出加权平均数：
  - 3月1日-12月31日（10个月）：4,000 × 10/12 = 3,333.33万元
  - 8月1日-12月31日（5个月）：3,000 × 5/12 = 1,250万元
  - 合计 = 4,583.33万元

- 超过专门借款的支出：4,583.33 - 6,000 = 0（未超过）

- 一般借款资本化金额 = 0 × 一般借款资本化率 = 0

**第三步：计算费用化一般借款利息**
```
一般借款利息费用 = 4,000 × 8% + 2,000 × 7% × 6/12 = 320 + 70 = 390万元
```

**答案：** 资本化借款费用合计 = 360 + 0 = 360万元

### 2.4 暂停资本化条件（多选题）

**题目：** 下列情形中，应当暂停借款费用资本化的有（ ）。

A. 由于劳动纠纷，连续中断4个月的购建活动
B. 由于发生安全事故，连续中断3个月的购建活动
C. 北方某建筑企业因雨季到来，连续中断2个月的购建活动
D. 由于资金周转困难，连续中断5个月的购建活动

**解析：** 暂停资本化需同时满足两个条件：
1. 非正常中断
2. 中断时间连续超过3个月

| 选项 | 情形 | 判断 |
|------|------|------|
| A | 劳动纠纷，属于非正常中断，4个月>3个月 | 暂停 |
| B | 安全事故，属于非正常中断，3个月=3个月（未超过） | 不暂停 |
| C | 雨季属于正常中断，不暂停资本化 | 不暂停 |
| D | 资金周转困难，属于非正常中断，5个月>3个月 | 暂停 |

**答案：** AD

### 2.5 停止资本化时点（单选题）

**题目：** 下列各项中，应停止借款费用资本化的条件是（ ）。

A. 资产的实体建造工作已全部完成
B. 资产已达到预定可使用状态，但尚未办理竣工决算
C. 与设计要求基本相符，但尚有部分细节需要完善
D. 继续发生在资产上的支出金额很少

**解析：** 停止资本化的时点是"资产达到预定可使用或可销售状态"，判断标志：
1. 实体建造已完成
2. 与设计要求基本相符
3. **继续支出很少或几乎不再发生**

选项C表明与设计要求基本相符，但需注意停止资本化的核心是"是否达到预定可使用状态"，而非"完全竣工"。

**答案：** C

## 三、分录/计算模板

### 3.1 专门借款利息资本化分录

```
借：在建工程                    （资本化金额）
    应收利息/银行存款            （闲置资金收益）
  贷：应付利息                   （实际利息）
```

### 3.2 一般借款利息资本化分录

```
借：在建工程                    （资本化金额）
    财务费用                     （费用化金额）
  贷：应付利息                   （实际利息）
```

### 3.3 辅助费用资本化分录

```
借：在建工程                    （资本化期间发生的辅助费用）
    财务费用                     （非资本化期间发生的辅助费用）
  贷：银行存款
```

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|-------|------|---------|
| 专门借款 vs 一般借款资本化 | 专门借款不与支出挂钩；一般借款必须与支出挂钩 | "专不用挂，一要挂钩" |
| 正常中断 vs 非正常中断 | 正常中断不暂停资本化；非正常中断>3个月暂停 | "天灾人祸要分清" |
| 资本化期间 vs 费用化期间 | 资本化期间利息资本化；非资本化期间利息费用化 | "开始→暂停/停止→结束" |
| 闲置资金收益 | 专门借款的闲置资金收益冲减资本化金额 | "专借收益要扣除" |

## 五、速记口诀

**借款费用资本化三步走：**
- 开始资本化：支出发生、借款到位、动工建造
- 暂停资本化：非正常中断、超过三个月
- 停止资本化：达到预定可使用状态

**专门借款计算公式：**
- 资本化金额 = 实际利息 - 闲置收益
- 不与支出挂钩，直接计算

**一般借款计算公式：**
- 资本化金额 = 累计支出超专门借款部分 × 资本化率
- 必须与支出挂钩
