# 所得税 —— 典型考题解析

| 考法 | 题型 | 频率 |
|------|------|------|

## 二、典型例题解析

### 2.1 资产计税基础的计算

**题目：** 甲公司2026年12月31日应收账款账面余额200万元，已计提坏账准备20万元。税法规定坏账准备在实际发生时方可扣除。求应收账款的计税基础及暂时性差异。

**解析：**
- 账面价值 = 200 - 20 = 180万元
- 计税基础 = 200万元（税法不认可坏账准备的扣除）
- 可抵扣暂时性差异 = 200 - 180 = 20万元

**答案：**
- 计税基础 = 200万元
- 可抵扣暂时性差异 = 20万元
- 确认递延所得税资产 = 20 × 25% = 5万元

### 2.2 负债计税基础的计算

**题目：** 甲公司2026年因产品质量保证计提预计负债50万元，税法规定在实际发生保修费用时方可扣除。求预计负债的计税基础及暂时性差异。

**解析：**
- 账面价值 = 50万元
- 计税基础 = 50 - 50 = 0万元（未来可全额扣除）
- 可抵扣暂时性差异 = 50 - 0 = 50万元

**答案：**
- 计税基础 = 0万元
- 可抵扣暂时性差异 = 50万元
- 确认递延所得税资产 = 50 × 25% = 12.5万元

### 2.3 应纳税暂时性差异与递延所得税负债

**题目：** 甲公司一项交易性金融资产成本100万元，年末公允价值130万元。税法以成本计量。求暂时性差异和递延所得税。

**解析：**
- 账面价值 = 130万元（公允价值）
- 计税基础 = 100万元（税法按成本）
- 应纳税暂时性差异 = 130 - 100 = 30万元
- 递延所得税负债 = 30 × 25% = 7.5万元

**答案：**
```
借：所得税费用  7.5
  贷：递延所得税负债  7.5
```

### 2.4 所得税费用的完整计算

**题目：** 甲公司2026年利润总额500万元，当期所得税180万元。年初递延所得税资产15万元，递延所得税负债10万元。年末新增可抵扣暂时性差异40万元，新增应纳税暂时性差异20万元（税率25%）。计算所得税费用。

**解析：**
- 递延所得税资产期末 = 15 + 40 × 25% = 25万元
- 递延所得税负债期末 = 10 + 20 × 25% = 15万元
- 递延所得税费用 = (15 - 10) - (25 - 15) = 5 - 10 = -5万元
  即递延所得税收益5万元
- 所得税费用 = 当期所得税 + 递延所得税费用 = 180 - 5 = 175万元

**答案：**
```
借：所得税费用——当期所得税  180
  贷：应交税费——应交所得税  180

借：递延所得税资产  10
  贷：所得税费用——递延所得税  10

借：所得税费用——递延所得税  5
  贷：递延所得税负债  5
```
净利润 = 500 - 175 = 325万元

### 2.5 不确认递延所得税的特殊情形

**题目：** 甲公司发生研发支出200万元（符合加计扣除条件，税法允许按175%扣除）。求是否确认递延所得税资产。

**解析：**
- 加计扣除部分（75万元）不是暂时性差异，而是永久性差异
- 永久性差异不产生递延所得税

**答案：** 不确认递延所得税资产。加计扣除产生的75万元属于永久性差异，当期直接调减应纳税所得额。

## 三、计算模板

### 3.1 所得税会计处理三步骤

```
Step 1: 确定资产/负债的账面价值和计税基础
Step 2: 计算暂时性差异 → 判断类型
  - 账面 > 计税 → 应纳税暂时性差异 → 递延所得税负债
  - 账面 < 计税 → 可抵扣暂时性差异 → 递延所得税资产
Step 3: 计算所得税费用
  所得税费用 = 当期所得税 + 递延所得税
  当期所得税 = 应纳税所得额 × 税率
  递延所得税 = (期末递延负债 - 期初递延负债) - (期末递延资产 - 期初递延资产)
```

### 3.2 不确认递延所得税的情形

| 情形 | 原因 |
|------|------|
| 商誉初始确认 | 不是产生于企业合并，且既不影响会计利润也不影响应纳税所得额 |
| 非企业合并产生的无形资产（内部研发） | 初始确认既不影响利润也不影响应税所得 |
| 长期股权投资（准备长期持有） | 被投资方不分红则不产生纳税义务 |

## 四、易混点对比

| 易混点 | 区别 | 记忆技巧 |
|-------|------|----------|
| 应纳税 vs 可抵扣暂时性差异 | 应纳税：账面>计税（将来多交税）；可抵扣：账面<计税（将来少交税） | "账大交多=应纳税，账小交少=可抵扣" |
| 递延所得税资产确认条件 | 需有足够未来应纳税所得额可供抵扣 | "有利润才确认DTA" |
| 暂时性差异 vs 永久性差异 | 暂时性差异会转回；永久性差异不会转回 | "暂回永不回" |
| 当期所得税 vs 所得税费用 | 当期=应交税金；费用=当期+递延 | "当期是交税，费用包含递延" |
| 递延所得税资产减值 | 未来无足够利润→减值；利润恢复→转回 | "利润不够DTA减，利润恢复DTA增" |

## 五、速记口诀

- **"账大应纳，账小可抵"**：账面价值大于计税基础→应纳税暂时性差异；反之→可抵扣
- **"递延三不认"**：商誉/内部研发初始/准备长期持有的长投→不确认递延所得税
- **"费用=当期+递延"**：所得税费用 = 当期所得税 + 递延所得税费用
- **"永久差异不递延"**：永久性差异只影响当期，不产生递延
